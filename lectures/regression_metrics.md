# Метрики регрессии

<!-- время: 12 мин -->

> **О чём лекция.** Как измерить качество модели, предсказывающей числа: что показывают MAE, MSE, RMSE, R² и MAPE, чем они отличаются и как выбрать метрику, которая отвечает на вопрос бизнеса.

## Зачем это нужно

Модель регрессии предсказывает число, и почти всегда ошибается — вопрос лишь насколько. Метрика превращает тысячи ошибок в одно число, по которому сравнивают модели, подбирают гиперпараметры и решают, готова ли модель к запуску.

Разные метрики по-разному «наказывают» ошибки. Одна модель может быть лучше по MAE и хуже по RMSE. Поэтому выбор метрики — не техническая мелочь, а решение о том, какие ошибки для задачи страшнее.

## Интуиция: одна большая ошибка или много маленьких

Представьте две модели прогноза спроса. Первая всегда ошибается на 10 единиц. Вторая почти всегда точна, но один раз ошиблась на 50. Какая лучше?

- Если важна **средняя** ошибка, и каждая лишняя единица стоит одинаково, — они почти равны.
- Если **большие промахи** особенно опасны (пустой склад в праздник), — первая лучше.
- Если важна **относительная** ошибка в процентах — ответ зависит от того, на каком объекте был промах.

Каждому из этих взглядов соответствует своя метрика.

## Как это работает

### MAE — средняя абсолютная ошибка

```
MAE = (1/n) · Σ |yᵢ − ŷᵢ|
```

Средний размер ошибки в единицах целевой переменной: «в среднем ошибаемся на 1.2 тыс. рублей». Все ошибки весят пропорционально своему размеру, поэтому метрика устойчива к выбросам. Минимизирующий MAE константный прогноз — медиана.

### MSE и RMSE

```
MSE  = (1/n) · Σ (yᵢ − ŷᵢ)²
RMSE = √MSE
```

Квадрат сильно усиливает большие ошибки: ошибка 10 даёт вклад 100, ошибка 50 — уже 2500. MSE измеряется в квадратных единицах (рубли²), поэтому для отчёта используют RMSE — он снова в единицах цели. Всегда `RMSE ≥ MAE`; чем больше разрыв, тем неравномернее ошибки — значит, есть крупные промахи. MSE — стандартная функция потерь при обучении: она гладкая и хорошо оптимизируется. Минимизирующая константа — среднее.

### R² — коэффициент детерминации

```
R² = 1 − Σ(yᵢ − ŷᵢ)² / Σ(yᵢ − ȳ)²
```

Сравнивает модель с простейшим прогнозом — средним значением цели ȳ:

- `R² = 1` — идеальные прогнозы;
- `R² = 0` — не лучше, чем всегда предсказывать среднее;
- `R² < 0` — хуже среднего: такое бывает на тесте у плохой модели.

R² безразмерен, поэтому удобен для сравнения на разных задачах. Но он зависит от разброса цели в выборке: та же модель на более однородных данных получит меньший R². На обучающей выборке R² линейной регрессии никогда не падает при добавлении признаков — даже случайных, поэтому для сравнения моделей с разным числом признаков используют скорректированный R² или, лучше, R² на тесте.

### MAPE — средняя абсолютная процентная ошибка

```
MAPE = (100% / n) · Σ |yᵢ − ŷᵢ| / |yᵢ|
```

Ошибка в процентах от истинного значения: «ошибаемся в среднем на 8%». Понятна бизнесу и сравнима для объектов разного масштаба. Недостатки серьёзные: не определена при `y = 0` и взрывается при значениях около нуля, асимметрична (занижение прогноза наказывается не больше чем на 100%, а завышение — неограниченно). Альтернативы — sMAPE и WAPE (сумма абсолютных ошибок, делённая на сумму фактов).

### Как выбрать

| ситуация | метрика |
|---|---|
| все ошибки одинаково важны, есть выбросы | MAE |
| большие ошибки особенно опасны | RMSE |
| нужно сравнить с «наивным» прогнозом, отчёт без единиц | R² |
| важна относительная ошибка, значения далеки от нуля | MAPE или WAPE |
| цель охватывает порядки величин (цены от тысяч до миллионов) | RMSLE или ошибка на логарифме цели |

## Пример на Python

Две модели из интуиции: A ошибается на 10 везде, B — точна, кроме одного промаха на 50.

```python
import numpy as np
from sklearn.metrics import (mean_absolute_error, mean_absolute_percentage_error,
                             mean_squared_error, r2_score)

y_true = np.array([100, 150, 200, 250, 300])
pred_a = np.array([110, 140, 210, 240, 310])   # ошибается на 10 везде
pred_b = np.array([100, 150, 200, 250, 350])   # точно, кроме одного промаха на 50

for name, p in [("A", pred_a), ("B", pred_b)]:
    mae = mean_absolute_error(y_true, p)
    rmse = np.sqrt(mean_squared_error(y_true, p))
    mape = mean_absolute_percentage_error(y_true, p) * 100   # sklearn возвращает долю
    print(f"{name}: MAE={mae:.1f}  RMSE={rmse:.1f}  MAPE={mape:.1f}%  R²={r2_score(y_true, p):.3f}")

# A: MAE=10.0  RMSE=10.0  MAPE=5.8%  R²=0.980
# B: MAE=10.0  RMSE=22.4  MAPE=3.3%  R²=0.900

print("R² прогноза средним:", r2_score(y_true, np.full(5, y_true.mean())))   # 0.0
print("R² плохой модели:", round(r2_score(y_true, y_true[::-1]), 3))         # -3.0
```

MAE у моделей одинаковый. RMSE и R² предпочитают A (нет крупных промахов), а MAPE — B (промах пришёлся на самое большое значение, где в процентах он невелик). Одна и та же пара моделей — три разных «победителя».

## Подводные камни

- **MAPE от sklearn — это доля**, а не проценты: 0.058 означает 5.8%.
- **MAPE при нулях** в цели бесполезна; используйте WAPE или MAE.
- **R² без контекста.** R² = 0.6 может быть отличным результатом для прогноза поведения людей и ужасным для физического процесса. Сравнивайте с baseline.
- **Метрика на train.** Почти любая метрика на обучающих данных оптимистична; смотрите на тест или кросс-валидацию.
- **Метрика обучения и бизнес-метрика различаются.** Модель обучается по MSE, но если бизнесу важна MAE, сравнивайте модели по MAE — или обучайте сразу с подходящей функцией потерь.
- **Асимметричные потери.** Если занижение прогноза спроса стоит дороже завышения, ни одна симметричная метрика это не отразит — нужна квантильная ошибка или своя функция стоимости.

## Итоги

- MAE — средняя ошибка в единицах цели, устойчива к выбросам.
- MSE/RMSE сильнее штрафуют большие ошибки; RMSE ≥ MAE, разрыв говорит о крупных промахах.
- R² сравнивает модель с прогнозом средним; может быть отрицательным.
- MAPE — понятные проценты, но ломается около нуля и асимметрична.
- Метрику выбирают по тому, какие ошибки дороже для задачи, и всегда считают на отложенных данных.
