# Diffusion модели

<!-- время: 18 мин -->

> **О чём лекция.** Как модели вроде Stable Diffusion рисуют картинки из чистого шума: сначала картинку постепенно зашумляют, а нейросеть учится шаг за шагом этот шум убирать. Разберём прямой и обратный процессы, простую функцию потерь DDPM, генерацию и classifier-free guidance.

## Зачем это нужно

Генеративные модели до диффузии имели заметные слабости: VAE дают размытые картинки, GAN нестабильны в обучении и страдают от mode collapse. Диффузионные модели (DDPM, Ho и соавторы, 2020) нашли третий путь: обучение у них простое и устойчивое (обычная регрессия с MSE), а качество и разнообразие образцов — лучшие. На них построены Stable Diffusion, DALL·E 2 и 3, Imagen, Midjourney, генерация видео, аудио и даже молекул.

Цена — скорость: картинка получается не за один проход сети, а за десятки или сотни шагов.

## Интуиция: капля чернил наоборот

Капните чернила в стакан воды — они постепенно расплываются, пока вода не станет равномерно мутной. Это **прямой процесс**: структура разрушается шумом, и в конце остаётся только шум. Он прост и не требует обучения.

Обратный процесс — собрать каплю из мутной воды — кажется невозможным. Но если каждый шаг маленький, то «отменить» его можно: глядя на чуть-чуть зашумлённую картинку, можно догадаться, какой шум добавили на последнем шаге. Нейросеть учат именно этому — предсказывать шум. А потом начинают с чистого шума и много раз подряд убирают его понемногу. Из ничего постепенно проявляется картинка.

## Как это работает

**Прямой процесс.** За T шагов (обычно T = 1000) к картинке x₀ понемногу добавляют гауссовский шум:

```
q(x_t | x_{t−1}) = N(x_t; √(1 − β_t) · x_{t−1}, β_t · I)
```

`β_t` — **расписание шума**, маленькие числа, например линейно от 0.0001 до 0.02. Главное удобство: до любого шага t можно дойти одним прыжком, без моделирования всей цепочки. Если `α_t = 1 − β_t` и `ᾱ_t = α_1 · α_2 · … · α_t`, то

```
x_t = √ᾱ_t · x₀ + √(1 − ᾱ_t) · ε,    ε ~ N(0, I)
```

Множитель `√ᾱ_t` — какая доля исходной картинки осталась, `√(1 − ᾱ_t)` — сколько шума. С линейным расписанием DDPM: на шаге 250 сигнала и шума примерно поровну (0.72 и 0.69), на шаге 500 сигнала остаётся 0.28, а к шагу 1000 — меньше 0.01: это практически чистый шум.

**Обучение.** Нейросеть ε_θ (обычно U-Net, в новых моделях — трансформер) получает зашумлённую картинку x_t и номер шага t и предсказывает, какой шум ε был добавлен. Функция потерь — обычная MSE:

```
L = E[ ‖ε − ε_θ(x_t, t)‖² ]
```

Алгоритм одного шага обучения:

1. Взять картинку x₀ из данных.
2. Выбрать случайный шаг t от 1 до T.
3. Сгенерировать шум ε и получить x_t формулой «одного прыжка».
4. Предсказать шум ε_θ(x_t, t) и сделать шаг градиентного спуска по MSE.

Никакой состязательной игры, никаких неустойчивых балансов — просто регрессия. Поэтому диффузия обучается стабильно.

**Генерация (sampling).** Начинаем с x_T ~ N(0, I) и идём назад, t = T, …, 1:

```
x_{t−1} = 1/√α_t · ( x_t − (1 − α_t)/√(1 − ᾱ_t) · ε_θ(x_t, t) ) + σ_t · z,   z ~ N(0, I)
```

На каждом шаге убираем предсказанную долю шума и (кроме последнего шага) добавляем немного свежего — это делает процесс стохастическим и разнообразным.

## Как сделать быстрее и управляемее

- **Быстрые сэмплеры.** DDIM, DPM-Solver и другие проходят обратный путь за 20–50 шагов вместо 1000 почти без потери качества.
- **Латентная диффузия (Stable Diffusion).** Диффузию запускают не на пикселях, а в сжатом латентном пространстве автоэнкодера (картинка 512×512×3 → тензор 64×64×4). Это в десятки раз дешевле; в конце декодер VAE превращает латент обратно в картинку.
- **Условие (текст).** Текстовый энкодер (например, CLIP) превращает промпт в векторы, и U-Net смотрит на них через cross-attention.
- **Classifier-free guidance.** Сеть обучают и с условием, и без него (иногда «забывая» промпт). При генерации делают два предсказания и усиливают разницу:

```
ε̃ = ε_θ(x_t, t, ∅) + w · (ε_θ(x_t, t, c) − ε_θ(x_t, t, ∅))
```

Вес `w` (guidance scale, в Stable Diffusion по умолчанию около 7.5) — компромисс: больше — точнее следует промпту, но меньше разнообразия и больше «пересвеченности».

## Пример на Python

Прямой процесс легко посмотреть на NumPy — он не требует обучения:

```python
import numpy as np

T = 1000
betas = np.linspace(1e-4, 0.02, T)           # линейное расписание из DDPM
alpha_bar = np.cumprod(1 - betas)            # ᾱ_t

for t in [1, 250, 500, 1000]:
    print(t, np.sqrt(alpha_bar[t-1]).round(3), np.sqrt(1 - alpha_bar[t-1]).round(3))
# 1     1.0    0.01
# 250   0.724  0.69
# 500   0.28   0.96
# 1000  0.006  1.0

rng = np.random.default_rng(0)
x0 = rng.uniform(-1, 1, size=(8, 8))         # «картинка» в [-1, 1]
eps = rng.normal(size=x0.shape)
x_t = np.sqrt(alpha_bar[499]) * x0 + np.sqrt(1 - alpha_bar[499]) * eps   # шаг 500 одним прыжком
print(np.corrcoef(x0.ravel(), x_t.ravel())[0, 1].round(2))              # 0.27
```

Шаг обучения в PyTorch (схема; `unet` — любая сеть, принимающая картинку и номер шага):

```python
import torch
import torch.nn.functional as F

alpha_bar = torch.cumprod(1 - torch.linspace(1e-4, 0.02, 1000), dim=0)

def train_step(unet, x0, optimizer):
    t = torch.randint(0, 1000, (x0.size(0),))
    eps = torch.randn_like(x0)
    a = alpha_bar[t].view(-1, 1, 1, 1)
    x_t = a.sqrt() * x0 + (1 - a).sqrt() * eps
    loss = F.mse_loss(unet(x_t, t), eps)            # предсказываем шум
    optimizer.zero_grad(); loss.backward(); optimizer.step()
    return loss.item()
```

Готовая модель через библиотеку `diffusers`:

```python
from diffusers import StableDiffusionPipeline

pipe = StableDiffusionPipeline.from_pretrained("stabilityai/stable-diffusion-2-1")
image = pipe("a cat in space", num_inference_steps=30, guidance_scale=7.5).images[0]
```

## Подводные камни

- **Медленная генерация.** Даже 30 шагов — это 30 проходов большой сети (а с guidance — 60). Для реального времени нужны дистилляция и «consistency»-модели.
- **Расписание шума важно.** С линейным расписанием на маленьких картинках информация уничтожается слишком рано; косинусное расписание распределяет шум равномернее.
- **Нормировка данных.** Формулы предполагают данные примерно в [−1, 1]. Картинки в [0, 255] или [0, 1] без приведения дают плохие результаты.
- **Слишком большой guidance.** При w ≈ 15–20 картинки становятся перенасыщенными и однообразными.
- **Память обучающих данных.** Большие диффузионные модели иногда почти дословно воспроизводят обучающие картинки — это вопрос и приватности, и авторских прав.

## Итоги

- Прямой процесс постепенно превращает картинку в шум; до любого шага можно дойти одним прыжком: `x_t = √ᾱ_t·x₀ + √(1−ᾱ_t)·ε`.
- Нейросеть учится предсказывать добавленный шум; потери — простая MSE, поэтому обучение стабильное.
- Генерация — многократное удаление шума, начиная с N(0, I). Быстрые сэмплеры сокращают путь до 20–50 шагов.
- Stable Diffusion работает в латентном пространстве и управляется текстом через cross-attention и classifier-free guidance.
- Плюсы — качество и разнообразие; минус — скорость генерации.
