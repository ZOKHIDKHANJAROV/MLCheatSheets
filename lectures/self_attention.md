# Self-attention

<!-- время: 16 мин -->

> **О чём лекция.** Как каждый токен последовательности «опрашивает» все остальные и собирает из них свой новый смысл: откуда берутся Q, K и V, зачем делить на √d_k, как работают маски и почему self-attention сам по себе не знает порядка слов.

## Зачем это нужно

Возьмём фразу «Животное не перешло улицу, потому что **оно** слишком устало». К чему относится «оно» — к животному или к улице? Человек понимает: устать может животное. Чтобы модель поняла то же самое, представление слова «оно» должно учитывать слово «животное», стоящее за несколько позиций до него.

В RNN информация от «животного» доходит до «оно» через цепочку шагов и по дороге размывается. **Self-attention** (самовнимание) позволяет каждому слову напрямую посмотреть на все слова той же последовательности и взять от них то, что нужно. Это центральная операция трансформеров — BERT, GPT, ViT и всех современных языковых моделей.

## Интуиция: каждое слово задаёт вопрос

В обычном механизме внимания декодер спрашивает энкодер. В self-attention **каждый токен спрашивает все токены своей же последовательности**, включая себя.

У каждого токена три роли:

- **Query** (запрос) — «что я ищу»: местоимению «оно» нужно существительное, к которому оно относится;
- **Key** (ключ) — «что я предлагаю»: слово «животное» сообщает «я одушевлённое существительное»;
- **Value** (значение) — «что я отдам, если меня выберут»: содержательная информация о слове.

Совпадение запроса одного токена с ключом другого — это их релевантность. Новое представление токена — смесь значений всех токенов, взвешенная по релевантности. После self-attention вектор «оно» уже содержит информацию о «животном».

## Как это работает

Пусть `X` — матрица входа размера n × d_model: n токенов, у каждого эмбеддинг длины d_model. Три обучаемые матрицы проецируют вход в запросы, ключи и значения:

```
Q = X · W_Q     (n × d_k)   — «что я ищу»
K = X · W_K     (n × d_k)   — «что я предлагаю»
V = X · W_V     (n × d_v)   — «что я отдам»
```

Затем — масштабированное скалярное внимание:

```
S = Q · Kᵀ / √d_k            (n × n) оценки «каждый с каждым»
A = softmax(S) по строкам    веса, сумма в каждой строке = 1
Z = A · V                    (n × d_v) новые представления
```

Строка i матрицы A — это то, как токен i распределяет внимание между всеми токенами. Новый вектор токена: `z_i = Σ_j a_ij · v_j`.

Важно: Q, K и V получаются из **одного и того же** X — отсюда «само» в названии. Если запросы берутся из одной последовательности, а ключи и значения из другой (декодер смотрит на энкодер), это **cross-attention**.

## Зачем делить на √d_k

Если компоненты векторов q и k — независимые величины со средним 0 и дисперсией 1, то их скалярное произведение `q · k` — сумма d_k слагаемых, и его дисперсия равна d_k. При d_k = 512 типичные оценки — порядка ±20–40. Softmax от таких чисел почти one-hot: один вес ≈ 1, остальные ≈ 0. Градиенты softmax в таком режиме почти нулевые, и обучение застревает.

Деление на `√d_k` возвращает дисперсию оценок к ≈ 1, и softmax остаётся «мягким». Это видно в примере ниже.

## Маски

Иногда токену нельзя смотреть на некоторые позиции. Для этого к оценкам **до softmax** прибавляют маску: 0 там, где можно, и −∞ там, где нельзя. После softmax запрещённые позиции получают вес ровно 0.

- **Padding-маска** — запрещает смотреть на токены-заполнители, которыми короткие последовательности дополнены до длины батча.
- **Каузальная маска** — запрещает смотреть в будущее: токен i видит только позиции ≤ i. Она нужна при генерации текста (GPT): модель учится предсказывать следующее слово и не должна подсматривать его. Маска — верхний треугольник матрицы n × n.

Если в строке замаскировано всё (например, пустая последовательность), softmax от одних −∞ даёт `nan` — такие случаи нужно обрабатывать отдельно.

## Порядок токенов

Self-attention **не знает порядка**: если переставить токены, выходы переставятся точно так же, а сами значения не изменятся. Для модели «собака укусила человека» и «человек укусил собаку» — одинаковый набор слов.

Поэтому к эмбеддингам добавляют **позиционное кодирование**: в исходном Transformer — фиксированные синусоиды разной частоты, в BERT и GPT-2 — обучаемые векторы позиций, в современных LLM — RoPE (поворот векторов q и k на угол, зависящий от позиции).

## Сложность

Матрица оценок имеет размер n × n, поэтому время и память растут как **O(n²)** по длине последовательности. Для 512 токенов это 262 тысячи оценок на голову, для 32 000 — уже миллиард. Отсюда много работ об «эффективном внимании»: разреженные и линейные варианты, скользящее окно и FlashAttention — точный алгоритм, который считает то же самое, но экономит память за счёт работы блоками.

## Пример на Python

Self-attention с каузальной маской на NumPy и проверка, зачем нужно масштабирование:

```python
import numpy as np

def softmax(z):
    z = z - z.max(axis=-1, keepdims=True)
    e = np.exp(z)
    return e / e.sum(axis=-1, keepdims=True)

def self_attention(X, W_Q, W_K, W_V, causal=False):
    Q, K, V = X @ W_Q, X @ W_K, X @ W_V
    d_k = K.shape[-1]
    S = Q @ K.T / np.sqrt(d_k)                         # (n, n): сходство каждого токена с каждым
    if causal:
        S = S + np.triu(np.full(S.shape, -np.inf), 1)  # запрещаем смотреть в будущее
    A = softmax(S)                                     # веса, сумма по строке = 1
    return A @ V, A

rng = np.random.default_rng(5)
n, d_model, d_k = 4, 8, 8
X = rng.normal(size=(n, d_model))                      # 4 токена
W_Q, W_K, W_V = (rng.normal(size=(d_model, d_k)) / np.sqrt(d_model) for _ in range(3))

Z, A = self_attention(X, W_Q, W_K, W_V, causal=True)
print(Z.shape)               # (4, 8)
print(A.round(2))            # нижний треугольник: токен видит только себя и прошлые
# [[1.   0.   0.   0.  ]
#  [0.49 0.51 0.   0.  ]
#  [0.39 0.37 0.24 0.  ]
#  [0.26 0.21 0.31 0.21]]

# Зачем делить на √d_k: дисперсия q·k растёт как d_k
for d in (4, 64, 512):
    q, k = rng.normal(size=(10000, d)), rng.normal(size=(10000, d))
    dots = (q * k).sum(axis=1)
    print(d, round(dots.var()), round((dots / np.sqrt(d)).var(), 2))
# 4 4 0.98
# 64 63 0.99
# 512 510 1.0
```

Первый токен видит только себя, поэтому его вес равен 1; последний распределяет внимание между всеми четырьмя.

## Подводные камни

- **Маска после softmax.** Маску прибавляют к оценкам *до* softmax; если обнулить веса после, строки перестанут суммироваться в 1.
- **Направление каузальной маски.** Запрещается верхний треугольник (будущее), `diagonal=1` — диагональ (сам токен) остаётся разрешённой.
- **Забытое позиционное кодирование.** Модель без него работает с «мешком слов» и не различает порядок.
- **Длина последовательности.** Память O(n²): удвоение контекста учетверяет матрицу внимания.
- **Полностью замаскированные строки** дают `nan` — проверяйте пустые последовательности.

## Итоги

- Self-attention: каждый токен смотрит на все токены своей последовательности и собирает новое представление как взвешенную сумму их значений.
- Q, K, V — три линейные проекции одного входа X; формула `softmax(Q·Kᵀ / √d_k + M) · V`.
- Деление на √d_k держит дисперсию оценок около 1, чтобы softmax не вырождался.
- Маски: padding-маска скрывает заполнители, каузальная — будущее.
- Self-attention не знает порядка — нужно позиционное кодирование; сложность O(n²) по длине.
