# Искусственный нейрон (перцептрон)

<!-- время: 12 мин -->

> **О чём лекция.** Из чего состоит искусственный нейрон, как перцептрон учится на ошибках, почему один нейрон не справляется с XOR и как из этой неудачи выросли многослойные нейросети.

## Зачем это нужно

Любая нейросеть — от маленького классификатора до языковой модели — собрана из одинаковых кирпичиков: искусственных нейронов. Если понять, что делает один нейрон, большие сети перестают быть «чёрным ящиком»: это просто много нейронов, соединённых слоями.

Перцептрон Розенблатта (1958) — первая обучаемая модель нейрона. Сам по себе он умеет немного, но на нём хорошо видны все ключевые идеи: веса, смещение, функция активации, обучение на ошибках и ограничения линейных моделей.

## Интуиция: взвешенное голосование

Представьте, что вы решаете, идти ли на прогулку. У вас есть несколько «входов»: светит ли солнце, есть ли свободное время, не холодно ли. Каждый фактор важен по-разному: солнце — очень, температура — чуть меньше. Вы мысленно складываете факторы с весами и сравниваете сумму с порогом: если сумма выше — идёте.

Нейрон делает ровно это:

- **входы** x₁…xₙ — признаки объекта;
- **веса** w₁…wₙ — насколько важен каждый признак (вес может быть и отрицательным — признак «голосует против»);
- **смещение** b — порог: насколько легко нейрону «сработать»;
- **функция активации** f — превращает сумму в ответ.

## Как это работает

Нейрон вычисляет выход в два шага:

```
z = w₁x₁ + w₂x₂ + … + wₙxₙ + b     # линейная комбинация
y = f(z)                            # активация
```

В классическом перцептроне активация ступенчатая: `y = 1`, если `z > 0`, иначе `0`. Уравнение `w·x + b = 0` задаёт прямую (в общем случае — гиперплоскость), которая делит пространство признаков на две части. Поэтому перцептрон — **линейный классификатор**: он умеет разделять только те классы, между которыми можно провести прямую.

Без смещения b эта прямая обязана проходить через начало координат. Смещение позволяет её сдвигать, поэтому без него нейрон заметно слабее.

В современных сетях вместо ступеньки используют гладкие активации — сигмоиду, tanh, ReLU. Нейрон с сигмоидой и функцией потерь log-loss — это в точности логистическая регрессия.

## Правило обучения перцептрона

Перцептрон учится на собственных ошибках. Для каждого объекта:

```
ŷ = 1, если w·x + b > 0, иначе 0
w ← w + η · (y − ŷ) · x
b ← b + η · (y − ŷ)
```

Если ответ верный, `y − ŷ = 0` и ничего не меняется. Если нейрон ответил 0, а нужно 1, веса сдвигаются в сторону x — в следующий раз сумма на этом объекте будет больше. При обратной ошибке веса сдвигаются от x.

**Теорема сходимости перцептрона** гарантирует: если классы линейно разделимы, алгоритм за конечное число шагов найдёт разделяющую прямую. Если не разделимы — веса будут вечно «качаться», и правило не остановится само.

## Проблема XOR

Возьмём четыре точки: (0,0), (0,1), (1,0), (1,1). Для логического «И» (AND) класс 1 только у (1,1) — его легко отрезать одной прямой. А для «исключающего ИЛИ» (XOR) класс 1 у (0,1) и (1,0), класс 0 — у (0,0) и (1,1). Нарисуйте эти точки: никакая одна прямая не отделит диагональ от диагонали.

В 1969 году Минский и Пейперт подробно разобрали это ограничение, и интерес к нейросетям надолго угас. Решение оказалось в другом: если поставить нейроны **слоями**, первый слой может провести две прямые, а второй — скомбинировать их. Так появился многослойный перцептрон, а обучать его научили позже — с помощью обратного распространения ошибки.

## Пример на Python

Обучим перцептрон на AND и на XOR правилом из лекции:

```python
import numpy as np

X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])

def train_perceptron(X, y, lr=0.1, epochs=20):
    w, b = np.zeros(X.shape[1]), 0.0
    for _ in range(epochs):
        for xi, yi in zip(X, y):
            y_hat = int(xi @ w + b > 0)        # ступенчатая активация
            w += lr * (yi - y_hat) * xi        # правило перцептрона
            b += lr * (yi - y_hat)
    return w, b

for name, y in [("AND", np.array([0, 0, 0, 1])), ("XOR", np.array([0, 1, 1, 0]))]:
    w, b = train_perceptron(X, y)
    pred = (X @ w + b > 0).astype(int)
    print(name, "предсказания:", pred, "верно:", (pred == y).sum(), "из 4")

# AND предсказания: [0 0 0 1] верно: 4 из 4
# XOR предсказания: [1 1 0 0] верно: 2 из 4
```

AND выучен идеально, а на XOR перцептрон угадывает лишь половину — сколько эпох ни добавляй. В PyTorch тот же нейрон с сигмоидой — это `nn.Linear(n_features, 1)` и `nn.Sigmoid()`.

## Подводные камни

- **Масштаб признаков.** Признак в тысячах «перекрикивает» признак в долях: его вклад в сумму огромен при любом весе. Перед обучением признаки стандартизируют.
- **Нет вероятностей.** Ступенчатый перцептрон отвечает только 0 или 1 и не говорит, насколько уверен. Если нужна уверенность — сигмоида и логистическая регрессия.
- **Неразделимые данные.** На реальных шумных данных классическое правило не сходится; результат зависит от того, на какой эпохе остановились. На практике берут логистическую регрессию или MLP.
- **Ступенька не дифференцируема.** Градиентный спуск через неё не проходит, поэтому в многослойных сетях ступенчатую активацию заменили гладкими.

## Итоги

- Нейрон считает взвешенную сумму входов плюс смещение и пропускает её через активацию: `y = f(w·x + b)`.
- Перцептрон — линейный классификатор: он проводит одну разделяющую гиперплоскость.
- Правило обучения меняет веса только на ошибках; на линейно разделимых данных оно гарантированно сходится.
- XOR одним нейроном не решить — нужны скрытые слои, то есть многослойный перцептрон.
- Нейрон с сигмоидой и log-loss — это логистическая регрессия.
