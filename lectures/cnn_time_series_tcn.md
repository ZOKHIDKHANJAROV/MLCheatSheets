# CNN для временных рядов (TCN)

<!-- время: 14 мин -->

> **О чём лекция.** Как свёрточные сети, привычные по картинкам, применяют к последовательностям: одномерная свёртка по времени, каузальность «только прошлое», дилатации, которые дают огромное поле зрения малым числом слоёв, и остаточные блоки. В итоге получается TCN — быстрая и стабильная альтернатива LSTM.

## Зачем это нужно

Рекуррентные сети обрабатывают ряд строго по шагам: чтобы посчитать состояние на шаге 1000, нужно сначала посчитать 999 предыдущих. Это медленно на длинных последовательностях и плохо загружает GPU. Кроме того, градиенты через сотни шагов затухают, и обучение бывает капризным.

**TCN (Temporal Convolutional Network)** решает задачу иначе: применяет к ряду свёртки. Свёртка считается для всех моментов времени параллельно, градиент идёт через небольшое число слоёв, а не через сотни шагов. В известном сравнении Бай, Колтера и Колтуна (2018) простая TCN на многих задачах с последовательностями оказалась не хуже LSTM и GRU, а часто лучше.

## Интуиция: скользящий фильтр по времени

Одномерная свёртка — это маленькое окно с обучаемыми весами, которое скользит вдоль ряда. Ядро размера 3 в каждый момент смотрит на три соседних значения и выдаёт их взвешенную сумму. Обучаемые веса превращаются в детекторы локальных шаблонов: «резкий рост», «пик», «плато».

Для прогнозирования нужно два улучшения:

1. **Каузальность.** Фильтр не должен видеть будущее: выход в момент t может зависеть только от входов в моменты t, t−1, t−2…
2. **Длинная память.** Обычная свёртка с ядром 3 видит всего 3 точки. Чтобы видеть 1000 точек, понадобились бы сотни слоёв. Решение — дилатации.

## Как это работает: каузальная свёртка

Каузальную свёртку получают, дополняя ряд нулями **только слева**, на `(k − 1) · d` позиций, где k — размер ядра, d — дилатация. Тогда фильтр в момент t «упирается» правым краем в t и не заглядывает вперёд.

```
y(t) = Σ w[j] · x(t − j·d),  j = 0..k−1
```

Если по ошибке дополнить ряд с двух сторон (`padding="same"`), сеть на обучении будет видеть будущие значения — прогноз на тренировке будет отличным, а в реальности бесполезным. Это классическая утечка.

## Дилатации: экспоненциальное поле зрения

**Дилатированная** (расширенная, dilated) свёртка берёт входы не подряд, а через шаг d: с ядром 3 и d = 4 фильтр смотрит на x(t), x(t−4), x(t−8). В TCN дилатацию удваивают с каждым слоем: 1, 2, 4, 8, 16…

**Рецептивное поле** — сколько прошлых точек влияет на выход. Для стека свёрток (по одной на уровень) с ядром k и дилатациями d₁…dₙ:

```
R = 1 + (k − 1) · (d₁ + d₂ + … + dₙ)
```

С ядром 3 и дилатациями 1, 2, 4, 8 получаем R = 1 + 2 · 15 = 31. Добавление уровня удваивает поле зрения: 10 уровней с ядром 3 уже видят 2047 шагов. Число параметров при этом растёт линейно, а поле зрения — экспоненциально.

## Остаточные блоки

Реальная TCN собирается из **остаточных блоков**: две каузальные дилатированные свёртки с нормализацией, активацией ReLU и dropout, плюс обходная связь, которая прибавляет вход блока к его выходу (как в ResNet). Если число каналов на входе и выходе разное, обходная связь проходит через свёртку 1×1. Остаточные связи позволяют обучать глубокие стеки без затухания градиентов.

Для прогноза берут выход последнего временного шага и подают его в линейный слой — так же, как у LSTM берут последнее скрытое состояние.

## TCN или RNN

| | TCN | RNN/LSTM |
|---|---|---|
| вычисления | параллельно по времени | последовательно |
| память | фиксированное рецептивное поле | теоретически не ограничена |
| градиенты | короткий путь, стабильное обучение | длинный путь, затухание |
| инференс в потоке | нужно хранить окно длины R | хранит только состояние |

Главное ограничение TCN: модель **ничего не знает** о событиях старше рецептивного поля. Его нужно подобрать заранее под задачу: если важна годовая сезонность дневных данных, поле зрения должно быть не меньше 365 шагов.

## Пример на Python

Каузальная дилатированная свёртка на NumPy. Подадим импульс в момент 0 и проверим, как далеко его «видят» четыре уровня с дилатациями 1, 2, 4, 8:

```python
import numpy as np

def causal_dilated_conv(x, w, dilation):
    """y[t] = Σ_j w[j] · x[t − j·d]; нули добавляем только слева — будущее не используется."""
    k = len(w)
    pad = (k - 1) * dilation
    xp = np.concatenate([np.zeros(pad), x])
    return np.array([sum(w[j] * xp[pad + t - j * dilation] for j in range(k)) for t in range(len(x))])

x = np.zeros(40); x[0] = 1.0                 # импульс в момент 0
h = x
for d in (1, 2, 4, 8):
    h = causal_dilated_conv(h, np.ones(3), d)
print("последний момент, до которого дошёл импульс:", np.nonzero(h)[0].max())   # 30
print("рецептивное поле:", 1 + (3 - 1) * (1 + 2 + 4 + 8))                         # 31
```

Импульс влияет на выходы в моменты 0…30 — ровно 31 точка, как и даёт формула. И ни один выход до момента 0 не изменился: каузальность соблюдена.

Тот же слой в PyTorch — свёртка с левым дополнением:

```python
import torch.nn as nn
import torch.nn.functional as F

class CausalConv1d(nn.Module):
    def __init__(self, c_in, c_out, kernel_size, dilation):
        super().__init__()
        self.pad = (kernel_size - 1) * dilation
        self.conv = nn.Conv1d(c_in, c_out, kernel_size, dilation=dilation)

    def forward(self, x):                       # x: (batch, channels, time)
        return self.conv(F.pad(x, (self.pad, 0)))   # нули только слева
```

Обратите внимание на порядок осей: `nn.Conv1d` ждёт `(batch, channels, time)`, а не `(batch, time, features)`, как LSTM с `batch_first=True`.

## Подводные камни

- **Утечка будущего** из-за симметричного дополнения (`padding="same"`). Проверка: измените последнюю точку входа — выходы в более ранние моменты меняться не должны.
- **Слишком маленькое рецептивное поле.** Посчитайте его по формуле и сравните с длиной важных зависимостей (сезонностью).
- **Перепутанные оси.** Ряд формы `(batch, time, features)` нужно транспонировать в `(batch, features, time)` перед `Conv1d`.
- **BatchNorm на маленьких батчах** ведёт себя нестабильно; в оригинальной TCN использовали weight normalization, часто подходит и LayerNorm.
- **Бейзлайны.** Как и с любой нейросетью для рядов, сравнивайте с наивным прогнозом и бустингом на лагах.

## Итоги

- TCN — стек одномерных свёрток по времени: каузальных (только прошлое) и дилатированных (с удваивающимся шагом).
- Рецептивное поле `R = 1 + (k − 1)·Σd` растёт экспоненциально с числом уровней.
- Остаточные блоки делают глубокие TCN обучаемыми.
- По сравнению с RNN: параллельные вычисления и стабильное обучение, но жёстко ограниченная память.
