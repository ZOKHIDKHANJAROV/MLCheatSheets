# Matplotlib/Seaborn для визуализации

<!-- время: 12 мин -->

> **О чём лекция.** Какие графики нужны на каждом этапе ML-проекта — от первого знакомства с данными до диагностики обученной модели — и как строить их в matplotlib и seaborn без лишних мучений.

## Зачем это нужно

Таблица из тысячи строк ничего не говорит человеку, а один график — говорит. Визуализация в ML решает три задачи:

- **понять данные** до обучения: распределения, выбросы, связи между признаками, дисбаланс классов;
- **отладить обучение**: кривые потерь, кривые обучения, переобучение;
- **проверить модель**: где она ошибается, для каких объектов, насколько уверенно.

Классический пример — квартет Энскомба: четыре набора точек с одинаковыми средними, дисперсиями и корреляцией, но совершенно разной формой. Одни лишь числа их не различают, график — сразу.

## Интуиция: два уровня инструментов

**Matplotlib** — базовая библиотека: умеет нарисовать что угодно, но многое приходится настраивать вручную. **Seaborn** построена поверх неё и работает с DataFrame: одной функцией строит статистический график с группировкой по категориям, доверительными интервалами и аккуратным оформлением. Обычно сочетают оба: seaborn рисует, matplotlib донастраивает.

В matplotlib есть понятия, без которых не обойтись:

- **Figure** — весь рисунок (окно, файл);
- **Axes** — одна координатная область с осями внутри рисунка; на рисунке их может быть несколько.

## Как это работает

### Объектный стиль

Надёжный способ — явно создать рисунок и оси и рисовать на конкретных осях:

```
fig, axes = plt.subplots(1, 3, figsize=(14, 4))
axes[0].hist(...)
axes[1].scatter(...)
axes[0].set_title("...")
fig.tight_layout()
fig.savefig("plot.png", dpi=120)
```

Последовательные вызовы `plt.plot()` рисуют на «текущих» осях — в простом скрипте это удобно, но в сетке графиков и в функциях легко нарисовать не туда. Все функции seaborn принимают аргумент `ax=`, поэтому прекрасно встраиваются в такую сетку.

### Какой график для какого вопроса

| вопрос | график |
|---|---|
| как распределён один признак? | гистограмма `hist` / `sns.histplot(kde=True)` |
| есть ли выбросы, как отличаются группы? | ящик с усами `sns.boxplot`, `sns.violinplot` |
| как связаны два числовых признака? | диаграмма рассеяния `scatter` / `sns.scatterplot` |
| какие признаки коррелируют? | тепловая карта `sns.heatmap(df.corr(numeric_only=True))` |
| все попарные связи сразу | `sns.pairplot(df, hue="target")` |
| сбалансированы ли классы? | столбчатая `sns.countplot` |
| как меняется величина во времени? | линия `plot` |

Ящик с усами показывает медиану (линия), квартили Q1 и Q3 (границы ящика), «усы» до 1.5·IQR и точки за ними — кандидатов в выбросы.

### Графики для диагностики модели

- **Кривая обучения** — потери на train и validation по эпохам или по размеру выборки: расходятся — переобучение, обе высокие — недообучение.
- **Факт против прогноза** (регрессия): точки должны лежать вдоль диагонали.
- **Остатки против прогноза**: облако без структуры вокруг нуля — хорошо; «воронка» или дуга — модель что-то упускает.
- **Матрица ошибок и ROC-кривая** (классификация).
- **Важность признаков** — горизонтальная столбчатая диаграмма.

## Пример на Python

Три диагностических графика для регрессии в одной сетке:

```python
import matplotlib
matplotlib.use("Agg")                 # рисуем в файл, без окна
import matplotlib.pyplot as plt
from sklearn.datasets import make_regression
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split

X, y = make_regression(n_samples=300, n_features=1, noise=15, random_state=0)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, random_state=0)
pred = LinearRegression().fit(X_tr, y_tr).predict(X_te)

fig, axes = plt.subplots(1, 3, figsize=(14, 4))
axes[0].hist(y, bins=30)
axes[0].set_title("Распределение цели")
axes[1].scatter(y_te, pred, alpha=0.6)
lims = [y_te.min(), y_te.max()]
axes[1].plot(lims, lims, "r--")       # идеальные прогнозы лежат на диагонали
axes[1].set(xlabel="факт", ylabel="прогноз", title="Факт vs прогноз")
axes[2].scatter(pred, y_te - pred, alpha=0.6)
axes[2].axhline(0, color="r", ls="--")
axes[2].set(xlabel="прогноз", ylabel="остаток", title="Остатки")
fig.tight_layout()
fig.savefig("diagnostics.png", dpi=120)
```

В Jupyter строку `matplotlib.use("Agg")` можно убрать — графики появятся прямо в тетрадке.

## Подводные камни

- **Наложение точек.** На scatter с десятками тысяч точек всё сливается в пятно. Помогают прозрачность `alpha=0.1`, маленький размер `s=2`, `sns.histplot(x=..., y=...)` или `hexbin`.
- **Число корзин гистограммы.** При 5 корзинах не видно формы, при 500 — один шум. Попробуйте несколько значений `bins`.
- **Обрезанная ось.** Столбчатая диаграмма, у которой ось Y начинается не с нуля, преувеличивает разницу.
- **Корреляция ≠ связь.** Тепловая карта корреляций Пирсона видит только линейные связи; зависимость вида U корреляция покажет как ноль. Смотрите и на scatter.
- **Логарифмическая шкала.** Доходы, цены, число просмотров обычно имеют длинный хвост; `ax.set_xscale("log")` или логарифм признака делают график читаемым.
- **Не забудьте подписи.** Название, оси и легенда — обязательны, иначе через неделю вы сами не поймёте график.

## Итоги

- Визуализация нужна на всех этапах: знакомство с данными, отладка обучения, проверка модели.
- Работайте в объектном стиле `fig, ax = plt.subplots()`; seaborn рисует на переданных осях через `ax=`.
- Распределение — гистограмма или boxplot, связь — scatter, корреляции — heatmap, попарно — pairplot.
- Для модели: кривые обучения, факт против прогноза, остатки, матрица ошибок.
