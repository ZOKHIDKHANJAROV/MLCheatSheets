# SHAP значения

<!-- время: 18 мин -->

> **О чём лекция.** Как честно разделить предсказание модели между признаками: идея значений Шепли из теории игр, свойство аддитивности «база + вклады = прогноз», быстрые алгоритмы для деревьев и основные графики библиотеки shap — waterfall, beeswarm и dependence.

## Зачем это нужно

Банк отказал клиенту в кредите, модель — градиентный бустинг на сотне признаков. Клиент, регулятор и сам аналитик хотят знать: **почему именно этому человеку?** Какие признаки толкнули вероятность дефолта вверх и на сколько?

Глобальная важность признаков на это не отвечает: она говорит, что «доход в среднем важен», но не что случилось в конкретном случае. Нужен **локальный** метод, который раскладывает конкретный прогноз на вклады признаков. SHAP (SHapley Additive exPlanations, Лундберг и Ли, 2017) стал стандартом для этого, потому что опирается на единственный способ разделения, удовлетворяющий набору разумных требований справедливости.

## Интуиция: делёж выигрыша в команде

Три человека вместе выиграли приз. Как поделить деньги честно, если они вносили разный вклад, а вместе работали лучше, чем по отдельности? Ллойд Шепли (1953) предложил: рассмотреть все порядки, в которых участники могли присоединяться к команде, и для каждого участника усреднить его **предельный вклад** — насколько выросла добыча команды в момент его прихода.

В ML «игроки» — признаки, «выигрыш» — отклонение прогноза модели от среднего прогноза. Значение Шепли признака φⱼ — его средний предельный вклад по всем возможным порядкам добавления признаков.

## Как это работает

Формула значения Шепли для признака j (M — число признаков, S — подмножество остальных):

```
φⱼ = Σ_{S ⊆ F∖{j}}  |S|! · (M − |S| − 1)! / M!  ·  [ v(S ∪ {j}) − v(S) ]
```

- `v(S)` — прогноз модели, когда известны только признаки из S. Неизвестные признаки «убирают», усредняя прогноз по фоновым данным;
- квадратная скобка — предельный вклад j при добавлении к S;
- веса — доля порядков, в которых перед j пришли именно признаки из S.

Ключевое свойство — **аддитивность** (local accuracy):

```
f(x) = φ₀ + φ₁ + φ₂ + … + φ_M
```

`φ₀` — базовое значение, средний прогноз на фоне (`expected_value`). Сумма вкладов в точности даёт прогноз для этого объекта. Положительный φⱼ толкает прогноз вверх, отрицательный — вниз.

Значения Шепли — единственное разделение со свойствами:

- **эффективность** — вклады складываются в прогноз;
- **симметрия** — одинаково влияющие признаки получают одинаковые вклады;
- **нулевой игрок** — признак, ни на что не влияющий, получает 0;
- **аддитивность** — для суммы моделей вклады складываются.

## Как это посчитать быстро

Точная формула требует 2^M вычислений v(S) — для 100 признаков это нереально. Поэтому есть разные алгоритмы:

| explainer | для чего | скорость |
|---|---|---|
| `TreeExplainer` | деревья и ансамбли: XGBoost, LightGBM, CatBoost, sklearn | точно и быстро, полиномиально |
| `LinearExplainer` | линейные модели | мгновенно: `φⱼ = wⱼ · (xⱼ − mean(xⱼ))` при независимых признаках |
| `DeepExplainer`, `GradientExplainer` | нейросети | приближённо, через градиенты |
| `KernelExplainer` | любая модель | приближённо, медленно — взвешенная линейная регрессия на подмножествах |
| `shap.Explainer` | автовыбор | выбирает подходящий по типу модели |

Для бустингов почти всегда используется TreeExplainer — именно он сделал SHAP практичным.

## Пример на Python

Сначала посчитаем значения Шепли «вручную» по формуле — для модели с тремя признаками и взаимодействием, чтобы увидеть аддитивность:

```python
from itertools import combinations
from math import factorial
import numpy as np

def model(X):
    return 2 * X[:, 0] + X[:, 1] + 3 * X[:, 0] * X[:, 2]   # x0 и x2 взаимодействуют

rng = np.random.default_rng(0)
background = rng.normal(size=(500, 3))      # фон — «типичные» данные
x = np.array([1.0, 2.0, 1.0])               # объект, который объясняем

def value(S):                               # v(S): признаки из S — от x, остальные — из фона
    Z = background.copy()
    Z[:, list(S)] = x[list(S)]
    return model(Z).mean()

M, phi = 3, np.zeros(3)
for j in range(M):
    others = [k for k in range(M) if k != j]
    for size in range(M):
        for S in combinations(others, size):
            w = factorial(len(S)) * factorial(M - len(S) - 1) / factorial(M)
            phi[j] += w * (value(S + (j,)) - value(S))

print("φ =", phi.round(2))                               # [3.97 1.92 1.34]
print(round(value(()) + phi.sum(), 2), model(x[None])[0])  # 7.0 7.0 — база + Σφ = прогноз
```

Вклад взаимодействия `3·x0·x2` поделился между x0 и x2, а сумма в точности совпала с прогнозом.

В реальной работе — библиотека `shap` (в среде курса не установлена, код по её актуальному API):

```python
import shap
import xgboost as xgb

model = xgb.XGBClassifier(n_estimators=300).fit(X_train, y_train)
explainer = shap.TreeExplainer(model)
sv = explainer(X_test)                      # объект Explanation: values, base_values, data

shap.plots.waterfall(sv[0])                 # разложение одного прогноза
shap.plots.beeswarm(sv)                     # все объекты: важность и направление влияния
shap.plots.bar(sv)                          # глобальная важность: mean(|φ|)
shap.plots.scatter(sv[:, "income"], color=sv)   # dependence: φ признака от его значения
```

Учтите: для классификатора XGBoost TreeExplainer по умолчанию раскладывает **логит** (log-odds), а не вероятность. Базовое значение плюс сумма φ дают логит; вероятность получается из него сигмоидой.

## Как читать графики

- **Waterfall** — один объект: от базового значения стрелки вкладов шаг за шагом приводят к прогнозу. Отвечает на вопрос «почему этот прогноз».
- **Beeswarm (summary)** — каждая точка — объект, по горизонтали φ, цвет — значение признака. Признаки отсортированы по mean(|φ|). Видно и важность, и направление: красные точки справа — «большое значение повышает прогноз».
- **Bar** — средний |φ| по признакам; глобальная важность, основанная на SHAP, обычно устойчивее MDI.
- **Dependence (scatter)** — как вклад признака зависит от его значения; разброс по вертикали при одном значении — признак взаимодействий.

## Подводные камни

- **Коррелированные признаки.** Чтобы «убрать» признак, его заменяют значениями из фона независимо от остальных. Для сильно коррелированных признаков это создаёт нереалистичные объекты (рост 2 м при весе 40 кг), и вклады делятся странно.
- **Выбор фона влияет на результат.** φ — вклад относительно фонового набора; другой фон даёт другие значения и другое φ₀.
- **SHAP объясняет модель, а не мир.** Большой вклад признака — это то, как модель использует признак, а не причинная связь.
- **Масштаб выхода.** Для классификаторов проверяйте, что раскладывается: вероятность, логит или margin.
- **KernelExplainer медленный.** На больших данных берите подвыборку фона (`shap.kmeans`, 50–100 точек) или специализированный explainer.

## Итоги

- SHAP раскладывает конкретный прогноз на вклады признаков на основе значений Шепли из теории игр.
- Аддитивность: базовое значение + сумма вкладов = прогноз.
- Значения Шепли — единственное разделение с разумными свойствами справедливости (симметрия, нулевой игрок, эффективность).
- Для деревьев TreeExplainer считает их точно и быстро; для остальных моделей есть приближения.
- Графики: waterfall — один прогноз, beeswarm и bar — глобальная картина, dependence — форма влияния и взаимодействия.
