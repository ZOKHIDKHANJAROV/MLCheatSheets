# Основы свёртки

<!-- время: 16 мин -->

> **О чём лекция.** Почему для изображений нужны свёрточные сети, как ядро «скользит» по картинке и находит паттерны, как считать размер выхода и число параметров и что такое рецептивное поле.

## Зачем это нужно

Картинка 224×224 в цвете — это 150 528 чисел. Полносвязный слой всего на 1000 нейронов потребует 150 миллионов весов — и при этом не будет знать главного об изображениях: соседние пиксели связаны, а кошка остаётся кошкой, где бы она ни была на кадре.

Свёрточные нейросети (CNN, convolutional neural networks) встраивают это знание в архитектуру. Они на порядки экономнее по параметрам, лучше обобщают и десять лет были стандартом компьютерного зрения: классификация, детекция, сегментация, медицинские снимки. Свёртки используют и для звука, сигналов и временных рядов.

## Интуиция: фонарик с шаблоном

Представьте, что вы водите по картинке маленьким фонариком 3×3 с трафаретом. В каждой позиции вы смотрите, насколько кусок картинки под фонариком похож на трафарет, и записываете число. Получается новая картинка — **карта признаков**, где яркие места означают «здесь есть этот паттерн».

Трафарет — это **ядро свёртки** (фильтр), и его значения сеть подбирает сама при обучении. Первые слои выучивают простые паттерны — границы, перепады цвета. Следующие слои смотрят уже на карты признаков и находят комбинации: углы, текстуры, затем части объектов, затем объекты целиком.

## Как это работает

В каждой позиции свёртка считает поэлементное произведение окна изображения на ядро и суммирует его (плюс смещение):

```
выход[i, j] = Σₘ Σₙ вход[i + m, j + n] · ядро[m, n] + b
```

Две ключевые идеи:

- **Локальность** — каждый выход зависит только от небольшой окрестности входа.
- **Разделение весов** — одно и то же ядро применяется во всех позициях. Детектор вертикальной границы одинаково полезен в любом углу картинки, поэтому учить его отдельно для каждого места незачем. Из-за этого свёртка **эквивариантна к сдвигу**: сдвинули объект — сдвинулась и его карта признаков.

На цветной картинке ядро трёхмерное: 3×3×(число входных каналов). Свёрточный слой содержит много ядер — по одному на каждый выходной канал, — и каждое даёт свою карту признаков.

## Размер выхода

Три параметра управляют геометрией:

- **kernel size** k — размер ядра (обычно 3);
- **stride** s — шаг, с которым ядро сдвигается;
- **padding** p — сколько нулей добавить по краям.

```
выход = ⌊(вход + 2p − k) / s⌋ + 1
```

Примеры для входа 32×32: ядро 3, p = 1, s = 1 → 32×32 (размер сохраняется, так называемый `same` padding); ядро 3, p = 0 → 30×30; ядро 3, p = 1, s = 2 → 16×16 (уменьшение вдвое).

## Число параметров

У слоя `Conv2d(in, out, kernel=k×k)`:

```
параметры = k · k · in · out + out
```

Для `Conv2d(3, 16, 3×3)` это `3·3·3·16 + 16 = 448` параметров — и они не зависят от размера картинки. Полносвязный слой с теми же 16 выходами на картинке 32×32×3 потребовал бы 49 168 параметров, а на 224×224 — уже 2.4 миллиона.

## Рецептивное поле

Рецептивное поле нейрона — область исходной картинки, от которой зависит его значение. После одного слоя 3×3 оно 3×3, после двух — 5×5, после трёх — 7×7: каждый слой 3×3 с шагом 1 добавляет 2 пикселя. Пулинг и stride > 1 увеличивают его гораздо быстрее. Глубокие слои «видят» почти всю картинку, поэтому могут распознавать целые объекты.

## Свёртка 1×1

Ядро 1×1 не смотрит на соседей — оно смешивает каналы в каждом пикселе, как маленький полносвязный слой. Так дёшево меняют число каналов: например, сжимают 256 каналов до 64 перед дорогой свёрткой 3×3. Этот приём используют Inception, ResNet (bottleneck) и MobileNet.

## Типичная CNN

Классическая схема: несколько блоков «свёртка → активация (ReLU) → пулинг», в которых пространственный размер уменьшается, а число каналов растёт (32 → 64 → 128…), затем `Flatten` или global pooling и полносвязная «голова» для классификации. Часто добавляют BatchNorm после свёртки и Dropout перед головой.

## Пример на Python

Свёртка вручную на NumPy: ядро Собеля находит вертикальную границу между тёмной и светлой половинами картинки.

```python
import numpy as np

def conv2d(image, kernel, stride=1, padding=0):
    image = np.pad(image, padding)
    k = kernel.shape[0]
    out = (image.shape[0] - k) // stride + 1
    result = np.zeros((out, out))
    for i in range(out):
        for j in range(out):
            patch = image[i * stride:i * stride + k, j * stride:j * stride + k]
            result[i, j] = np.sum(patch * kernel)   # скалярное произведение окна и ядра
    return result

image = np.zeros((6, 6))
image[:, 3:] = 1                                   # слева тёмное, справа светлое
sobel_x = np.array([[-1, 0, 1], [-2, 0, 2], [-1, 0, 1]])

print(conv2d(image, sobel_x))                      # 4×4: столбцы [0 4 4 0] — отклик на границе
print(conv2d(image, sobel_x, padding=1).shape)     # (6, 6) — padding сохраняет размер
print(conv2d(image, sobel_x, stride=2).shape)      # (2, 2)

# Параметры Conv2d(3 → 16, ядро 3×3) против полносвязного слоя на картинке 32×32×3
print("conv:", 3 * 3 * 3 * 16 + 16, " dense:", 32 * 32 * 3 * 16 + 16)   # conv: 448  dense: 49168
```

Строго говоря, в нейросетях считают взаимную корреляцию (ядро не переворачивают), но её по традиции называют свёрткой — для обучаемых ядер разницы нет. В PyTorch слой — `nn.Conv2d(3, 32, kernel_size=3, padding=1)`, вход в формате (батч, каналы, высота, ширина); в Keras — `layers.Conv2D(32, 3, padding="same")` с каналами в конце.

## Подводные камни

- **Порядок осей.** PyTorch ждёт `(N, C, H, W)`, Keras и большинство библиотек изображений — `(N, H, W, C)`. Путаница даёт ошибки размерностей или молчаливо неверные результаты.
- **Размер перед полносвязным слоем.** После нескольких свёрток и пулингов легко ошибиться в `nn.Linear(64 * 8 * 8, …)`. Пропустите один тензор через `features` и посмотрите `shape`, или используйте global average pooling / `nn.LazyLinear`.
- **Нормализация входа.** Пиксели 0…255 нужно привести к 0…1 и стандартизировать; для предобученных моделей — их средними и стандартными отклонениями.
- **Мало данных.** Свёрточная сеть с нуля на паре тысяч картинок переобучается; используйте аугментацию и transfer learning.
- **Свёртка не инвариантна к повороту и масштабу.** Это нужно добирать аугментацией.

## Итоги

- Свёртка — скользящее ядро, которое находит локальный паттерн во всех позициях картинки.
- Локальность и разделение весов делают CNN экономными и эквивариантными к сдвигу.
- Размер выхода: `⌊(n + 2p − k)/s⌋ + 1`; параметры слоя: `k·k·in·out + out`, независимо от размера картинки.
- Рецептивное поле растёт с глубиной — глубокие слои видят крупные объекты.
- Свёртка 1×1 смешивает каналы и дёшево меняет их число.
