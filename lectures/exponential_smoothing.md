# Экспоненциальное сглаживание

<!-- время: 14 мин -->

> **О чём лекция.** Самый простой и при этом очень живучий метод прогнозирования: прогноз — это взвешенное среднее прошлого, где свежие наблюдения важнее старых. Разберём, как от простого сглаживания перейти к методу Хольта (тренд) и Хольта–Уинтерса (тренд и сезонность), и как один параметр α управляет памятью модели.

## Зачем это нужно

Нужно спрогнозировать спрос на тысячи товаров на следующую неделю. Строить для каждого сложную модель долго, данных по многим товарам мало. Нужен метод, который:

- считается мгновенно;
- работает даже на коротких рядах;
- понятен человеку («прогноз — это сглаженный уровень плюс тренд плюс сезонная поправка»).

Экспоненциальное сглаживание — именно такой метод. Ему больше 60 лет, но он до сих пор входит в стандартные инструменты прогнозирования спроса и часто оказывается трудным для обыгрывания бейзлайном на соревнованиях по прогнозированию.

## Интуиция: память, которая угасает

Есть две крайние стратегии прогноза:

- **наивный прогноз** — «завтра будет как сегодня»: используем только последнее значение, вся история забыта;
- **среднее за всё время** — все наблюдения одинаково важны, даже пятилетней давности.

Обе плохи: первая слишком нервная (реагирует на каждый случайный всплеск), вторая слишком инертная (не замечает изменений). Экспоненциальное сглаживание — золотая середина: учитывает всю историю, но **веса убывают экспоненциально** в прошлое. Вчера — вес α, позавчера — α(1−α), три дня назад — α(1−α)² и так далее.

## Как это работает: простое сглаживание (SES)

Модель хранит одно число — **уровень** ℓ, текущую «сглаженную» оценку ряда. С каждым новым наблюдением уровень обновляется:

```
ℓ(t) = α · y(t) + (1 − α) · ℓ(t−1)
прогноз на любой шаг вперёд: ŷ(t+h) = ℓ(t)
```

Читается так: новый уровень — это смесь свежего факта и старого уровня. Параметр α от 0 до 1 задаёт память:

| α | поведение |
|---|---|
| близко к 1 | почти наивный прогноз, быстро реагирует, но шумит |
| около 0.1–0.3 | плавный прогноз, долгая память |
| близко к 0 | почти константа, медленно замечает изменения |

Прогноз простого сглаживания — **горизонтальная линия**: модель не знает о тренде и сезонности. Поэтому SES подходит для рядов без явного тренда, например для стабильного спроса.

На практике α подбирают автоматически, минимизируя ошибку прогноза на шаг вперёд на истории.

## Метод Хольта: добавляем тренд

Если ряд растёт, SES будет систематически отставать. **Метод Хольта** (двойное сглаживание) добавляет вторую величину — **тренд** b, сглаженную скорость изменения:

```
ℓ(t) = α · y(t) + (1 − α) · (ℓ(t−1) + b(t−1))
b(t) = β · (ℓ(t) − ℓ(t−1)) + (1 − β) · b(t−1)
прогноз: ŷ(t+h) = ℓ(t) + h · b(t)
```

Теперь прогноз — наклонная прямая. Параметр β управляет тем, как быстро модель меняет оценку наклона.

**Затухающий тренд.** Продлевать текущий тренд на год вперёд опасно: рост рано или поздно замедляется. Вариант с затуханием умножает тренд на φ < 1 на каждом следующем шаге, и прогноз постепенно выходит на плато. Эмпирически затухающий тренд часто даёт более точные долгосрочные прогнозы, чем линейный.

## Хольт–Уинтерс: добавляем сезонность

**Метод Хольта–Уинтерса** (тройное сглаживание) добавляет третью компоненту — **сезонные поправки** s для каждой позиции в сезоне (для месячных данных — 12 поправок, по одной на каждый месяц). Поправки тоже обновляются со своим параметром γ.

Сезонность бывает двух видов:

- **аддитивная**: ŷ = уровень + тренд + сезонная поправка. Подходит, когда размах сезонных колебаний постоянен («в декабре на 100 штук больше»);
- **мультипликативная**: ŷ = (уровень + тренд) × сезонный коэффициент. Подходит, когда колебания растут вместе с уровнем («в декабре на 20% больше»).

Определить вид проще всего по графику: если «волны» становятся выше с ростом ряда — сезонность мультипликативная. Альтернатива — взять логарифм ряда и использовать аддитивную модель.

## ETS: то же самое как статистическая модель

Современная формулировка всех этих методов — семейство моделей **ETS** (Error, Trend, Seasonality): каждая компонента может отсутствовать, быть аддитивной или мультипликативной, а тренд — ещё и затухающим. Статистическая формулировка даёт интервалы прогноза и позволяет выбирать вариант модели по AIC. В statsmodels это `ETSModel`, в R — функция `ets()`.

## Пример на Python

Простое сглаживание и метод Хольта на чистом NumPy:

```python
import numpy as np

y = np.array([112, 118, 132, 129, 121, 135, 148, 148, 136, 119], dtype=float)

def ses(y, alpha):
    level = y[0]
    for value in y[1:]:
        level = alpha * value + (1 - alpha) * level   # новый уровень = α·факт + (1−α)·старый
    return level                                      # прогноз на все шаги вперёд

def holt(y, alpha, beta, h):
    level, trend = y[0], y[1] - y[0]
    for value in y[1:]:
        prev = level
        level = alpha * value + (1 - alpha) * (level + trend)
        trend = beta * (level - prev) + (1 - beta) * trend
    return [level + k * trend for k in range(1, h + 1)]

for a in (0.2, 0.8):
    print(f"SES α={a}: прогноз {ses(y, a):.1f}")      # 129.9 и 122.9
print("Holt:", np.round(holt(y, 0.8, 0.2, 3), 1))     # [122.5 121.3 120.2]
```

При α = 0.2 прогноз (129.9) «помнит» высокие значения середины ряда, при α = 0.8 он ближе к последнему значению 119. Метод Хольта уловил спад последних точек и продлил его.

В statsmodels Хольт–Уинтерс с подбором параметров выглядит так:

```python
from statsmodels.tsa.holtwinters import ExponentialSmoothing

model = ExponentialSmoothing(train, trend="add", damped_trend=True,
                             seasonal="mul", seasonal_periods=12)
fitted = model.fit()                    # α, β, γ, φ подбираются автоматически
forecast = fitted.forecast(12)
```

## Подводные камни

- **Неверный вид сезонности.** Аддитивная сезонность на ряде с растущими колебаниями будет недооценивать пики. Посмотрите на график или прологарифмируйте ряд.
- **Мультипликативная модель и нули.** Мультипликативная сезонность не работает с нулевыми и отрицательными значениями — например, с редкими продажами, где много нулей. Для прерывистого спроса есть специальные методы (метод Кростона).
- **Мало сезонов.** Чтобы оценить сезонные поправки, нужно хотя бы два полных сезона данных, лучше больше.
- **Слепое продление тренда.** Линейный тренд на длинном горизонте часто завышает прогноз. Попробуйте затухающий тренд.
- **Сравнение без бейзлайна.** Сравнивайте с наивным и сезонным наивным прогнозом («как год назад»).

## Итоги

- Экспоненциальное сглаживание — взвешенное среднее прошлого с экспоненциально убывающими весами.
- SES хранит только уровень, α управляет памятью; прогноз — горизонтальная линия.
- Метод Хольта добавляет тренд (β), затухающий тренд (φ) делает долгосрочный прогноз осторожнее.
- Хольт–Уинтерс добавляет сезонность (γ), аддитивную или мультипликативную.
- ETS — статистическая формулировка того же семейства: интервалы прогноза и выбор модели по AIC.
