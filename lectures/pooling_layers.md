# Пулинг-слои (Max, Average, Global Pooling)

<!-- время: 10 мин -->

> **О чём лекция.** Зачем свёрточным сетям уменьшать карты признаков, чем max pooling отличается от average, как global average pooling заменяет огромные полносвязные слои и почему пулинг в современных сетях иногда заменяют свёрткой с шагом.

## Зачем это нужно

После свёрточного слоя карты признаков имеют почти тот же размер, что и вход. Если ничего не уменьшать, вычисления и память на глубоких слоях становятся огромными, а рецептивное поле растёт медленно — сеть так и не «увидит» объект целиком.

Пулинг (pooling, «объединение») решает это: сжимает каждую карту признаков, например вдвое по высоте и ширине. Это уменьшает вычисления в последующих слоях в 4 раза, быстро расширяет рецептивное поле и делает признаки немного устойчивее к мелким сдвигам.

## Интуиция: сводка по районам

Представьте карту города с отметками «здесь есть кафе». Вместо подробной карты вы делите город на районы 2×2 квартала и для каждого района пишете одно число:

- **max pooling** — «есть ли в районе хоть одно кафе и насколько хорошее» (берём максимум);
- **average pooling** — «сколько в среднем кафе на квартал» (берём среднее).

Для распознавания образов обычно важнее первое: признак «здесь есть глаз» сильный хотя бы в одной точке окна — значит, глаз в этом районе есть, а где именно до пикселя — уже не так важно.

## Как это работает

Окно размера k (обычно 2×2) с шагом s (обычно 2) скользит по каждой карте признаков **отдельно**, и для каждого окна считается одно число. Число каналов не меняется, меняется только высота и ширина — по той же формуле, что у свёртки:

```
выход = ⌊(вход + 2p − k) / s⌋ + 1
```

Max pooling 2×2 со stride 2 превращает тензор 64×56×56 в 64×28×28.

Важное свойство: **у пулинга нет обучаемых параметров**. Это фиксированная операция — максимум или среднее. При обратном распространении max pooling передаёт градиент только в тот элемент окна, который оказался максимальным; остальные получают ноль. Average pooling делит градиент поровну между всеми элементами окна.

## Max или average

| вид | что делает | где используют |
|---|---|---|
| Max pooling | максимум в окне | между свёрточными блоками в классических CNN (VGG, ResNet в начале сети) |
| Average pooling | среднее в окне | LeNet, сглаживание; реже между блоками |
| Global average pooling | среднее по всей карте | в конце современных CNN перед классификатором |
| Global max pooling | максимум по всей карте | когда важно «есть ли признак где-нибудь» |

Max pooling сохраняет самые сильные отклики и подавляет шум; average pooling сохраняет общий фон и сглаживает.

## Global average pooling

Global average pooling (GAP) усредняет каждую карту признаков целиком: тензор (каналы, H, W) превращается в вектор длины «каналы». У ResNet в конце 512 (у ResNet-50 — 2048) карт 7×7 → вектор из 512 (2048) чисел → линейный слой на число классов.

Почему это удобно:

- **меньше параметров**: VGG16 вытягивает 512×7×7 = 25 088 чисел в полносвязный слой на 4096 нейронов — это больше 100 миллионов весов; с GAP голова занимает лишь тысячи–миллионы;
- **меньше переобучения**: нечему переобучаться в самом пулинге;
- **любой размер входа**: после GAP длина вектора зависит только от числа каналов, поэтому сеть работает с картинками разного размера.

В PyTorch это `nn.AdaptiveAvgPool2d(1)` (выход фиксированного размера при любом входе), в Keras — `layers.GlobalAveragePooling2D()`.

## Пулинг или свёртка с шагом

Современные архитектуры часто уменьшают размер не пулингом, а свёрткой со `stride=2`: она тоже вдвое сжимает карту, но делает это обучаемо. ResNet, например, использует один max pooling в начале и свёртки с шагом 2 внутри. А global average pooling в конце остаётся почти во всех CNN.

## Пример на Python

```python
import numpy as np

x = np.array([[1, 3, 2, 4],
              [5, 6, 7, 8],
              [9, 2, 1, 3],
              [4, 5, 6, 7]], dtype=float)

def pool2d(x, size=2, mode="max"):
    h, w = x.shape[0] // size, x.shape[1] // size
    windows = x[:h * size, :w * size].reshape(h, size, w, size)
    return windows.max(axis=(1, 3)) if mode == "max" else windows.mean(axis=(1, 3))

print(pool2d(x, mode="max"))    # [[6. 8.] [9. 7.]]
print(pool2d(x, mode="avg"))    # [[3.75 5.25] [5.   4.25]]

# Сдвиг на один пиксель вправо: часть максимумов сохранилась, часть изменилась
shifted = np.roll(x, 1, axis=1)
print(pool2d(shifted, mode="max"))   # [[8. 7.] [9. 6.]]

# Global average pooling: тензор (каналы, H, W) → вектор длины «каналы»
features = np.random.default_rng(0).normal(size=(512, 7, 7))
print(features.mean(axis=(1, 2)).shape)   # (512,)
```

Пример со сдвигом показывает честную картину: устойчивость пулинга к сдвигам только *частичная*. Сдвиг внутри окна не меняет максимум, а сдвиг через границу окна — меняет. Настоящую устойчивость к сдвигам и поворотам дают аугментация и глубина сети.

## Подводные камни

- **Слишком агрессивный пулинг** теряет мелкие детали: для сегментации и детекции маленьких объектов пространственную информацию приходится восстанавливать (U-Net, FPN).
- **Нечётные размеры.** Max pooling 2×2 на карте 7×7 даёт 3×3 — последний ряд и столбец отбрасываются. Учитывайте это при расчёте размеров или используйте `ceil_mode=True`.
- **Пулинг по каналам он не делает.** Число каналов после пулинга то же; уменьшать каналы — задача свёртки 1×1.
- **Flatten вместо GAP** привязывает сеть к одному размеру входа и резко увеличивает число параметров головы.

## Итоги

- Пулинг уменьшает высоту и ширину карт признаков, не меняя число каналов, и не имеет обучаемых параметров.
- Max pooling берёт максимум и сохраняет сильные отклики; average — среднее.
- Max pooling 2×2 со stride 2 уменьшает каждую сторону вдвое, а вычисления дальше — в 4 раза.
- Global average pooling сводит каждую карту к одному числу и заменяет громоздкие полносвязные слои.
- В современных сетях между блоками часто используют свёртку со stride 2, а GAP — в конце.
