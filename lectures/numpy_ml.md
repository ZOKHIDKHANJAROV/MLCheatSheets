> **О чём лекция.** Почему всё машинное обучение в Python стоит на NumPy, как устроен массив, что такое оси и broadcasting и как писать вычисления без циклов — «векторизованно».

## Зачем это нужно

Данные в машинном обучении — это почти всегда таблица чисел: строки — объекты (клиенты, картинки, транзакции), столбцы — признаки. Модель — это тоже числа: веса, смещения, матрицы. Обучение — это миллионы арифметических операций над этими таблицами.

Обычные списки Python для этого слишком медленные: каждый элемент списка — отдельный объект, а цикл `for` на каждой итерации проверяет типы. NumPy хранит числа одним сплошным блоком памяти одного типа и выполняет операции в скомпилированном C-коде. На практике это ускоряет вычисления в десятки и сотни раз.

Поверх NumPy построены pandas, scikit-learn, matplotlib, а интерфейс тензоров PyTorch и TensorFlow почти полностью повторяет его. Кто уверенно владеет NumPy, тот легко читает код любой ML-библиотеки.

## Интуиция: массив — это таблица с формой

Главный объект — `ndarray`, многомерный массив. У него есть:

- **форма** `shape` — размеры по каждой оси, например `(1000, 20)`: 1000 объектов × 20 признаков;
- **число осей** `ndim` — 1 для вектора, 2 для матрицы, 4 для пачки цветных картинок `(батч, высота, ширина, каналы)`;
- **тип** `dtype` — один для всех элементов: `float64`, `float32`, `int64`, `bool`.

Привыкайте первым делом смотреть на `shape`. Большинство ошибок в ML-коде — это несовпадение форм: перепутали строки и столбцы, забыли, что вектор `(n,)` и матрица-столбец `(n, 1)` — разные вещи.

## Как это работает

### Оси и агрегаты

Функции вроде `sum`, `mean`, `std`, `max` принимают аргумент `axis` — ось, **вдоль которой** схлопываются значения.

```
X.shape          → (n_объектов, n_признаков)
X.mean(axis=0)   → (n_признаков,)   — среднее каждого признака по всем объектам
X.mean(axis=1)   → (n_объектов,)    — среднее по признакам для каждого объекта
```

Запомнить просто: `axis=0` «идёт вниз по строкам» и даёт по одному числу на столбец. В ML это нужно постоянно — для стандартизации, нормализации, подсчёта статистик.

### Векторизация

Векторизация — запись вычисления целиком над массивами вместо цикла по элементам. Вместо

```
for i in range(n): y_pred[i] = sum(X[i, j] * w[j] for j ...) + b
```

пишут одну строку `y_pred = X @ w + b`. Это и короче, и быстрее на порядки.

Важно различать операторы:

- `A * B` — поэлементное умножение (формы должны совпадать или быть совместимы);
- `A @ B` — матричное умножение (число столбцов `A` равно числу строк `B`).

### Broadcasting

Broadcasting — правило, по которому NumPy выполняет операции над массивами разных форм. Формы сравниваются справа налево; размеры совместимы, если они равны или один из них равен 1. Недостающие оси добавляются слева.

```
X:     (1000, 20)
mean:        (20,)    → растягивается до (1000, 20)
X - mean              → из каждой строки вычитается вектор средних
```

Именно так одной строкой делается стандартизация `(X - mean) / std`. Копии данных при этом не создаются — NumPy «виртуально» повторяет вектор.

### Индексация и маски

- `X[0]` — первая строка, `X[:, 2]` — третий столбец, `X[10:20]` — срез строк.
- `X[X[:, 0] > 60]` — **булева маска**: строки, где первый признак больше 60.
- `X[[3, 7, 1]]` — **индексация списком**: выбор строк в заданном порядке (так делают перемешивание и батчи).

## Пример на Python

Типичный «ML-набор» операций: сгенерировать данные, стандартизировать, посчитать предсказания линейной модели и отфильтровать объекты.

```python
import numpy as np

rng = np.random.default_rng(0)
X = rng.normal(loc=[50, 0.5], scale=[10, 0.1], size=(1000, 2))   # 1000 объектов × 2 признака

print(X.shape)                       # (1000, 2)
mean, std = X.mean(axis=0), X.std(axis=0)   # по столбцам: по одному числу на признак
X_std = (X - mean) / std             # broadcasting: (1000, 2) − (2,)
print(X_std.mean(axis=0).round(3), X_std.std(axis=0).round(3))   # [-0. -0.] [1. 1.]

w = np.array([2.0, -1.0])
y_pred = X_std @ w + 0.5             # предсказания для всех объектов сразу
print(y_pred.shape)                  # (1000,)

mask = X[:, 0] > 60                  # булева маска
print(mask.sum())                    # 154 — столько объектов с первым признаком > 60
```

Обратите внимание: ни одного цикла, а кодом обработана вся выборка. `-0.` — это ноль с крошечной отрицательной погрешностью вычислений, так бывает.

## Подводные камни

- **Срез — это «окно», а не копия.** `b = a[1:3]` ссылается на те же данные, и `b[0] = 100` изменит `a`. Если нужна независимая копия — `a[1:3].copy()`. Булева маска и индексация списком, наоборот, всегда создают копию.
- **`(n,)` против `(n, 1)`.** Вектор и столбец ведут себя по-разному при broadcasting: `y_pred - y`, где одна форма `(n,)`, а другая `(n, 1)`, даст матрицу `(n, n)` вместо вектора ошибок. Ошибка без исключения — только неверные числа. Используйте `ravel()` или `reshape(-1, 1)` осознанно.
- **Целочисленный тип.** `np.array([1, 2, 3])` имеет тип `int64`; запись туда `0.5` молча превратится в 0. Для данных используйте `float`.
- **Глобальный `np.random.seed`.** Современный способ — генератор `rng = np.random.default_rng(42)`: воспроизводимо и не влияет на другой код.
- **Сравнение float.** `0.1 + 0.2 == 0.3` — ложь. Для проверок используйте `np.isclose` / `np.allclose`.

## Итоги

- NumPy — фундамент ML-стека: быстрые однотипные массивы и операции в C.
- Первым делом смотрите на `shape`; `axis=0` агрегирует по объектам и даёт значение на каждый признак.
- Пишите векторизованно: `X @ w + b` вместо циклов; `*` — поэлементно, `@` — матрично.
- Broadcasting позволяет одной строкой вычитать средние, делить на std и т.п.
- Помните, что срез — это представление данных, а не копия.
