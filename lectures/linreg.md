# Линейная регрессия

<!-- время: 15 мин -->

> **О чём лекция.** Как устроена самая простая и самая важная модель машинного обучения: что она предсказывает, как находятся веса, как их интерпретировать и на каких предположениях всё держится.

## Зачем это нужно

Линейная регрессия предсказывает **число**: цену квартиры, спрос на товар, время доставки. Это одна из старейших моделей — и до сих пор одна из самых используемых:

- она быстро обучается и мгновенно предсказывает;
- её веса легко интерпретировать: «каждый квадратный метр добавляет к цене 100 тысяч»;
- она служит базовой моделью (baseline), с которой сравнивают всё остальное;
- на её идеях построены логистическая регрессия, регуляризация, нейросети — один нейрон без активации и есть линейная регрессия.

## Интуиция: лучшая прямая через облако точек

Если нарисовать цены квартир против их площади, получится облако точек, вытянутое вверх-вправо. Линейная регрессия проводит через него прямую так, чтобы точки в среднем были к ней как можно ближе. Для одного признака это прямая, для двух — плоскость, для многих — гиперплоскость.

«Как можно ближе» измеряется **остатками** — вертикальными расстояниями от точек до прямой: `y − ŷ`. Модель минимизирует сумму их квадратов.

## Как это работает

### Модель

```
ŷ = w₁x₁ + w₂x₂ + … + wₙxₙ + b = Xw + b
```

- `x₁…xₙ` — признаки объекта;
- `w₁…wₙ` — веса (коэффициенты);
- `b` — смещение (intercept): прогноз, когда все признаки равны нулю.

### Функция потерь: метод наименьших квадратов

Веса подбирают так, чтобы минимизировать среднеквадратичную ошибку:

```
MSE = (1/n) · Σ (yᵢ − ŷᵢ)²
```

Квадрат делает все ошибки положительными, сильнее штрафует большие промахи и даёт гладкую функцию с единственным минимумом — поэтому решение всегда находится.

### Как найти веса

**Аналитически.** Если добавить к X столбец единиц для смещения, минимум MSE задаётся нормальным уравнением:

```
w = (XᵀX)⁻¹ Xᵀy
```

На практике обратную матрицу явно не считают — используют численно устойчивые разложения (так делает `LinearRegression` в scikit-learn). Сложность растёт примерно как куб числа признаков, и на миллионах объектов или признаков это становится дорого.

**Градиентным спуском.** Итеративно двигают веса против градиента MSE. Это масштабируется на огромные данные, работает с мини-батчами и потоками и легко обобщается на другие функции потерь. Так обучают `SGDRegressor` и нейросети.

### Интерпретация весов

Вес `wⱼ` показывает, на сколько изменится прогноз, если увеличить признак `xⱼ` на единицу, **при прочих равных** признаках. Отсюда два следствия:

- веса признаков в разных единицах нельзя сравнивать напрямую; для сравнения важности признаки стандартизируют;
- «при прочих равных» не значит «причина»: регрессия описывает связь в данных, а не причинно-следственный эффект.

### Предположения классической модели

1. **Линейность** — зависимость цели от признаков действительно линейна (или стала такой после преобразований).
2. **Независимость** ошибок — нет, например, автокорреляции во времени.
3. **Гомоскедастичность** — разброс ошибок одинаков при всех значениях прогноза.
4. **Нормальность** ошибок — важна для доверительных интервалов и p-значений, но не для самих прогнозов.
5. **Нет сильной мультиколлинеарности** — признаки не являются почти линейными комбинациями друг друга.

Для прогнозирования важнее всего первые два пункта. Остальные критичны, если вы хотите делать статистические выводы о весах.

### Мультиколлинеарность

Если два признака почти дублируют друг друга (площадь в м² и в футах²), модель не может решить, кому отдать вес: коэффициенты становятся огромными, с разными знаками и меняются от выборки к выборке. Прогнозы при этом могут оставаться хорошими, но интерпретация разваливается. Лечение — удалить дубликаты, посмотреть на VIF, использовать Ridge-регуляризацию.

## Пример на Python

Синтетические цены квартир: истинные коэффициенты известны, проверим, найдёт ли их модель.

```python
import numpy as np
from sklearn.linear_model import LinearRegression
from sklearn.model_selection import train_test_split

rng = np.random.default_rng(0)
n = 500
area = rng.uniform(30, 120, n)                 # площадь, м²
rooms = rng.integers(1, 5, n)                  # комнат
dist = rng.uniform(1, 20, n)                   # до центра, км
price = 2.0 + 0.10 * area + 0.5 * rooms - 0.15 * dist + rng.normal(0, 0.8, n)   # млн

X = np.column_stack([area, rooms, dist])
X_tr, X_te, y_tr, y_te = train_test_split(X, price, random_state=0)
model = LinearRegression().fit(X_tr, y_tr)
print("веса:", model.coef_.round(3), "смещение:", round(model.intercept_, 2))
# веса: [ 0.1    0.565 -0.144] смещение: 1.81
print(f"R² на тесте: {model.score(X_te, y_te):.3f}")   # R² на тесте: 0.899

Xb = np.column_stack([np.ones(len(X_tr)), X_tr])     # то же через МНК вручную
w = np.linalg.lstsq(Xb, y_tr, rcond=None)[0]
print("МНК вручную:", w.round(3))                    # [ 1.806  0.1    0.565 -0.144]
```

Модель восстановила коэффициенты (0.10, 0.5, −0.15) с небольшой погрешностью из-за шума. Интерпретация: каждый метр площади добавляет около 100 тысяч, каждый километр от центра отнимает около 144 тысяч — при прочих равных.

## Подводные камни

- **Нелинейная зависимость.** Прямая на дуге даёт систематические ошибки — это видно на графике остатков. Помогают преобразования признаков (логарифм, полиномы) или нелинейные модели.
- **Выбросы.** MSE возводит ошибки в квадрат, поэтому несколько выбросов могут сильно повернуть прямую. Рассмотрите `HuberRegressor` или обработку выбросов.
- **Экстраполяция.** За пределами диапазона обучающих данных линейная модель уверенно продолжает прямую — даже если в реальности зависимость там другая.
- **Категории как числа.** Номера городов `1, 2, 3` в линейной модели означают ложный порядок; нужен one-hot.
- **Много признаков, мало объектов.** Модель переобучается, а при числе признаков больше числа объектов решение не единственно. Нужна регуляризация.
- **Сравнение весов без стандартизации** — бессмысленно.

## Итоги

- Линейная регрессия: `ŷ = Xw + b`, веса минимизируют MSE.
- Решение — нормальное уравнение (точно, для умеренных размеров) или градиентный спуск (масштабируется).
- Вес — изменение прогноза при росте признака на единицу при прочих равных; это связь, а не причина.
- Важные предположения: линейность и независимость ошибок; мультиколлинеарность ломает интерпретацию.
- Это отличный baseline и строительный блок для более сложных моделей.
