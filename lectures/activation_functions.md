# Функции активации (ReLU, Sigmoid, Tanh, Softmax)

<!-- время: 13 мин -->

> **О чём лекция.** Зачем нейросети нелинейность, чем сигмоида и tanh мешают глубоким сетям, почему ReLU стала стандартом и какую активацию ставить на выход для разных задач.

## Зачем это нужно

Функция активации — нелинейное преобразование, которое нейрон применяет к своей взвешенной сумме. Без неё любая многослойная сеть схлопывается в одну линейную модель: произведение матриц — тоже матрица. Именно активации дают сети способность строить изогнутые границы и сложные зависимости.

Выбор активации влияет не только на выразительность, но и на то, будет ли сеть вообще учиться: от формы функции зависит, дойдёт ли градиент до первых слоёв.

## Интуиция: что делает активация

Активацию удобно представлять как «кран» на выходе нейрона:

- **сигмоида** плавно открывается от 0 до 1 — похоже на вероятность;
- **tanh** — то же, но от −1 до 1, с центром в нуле;
- **ReLU** полностью закрыта для отрицательных значений и пропускает положительные без изменений.

Для обучения важна не только сама функция, но и её **производная**: при обратном распространении градиент на каждом слое умножается на производную активации. Если производная маленькая, градиент тает с каждым слоем.

## Как это работает: основные функции

| функция | формула | диапазон | производная |
|---|---|---|---|
| Sigmoid | `σ(x) = 1 / (1 + e⁻ˣ)` | (0, 1) | `σ(x)·(1 − σ(x))`, не больше 0.25 |
| Tanh | `(eˣ − e⁻ˣ) / (eˣ + e⁻ˣ)` | (−1, 1) | `1 − tanh²(x)`, не больше 1 |
| ReLU | `max(0, x)` | [0, ∞) | 1 при x > 0, 0 при x < 0 |
| Leaky ReLU | `max(αx, x)`, α ≈ 0.01 | (−∞, ∞) | 1 или α |
| GELU | `x · Φ(x)` | ≈ (−0.17, ∞) | гладкая |
| Softmax | `e^zᵢ / Σ e^zⱼ` | (0, 1), сумма = 1 | — (векторная) |

## Затухание градиента: проблема сигмоиды

У сигмоиды производная не больше 0.25, а при больших |x| (зоны насыщения) почти ноль. Градиент для первого слоя глубокой сети — произведение производных всех слоёв. Даже в лучшем случае через 20 сигмоид остаётся `0.25²⁰ ≈ 9·10⁻¹³` от исходного сигнала: первые слои практически не учатся. Это и есть **затухание градиента** (vanishing gradient).

Tanh чуть лучше: её производная в нуле равна 1, а выходы центрированы вокруг нуля. У сигмоиды выходы всегда положительны, из-за чего градиенты весов следующего слоя имеют одинаковый знак и обновления идут «зигзагом». Поэтому tanh раньше предпочитали в скрытых слоях, а сейчас её используют в основном внутри RNN и LSTM.

## ReLU и её потомки

ReLU решила проблему радикально: на положительной части производная равна ровно 1, и градиент проходит через много слоёв без затухания. Плюс она очень дешёвая — одно сравнение. Начиная с AlexNet (2012), ReLU — активация по умолчанию для скрытых слоёв.

Её слабое место — **«мёртвые нейроны»**. Если вход нейрона всегда отрицателен (например, после слишком большого шага обучения), выход всегда 0, градиент всегда 0, и нейрон больше никогда не обновится. Лекарства:

- **Leaky ReLU** — небольшой наклон α при x < 0, градиент не обнуляется; популярна в GAN;
- **ELU** — гладкая экспоненциальная ветвь для отрицательных значений;
- **GELU** — гладкая функция `x·Φ(x)`, где Φ — функция распределения стандартной нормальной величины; стандарт в трансформерах (BERT, GPT);
- **SiLU/Swish** — `x·σ(x)`, используется в EfficientNet и многих современных сетях.

## Активации на выходе

Выходной слой выбирают по задаче, а не по моде:

- **регрессия** — без активации (линейный выход);
- **бинарная классификация** — sigmoid: один выход, вероятность класса 1;
- **многоклассовая** — softmax: вектор вероятностей, сумма которых 1;
- **multi-label** (несколько меток сразу) — sigmoid на каждый выход.

Softmax превращает логиты в распределение: большие логиты получают большую долю, но все вероятности положительны. Её применяют и внутри механизма внимания, чтобы получить веса, суммирующиеся в 1.

## Пример на Python

```python
import numpy as np

def sigmoid(z): return 1 / (1 + np.exp(-z))
def relu(z): return np.maximum(0, z)

z = np.array([-5.0, -1.0, 0.0, 1.0, 5.0])
print("sigmoid :", sigmoid(z).round(3))                         # [0.007 0.269 0.5 0.731 0.993]
print("σ'(z)   :", (sigmoid(z) * (1 - sigmoid(z))).round(3))    # [0.007 0.197 0.25 0.197 0.007]
print("relu    :", relu(z))                                     # [0. 0. 0. 1. 5.]
print("relu'(z):", (z > 0).astype(float))                       # [0. 0. 0. 1. 1.]

# Градиент, прошедший через 20 слоёв: перемножаются производные активаций
print("20 сигмоид, лучший случай:", 0.25 ** 20)                 # ≈ 9.1e-13
print("20 ReLU на активной части:", 1.0 ** 20)                  # 1.0

logits = np.array([2.0, 1.0, 0.1])
p = np.exp(logits - logits.max()); p /= p.sum()                 # вычитаем максимум — защита от переполнения
print("softmax:", p.round(3), "сумма:", p.sum())                # [0.659 0.242 0.099] сумма: 1.0
```

В PyTorch активации — это `nn.ReLU()`, `nn.GELU()`, `nn.Sigmoid()` или функции `torch.relu`, `F.gelu`; в Keras — аргумент `activation="relu"` у слоя.

## Подводные камни

- **Двойной softmax.** `nn.CrossEntropyLoss` в PyTorch сама применяет softmax. Если поставить softmax и в модели, обучение станет медленнее и хуже.
- **Сигмоида в скрытых слоях глубокой сети** — почти гарантированное затухание градиента. В скрытых слоях берите ReLU/GELU.
- **Мёртвые ReLU** появляются при слишком большом learning rate. Если большая доля нейронов всегда выдаёт ноль — уменьшите шаг или возьмите Leaky ReLU.
- **Наивный softmax переполняется** при больших логитах (`e¹⁰⁰⁰ = inf`). Вычитание максимума не меняет результат, но спасает от `nan`.
- **Инициализация согласуется с активацией**: для ReLU — He (Kaiming), для tanh/sigmoid — Xavier (Glorot).

## Итоги

- Активации дают сети нелинейность; без них многослойная сеть эквивалентна линейной модели.
- Сигмоида и tanh насыщаются, их малые производные вызывают затухание градиента в глубоких сетях.
- ReLU — стандарт для скрытых слоёв: дешёвая и не гасит градиент, но может давать «мёртвые» нейроны.
- Leaky ReLU, ELU, GELU, SiLU сглаживают недостатки ReLU; GELU — стандарт в трансформерах.
- На выходе: линейная для регрессии, sigmoid для бинарной, softmax для многоклассовой классификации.
