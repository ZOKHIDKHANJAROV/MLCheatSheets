# Деревья решений для классификации

<!-- время: 15 мин -->

> **О чём лекция.** Как модель из простых вопросов «признак больше порога?» учится классифицировать, как дерево выбирает лучший вопрос с помощью Джини и энтропии, почему глубокое дерево переобучается и как его ограничить.

## Зачем это нужно

Дерево решений — модель, которую можно нарисовать на листе бумаги и показать кому угодно. «Если доход меньше 30 тысяч и есть просрочки — отказать. Иначе, если стаж больше трёх лет — одобрить». Именно так люди часто и принимают решения, поэтому деревья легко объяснять и проверять экспертам.

Но главное значение деревьев — в другом: они **строительный блок** самых сильных моделей для табличных данных. Случайный лес, градиентный бустинг, XGBoost, LightGBM и CatBoost — это ансамбли деревьев. Чтобы понимать их, нужно сначала понять одно дерево.

## Интуиция: игра в «20 вопросов»

Вы загадываете животное, я задаю вопросы с ответами «да/нет». Хорошая стратегия — задавать вопросы, которые сильнее всего сокращают неопределённость. «Это млекопитающее?» лучше, чем «Это жираф?»: первый вопрос делит варианты примерно пополам, второй почти ничего не даёт.

Дерево решений играет в ту же игру с данными. В каждом узле оно выбирает вопрос вида «признак xⱼ ≤ t?», после которого объекты в двух ветках становятся как можно более **однородными** по классу. Потом повторяет то же самое внутри каждой ветки. В **листьях** — конечных узлах — стоит ответ: самый частый класс среди попавших туда обучающих объектов (а доли классов дают вероятность).

## Как это работает

Нужна мера «неоднородности» (impurity) узла. Пусть pₖ — доля класса k в узле.

```
Джини:    G = 1 − Σ pₖ²
Энтропия: H = −Σ pₖ · log₂ pₖ
```

Обе меры равны нулю, если в узле один класс, и максимальны при равной смеси. Для двух классов:

| смесь в узле | Джини | энтропия |
|---|---|---|
| 100 / 0 | 0 | 0 |
| 90 / 10 | 0.18 | 0.469 |
| 50 / 50 | 0.5 | 1.0 |

**Выбор разбиения.** Алгоритм (в sklearn — CART) перебирает все признаки и все возможные пороги и для каждого варианта считает, насколько уменьшится неоднородность:

```
Прирост = Impurity(родитель) − (n_лев/n · Impurity(левый) + n_прав/n · Impurity(правый))
```

Выбирается разбиение с максимальным приростом. При энтропии этот прирост называют **information gain**. Затем алгоритм рекурсивно повторяет процедуру для каждой ветки. Это **жадный** алгоритм: в каждом узле выбирается лучший вопрос «здесь и сейчас», без попытки найти лучшее дерево целиком (это вычислительно невозможно).

**Джини или энтропия?** На практике разница минимальна: деревья получаются почти одинаковыми. Джини чуть быстрее (нет логарифма) и используется в sklearn по умолчанию.

Для **регрессии** дерево устроено так же, только мерой неоднородности служит дисперсия (MSE) ответа в узле, а в листе предсказывается среднее значение.

## Переобучение и как его ограничить

Без ограничений дерево растёт, пока в каждом листе не останется один класс — часто это один-два объекта. Такое дерево идеально запоминает обучающую выборку вместе с шумом и плохо работает на новых данных. Одиночные деревья — классический пример модели с **высокой дисперсией**: небольшое изменение данных может полностью поменять структуру дерева.

Способы ограничения (**предварительная обрезка**):

- `max_depth` — максимальная глубина, обычно 3–10;
- `min_samples_leaf` — минимум объектов в листе (например, 10–50): запрещает листья из пары объектов;
- `min_samples_split` — минимум объектов в узле, чтобы его разрезать;
- `max_leaf_nodes` — максимум листьев.

Есть и **последующая обрезка**: вырастить большое дерево и удалить ветки, которые мало помогают. В sklearn это `ccp_alpha` (cost-complexity pruning): чем больше значение, тем сильнее обрезка. Параметры подбирают кросс-валидацией.

## Пример на Python

Данные «две луны» с шумом: классы разделяет изогнутая граница.

```python
from sklearn.datasets import make_moons
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, export_text

X, y = make_moons(n_samples=500, noise=0.3, random_state=0)
X_tr, X_te, y_tr, y_te = train_test_split(X, y, random_state=0)

for depth in [1, 3, 5, None]:
    tree = DecisionTreeClassifier(max_depth=depth, random_state=0).fit(X_tr, y_tr)
    print(f"max_depth={depth}: train {tree.score(X_tr, y_tr):.3f}, "
          f"test {tree.score(X_te, y_te):.3f}, листьев {tree.get_n_leaves()}")

# max_depth=1: train 0.824, test 0.784, листьев 2
# max_depth=3: train 0.901, test 0.864, листьев 6
# max_depth=5: train 0.909, test 0.856, листьев 14
# max_depth=None: train 1.000, test 0.856, листьев 49

small = DecisionTreeClassifier(max_depth=2, random_state=0).fit(X_tr, y_tr)
print(export_text(small, feature_names=["x1", "x2"]))
# |--- x2 <= 0.20
# |   |--- x1 <= -0.59
# |   |   |--- class: 0
# |   |--- x1 >  -0.59
# |   |   |--- class: 1
# |--- x2 >  0.20
# ...
```

Неограниченное дерево вырастило 49 листьев и выучило обучающую выборку на 100%, но на тесте не лучше, чем дерево из 6 листьев. Дерево глубины 1 («пень») слишком простое. `export_text` показывает правила — их можно прочитать как обычные if-else.

## Плюсы и минусы

| плюсы | минусы |
|---|---|
| понятные правила, легко объяснить | склонность к переобучению |
| не нужно масштабирование признаков | неустойчивость: небольшое изменение данных меняет дерево |
| ловит нелинейности и взаимодействия признаков | ступенчатые границы, параллельные осям; плохо описывает диагональные границы |
| быстро обучается и предсказывает | одно дерево обычно уступает ансамблям по качеству |
| работает с числовыми признаками любого масштаба | не умеет экстраполировать: в регрессии прогноз не выходит за диапазон обучающих ответов |

## Подводные камни

- **Масштабирование не нужно**: разбиение «x ≤ t» не меняется при монотонном преобразовании признака. Это частый вопрос на собеседованиях.
- **Категориальные признаки** в sklearn нужно закодировать. One-hot для признака с сотнями категорий делает дерево глубоким и неудобным; иногда лучше target/ordinal-кодирование или бустинги с нативной поддержкой категорий.
- **Важность признаков по impurity** (`feature_importances_`) завышает признаки с большим числом уникальных значений. Надёжнее permutation importance.
- **Дисбаланс классов**: дерево может просто не строить ветки для редкого класса. Помогает `class_weight="balanced"`.
- **Глубина без ограничений** почти всегда означает переобучение. Начинайте с `max_depth` 3–6 и `min_samples_leaf` порядка нескольких десятков.

## Итоги

- Дерево решений задаёт последовательность вопросов «xⱼ ≤ t?», в листьях — ответ.
- Разбиение выбирается жадно по максимальному уменьшению неоднородности: Джини или энтропии (для регрессии — дисперсии).
- Неограниченное дерево запоминает данные; ограничивайте глубину, размер листа или используйте обрезку `ccp_alpha`.
- Деревья не требуют масштабирования, ловят нелинейности, легко интерпретируются, но неустойчивы.
- Одиночное дерево — основа случайного леса и градиентного бустинга.
