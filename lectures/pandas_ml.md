> **О чём лекция.** Как с помощью pandas загрузить, осмотреть, почистить и подготовить табличные данные к обучению модели — и каких ловушек при этом избегать.

## Зачем это нужно

Реальные данные редко приходят в виде аккуратной числовой матрицы. Это CSV-выгрузки, таблицы из баз данных, Excel-файлы: со строковыми столбцами, датами, пропусками, дубликатами и опечатками. Прежде чем отдать данные модели, их нужно понять и привести в порядок. Говорят, что на подготовку данных уходит большая часть времени ML-проекта, — и почти вся эта работа делается в pandas.

Pandas даёт два главных объекта:

- **`Series`** — один столбец значений с индексом;
- **`DataFrame`** — таблица из именованных столбцов, у каждого свой тип.

Внутри pandas опирается на NumPy, поэтому операции над целыми столбцами выполняются быстро, а `df.to_numpy()` превращает таблицу в массив для модели.

## Интуиция: таблица с подписями

Если NumPy-массив — это «голые» числа, то DataFrame — та же таблица, но с подписями: у строк есть индекс, у столбцов — имена, а у каждого столбца свой тип. Поэтому можно писать `df["age"]` вместо «второй столбец», хранить в одной таблице числа, строки и даты, а при объединении таблиц pandas сам сопоставит строки по ключам.

Типичный путь данных в ML-проекте выглядит так: загрузить → осмотреть → почистить → создать признаки → разделить на `X` и `y` → отдать в scikit-learn.

## Как это работает

### Загрузка и первый осмотр

```
df = pd.read_csv("data.csv")   # также read_parquet, read_excel, read_sql
df.shape                        # (строки, столбцы)
df.head()                       # первые строки
df.info()                       # типы столбцов и число непустых значений
df.describe()                   # статистики числовых столбцов
df.isna().sum()                 # пропуски по столбцам
```

Эти пять команд стоит запускать на любом новом датасете. `info()` сразу покажет, что столбец с ценами прочитался как `object` (строки) из-за пары «грязных» значений, а `describe()` — что минимальный возраст равен −1.

### Выбор данных: `loc` и `iloc`

- `df.loc[строки, столбцы]` — выбор **по меткам**: `df.loc[df["age"] > 30, ["age", "city"]]`.
- `df.iloc[строки, столбцы]` — выбор **по позициям**: `df.iloc[:100, :3]`.

Фильтрация булевой маской — самый частый приём: `df[df["city"] == "Казань"]`.

### Пропуски

`df.dropna()` удаляет строки с пропусками, `df["age"].fillna(df["age"].median())` заполняет медианой. Удалять стоит, только если пропусков мало и они случайны; иначе заполняют и иногда добавляют признак «значение было пропущено».

### Группировка и объединение

`groupby` разбивает таблицу на группы по значению столбца, считает статистику в каждой и собирает результат: «средний чек по городам» — это `df.groupby("city")["check"].mean()`. Так строят агрегированные признаки: средняя сумма покупок клиента, число заказов за месяц.

Для объединения таблиц:

- `pd.merge(left, right, on="user_id", how="left")` — соединение по ключу, как JOIN в SQL;
- `pd.concat([df1, df2])` — склеивание таблиц друг под другом (или рядом при `axis=1`).

### Подготовка к модели

Модели scikit-learn ждут числа. Категориальные столбцы превращают в числовые (например, `pd.get_dummies` делает one-hot кодирование), даты раскладывают на компоненты (`df["date"].dt.month`, `dt.dayofweek`), затем отделяют цель: `X = df.drop(columns="target")`, `y = df["target"]`.

## Пример на Python

Сгенерируем «клиентскую» таблицу, найдём и заполним пропуски, посчитаем статистику по группам и подготовим `X` и `y`.

```python
import numpy as np
import pandas as pd

rng = np.random.default_rng(1)
df = pd.DataFrame({
    "city": rng.choice(["Москва", "Казань", "Самара"], size=200),
    "age": rng.integers(18, 70, size=200).astype(float),
    "check": rng.gamma(2.0, 500, size=200).round(0),
})
df.loc[rng.choice(200, size=15, replace=False), "age"] = np.nan

print(df.shape)                            # (200, 3)
print(df.isna().sum()["age"])              # 15
df["age"] = df["age"].fillna(df["age"].median())

stats = df.groupby("city")["check"].agg(["mean", "count"]).round(1)
print(stats)                               # средний чек и число клиентов по городам

df["is_big"] = (df["check"] > 1500).astype(int)   # новый бинарный признак-цель
X = pd.get_dummies(df[["age", "city"]], columns=["city"], dtype=int)
y = df["is_big"]
print(X.columns.tolist())   # ['age', 'city_Казань', 'city_Москва', 'city_Самара']
```

## Подводные камни

- **`SettingWithCopyWarning`.** Запись в результат фильтрации (`df[df.age > 30]["x"] = 0`) может изменить временную копию, а не исходную таблицу. Пишите явно: `df.loc[df.age > 30, "x"] = 0`, а для отдельной таблицы делайте `.copy()`.
- **`inplace=True` и цепочки.** `df["age"].fillna(..., inplace=True)` в новых версиях pandas может не изменить `df`. Надёжнее присваивать: `df["age"] = df["age"].fillna(...)`.
- **Статистики по всей таблице до разбиения.** Если заполнить пропуски медианой всего датасета и только потом разделить на train/test, тест «подсмотрен». Статистики для заполнения считают на обучающей части — удобнее всего внутри `Pipeline` scikit-learn.
- **`merge` размножает строки.** Если ключ в правой таблице не уникален, строк станет больше. После `merge` сверяйте `shape`; параметр `validate="many_to_one"` поймает это сразу.
- **Типы.** Числа, прочитанные как строки, ломают и `describe()`, и модели. Используйте `pd.to_numeric(..., errors="coerce")` и проверяйте `dtypes`.
- **`get_dummies` на train и test по отдельности** даст разные наборы столбцов. В продакшене используйте `OneHotEncoder` из scikit-learn, который запоминает категории.

## Итоги

- DataFrame — таблица с именованными столбцами разных типов; основа подготовки данных.
- Осмотр нового датасета: `shape`, `head`, `info`, `describe`, `isna().sum()`.
- `loc` — по меткам, `iloc` — по позициям; фильтрация — булевыми масками.
- `groupby` строит агрегированные признаки, `merge` и `concat` объединяют таблицы.
- Статистики для очистки считайте только на обучающих данных, а изменения записывайте через `loc`.
