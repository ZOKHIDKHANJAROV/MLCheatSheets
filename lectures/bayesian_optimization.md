> **О чём лекция.** Как искать минимум функции, каждое вычисление которой стоит минуты или часы: строим дешёвую вероятностную модель-заменитель, она говорит, где минимум вероятен и где мы ещё мало знаем, и следующую точку выбираем с умом. Разберём суррогатную модель, функции выбора и баланс исследования и использования.

## Зачем это нужно

Подбор гиперпараметров — это минимизация функции f(x), где x — набор гиперпараметров, а f — ошибка на кросс-валидации. У этой функции неприятные свойства:

- **дорогая**: одно вычисление — обучение модели, иногда несколько часов;
- **чёрный ящик**: формулы и градиента нет, видим только значения в точках;
- **шумная**: CV-оценка немного меняется от разбиения.

Grid и Random Search тратят пробы вслепую: следующая точка никак не зависит от того, что мы уже узнали. Если каждая проба стоит час, это расточительно. **Байесовская оптимизация** использует все прошлые результаты, чтобы выбрать следующую точку, и обычно находит хорошее решение за десятки вычислений вместо сотен. Применяется для гиперпараметров, настройки экспериментов, проектирования материалов — везде, где пробы дороги.

## Интуиция: поиск нефти

Геолог ищет нефть, каждая скважина стоит миллион. После нескольких скважин у него есть представление: «здесь, скорее всего, пусто; там было неплохо, рядом, вероятно, тоже; а вот в том углу мы вообще не бурили — может быть что угодно». Следующую скважину он ставит либо рядом с лучшей находкой (**использование**, exploitation), либо в неисследованном месте, где может оказаться ещё лучше (**исследование**, exploration).

Байесовская оптимизация формализует именно это:

- **суррогатная модель** — представление геолога: прогноз f(x) в каждой точке *вместе с неуверенностью*;
- **функция выбора (acquisition function)** — правило, куда бурить дальше, взвешивающее «вероятно хорошо» и «мы мало знаем».

## Как это работает

Алгоритм:

1. Вычислить f в нескольких случайных начальных точках.
2. Обучить суррогатную модель на всех парах (x, f(x)).
3. Найти точку, где функция выбора максимальна. Это дешёвая задача: суррогат считается мгновенно.
4. Вычислить настоящую f в этой точке и добавить результат к данным.
5. Повторять шаги 2–4, пока не кончится бюджет.

**Суррогат — гауссовский процесс (GP).** GP — это модель, которая для любой точки x выдаёт не одно число, а нормальное распределение: среднее μ(x) (прогноз) и стандартное отклонение σ(x) (неуверенность). Рядом с уже вычисленными точками σ мало, вдали — велико. Насколько далеко «распространяется» знание о точке, определяет ядро (например, Matern или RBF) — его параметры GP подбирает сам.

**Функции выбора** (для минимизации, f* — лучшее найденное значение):

| функция | идея |
|---|---|
| Probability of Improvement (PI) | вероятность, что f(x) < f* |
| Expected Improvement (EI) | ожидаемый размер улучшения — учитывает не только «улучшит ли», но и «насколько» |
| Lower Confidence Bound (LCB) | `μ(x) − κ·σ(x)`: оптимистичная оценка, κ регулирует смелость |

EI — самая популярная:

```
z = (f* − μ(x)) / σ(x)
EI(x) = (f* − μ(x)) · Φ(z) + σ(x) · φ(z)
```

Φ и φ — функция распределения и плотность стандартного нормального. Первое слагаемое большое там, где прогноз хорош (использование), второе — там, где велика неуверенность (исследование). Баланс получается сам собой.

## Варианты суррогатов

GP хорош для малого числа непрерывных параметров (до 10–20) и сотен точек: его стоимость растёт как куб числа точек. Для смешанных пространств (целые, категориальные, условные параметры) используют другие суррогаты:

- **TPE** (Tree-structured Parzen Estimator) — моделирует, как выглядят «хорошие» и «плохие» x; используется в Optuna и Hyperopt;
- **случайный лес** — в SMAC;
- **деревья с бустингом** — в некоторых AutoML-системах.

## Пример на Python

Байесовская оптимизация «с нуля» на scikit-learn: гауссовский процесс + Expected Improvement для функции одной переменной.

```python
import numpy as np
from scipy.stats import norm
from sklearn.gaussian_process import GaussianProcessRegressor
from sklearn.gaussian_process.kernels import Matern

def f(x):                                    # «дорогая» функция, например CV-ошибка
    return np.sin(3 * x) + 0.3 * (x - 1) ** 2

grid = np.linspace(-2, 3, 500).reshape(-1, 1)
rng = np.random.default_rng(0)
X = rng.uniform(-2, 3, size=(3, 1))          # 3 стартовые случайные точки
y = f(X).ravel()

for step in range(10):
    gp = GaussianProcessRegressor(Matern(nu=2.5), normalize_y=True, alpha=1e-6).fit(X, y)
    mu, sigma = gp.predict(grid, return_std=True)
    z = (y.min() - mu) / np.maximum(sigma, 1e-9)
    ei = (y.min() - mu) * norm.cdf(z) + sigma * norm.pdf(z)
    x_next = grid[np.argmax(ei)]             # следующая точка — максимум EI
    X = np.vstack([X, x_next]); y = np.append(y, f(x_next))

print(f"x={X[y.argmin(), 0]:.3f}, f={y.min():.3f} за {len(y)} вычислений")
# x=1.537, f=-0.908 за 13 вычислений — ровно истинный минимум на сетке
```

У функции несколько локальных минимумов, но за 13 вычислений найден глобальный. Случайному поиску для такой точности понадобились бы сотни проб.

## Подводные камни

- **Размерность.** GP плохо работает больше чем с ~20 параметрами: «исследовать» многомерное пространство трудно. Отберите самые важные гиперпараметры.
- **Последовательность.** Классическая версия выбирает по одной точке и плохо параллелится. Для параллельного запуска есть пакетные варианты, но выигрыш у случайного поиска при большом числе машин уменьшается.
- **Шкалы.** Learning rate и регуляризацию задавайте в логарифмической шкале, иначе суррогату трудно.
- **Слишком жадная функция выбора.** PI и LCB с малым κ застревают у первого найденного минимума. EI или LCB с κ ≈ 2 — разумный старт.
- **Не волшебство.** При дешёвой функции (секунды на вычисление) накладные расходы на суррогат не окупаются, и Random Search с большим бюджетом не хуже.

## Итоги

- Байесовская оптимизация — для дорогих функций-чёрных ящиков, в первую очередь для подбора гиперпараметров.
- Суррогатная модель (обычно гауссовский процесс) даёт прогноз и неуверенность в каждой точке.
- Функция выбора (EI, PI, LCB) балансирует исследование неизвестных областей и использование хороших.
- Каждая следующая проба учитывает все предыдущие — поэтому нужно намного меньше вычислений, чем при случайном поиске.
- TPE (Optuna, Hyperopt) — тот же подход с другим суррогатом, удобный для смешанных пространств.
