# Обратное распространение ошибки (Backpropagation)

<!-- время: 18 мин -->

> **О чём лекция.** Как нейросеть узнаёт, какой из миллионов весов виноват в ошибке: прямой и обратный проход, цепное правило, почему это дёшево и откуда берутся затухание и взрыв градиентов.

## Зачем это нужно

Градиентный спуск требует градиент функции потерь по **каждому** параметру. У сети миллионы весов, и считать производную по каждому отдельно — немыслимо дорого. Обратное распространение ошибки (backpropagation) вычисляет все эти производные за один проход от выхода к входу, примерно за ту же цену, что и само предсказание.

Именно этот алгоритм сделал обучение многослойных сетей практичным. Сегодня его выполняет автодифференцирование — `loss.backward()` в PyTorch или `GradientTape` в TensorFlow, — но понимать, что происходит внутри, нужно, чтобы разбираться с затуханием градиентов, `nan` и странным поведением обучения.

## Интуиция: кто виноват в ошибке

Представьте сборочный конвейер из нескольких цехов. На выходе обнаружили брак. Чтобы исправить процесс, нужно понять вклад каждого цеха. Последний цех видно сразу. Вклад предпоследнего — это его влияние на последний цех, умноженное на то, насколько последний цех влияет на брак. И так по цепочке назад.

Backpropagation делает то же: начинает с ошибки на выходе и шаг за шагом передаёт «долю вины» назад, к более ранним слоям, умножая на локальные производные.

## Как это работает: цепное правило

Основа — правило дифференцирования сложной функции. Если `z = f(y)`, а `y = g(x)`, то

```
∂z/∂x = (∂z/∂y) · (∂y/∂x)
```

Нейросеть — длинная композиция функций: линейный слой, активация, снова линейный слой, функция потерь. Производная потерь по весу первого слоя — произведение локальных производных вдоль пути от этого веса до потерь.

Обучение состоит из двух проходов:

1. **Прямой проход (forward).** Данные идут от входа к выходу, на каждом слое считаются и **сохраняются** промежуточные значения (входы слоёв, активации). В конце считаются потери.
2. **Обратный проход (backward).** Начинаем с `∂L/∂ŷ` и идём назад. На каждом слое из градиента по его выходу получаем градиент по его весам (для обновления) и по его входу (для передачи дальше назад).

Промежуточные значения сохраняют потому, что они нужны в формулах обратного прохода: например, производная tanh равна `1 − tanh²(z)`, а градиент по весам линейного слоя — `входᵀ · градиент_выхода`. Отсюда и большой расход памяти при обучении по сравнению с предсказанием.

## Формулы для одного слоя

Для линейного слоя `z = h·W + b` с известным градиентом `δ = ∂L/∂z`:

```
∂L/∂W = hᵀ · δ          # градиент по весам — для обновления
∂L/∂b = сумма δ по батчу
∂L/∂h = δ · Wᵀ          # градиент по входу — передаём в предыдущий слой
```

Для поэлементной активации `h = f(z)`: `∂L/∂z = ∂L/∂h ⊙ f′(z)` (⊙ — поэлементное умножение). Удобный частный случай: sigmoid вместе с бинарной кросс-энтропией даёт на логите просто `p − y`.

## Почему это эффективно

Наивный способ — сдвинуть один вес на крошечное ε и посмотреть, как изменились потери, — требует отдельного прямого прохода на каждый вес: миллион весов — миллион проходов. Backpropagation переиспользует общие части цепочек: градиент слоя считается один раз и используется для всех весов перед ним. Весь обратный проход стоит примерно как два-три прямых.

Тот самый наивный способ всё же полезен — для **проверки градиентов** (gradient check): если пишете свой слой, сравните аналитический градиент с численным `(L(w+ε) − L(w−ε)) / 2ε` на паре весов.

## Затухание и взрыв градиентов

Градиент для ранних слоёв — произведение многих множителей: весов и производных активаций. Если множители в среднем меньше 1, произведение экспоненциально стремится к нулю — **затухание**, ранние слои не учатся. Если больше 1 — **взрыв**, градиенты становятся огромными, потери превращаются в `nan`.

Что помогает:

- **ReLU** вместо сигмоиды в скрытых слоях (производная 1 на активной части);
- **правильная инициализация** весов (He для ReLU, Xavier для tanh), чтобы масштаб сигнала сохранялся от слоя к слою;
- **нормализация** (BatchNorm, LayerNorm);
- **residual-связи** (ResNet, трансформеры): градиент проходит в обход слоёв;
- **gradient clipping** — обрезка нормы градиента, особенно в RNN.

## Пример на Python

Двухслойная сеть на NumPy с ручным обратным проходом учит XOR — задачу, которую один нейрон не решает:

```python
import numpy as np

rng = np.random.default_rng(0)
X = np.array([[0, 0], [0, 1], [1, 0], [1, 1]], dtype=float)
y = np.array([[0], [1], [1], [0]], dtype=float)       # XOR

W1, b1 = rng.normal(size=(2, 8)), np.zeros(8)
W2, b2 = rng.normal(size=(8, 1)), np.zeros(1)
sigmoid = lambda z: 1 / (1 + np.exp(-z))
lr = 0.5

for epoch in range(5000):
    # прямой проход: сохраняем промежуточные значения
    z1 = X @ W1 + b1
    h = np.tanh(z1)
    p = sigmoid(h @ W2 + b2)
    loss = -np.mean(y * np.log(p) + (1 - y) * np.log(1 - p))

    # обратный проход: цепное правило от выхода к входу
    dz2 = (p - y) / len(X)              # sigmoid + BCE дают простую производную
    dW2, db2 = h.T @ dz2, dz2.sum(0)
    dh = dz2 @ W2.T
    dz1 = dh * (1 - h ** 2)             # производная tanh
    dW1, db1 = X.T @ dz1, dz1.sum(0)

    W1 -= lr * dW1; b1 -= lr * db1
    W2 -= lr * dW2; b2 -= lr * db2
    if epoch % 1000 == 0:
        print(epoch, round(loss, 4))    # 0.7414 → 0.0029 → … → 0.0006

print(p.round(2).ravel())   # [0. 1. 1. 0.]
```

В PyTorch весь обратный проход заменяется одной строкой `loss.backward()`: фреймворк сам запоминает граф вычислений при прямом проходе и применяет цепное правило.

## Подводные камни

- **`optimizer.zero_grad()`.** PyTorch *накапливает* градиенты в `.grad`. Если не обнулять их перед `loss.backward()`, градиенты разных батчей складываются, и шаги становятся неверными.
- **Память.** Сохранённые активации занимают основную память при обучении. Меньший батч, mixed precision или gradient checkpointing (пересчёт части активаций) помогают уместиться в GPU.
- **`nan` в потерях** — часто взрыв градиентов: уменьшите learning rate, включите clipping, проверьте `log(0)` и деление на ноль.
- **Отключайте градиенты на инференсе** (`torch.no_grad()`): граф не строится, памяти и времени уходит меньше.
- **Самописные слои** проверяйте численным градиентом — ошибка в формуле обратного прохода не вызывает исключения, сеть просто плохо учится.

## Итоги

- Backpropagation вычисляет градиенты по всем весам за один обратный проход, применяя цепное правило от выхода к входу.
- Прямой проход сохраняет промежуточные значения — они нужны обратному проходу.
- Стоимость обратного прохода сопоставима с прямым, а не растёт с числом весов.
- Градиент ранних слоёв — произведение многих множителей, отсюда затухание и взрыв; лечат ReLU, инициализацией, нормализацией, residual-связями и clipping.
- В фреймворках это делает автодифференцирование: `zero_grad()` → `backward()` → `step()`.
