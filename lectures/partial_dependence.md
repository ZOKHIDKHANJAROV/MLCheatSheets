# Частичные зависимости (Partial Dependence Plots)

<!-- время: 14 мин -->

> **О чём лекция.** Как увидеть *форму* влияния признака на прогноз модели: растёт ли прогноз линейно, выходит ли на плато, есть ли порог. Разберём построение PDP, кривые ICE для отдельных объектов и главную ловушку метода — коррелированные признаки.

## Зачем это нужно

Важность признаков отвечает на вопрос «насколько признак важен», но не «как он влияет». Модель кредитного скоринга может сильно опираться на возраст — но риск падает с возрастом монотонно? Или есть минимум в 40 лет? Или резкий скачок на 18? Для линейной модели ответ — коэффициент, а для бустинга или нейросети нужен инструмент, который покажет зависимость прогноза от признака графиком.

**Partial Dependence Plot** (Фридман, 2001) — такой инструмент. Он глобальный (одна кривая для всей модели) и model-agnostic (нужен только `predict`). Его используют, чтобы проверить, что модель ведёт себя разумно («цена растёт с площадью»), найти пороги и насыщения и объяснить модель людям.

## Интуиция: «что если» для всех сразу

Возьмём всех клиентов из выборки и спросим модель: «а что, если бы у *каждого* возраст был 25?» — получим прогнозы и усредним. Потом то же для 30, 35, 40 и так далее. Получится кривая: как в среднем меняется прогноз, если менять только возраст, а всё остальное у людей оставить как есть. Это и есть частичная зависимость.

## Как это работает

Определение: пусть x_S — интересующий признак, x_C — все остальные. Частичная зависимость — среднее предсказание по распределению остальных признаков:

```
PD_S(v) = E_{X_C}[ f(v, X_C) ]
```

Оценка по выборке из n объектов:

```
PD̂_S(v) = (1/n) · Σᵢ f(v, x_C⁽ⁱ⁾)
```

Алгоритм:

1. Выбрать признак j и сетку значений v₁…v_G — обычно равномерно между 5-м и 95-м перцентилями или по квантилям.
2. Для каждого v_g: скопировать датасет, во всех строках заменить признак j на v_g, получить предсказания модели и усреднить.
3. Нарисовать точки (v_g, среднее) — это PDP.

Для линейной модели PDP — прямая с наклоном, равным коэффициенту; для деревьев — ступеньки. Для классификации обычно рисуют вероятность (или логит) нужного класса.

**Двумерный PDP** — то же для пары признаков, на сетке v × u; рисуется тепловой картой и показывает взаимодействия.

## ICE: не усреднять

Усреднение может спрятать важное. Пусть для половины объектов прогноз растёт с признаком, а для другой половины — падает. Средняя кривая будет плоской, и PDP скажет «признак не влияет» — неправда.

**ICE-кривые** (Individual Conditional Expectation) показывают зависимость для каждого объекта отдельно, без усреднения: f(v, x_C⁽ⁱ⁾) как функция v. PDP — их среднее. Если ICE-кривые параллельны, взаимодействий нет и PDP хорошо всё описывает. Если они расходятся веером или пересекаются — признак взаимодействует с другими, и одной средней кривой мало.

Полезный приём — **центрированные ICE (c-ICE)**: из каждой кривой вычитают её значение в левой точке сетки. Тогда все кривые стартуют из нуля, и различия в наклоне видны лучше.

## Пример на Python

Модель обучена на данных `y = x0² + 2·x1 + x1·x2 + шум`. Ожидаем: PDP по x0 — парабола; влияние x1 зависит от x2 (взаимодействие).

```python
import numpy as np
from sklearn.ensemble import HistGradientBoostingRegressor
from sklearn.inspection import partial_dependence

rng = np.random.default_rng(0)
X = rng.uniform(-2, 2, size=(3000, 3))
y = X[:, 0] ** 2 + 2 * X[:, 1] + X[:, 1] * X[:, 2] + rng.normal(scale=0.2, size=3000)
model = HistGradientBoostingRegressor(random_state=0).fit(X, y)

pd0 = partial_dependence(model, X, features=[0], grid_resolution=5)
print(pd0["grid_values"][0].round(2))   # [-1.81 -0.9   0.01  0.91  1.82]
print(pd0["average"][0].round(2))       # [ 1.79 -0.53 -1.29 -0.52  1.97]  — парабола

ice = partial_dependence(model, X[:3], features=[1], kind="individual", grid_resolution=3)
print(ice["individual"][0].round(2))
# [[ 0.11  0.25  0.6 ]     x2 = −1.84 → наклон ≈ 0.2
#  [ 0.24  4.64  8.33]     x2 =  1.65 → наклон ≈ 3.7
#  [-1.65  0.67  2.92]]    x2 =  0.17 → наклон ≈ 2.1
```

PDP по x0 повторил параболу (сдвинутую на константу — уровень PDP зависит от остальных признаков). ICE по x1 для трёх объектов имеют разный наклон, примерно `2 + x2`, — ровно взаимодействие из формулы. По одной средней кривой этого бы не было видно.

Графики строятся одной функцией:

```python
from sklearn.inspection import PartialDependenceDisplay

PartialDependenceDisplay.from_estimator(model, X, features=[0, 1, (1, 2)],
                                        kind="average")          # два PDP и 2D-PDP
PartialDependenceDisplay.from_estimator(model, X, features=[1],
                                        kind="both", centered=True)  # c-ICE + PDP
```

## Подводные камни

- **Коррелированные признаки.** Главная ловушка. Подставляя «площадь = 200 м²» во все строки, мы создаём квартиры с площадью 200 м² и одной комнатой — таких в данных нет, и модель на них экстраполирует как придётся. Если признаки сильно коррелированы, PDP может показывать артефакты. Альтернатива — **ALE-графики** (Accumulated Local Effects): они считают эффект по малым изменениям внутри реальных данных и устойчивы к корреляциям.
- **Края распределения.** Там, где данных мало, кривая ненадёжна. Рисуйте под графиком распределение признака (rug plot) и ограничивайте сетку перцентилями.
- **Усреднение прячет гетерогенность.** Всегда смотрите хотя бы на выборку ICE-кривых.
- **Не причинность.** PDP показывает, как реагирует *модель*, а не что произойдёт в реальности при изменении признака.
- **Стоимость.** Для сетки из G точек нужно G·n предсказаний; на больших данных считайте по подвыборке.

## Итоги

- PDP показывает, как в среднем меняется прогноз модели при изменении одного или двух признаков: `PD(v) = среднее по объектам f(v, x_C⁽ⁱ⁾)`.
- Метод глобальный и работает с любой моделью.
- ICE-кривые — зависимость для каждого объекта; их разброс выявляет взаимодействия, которые PDP усредняет.
- Двумерный PDP показывает взаимодействие пары признаков.
- При коррелированных признаках PDP опирается на нереалистичные объекты — используйте ALE и ограничивайте сетку областью с данными.
