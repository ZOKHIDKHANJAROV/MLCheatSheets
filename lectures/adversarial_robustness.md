# Adversarial robustness (классические атаки)

<!-- время: 16 мин -->

> **О чём лекция.** Почему точная модель может уверенно ошибиться из-за изменения входа, незаметного человеку, как строятся такие adversarial-примеры (FGSM, PGD) и как от них защищаются — в первую очередь adversarial training.

## Зачем это нужно

В 2013–2014 годах исследователи (Szegedy, Goodfellow и соавторы) обнаружили неожиданное: к фотографии панды можно добавить специально подобранный шум, невидимый глазу, и сеть с уверенностью 99% назовёт её гиббоном. Такие входы называют **adversarial-примерами** (состязательными).

Это не курьёз, а проблема безопасности:

- наклейки на дорожном знаке «Стоп» заставляют систему распознавания видеть знак ограничения скорости;
- небольшие изменения в медицинском снимке меняют диагноз;
- спам и вредоносные файлы модифицируют так, чтобы обойти классификатор;
- атаки работают и против систем распознавания лиц и голоса.

Кроме безопасности, уязвимость к малым изменениям говорит о том, что модель опирается на признаки, совсем не похожие на человеческие.

## Интуиция: высокая размерность

Почему маленькое изменение может так сильно повлиять? Объяснение Goodfellow — **линейность в высокой размерности**. Пусть модель считает скалярное произведение `w·x`. Если к каждому из n пикселей добавить ±ε в сторону знака соответствующего веса, выход изменится на `ε · Σ|wᵢ|`. Каждый пиксель изменился на ничтожную величину, но в картинке 224×224×3 пикселей 150 тысяч — и суммарный сдвиг огромен.

Нейросети с ReLU во многом ведут себя почти линейно, поэтому эффект проявляется и у них. Человек смотрит на форму объекта, а модели достаточно согласованного сдвига мелких деталей.

## Как это работает

**Модель угрозы** — что разрешено атакующему:

- **white-box** — атакующий знает модель и может считать градиенты;
- **black-box** — видит только ответы; использует **переносимость** (примеры, построенные на своей модели, часто обманывают и чужую) или оценивает градиент по запросам;
- **бюджет возмущения** — обычно ограничение по норме: L∞ (каждый пиксель меняется не больше чем на ε, например 8/255), L2 или L0 (число изменённых пикселей).

**FGSM (Fast Gradient Sign Method)** — один шаг в сторону роста ошибки:

```
x_adv = x + ε · sign(∇ₓ L(θ, x, y))
```

Градиент считается **по входу x**, а не по весам: мы не учим модель, а меняем картинку. Знак градиента даёт максимальное увеличение линейного приближения потерь при ограничении L∞.

**PGD (Projected Gradient Descent)** — многошаговая и намного более сильная версия:

```
x⁰ = x + случайный шум в пределах ε
xᵗ⁺¹ = Proj_{‖x' − x‖∞ ≤ ε} ( xᵗ + α · sign(∇ₓ L(θ, xᵗ, y)) )
```

Делаем несколько маленьких шагов размера α, после каждого возвращаем (проецируем) результат в ε-окрестность исходной картинки и в допустимый диапазон пикселей. PGD считается стандартной проверкой устойчивости.

Другие известные атаки: **C&W** (Carlini–Wagner, оптимизирует минимальное L2-возмущение), **DeepFool**, **патчи** — видимые наклейки, работающие в физическом мире.

## Защита

| метод | идея | оговорки |
|---|---|---|
| Adversarial training | обучать на adversarial-примерах (обычно PGD), генерируя их на каждом батче | самая надёжная эмпирическая защита; в 3–10 раз дороже обучения, снижает точность на чистых данных |
| Сертифицированная защита (randomized smoothing) | усреднять ответы модели по зашумлённым копиям входа | даёт доказуемую гарантию в радиусе r, но радиусы небольшие |
| Предобработка входа (сжатие JPEG, фильтры) | убрать «высокочастотный» шум | обычно обходится адаптивной атакой |
| Детекторы adversarial-примеров | отдельная модель отличает атакованные входы | тоже часто обходится |

Adversarial training формализуется как минимакс-задача (Madry и соавторы, 2018):

```
min_θ  E_(x,y) [ max_{‖δ‖ ≤ ε} L(θ, x + δ, y) ]
```

Внутренний максимум — сильнейшая атака в окрестности, внешний минимум — обучение на ней.

Важный урок истории области: многие защиты казались надёжными, пока их не проверили **адаптивной атакой**, учитывающей саму защиту. Защиты, которые «маскируют градиенты» (делают их нулевыми или шумными), дают ложное чувство безопасности.

## Пример на Python

FGSM на логистической регрессии — модели, для которой градиент по входу выписывается явно: `∂L/∂x = (p − y) · w`. Задача — отличить рукописные «3» и «8».

```python
import numpy as np
from sklearn.datasets import load_digits
from sklearn.linear_model import LogisticRegression

X, y = load_digits(return_X_y=True)
X = X / 16.0                                          # пиксели в [0, 1]
mask = (y == 3) | (y == 8)
X, y = X[mask], (y[mask] == 8).astype(int)
clf = LogisticRegression(max_iter=1000).fit(X, y)
print(round(clf.score(X, y), 3))                      # 1.0

p = clf.predict_proba(X)[:, 1]
grad_x = (p - y)[:, None] * clf.coef_[0]              # ∂(log-loss)/∂x
for eps in [0.05, 0.1, 0.2]:
    X_adv = np.clip(X + eps * np.sign(grad_x), 0, 1)  # FGSM + допустимый диапазон
    print(eps, round(clf.score(X_adv, y), 3))
# 0.05 0.955
# 0.1  0.782
# 0.2  0.216
```

Модель безошибочна на чистых данных, но сдвиг каждого пикселя на 0.2 от его диапазона роняет точность до 22% — хуже, чем случайное угадывание. На картинках с десятками тысяч пикселей хватает гораздо меньших ε.

FGSM для нейросети на PyTorch (в среде курса torch не установлен — код по актуальному API):

```python
import torch
import torch.nn.functional as F

def fgsm(model, x, y, eps=8 / 255):
    x = x.clone().detach().requires_grad_(True)
    loss = F.cross_entropy(model(x), y)
    grad, = torch.autograd.grad(loss, x)
    return (x + eps * grad.sign()).clamp(0, 1).detach()

# adversarial training: на каждом батче
# x_adv = fgsm(model, x, y)  (или PGD)
# loss = F.cross_entropy(model(x_adv), y); loss.backward(); optimizer.step()
```

## Подводные камни

- **Оценка устойчивости слабой атакой.** Проверка только FGSM завышает устойчивость; используйте PGD с несколькими случайными стартами или наборы вроде AutoAttack.
- **Маскировка градиентов.** Если после «защиты» атака вдруг перестаёт работать, а случайный шум того же размера работает, — градиенты, скорее всего, просто сломаны, а модель не устойчива.
- **Режим модели.** Атаку и оценку проводят в `model.eval()`: dropout и BatchNorm в режиме обучения искажают и градиенты, и результаты.
- **Нормировка.** ε задаётся в пространстве исходных пикселей [0, 1]; если нормировка (вычитание среднего, деление на std) встроена в модель, считать удобнее.
- **Цена устойчивости.** Adversarial training снижает точность на чистых данных и требует больше вычислений — это компромисс, который нужно выбирать под задачу.

## Итоги

- Adversarial-пример — вход с малым, незаметным возмущением, на котором модель ошибается; это проблема безопасности.
- Причина — почти линейное поведение моделей в высокой размерности: малые согласованные сдвиги складываются.
- FGSM — один шаг по знаку градиента по входу; PGD — несколько шагов с проекцией, стандарт для проверки.
- Самая надёжная практическая защита — adversarial training; сертифицированные методы дают гарантии в малом радиусе.
- Защиту проверяют адаптивными сильными атаками, иначе легко принять маскировку градиентов за устойчивость.
