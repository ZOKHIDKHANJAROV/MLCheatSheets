# ReAct-агенты

<!-- время: 14 мин -->

> **О чём лекция.** Как устроен подход ReAct (Reasoning + Acting): формат Thought / Action / Observation, зачем чередовать рассуждение и действие, как цикл останавливается и какие у него типичные сбои.

## Зачем это нужно

Если просить модель просто «подумать шаг за шагом» (Chain-of-Thought), она рассуждает только на основе своей памяти и может уверенно выдумать факт. Если просто давать ей вызывать инструменты без объяснений, ход решения трудно понять и исправить. Подход **ReAct** (Reasoning + Acting, статья Yao и др., 2022) соединяет оба варианта: модель вслух рассуждает, действует, смотрит на результат и рассуждает дальше. Это один из базовых шаблонов построения агентов.

## Интуиция: детектив

Детектив не строит версию целиком в голове и не бегает по городу бессистемно. Он делает так: «Подозреваю садовника (мысль) → проверю его алиби (действие) → алиби подтвердилось (наблюдение) → значит, версия неверна, подозреваю кухарку (новая мысль)». Мысль решает, какое действие нужно, а результат действия меняет следующую мысль.

## Как это работает

Каждый шаг состоит из трёх частей:

- **Thought** — рассуждение модели: что известно и что нужно узнать;
- **Action** — действие в заранее оговорённом формате, например `search[запрос]`;
- **Observation** — результат действия. Его пишет **только среда**, а не модель.

```
Question: Сколько жителей в столице Франции?
Thought: нужно узнать столицу
Action: search[столица Франции]
Observation: Париж
Thought: теперь нужно население Парижа
Action: search[население Парижа]
Observation: 2.1 млн
Thought: данных достаточно
Final Answer: 2.1 млн
```

Цикл в псевдокоде:

```
transcript = вопрос
повторять до max_steps:
    out = llm(transcript, stop=["Observation:"])
    transcript += out
    если в out есть "Final Answer:" → вернуть ответ
    action = разобрать(out)
    если action уже был → остановиться (зацикливание)
    transcript += "Observation: " + выполнить(action)
```

Стоп-последовательность `Observation:` не даёт модели дописать результат самостоятельно.

### Сравнение с CoT и чистым act

| | Chain-of-Thought | чистый act | ReAct |
|---|---|---|---|
| рассуждение | есть | нет | есть |
| инструменты | нет | есть | есть |
| свежие данные | нет | есть | есть |
| прозрачность шагов | высокая | низкая | высокая |
| основной риск | выдумка без проверки | бессмысленные действия | зацикливание, цена |

### Когда цикл останавливается

- модель выдала `Final Answer`;
- достигнут `max_steps` или бюджет токенов и времени;
- сработала защита от повторов (то же действие с теми же аргументами);
- несколько раз подряд не удалось разобрать формат.

## Пример на Python

«Модель» снова заглушка: она решает по числу уже полученных наблюдений. Вторая заглушка нарочно зацикливается, чтобы показать защиту.

```python
import re

KB = {"столица Франции": "Париж", "население Парижа": "2.1 млн"}   # условная база знаний

def search(query):
    return KB.get(query, "ничего не найдено")

def fake_llm(transcript):
    """Заглушка модели: решает по числу уже полученных наблюдений."""
    n = transcript.count("Observation:")
    if n == 0:
        return "Thought: нужно узнать столицу Франции\nAction: search[столица Франции]"
    if n == 1:
        return "Thought: теперь нужно население города Париж\nAction: search[население Парижа]"
    return "Thought: данных достаточно\nFinal Answer: 2.1 млн"

def looping_llm(transcript):
    """«Сломанная» модель: повторяет одно и то же действие."""
    return "Thought: попробую ещё раз\nAction: search[курс неизвестной валюты]"

ACTION = re.compile(r"Action: (\w+)\[(.*)\]")

def react(question, llm, max_steps=6):
    transcript = f"Question: {question}\n"
    seen = set()
    for _ in range(max_steps):
        out = llm(transcript)                      # генерация останавливается перед Observation
        transcript += out + "\n"
        if "Final Answer:" in out:
            return out.split("Final Answer:")[1].strip(), transcript
        match = ACTION.search(out)
        if match is None:
            obs = "ошибка формата: нужен Action: имя[аргумент]"
        else:
            name, arg = match.groups()
            if (name, arg) in seen:                # защита от зацикливания
                return "зацикливание", transcript
            seen.add((name, arg))
            obs = search(arg) if name == "search" else "неизвестное действие"
        transcript += f"Observation: {obs}\n"      # наблюдение пишет среда, а не модель
    return "лимит шагов", transcript

answer, log = react("Сколько жителей в столице Франции?", fake_llm)
print(answer)                                      # 2.1 млн
print(react("курс?", looping_llm)[0])              # зацикливание
```

Среда (функция `react`) сама добавляет строку `Observation:` после реального вызова `search`, а модель её не пишет. Повторное действие `search[курс неизвестной валюты]` ловится множеством `seen`, и цикл прерывается раньше `max_steps`.

## Подводные камни

- **Зацикливание.** Если инструмент не помогает, модель может раз за разом повторять тот же вызов. Нужны `max_steps`, проверка повторов и подсказки в сообщениях об ошибках («попробуйте другой запрос»).
- **Галлюцинация наблюдений.** Без стоп-последовательности модель сама дописывает «Observation» и выдумывает результат. Наблюдение должна вставлять только программа.
- **Хрупкий формат.** Если в тексте нет строки `Action:` или нарушены скобки, парсер ломается. Обрабатывайте ошибки формата и сообщайте о них модели.
- **Рост контекста.** История увеличивается на каждом шаге; длинные результаты обрезайте.
- **Потеря цели.** В длинной траектории модель может «забыть» исходный вопрос; повторяйте цель в промпте.
- **Лишняя сложность.** Для простых вопросов ReAct дороже, чем один запрос или CoT.

## Итоги

- ReAct чередует рассуждение (Thought), действие (Action) и наблюдение (Observation).
- Рассуждение направляет выбор действий, наблюдение даёт реальные данные и корректирует план.
- В отличие от CoT он использует внешние данные, в отличие от чистого act — объясняет шаги.
- Остановка: Final Answer, лимит шагов, бюджет, защита от повторов.
- Главные сбои — зацикливание, выдуманные наблюдения и ошибки формата.
