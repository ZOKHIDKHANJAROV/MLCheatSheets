> **О чём лекция.** Почему очень глубокие «обычные» сети учатся хуже неглубоких, как одна строчка `F(x) + x` решила эту проблему, как устроены базовый и bottleneck-блоки и почему skip-связи сегодня есть почти в каждой архитектуре.

## Зачем это нужно

К 2015 году было ясно, что глубина помогает: VGG с 19 слоями была точнее AlexNet с 8. Логично было ожидать, что 50 или 100 слоёв будут ещё лучше. Но эксперимент показывал обратное: обычная сеть на 56 слоёв имела **большую ошибку даже на обучающей выборке**, чем сеть на 20 слоёв.

Это не переобучение (тогда ошибка на обучении была бы ниже), а **проблема деградации**: глубокую сеть просто не получается оптимизировать. ResNet (Residual Network, Кайминг Хе и коллеги из Microsoft Research) решила эту проблему, выиграла ImageNet 2015 и позволила обучать сети на 152 слоя и глубже. Residual-связи теперь стоят в трансформерах, U-Net, диффузионных моделях — почти везде.

## Интуиция: учить поправку, а не всё заново

Рассуждение авторов было простым. Возьмём хорошую неглубокую сеть и добавим к ней слои, которые ничего не делают — тождественное отображение `H(x) = x`. Такая глубокая сеть заведомо не хуже неглубокой. Значит, проблема в том, что обычным слоям трудно выучить даже «ничего не делать»: нужно точно подобрать веса, чтобы стопка свёрток и ReLU воспроизводила вход.

Решение: пусть блок учит не весь результат H(x), а только **поправку** (остаток, residual) `F(x) = H(x) − x`. Тогда выход блока — `F(x) + x`. Если блок не нужен, достаточно обнулить веса, и блок станет тождественным. Сделать «чуть-чуть лучше, чем вход» гораздо проще, чем построить результат с нуля.

Аналогия: редактору проще внести правки в готовый текст, чем каждый раз переписывать его целиком.

## Как это работает: residual-блок

Базовый блок (BasicBlock, в ResNet-18 и ResNet-34):

```
x → Conv 3×3 → BN → ReLU → Conv 3×3 → BN → (+ x) → ReLU
```

Вход `x` идёт двумя путями: через свёртки (это F(x)) и напрямую в обход — по **skip-связи** (shortcut, identity). В конце они складываются.

```python
import torch.nn as nn
import torch.nn.functional as F

class BasicBlock(nn.Module):
    def __init__(self, c_in, c_out, stride=1):
        super().__init__()
        self.conv1 = nn.Conv2d(c_in, c_out, 3, stride, 1, bias=False)
        self.bn1 = nn.BatchNorm2d(c_out)
        self.conv2 = nn.Conv2d(c_out, c_out, 3, 1, 1, bias=False)
        self.bn2 = nn.BatchNorm2d(c_out)
        self.shortcut = nn.Identity()
        if stride != 1 or c_in != c_out:         # размеры не совпадают — проекция 1×1
            self.shortcut = nn.Sequential(nn.Conv2d(c_in, c_out, 1, stride, bias=False),
                                          nn.BatchNorm2d(c_out))

    def forward(self, x):
        out = F.relu(self.bn1(self.conv1(x)))
        out = self.bn2(self.conv2(out))
        return F.relu(out + self.shortcut(x))    # skip-связь
```

## Почему skip-связи помогают обучению

Посмотрим на градиент. Если `y = x + F(x)`, то

```
∂y/∂x = 1 + ∂F/∂x
```

Единица означает, что у градиента всегда есть «прямая дорога» назад через сложение — он не обязан проходить через все свёртки и активации, где мог бы затухнуть. В сети из многих блоков градиент от потерь доходит до первых слоёв почти без потерь. Дополнительно сеть ведёт себя как ансамбль путей разной длины: часть сигнала проходит через немногие блоки, часть — через все.

## Когда размеры не совпадают

Сложить `F(x) + x` можно, только если у них одинаковая форма. При переходе к следующей стадии сеть уменьшает размер вдвое (stride 2) и удваивает число каналов. Тогда в skip-связи ставят **проекцию** — свёртку 1×1 с тем же шагом, которая приводит x к нужной форме (как в коде выше). Можно и дополнить каналы нулями, но проекция работает чуть лучше.

## Bottleneck-блок и семейство ResNet

В ResNet-50 и глубже используют **bottleneck**-блок из трёх свёрток:

```
1×1 (сжать каналы, например 256 → 64) → 3×3 (на 64 каналах) → 1×1 (вернуть 64 → 256)
```

Дорогая свёртка 3×3 работает на сжатом представлении, поэтому сеть получается глубокой, но не слишком тяжёлой.

| модель | блок | слоёв | параметров |
|---|---|---|---|
| ResNet-18 | basic | 18 | ~11.7 млн |
| ResNet-34 | basic | 34 | ~21.8 млн |
| ResNet-50 | bottleneck | 50 | ~25.6 млн |
| ResNet-101 | bottleneck | 101 | ~44.5 млн |
| ResNet-152 | bottleneck | 152 | ~60.2 млн |

Общая структура: «стебель» (свёртка 7×7 со stride 2 и max pooling), четыре стадии блоков с удвоением каналов, global average pooling и один линейный слой. Потомки — ResNeXt (группы свёрток), Wide ResNet, ResNet-D и ConvNeXt.

## Пример на Python

Игрушечный эксперимент на NumPy: пропустим сигнал через 50 случайных слоёв «линейный + ReLU» с небольшими весами — обычным способом и с residual-связями.

```python
import numpy as np

rng = np.random.default_rng(0)
depth, width = 50, 64
x = rng.normal(size=width)

def layer(W, h):
    return np.maximum(0, W @ h)          # линейный слой + ReLU

weights = [rng.normal(scale=0.5 / np.sqrt(width), size=(width, width)) for _ in range(depth)]

plain, residual = x.copy(), x.copy()
for W in weights:
    plain = layer(W, plain)                            # обычная сеть: h = F(h)
    residual = residual + layer(W, residual) * 0.1     # residual-сеть: h = h + F(h)

print(f"норма входа: {np.linalg.norm(x):.2f}")                     # 7.32
print(f"обычная сеть, 50 слоёв:   {np.linalg.norm(plain):.2e}")     # 2.34e-22
print(f"residual-сеть, 50 слоёв: {np.linalg.norm(residual):.2f}")  # 11.96
```

В обычной сети сигнал угасает до 10⁻²² — то же произойдёт и с градиентом на обратном пути. В residual-сети тождественный путь сохраняет сигнал. Множитель 0.1 у ветви F похож на приём, который используют на практике: последний BatchNorm блока инициализируют нулём, чтобы в начале обучения каждый блок был почти тождественным.

Готовые модели: `torchvision.models.resnet50(weights="IMAGENET1K_V2")`, `keras.applications.ResNet50(weights="imagenet")`.

## Подводные камни

- **Сложение до ReLU, а не после.** В оригинальном блоке ReLU применяется после сложения; есть и вариант «pre-activation» (ResNet v2), где BN и ReLU стоят перед свёртками. Не смешивайте схемы случайно.
- **Несовпадение форм** в skip-связи даёт ошибку при сложении — при смене stride или числа каналов нужна проекция.
- **`bias=False` в свёртках перед BatchNorm** — смещение бесполезно, его «съедает» BN.
- **ResNet-50 — не всегда лучше ResNet-18.** На маленьких датасетах и при жёстких требованиях к скорости меньшая модель часто выигрывает.
- **BatchNorm и маленький батч.** При батче в 2–4 изображения статистики BN шумные; используйте GroupNorm или заморозьте BN при дообучении.

## Итоги

- Очень глубокие обычные сети страдают от деградации: они хуже оптимизируются, и ошибка растёт даже на обучении.
- Residual-блок учит поправку F(x), а выход равен `F(x) + x`; тождественное отображение получается обнулением весов.
- Skip-связь даёт градиенту прямой путь: `∂y/∂x = 1 + ∂F/∂x`.
- При смене размера в skip-связь ставят проекцию 1×1; в глубоких версиях используют bottleneck 1×1 → 3×3 → 1×1.
- Residual-связи стали стандартом далеко за пределами CNN — в трансформерах и генеративных моделях.
