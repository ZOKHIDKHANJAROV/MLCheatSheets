# k-ближайших соседей (k-NN)

<!-- время: 12 мин -->

> **О чём лекция.** Самый интуитивный алгоритм машинного обучения: прогноз по похожим объектам. Разберём, как k-NN делает предсказания, как выбор k и метрики расстояния влияет на результат, почему без масштабирования он не работает и почему плохо масштабируется на большие данные.

## Зачем это нужно

k-NN (k nearest neighbors) — алгоритм, который почти не нужно объяснять заказчику: «Мы нашли пять клиентов, больше всего похожих на вас. Четверо из них купили этот товар — поэтому мы рекомендуем его вам».

Он полезен как **быстрый baseline**: если сложная модель не обыгрывает k-NN, с ней что-то не так. Идея поиска похожих объектов лежит в основе рекомендательных систем, поиска дубликатов, заполнения пропусков (`KNNImputer`) и современного векторного поиска по эмбеддингам, где k-NN работает над представлениями из нейросетей.

А ещё k-NN хорошо показывает базовые понятия ML: компромисс смещения и дисперсии, роль масштабирования признаков и проклятие размерности.

## Интуиция: скажи мне, кто твой сосед

Каждый объект — это точка в пространстве признаков. Например, клиент с возрастом 35 лет и доходом 80 тысяч — точка (35, 80). Похожие клиенты лежат рядом. Чтобы предсказать что-то для нового клиента, найдём k самых близких к нему точек из обучающей выборки и посмотрим на их ответы:

- **классификация** — голосование: какой класс чаще среди соседей, тот и предсказываем;
- **регрессия** — среднее значение ответа у соседей.

Можно голосовать с весами: близкие соседи важнее далёких (`weights="distance"`, вес обратно пропорционален расстоянию).

## Как это работает

**Обучения в обычном смысле нет.** Метод `fit` просто запоминает обучающую выборку (иногда строит структуру для быстрого поиска — KD-дерево или Ball tree). Вся работа происходит в момент прогноза. Поэтому k-NN называют **ленивым** обучением.

Прогноз для нового объекта x:

1. Посчитать расстояние от x до всех объектов обучающей выборки.
2. Выбрать k ближайших.
3. Проголосовать (или усреднить) их ответы.

**Метрика расстояния** — часть модели:

```
Евклидово:  d(a, b) = √Σ(aⱼ − bⱼ)²       — по умолчанию
Манхэттен:  d(a, b) = Σ|aⱼ − bⱼ|          — устойчивее к выбросам в отдельных признаках
Косинусное: 1 − cos(a, b)                 — для текстов и эмбеддингов, важно направление, а не длина
```

## Выбор k: смещение против дисперсии

- **k = 1** — модель повторяет ближайший пример. Граница между классами очень изрезанная, любой шумный объект создаёт вокруг себя «островок». Ошибка на обучении нулевая, на новых данных — большая. Это переобучение: высокая дисперсия.
- **Большое k** — модель усредняет по огромной окрестности, граница сглаживается, мелкие закономерности пропадают. При k, равном размеру выборки, модель всегда предсказывает самый частый класс. Это недообучение: высокое смещение.

Хорошее k ищут кросс-валидацией. Типичный диапазон — от 3 до 30. В бинарной классификации удобно брать нечётное k, чтобы не было ничьих.

## Почему масштабирование обязательно

Расстояние складывается из разностей по признакам. Если возраст измеряется в годах (разница 10–40), а доход — в рублях (разница в десятки тысяч), доход полностью определяет расстояние, а возраст как будто не существует. Модель будет искать соседей только по доходу.

Поэтому перед k-NN признаки приводят к одному масштабу — `StandardScaler` или `MinMaxScaler`, и делают это внутри пайплайна, чтобы параметры масштабирования считались только по обучающим данным.

## Проклятие размерности

С ростом числа признаков пространство становится огромным и пустым. В высокой размерности расстояния от точки до ближайшего и до самого дальнего объекта становятся почти одинаковыми, и понятие «ближайший сосед» теряет смысл. Кроме того, каждый шумный признак добавляет к расстоянию случайный вклад.

На практике k-NN хорошо работает на десятках признаков и плохо — на сотнях и тысячах сырых признаков. Помогают отбор признаков, PCA или переход к хорошим эмбеддингам.

## Пример на Python

Сравним k-NN с масштабированием и без на наборе данных о раке груди, где признаки имеют очень разные единицы измерения.

```python
from sklearn.datasets import load_breast_cancer
from sklearn.model_selection import cross_val_score
from sklearn.neighbors import KNeighborsClassifier
from sklearn.pipeline import make_pipeline
from sklearn.preprocessing import StandardScaler

X, y = load_breast_cancer(return_X_y=True)
for k in [1, 5, 15, 51]:
    raw = cross_val_score(KNeighborsClassifier(n_neighbors=k), X, y, cv=5).mean()
    scaled = cross_val_score(make_pipeline(StandardScaler(), KNeighborsClassifier(n_neighbors=k)),
                             X, y, cv=5).mean()
    print(f"k={k:2}: без масштабирования {raw:.3f}, со StandardScaler {scaled:.3f}")

# k= 1: без масштабирования 0.905, со StandardScaler 0.954
# k= 5: без масштабирования 0.928, со StandardScaler 0.965
# k=15: без масштабирования 0.930, со StandardScaler 0.961
# k=51: без масштабирования 0.916, со StandardScaler 0.951
```

Видны оба эффекта. Масштабирование даёт прибавку при любом k. А по k качество сначала растёт (k = 1 переобучается), потом падает (k = 51 слишком сглаживает). Лучшее значение здесь — около 5.

## Подводные камни

- **Медленный прогноз.** Для каждого нового объекта нужно посчитать расстояния до всей выборки: при миллионах объектов это дорого. KD-деревья помогают в низкой размерности, а для больших данных используют приближённый поиск соседей (FAISS, Annoy, HNSW).
- **Память.** Модель хранит всю обучающую выборку.
- **Категориальные признаки** нужно закодировать (one-hot), а евклидово расстояние на смеси числовых и бинарных признаков ведёт себя не всегда разумно.
- **Дисбаланс классов.** При голосовании частый класс побеждает просто числом. Помогают взвешивание по расстоянию и подбор порога по вероятностям `predict_proba`.
- **Утечка при масштабировании.** `StandardScaler`, обученный на всех данных до разбиения, «подсматривает» тест. Используйте пайплайн.
- **Дубликаты и шум.** При малом k один ошибочный объект портит прогнозы вокруг себя.

## Итоги

- k-NN предсказывает по k ближайшим объектам: голосование в классификации, среднее в регрессии.
- Обучения нет — модель хранит данные, а вся работа происходит при прогнозе.
- Малое k — переобучение, большое — недообучение; k подбирают кросс-валидацией.
- Масштабирование признаков обязательно, метрика расстояния — часть модели.
- В высокой размерности и на больших данных k-NN работает плохо без снижения размерности и приближённого поиска.
