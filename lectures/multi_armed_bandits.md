# Многорукие бандиты (Multi-armed bandits)

<!-- время: 15 мин -->

> **О чём лекция.** Самая чистая форма дилеммы «исследовать или использовать»: несколько вариантов с неизвестной отдачей, и нужно как можно быстрее начать выбирать лучший, не потеряв слишком много на проверках. Разберём regret, ε-жадную стратегию, UCB и Thompson Sampling, а также контекстных бандитов, на которых работают рекомендации и персонализация.

## Зачем это нужно

У вас три варианта баннера на сайте. Какой приносит больше кликов — неизвестно. Классический путь — A/B-тест: делим трафик поровну на несколько недель, затем выбираем победителя. Но всё это время две трети трафика уходят на варианты, которые, возможно, заметно хуже.

**Многорукий бандит** — постановка, где учиться и зарабатывать нужно одновременно: по мере накопления данных постепенно отдавать больше показов вариантам, которые выглядят лучше. Так выбирают заголовки новостей, рекламные креативы, цены, порядок товаров в ленте и даже дозировки в адаптивных клинических испытаниях.

## Интуиция: игровые автоматы

Название — от игровых автоматов («однорукий бандит»). Перед вами K автоматов, у каждого свой неизвестный средний выигрыш. За T попыток нужно набрать как можно больше.

Если играть только на автомате, который пока выглядит лучшим, можно навсегда пропустить лучший автомат, которому просто не повезло в первых попытках. Если долго играть на всех поровну — тратишь попытки на заведомо плохие. Хорошая стратегия исследует **там, где неопределённость велика, а вариант ещё может оказаться лучшим**.

Бандит — это RL без состояний: действие не меняет мир, награда приходит сразу. Поэтому вся сложность — только в балансе исследования и использования.

## Как это работает: regret

Качество стратегии измеряют **сожалением** (regret) — сколько мы недополучили по сравнению с тем, кто с самого начала знал лучшую руку:

```
R(T) = T · μ* − Σ μ(a_t)
```

где μ* — средняя награда лучшей руки, μ(a_t) — средняя награда выбранной руки на шаге t.

- Стратегия, которая никогда не перестаёт ошибаться с постоянной частотой, имеет **линейный** regret: R(T) растёт пропорционально T.
- Хорошие алгоритмы имеют **логарифмический** regret: R(T) ~ log T. Со временем они почти перестают ошибаться. Лай и Роббинс доказали, что лучше логарифма в общем случае нельзя.

## ε-жадная стратегия

С вероятностью ε выбираем случайную руку, иначе — руку с лучшим средним:

- просто и понятно;
- но исследует **вслепую**: продолжает тратить ε попыток на руки, о которых уже всё ясно;
- при постоянном ε regret линейный: примерно ε · T · (средний разрыв с лучшей рукой). Помогает уменьшение ε со временем.

## UCB: оптимизм перед лицом неопределённости

**UCB (Upper Confidence Bound)** выбирает руку с максимальной *верхней границей* правдоподобного среднего:

```
UCB(a) = Q̂(a) + c · √( ln t / N(a) )
```

- Q̂(a) — среднее наблюдаемое вознаграждение руки;
- N(a) — сколько раз руку выбирали; чем меньше, тем больше бонус;
- c — сила исследования.

Логика: «если рука может оказаться хорошей — попробуй её». Рука, которую давно не выбирали, получает растущий бонус (ln t растёт), а рука с большим N(a) — маленький. Плохие руки выбираются всё реже, но никогда не забываются совсем. Regret UCB логарифмический.

Тонкость: c нужно согласовать с масштабом наград. При конверсиях порядка 5% бонус с c = 2 огромен по сравнению с разницей между руками — алгоритм будет исследовать слишком долго.

## Thompson Sampling: исследование через неопределённость

**Thompson Sampling** — байесовский подход. Для каждой руки храним апостериорное распределение её среднего. Для конверсий (клик / не клик) удобно **бета-распределение**: после s успехов и f неудач оно равно Beta(1 + s, 1 + f).

На каждом шаге:

1. Для каждой руки **сэмплируем** правдоподобное значение среднего из её распределения.
2. Выбираем руку с максимальным сэмплом.
3. Обновляем распределение выбранной руки.

Рука выбирается с вероятностью, равной вероятности того, что она лучшая. Пока о руке мало данных, её распределение широкое, и она иногда «выстреливает» высоким сэмплом — это и есть исследование. Thompson Sampling прост, имеет логарифмический regret и часто лучший на практике.

## Контекстные бандиты

В реальности лучший вариант зависит от **контекста**: молодым пользователям нравится один баннер, остальным — другой. **Контекстный бандит** получает перед выбором вектор признаков x (пользователь, время, устройство) и учит модель ожидаемой награды каждой руки по контексту.

Классический алгоритм — **LinUCB**: для каждой руки линейная модель награды и UCB-бонус по неопределённости этой модели. Есть и Thompson Sampling с линейными или нейросетевыми моделями. На контекстных бандитах построены персонализация новостей, рекламы и рекомендаций.

## Пример на Python

Сравним три стратегии на трёх баннерах с конверсиями 4%, 5% и 7%:

```python
import numpy as np

true_p = np.array([0.04, 0.05, 0.07])     # истинные конверсии (агенту неизвестны)

def run(choose, T, seed=42):
    rng = np.random.default_rng(seed)
    n, s = np.zeros(3), np.zeros(3)       # показы и клики по каждой руке
    regret = 0.0
    for t in range(1, T + 1):
        a = choose(n, s, t, rng)
        s[a] += rng.random() < true_p[a]
        n[a] += 1
        regret += true_p.max() - true_p[a]
    return regret

def eps_greedy(n, s, t, rng, eps=0.1):
    if rng.random() < eps or n.min() == 0:
        return rng.integers(3)                        # исследуем
    return int(np.argmax(s / n))                      # используем лучшую по среднему

def ucb(n, s, t, rng, c=0.2):                         # c подобран под масштаб конверсий
    if n.min() == 0:
        return int(np.argmin(n))                      # сначала каждую руку по разу
    return int(np.argmax(s / n + c * np.sqrt(np.log(t) / n)))

def thompson(n, s, t, rng):
    return int(np.argmax(rng.beta(1 + s, 1 + n - s)))   # сэмпл из апостериорного Beta

for T in (10_000, 100_000):
    print(T, {name: round(float(run(f, T)), 1) for name, f in
              [("ε-greedy", eps_greedy), ("UCB", ucb), ("Thompson", thompson)]})
# 10000 {'ε-greedy': 17.4, 'UCB': 31.1, 'Thompson': 25.6}
# 100000 {'ε-greedy': 169.1, 'UCB': 32.7, 'Thompson': 46.5}
```

На 10 000 показов ε-жадная стратегия даже выигрывает. Но её regret растёт линейно — в 10 раз больше показов, почти в 10 раз больше потерь, а у UCB и Thompson он почти не вырос. На длинной дистанции логарифмический regret побеждает.

## Подводные камни

- **Нестационарность.** Если конверсии меняются со временем (сезон, усталость от креатива), старые данные мешают. Используйте скользящее окно или экспоненциальное забывание.
- **Задержка награды.** Покупка может случиться через день после показа. Алгоритм, обновляемый мгновенно, будет недооценивать руки с поздней конверсией.
- **Бандит — не замена A/B-тесту.** Бандит максимизирует награду, но из-за неравного распределения трафика по нему сложнее сделать строгий статистический вывод о разнице вариантов. Если цель — знание, а не заработок, нужен эксперимент.
- **Неверный масштаб c в UCB** превращает его в почти случайный выбор или, наоборот, в жадный.
- **Метрика-заместитель.** Оптимизировать клики легко, но кликбейтный заголовок может ухудшить удержание пользователей.

## Итоги

- Многорукий бандит — задача выбора из K вариантов с неизвестной отдачей, где нужно одновременно учиться и зарабатывать.
- Качество измеряют regret; хорошие алгоритмы имеют логарифмический regret.
- ε-жадная стратегия проста, но при постоянном ε теряет линейно; UCB добавляет бонус за неопределённость; Thompson Sampling сэмплирует из апостериорных распределений.
- Контекстные бандиты (LinUCB) учитывают признаки пользователя и лежат в основе персонализации.
