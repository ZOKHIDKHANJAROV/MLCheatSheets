> **О чём лекция.** Чем временной ряд отличается от обычной таблицы, что такое стационарность и зачем брать разности, как устроены три буквы ARIMA и что добавляет к ним S. И главное — как честно проверить прогноз, не заглядывая в будущее.

## Зачем это нужно

Продажи по дням, нагрузка на серверы, курс валюты, потребление электричества — это **временные ряды**: значения, упорядоченные во времени. Задача почти всегда одна — прогноз: сколько товара заказать на следующую неделю, сколько серверов поднять к вечеру.

У временных рядов есть свойство, которое ломает привычные ML-подходы: **наблюдения зависят друг от друга**. Сегодняшние продажи похожи на вчерашние, декабрь похож на прошлый декабрь. Это одновременно подсказка (прошлое помогает предсказывать) и ловушка (нельзя перемешивать данные).

ARIMA — классическая статистическая модель, которая использует эту зависимость явно. Она остаётся сильным бейзлайном, хорошо работает на коротких рядах и даёт интервалы прогноза «из коробки».

## Интуиция: из чего складывается ряд

Обычно ряд раскладывают на части:

- **тренд** — долгосрочный рост или спад;
- **сезонность** — регулярные повторения с известным периодом (неделя, год);
- **остаток** — то, что осталось: шум и краткосрочная зависимость.

ARIMA моделирует краткосрочную зависимость: «следующее значение зависит от нескольких предыдущих значений и предыдущих ошибок». Тренд она убирает разностями, а сезонность — сезонным расширением SARIMA.

## Стационарность и разности

Модели AR и MA предполагают, что ряд **стационарен**: его среднее, дисперсия и характер зависимости не меняются со временем. Ряд с трендом нестационарен — его среднее растёт. Ряд с сезонностью тоже.

Самый частый способ сделать ряд стационарным — **взять разность**:

```
y'(t) = y(t) − y(t−1)
```

Вместо самих продаж моделируем их изменение за день. Если тренд линейный, после одной разности он превращается в константу. Иногда нужна вторая разность.

Проверяют стационарность глазами (график ряда и скользящих среднего и стандартного отклонения) и тестом **ADF** (расширенный тест Дики–Фуллера): нулевая гипотеза — ряд нестационарен, поэтому маленькое p-value (< 0.05) говорит в пользу стационарности.

## Как это работает: три буквы ARIMA(p, d, q)

- **AR(p) — авторегрессия.** Значение — линейная комбинация p предыдущих значений:

```
y(t) = c + φ₁·y(t−1) + … + φₚ·y(t−p) + ε(t)
```

- **I(d) — интегрирование.** Модель строится не на исходном ряде, а на его разностях порядка d. При прогнозе разности «складываются» обратно.
- **MA(q) — скользящее среднее ошибок.** Значение зависит от q предыдущих ошибок прогноза (неожиданностей):

```
y(t) = c + ε(t) + θ₁·ε(t−1) + … + θ_q·ε(t−q)
```

Пример: ARIMA(1, 1, 0) значит «взять одну разность и описать приращения авторегрессией первого порядка»: сегодняшнее изменение похоже на вчерашнее изменение с коэффициентом φ.

## Как выбрать p и q: ACF и PACF

Два графика помогают подобрать порядки по стационарному (уже продифференцированному) ряду:

- **ACF** (автокорреляционная функция) — корреляция ряда с самим собой со сдвигом на k шагов;
- **PACF** (частная автокорреляция) — та же корреляция, но очищенная от влияния промежуточных лагов.

| что видим | что это значит |
|---|---|
| PACF обрывается после лага p, ACF затухает | AR(p) |
| ACF обрывается после лага q, PACF затухает | MA(q) |
| оба затухают постепенно | смешанная ARMA, подбирать перебором |

На практике часто перебирают несколько вариантов и выбирают модель с минимальным **AIC** (критерий Акаике: качество подгонки со штрафом за число параметров). Так делает, например, `auto_arima` из библиотеки pmdarima.

## SARIMA: сезонность

Если у ряда есть сезонность с периодом m (m = 7 для дневных данных с недельным циклом, m = 12 для месячных с годовым), используют **SARIMA(p, d, q)(P, D, Q)ₘ**. Вторая тройка — те же AR, разности и MA, но с шагом m: сезонная разность `y(t) − y(t−m)` сравнивает понедельник с прошлым понедельником, а сезонная AR-часть использует значение ровно сезон назад.

Если на ряд влияют внешние факторы (цены, праздники, погода), их добавляют как регрессоры — это **SARIMAX** (X — exogenous, внешние переменные).

## Как честно проверить прогноз

Главное правило: **будущее не должно попасть в обучение**. Случайное разбиение train/test, привычное для табличных данных, здесь запрещено: модель увидит соседние дни и получит нереалистично хорошую оценку.

- Делите по времени: обучение на прошлом, проверка на последнем отрезке.
- Лучше — **скользящее окно** (rolling origin): обучаем до момента t, прогнозируем следующий отрезок, сдвигаем t и повторяем. В scikit-learn для этого есть `TimeSeriesSplit`.
- **Всегда сравнивайте с наивным прогнозом** — «завтра как сегодня» или «как неделю назад». Если сложная модель его не обыгрывает, она бесполезна.
- Проверьте **остатки** обученной модели: в них не должно остаться автокорреляции (тест Льюнга–Бокса), иначе модель упустила часть структуры.

## Пример на Python

Чтобы увидеть, что внутри, оценим ARIMA(1, 1, 0) вручную: сгенерируем ряд с трендом, возьмём разность и подберём φ методом наименьших квадратов:

```python
import numpy as np

rng = np.random.default_rng(0)
n = 300
e = rng.normal(size=n)
dy = np.zeros(n)
for t in range(1, n):                       # приращения — AR(1) с φ = 0.6
    dy[t] = 0.6 * dy[t - 1] + e[t]
y = 100 + np.cumsum(dy + 0.2)               # ряд с трендом: ARIMA(1,1,0) со сносом

train, test = y[:250], y[250:]              # режем по времени, без перемешивания
d = np.diff(train)                          # d = 1: переходим к приращениям
A = np.column_stack([np.ones(len(d) - 1), d[:-1]])
c, phi = np.linalg.lstsq(A, d[1:], rcond=None)[0]
print(f"оценка φ = {phi:.2f}")              # 0.64 — близко к истинным 0.6

# прогноз на шаг вперёд по каждой точке теста
pred_ar = [y[t - 1] + c + phi * (y[t - 1] - y[t - 2]) for t in range(250, n)]
pred_naive = y[249:n - 1]                   # наивный прогноз: «завтра как сегодня»
mae = lambda p: np.mean(np.abs(test - np.array(p)))
print(f"MAE AR: {mae(pred_ar):.2f}, MAE наивный: {mae(pred_naive):.2f}")   # 0.83 и 0.90
```

В реальной работе то же делают одной строкой в statsmodels:

```python
from statsmodels.tsa.statespace.sarimax import SARIMAX

model = SARIMAX(train, order=(1, 1, 0), seasonal_order=(1, 1, 1, 7), trend="c")
fitted = model.fit(disp=False)
forecast = fitted.get_forecast(steps=30)
print(forecast.predicted_mean, forecast.conf_int())   # прогноз и 95%-й интервал
```

## Подводные камни

- **Перемешивание данных** при разбиении — самая частая и самая дорогая ошибка. Только разбиение по времени.
- **Лишние разности.** Если продифференцировать стационарный ряд, появится искусственная отрицательная автокорреляция и прогноз ухудшится. Берите столько разностей, сколько нужно, и не больше.
- **Длинный горизонт.** Ошибки ARIMA накапливаются: прогноз на 1 шаг может быть хорош, а на 60 шагов — сходиться к среднему или тренду. Оценивайте качество на том горизонте, который нужен бизнесу.
- **Много рядов.** ARIMA строится отдельно для каждого ряда. Для 100 000 товаров это долго и не использует общую информацию — тут удобнее бустинг на лаговых признаках или глобальные нейросетевые модели.
- **Структурные сдвиги.** Пандемия, смена цены, новый конкурент — модель, обученная на старом режиме, будет ошибаться. Следите за остатками и переобучайте.

## Итоги

- Временной ряд — зависимые наблюдения во времени; данные нельзя перемешивать.
- ARIMA(p, d, q): d разностей делают ряд стационарным, AR(p) использует прошлые значения, MA(q) — прошлые ошибки.
- p и q подбирают по ACF/PACF и по AIC; SARIMA добавляет сезонные компоненты с периодом m, SARIMAX — внешние регрессоры.
- Проверка — только по времени (скользящее окно), сравнение — с наивным прогнозом, остатки — без автокорреляции.
