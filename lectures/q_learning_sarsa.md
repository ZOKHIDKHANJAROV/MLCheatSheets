# Q-learning и SARSA

<!-- время: 15 мин -->

> **О чём лекция.** Два базовых алгоритма обучения с подкреплением без модели среды: оба учат таблицу Q(s, a) по одной формуле, отличаясь единственным членом. Разберём, что такое TD-обучение, почему Q-learning — off-policy, а SARSA — on-policy, и как эта разница превращается в смелого и осторожного агента на краю обрыва.

## Зачем это нужно

Итерация по ценности решает уравнение Беллмана, но требует знать модель среды: вероятности переходов и награды. В реальности модели нет — агент может только действовать и смотреть, что происходит.

Q-learning и SARSA учат функцию ценности действий Q(s, a) прямо из опыта, по одному переходу (s, a, r, s'). Это фундамент: DQN, победивший людей в играх Atari, — это Q-learning с нейросетью вместо таблицы. Поняв табличную версию, вы поймёте, что происходит в глубоком RL.

## Интуиция: учиться на собственных ожиданиях

Представьте, что вы оцениваете, сколько времени займёт дорога домой. Утром вы думали «40 минут». Через 10 минут вы попали в пробку и теперь думаете, что осталось ещё 45. Не дожидаясь приезда, вы уже понимаете: исходная оценка была слишком оптимистичной — путь займёт около 55 минут. Её можно поправить прямо сейчас.

Это идея **TD-обучения** (temporal difference, обучение на временных разностях): обновлять оценку по разнице между тем, что мы ожидали, и тем, что увидели плюс новой оценкой будущего. Ждать конца эпизода не нужно — учимся на каждом шаге.

## Как это работает: Q-learning

Агент хранит таблицу Q: строки — состояния, столбцы — действия. После каждого перехода (s, a, r, s') он обновляет одну ячейку:

```
Q(s, a) ← Q(s, a) + α · [ r + γ · max_a' Q(s', a') − Q(s, a) ]
```

- `r + γ · max_a' Q(s', a')` — **TD-цель**: полученная награда плюс дисконтированная ценность лучшего действия в новом состоянии;
- разность в квадратных скобках — **TD-ошибка**, «неожиданность»;
- α — скорость обучения (часто 0.1–0.5), γ — коэффициент дисконтирования.

Если s' — терминальное состояние, будущего нет, и цель равна просто r.

Действия при этом выбираются **ε-жадно**: с вероятностью ε — случайное, иначе — с максимальным Q.

## Как это работает: SARSA

SARSA отличается одним членом. Вместо максимума по действиям в s' она берёт **то действие a', которое агент действительно выберет** следующим:

```
Q(s, a) ← Q(s, a) + α · [ r + γ · Q(s', a') − Q(s, a) ]
```

Название — это кортеж, по которому делается обновление: **S**tate, **A**ction, **R**eward, **S**tate, **A**ction.

## Off-policy и on-policy

Эта маленькая разница меняет то, чему учится агент:

- **Q-learning — off-policy.** Цель использует max, то есть ценность *оптимальной* жадной политики, хотя сам агент действует ε-жадно. Он учит, как было бы хорошо действовать идеально, независимо от того, как действует сейчас. Плюс: можно учиться на чужом опыте и старых записях (это и использует replay buffer в DQN).
- **SARSA — on-policy.** Цель использует реальное следующее действие, включая случайные. SARSA учит ценность *той политики, которой агент реально следует*, со всеми её ошибками исследования.

| | Q-learning | SARSA |
|---|---|---|
| цель | r + γ · max Q(s', ·) | r + γ · Q(s', a') |
| тип | off-policy | on-policy |
| что учит | оптимальную политику | ценность текущей ε-жадной политики |
| характер | смелый | осторожный |

## Прогулка по краю обрыва

Классический пример из учебника Саттона и Барто — **cliff walking**. Сетка 4×12, старт в левом нижнем углу, цель — в правом нижнем, а между ними вдоль нижнего края — обрыв: шаг туда даёт −100 и возвращает на старт. Каждый обычный шаг стоит −1.

- **Q-learning** выучивает **кратчайший путь** — прямо по краю обрыва. Это оптимально для идеального агента. Но агент при обучении действует ε-жадно: иногда случайно шагает в сторону и падает. Средняя награда за эпизод во время обучения низкая.
- **SARSA** учитывает, что агент иногда делает случайные шаги, и выучивает **безопасный путь** подальше от края. Он длиннее, но падений почти нет, и средняя награда при обучении выше.

Кто «прав» — зависит от задачи. Если после обучения агент будет действовать жадно, путь Q-learning лучше. Если ошибки исследования неизбежны и дороги (робот у лестницы), осторожность SARSA ценнее.

## Пример на Python

Воспроизведём cliff walking. Обе функции различаются одной строкой — вычислением цели:

```python
import numpy as np

H, W = 4, 12
moves = [(-1, 0), (1, 0), (0, -1), (0, 1)]       # вверх, вниз, влево, вправо

def step(s, a):
    r, c = divmod(s, W)
    r = min(max(r + moves[a][0], 0), H - 1)
    c = min(max(c + moves[a][1], 0), W - 1)
    if r == 3 and 1 <= c <= 10:                  # обрыв: −100 и назад на старт
        return 3 * W, -100, False
    return r * W + c, -1, (r == 3 and c == 11)

def train(method, episodes=2000, alpha=0.5, gamma=1.0, eps=0.1, seed=0):
    rng = np.random.default_rng(seed)
    Q = np.zeros((H * W, 4))
    pick = lambda s: rng.integers(4) if rng.random() < eps else int(np.argmax(Q[s]))
    returns = []
    for _ in range(episodes):
        s, total, done = 3 * W, 0, False
        a = pick(s)
        while not done:
            s2, r, done = step(s, a)
            a2 = pick(s2)
            if method == "q":
                target = r + gamma * (0 if done else Q[s2].max())     # лучшее действие
            else:
                target = r + gamma * (0 if done else Q[s2, a2])       # действие, которое сделаем
            Q[s, a] += alpha * (target - Q[s, a])
            s, a, total = s2, a2, total + r
        returns.append(total)
    return Q, np.mean(returns[-100:])

for method in ("q", "sarsa"):
    Q, avg = train(method)
    s, steps, top_row = 3 * W, 0, 3
    while True:                                  # жадный путь по выученной Q
        top_row = min(top_row, s // W)
        s, _, done = step(s, int(np.argmax(Q[s])))
        steps += 1
        if done or steps > 50:
            break
    print(f"{method}: награда при обучении {avg:.1f}, шагов {steps}, самая верхняя строка {top_row}")
# q: награда при обучении -52.6, шагов 13, самая верхняя строка 2
# sarsa: награда при обучении -21.9, шагов 17, самая верхняя строка 0
```

Q-learning идёт по строке 2 прямо над обрывом (13 шагов), SARSA уходит на самую верхнюю строку (17 шагов), зато при обучении падает гораздо реже.

## Подводные камни

- **Нет исследования.** С ε = 0 и нулевой начальной таблицей агент может навсегда застрять на первом найденном пути.
- **Неверная обработка терминального состояния.** В конце эпизода цель — просто r, без γ · Q(s', ·). Ошибка здесь искажает все ценности.
- **Слишком большой α.** В стохастических средах ценности скачут и не сходятся; уменьшайте α со временем.
- **Таблица не масштабируется.** У шахмат около 10⁴³ позиций, у картинки с экрана — бесконечность состояний. Табличные методы работают только для маленьких дискретных задач; дальше — аппроксимация функцией, например нейросетью (DQN).
- **Переоценка.** Максимум по шумным оценкам систематически завышен; в Q-learning это ведёт к переоптимизму. Решение — Double Q-learning.

## Итоги

- Q-learning и SARSA учат таблицу Q(s, a) из опыта по TD-ошибке, без модели среды.
- Q-learning использует в цели max Q(s', ·) — off-policy, учит оптимальную политику.
- SARSA использует реальное следующее действие — on-policy, учит ценность текущей политики с её исследованием.
- На краю обрыва Q-learning выбирает кратчайший рискованный путь, SARSA — безопасный.
- Табличные методы работают только для маленьких дискретных задач.
