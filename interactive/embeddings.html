🎮 Эмбеддинги слов: word2vec в браузере

📘 Шпаргалка

Skip-gram с negative sampling учится прямо здесь на крошечном корпусе из 60 предложений про животных, еду, города и движение (уже очищен: леммы, без служебных слов). Для каждой пары «слово → слово из окна» модель повышает σ(u·v), а для k случайных «негативных» слов — понижает. Слова, встречающиеся в похожих контекстах, получают похожие векторы. Цвет точки — тема, которую модель не видит. Кликните по слову, чтобы увидеть его ближайших соседей по косинусу.

Модель

Эпоха0 Пар (центр, контекст)— Лосс за эпоху— Ср. косинус внутри тем— Ср. косинус между темами— Ближайший сосед из своей темы— Дисперсия, видная на картинке—

Соседи слова

Кликните по слову на холсте.

Лосс по эпохам

средний лосс на пару: −log σ(u·v) − Σ log σ(−uₙ·v)

Что попробовать

  • Нажмите «▶ Обучать» при настройках по умолчанию: к 100-й эпохе слова разъезжаются на 4 «луча» по темам, и ближайший сосед почти у каждого слова (95–100%) — из его же темы, хотя темы модели никто не сообщал.
  • В 2D косинус внутри темы почти 1, а между темами ≈ 0.55: группы различаются направлением, а не расстоянием — поэтому соседей ищут по косинусу. Лосс при этом застревает около 2.0: двух чисел на слово мало.
  • Размерность 8: лосс опускается до ≈ 1.1. Около 20-й эпохи слова темы почти слипаются (косинус внутри ≈ 0.95), затем расходятся до ≈ 0.6 — модель начинает различать слова внутри темы. Проекция PCA показывает лишь ≈ 40% разброса (при d = 16 — ≈ 23%), поэтому картинка — грубый срез, а честные соседи — в списке справа.
  • Окно 1 против 4 (d = 8): пар меньше (242 против 378), и темы разделяются позже — на 20-й эпохе косинус между темами ≈ 0.9 против ≈ 0.5. Итоговый лосс с окном 1 ниже (≈ 0.9 против ≈ 1.1): соседнее слово предсказать легче, чем любое слово предложения.
  • k = 0 (без негативов, d = 8): к 50-й эпохе лосс падает почти до 0 — достаточно сделать все u·v большими, ничего не «отталкивается». Слова одной темы слипаются (косинус внутри ≈ 0.95 против ≈ 0.6 при k = 5) и перестают различаться.
  • Learning rate 0.005 (d = 8): около 100-й эпохи все слова сначала выстраиваются в одном направлении (косинус и внутри, и между темами ≈ 0.98), и только к 300-й эпохе темы расходятся. При 0.5 лосс скачет около 3.5 и не сходится.
