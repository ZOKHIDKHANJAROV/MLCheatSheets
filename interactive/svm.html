🎮 Метод опорных векторов (SVM)

📘 Шпаргалка

SVM ищет разделяющую границу (сплошная линия) с максимальным зазором до классов (пунктир: f(x) = ±1). Границу определяют только опорные векторы — обведённые точки. Клик добавляет точку выбранного класса, правый клик удаляет ближайшую.

Что попробовать

  • Линейное ядро, «два облака»: двигайте C. Маленькое C — широкий зазор, допускаются нарушения, много опорных векторов. Большое C — узкий зазор, модель старается не ошибиться ни на одной точке.
  • Перетащите (удалите и добавьте) точку, которая не обведена: граница не изменится. Сдвиньте опорный вектор — граница сдвинется.
  • «Круг в кольце» линейным ядром не разделить. Переключитесь на RBF — это «трюк с ядром»: линейное разделение в неявном пространстве высокой размерности.
  • RBF: большое γ — каждая точка влияет только на маленькую окрестность, граница обтягивает точки (переобучение). Маленькое γ — граница почти линейная.
  • RBF с большими C и γ одновременно — классическое переобучение: сравните accuracy на обучении и на тесте.
