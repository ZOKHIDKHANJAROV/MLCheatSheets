Что попробовать

  • Схема «Hold-out», нажмите «×50 повторов»: гистограмма hold-out (одно разбиение) заметно шире, чем у K-Fold — одна валидационная выборка из N/K объектов даёт шумную оценку, а усреднение по K фолдам сужает разброс (при N = 100, K = 5 std ошибки hold-out ≈ 0.06–0.08, у K-Fold ≈ 0.035).
  • Доля редкого класса 0.05, N = 200, K = 10, «K-Fold с перемешиванием»: в нескольких фолдах нет ни одного объекта редкого класса (счётчик «Фолдов без редкого класса»). Переключитесь на «Stratified K-Fold» — в каждом фолде ровно по одному редкому объекту.
  • Данные «Дрейф во времени» (x₁ — номер недели, x₂ — цена с трендом, класс — «дорого относительно текущего уровня»): «K-Fold с перемешиванием», «×50 повторов» — оценка в среднем завышена на 0.15–0.18: валидационные объекты окружены обучающими из той же недели, а в будущем таких соседей нет. Выберите «TimeSeriesSplit» — смещение падает до 0.01–0.04 (разброс остаётся большим: качество в будущем само по себе шумное).
  • Данные «Группы»: перемешанный K-Fold кладёт объекты одного клиента и в train, и в validation и завышает качество примерно на 0.1 (видно по «×50 повторов»); «Group K-Fold» держит клиента целиком в одном фолде, и смещение исчезает (|смещение| ≤ 0.03).
  • «Leave-One-Out» при N = 30: 30 обучений, accuracy каждого фолда — 0 или 1, поэтому std фолдов огромный, а смысл имеет только среднее. При N = 300 это уже 300 обучений.
  • TimeSeriesSplit с gap = 10: между train и validation появляется зазор — так моделируют задержку между сбором признаков и моментом прогноза.
