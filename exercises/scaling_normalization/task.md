# Упражнение: Масштабирование и нормализация

## Задание

Дан файл `input.csv` с данными о людях: `height`, `weight`, `age`, `income`. Примените к каждому признаку свой метод масштабирования:

1. **MinMaxScaler** для `height`: x′ = (x − min) / (max − min) — диапазон [0, 1].
2. **StandardScaler** для `weight`: x′ = (x − mean) / std, std с ddof = 0.
3. **RobustScaler** для `age`: x′ = (x − median) / IQR, где IQR = Q3 − Q1 (квантили 25 % и 75 % с линейной интерполяцией, как `np.percentile` по умолчанию).
4. **MaxAbsScaler** для `income`: x′ = x / max(|x|).

## Подсказки

- Все четыре формулы пишутся в одну строку на NumPy — сделайте вручную, а потом сверьтесь с классами из `sklearn.preprocessing`.
- Стандартное отклонение — с ddof = 0 (у pandas `.std()` по умолчанию ddof = 1).
- Для IQR: `np.percentile(x, 75) - np.percentile(x, 25)`. Подумайте, какой из четырёх методов меньше всего пострадает, если добавить человека с доходом 10 000 000.

## Ожидаемый формат выходного файла

CSV с колонками `height_minmax, weight_standard, age_robust, income_maxabs` в исходном порядке строк;
значения округлить до 4 знаков.

## Разбор

> Читайте после своей попытки — в портале разбор открывается, когда упражнение решено.

**Идея.** Все скейлеры имеют вид (x − сдвиг) / масштаб и различаются только тем, что берут за сдвиг и масштаб: min и размах, среднее и std, медиану и IQR, ноль и max|x|.

**Типичные ошибки:**
- std с ddof = 1 — значения `weight_standard` в √(n/(n−1)) раза меньше по модулю.
- IQR из другой интерполяции квантилей (`method='nearest'` и т. п.) — `age_robust` немного отличается.
- MinMax через max − min всего датафрейма, а не одного признака.

**Что вынести:** MinMax и MaxAbs чувствительны к выбросам (один экстремум сжимает всех остальных к нулю), RobustScaler — нет: медиана и IQR не замечают крайние значения. MaxAbs сохраняет нули и разреженность — им масштабируют разреженные матрицы. → шпаргалка «Масштабирование и нормализация».
