# Упражнение: Функции активации и их производные

## Задание

Дан файл `input.csv` со значениями `x`. Для каждого x вычислите функции активации и их производные:

1. **sigmoid**: σ(x) = 1 / (1 + e⁻ˣ), производная σ′(x) = σ(x)·(1 − σ(x))
2. **tanh**: tanh(x), производная 1 − tanh²(x)
3. **ReLU**: max(0, x), производная 1 при x > 0, иначе 0 (в точке 0 принимаем 0)

## Подсказки

- Используйте NumPy и векторные операции — без циклов.
- Выразите производные через уже посчитанные значения функций — так делают и во фреймворках.
- Посмотрите на максимум σ′(x): почему сигмоида приводит к затуханию градиента в глубоких сетях?

## Ожидаемый формат выходного файла

значения округлить до 4 знаков.

## Разбор

> Читайте после своей попытки — в портале разбор открывается, когда упражнение решено.

**Идея.** Производные удобно выражать через уже посчитанные значения: σ′ = σ(1 − σ), tanh′ = 1 − tanh². Так их и считают во фреймворках при обратном проходе.

**Типичные ошибки:**
- Производная ReLU в нуле: по заданию 0, а не 1 или 0.5.
- Наивная сигмоида `1/(1+np.exp(-x))` на больших отрицательных x даёт предупреждение о переполнении; результат верен, но привыкайте к устойчивым формулам.
- Перепутать порядок столбцов не страшно — проверка сравнивает по именам, но имена должны совпадать.

**Что вынести:** max σ′ = 0.25, поэтому в глубокой сети с сигмоидами градиент затухает. ReLU не насыщается при x > 0 — причина её популярности, но «мёртвые» нейроны с x < 0 не учатся. → шпаргалка «Функции активации».
