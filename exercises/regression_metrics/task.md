# Упражнение: Метрики регрессии

## Задание

Дан файл `input.csv` с истинными значениями `y_true` и предсказаниями модели `y_pred` (30 объектов).

Вычислите метрики качества регрессии:

1. **MAE** — средняя абсолютная ошибка
2. **MSE** — средняя квадратичная ошибка
3. **RMSE** — корень из MSE
4. **R²** — коэффициент детерминации
5. **MAPE** — средняя абсолютная процентная ошибка **в процентах** (т.е. умноженная на 100)

## Формулы

- MAE = mean(|y − ŷ|)
- MSE = mean((y − ŷ)²)
- RMSE = √MSE
- R² = 1 − Σ(y − ŷ)² / Σ(y − ȳ)²
- MAPE = 100 · mean(|y − ŷ| / |y|)

## Разбор

> Читайте после своей попытки — в портале разбор открывается, когда упражнение решено.

**Идея.** Все метрики считаются из вектора ошибок e = y − ŷ: MAE — среднее |e|, MSE — среднее e², RMSE возвращает MSE в единицы y, R² сравнивает ошибку модели с ошибкой константы ȳ.

**Типичные ошибки:**
- MAPE в долях вместо процентов — ответ в 100 раз меньше.
- RMSE как среднее корней |e| вместо корня из среднего — получится MAE.
- R² как квадрат корреляции — совпадает с R² только для линейной регрессии на обучающих данных.

**Что вынести:** RMSE ≥ MAE всегда, и чем больше разрыв, тем больше крупных ошибок. MAPE ломается при y около нуля. R² может быть отрицательным — модель хуже константы. → шпаргалка «Метрики регрессии».
