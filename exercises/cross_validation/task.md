# Упражнение: Кросс-валидация

## Задание

Дан файл `input.csv` с признаками `x1, x2, x3, x4` и целевой переменной `y` (100 объектов).

1. Разбейте данные с помощью `KFold(n_splits=5, shuffle=True, random_state=42)`
2. На каждом фолде обучите `Ridge(alpha=1.0)` и посчитайте **R²** на валидационной части
3. Сохраните R² каждого фолда

## Подсказки

- Можно написать цикл по `kf.split(X)` вручную, а можно использовать `cross_val_score` с `cv=kf`.
  Результаты должны совпасть — проверьте!
- Посчитайте среднее и стандартное отклонение R² по фолдам. Что говорит большой разброс?

## Ожидаемый формат выходного файла

CSV с колонками `fold, r2` — 5 строк, `fold` от 1 до 5, `r2` округлить до 4 знаков.

## Разбор

> Читайте после своей попытки — в портале разбор открывается, когда упражнение решено.

**Идея.** K-fold делит данные на K частей; каждая по очереди становится валидацией, остальные — обучением. Среднее по фолдам надёжнее одной случайной отложенной выборки, а разброс показывает, насколько оценке можно верить.

**Типичные ошибки:**
- `KFold` без `shuffle=True, random_state=42` — фолды другие, значения R² другие.
- Нумерация фолдов с 0 — проверка подскажет «сдвиг на 1».
- `cross_val_score` с моделью по умолчанию (`LinearRegression` вместо `Ridge(alpha=1.0)`).

**Что вынести:** CV оценивает процедуру обучения, а не конкретную модель. Для классификации берите `StratifiedKFold`, для временных рядов — `TimeSeriesSplit`. → шпаргалка «Кросс-валидация».
