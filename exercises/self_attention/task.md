# Упражнение: Scaled dot-product attention

## Задание

В файле `input.csv` — 4 токена и уже посчитанные для них векторы запроса, ключа и значения
(размерность d = 3): колонки `q0..q2`, `k0..k2`, `v0..v2`.

Вычислите self-attention:

1. Оценки сходства: S = Q·Kᵀ / √d (матрица 4×4)
2. Веса внимания: A = softmax(S) **по строкам** (каждая строка — распределение по всем токенам)
3. Выход: O = A·V (матрица 4×3)

## Подсказки

- Не забудьте деление на √d и устойчивый softmax (вычитание максимума строки).
- Сумма каждой строки A должна быть равна 1 — проверьте.
- Бонус: примените каузальную маску (токен i видит только токены ≤ i): до softmax поставьте −∞
  в верхний треугольник S. Так работает декодер GPT. В ответ это не входит.

## Ожидаемый формат выходного файла

CSV с колонками `token, w0, w1, w2, w3, o0, o1, o2`: веса внимания токена ко всем четырём токенам
и его выходной вектор. Значения округлить до 4 знаков.

## Разбор

> Читайте после своей попытки — в портале разбор открывается, когда упражнение решено.

**Идея.** Каждый токен сравнивает свой запрос со всеми ключами (QKᵀ/√d), превращает оценки в распределение (softmax по строке) и берёт взвешенную сумму значений V. Деление на √d не даёт softmax насыщаться при большой размерности.

**Типичные ошибки:**
- Softmax по столбцам вместо строк — веса не суммируются в 1 по строке.
- Забыть /√d — веса «острее», значения другие.
- K·Qᵀ вместо Q·Kᵀ — получится транспонированная матрица оценок.

**Что вынести:** self-attention — это мягкий поиск по словарю: запрос → ключи → значения. Маска в декодере запрещает смотреть вперёд, multi-head делает несколько таких поисков в разных подпространствах. → шпаргалка «Self-attention».
