# Упражнение: Дерево решений: одобрение кредита

## Задание

Дан файл `input.csv` с заявками на кредит:

- `income` — доход, тыс., `debt` — текущий долг, тыс., `credit_years` — кредитная история, лет, `age` — возраст
- `approved` — одобрен ли кредит (целевая переменная)
- `split` — `train` или `test`

1. Обучите `DecisionTreeClassifier(max_depth=3, random_state=42)` на train,
   признаки: `income, debt, credit_years, age`
2. Предскажите класс для test
3. Посчитайте важность признаков (`feature_importances_`)

## Подсказки

- Деревьям не нужно масштабирование признаков — почему?
- Нарисуйте дерево: `sklearn.tree.plot_tree` или `export_text` — правила легко прочитать.
- Сравните accuracy на train и test при `max_depth=3` и без ограничения глубины: где переобучение?

CSV с колонками `id, approved_pred` для тестовых строк в исходном порядке.

## Разбор

> Читайте после своей попытки — в портале разбор открывается, когда упражнение решено.

**Идея.** Дерево жадно выбирает разбиение признака по порогу, которое сильнее всего уменьшает неоднородность (Gini). `max_depth=3` ограничивает сложность — это главный рычаг против переобучения.

**Типичные ошибки:**
- Не указать `random_state` — при равных по качеству разбиениях дерево может выбрать другое, и предсказания разойдутся.
- Масштабировать признаки «на всякий случай» — не ошибка, но бесполезно: дереву важен только порядок значений.
- Обучить без ограничения глубины — train accuracy ≈ 1, test хуже.

**Что вынести:** глубокое дерево запоминает выборку, ограниченное обобщает. Важность признаков в дереве смещена в пользу признаков с большим числом уникальных значений. → шпаргалка «Деревья решений».
