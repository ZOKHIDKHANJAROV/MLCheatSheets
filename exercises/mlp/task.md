# Упражнение: Прямой проход многослойного перцептрона

## Задание

Дана обученная сеть 2 → 3 → 1. Веса лежат в `weights.json`:

- `W1` — матрица 3×2 (строка = нейрон скрытого слоя), `b1` — 3 смещения, активация **tanh**;
- `W2` — матрица 1×3, `b2` — 1 смещение, выход — **sigmoid**.

Для каждой строки `input.csv` (`x1, x2`) вычислите:

1. Скрытый слой: h = tanh(W1·x + b1) → `h1, h2, h3`
2. Выход: p = σ(W2·h + b2) → вероятность класса 1
3. Предсказание `pred` = 1, если p ≥ 0.5, иначе 0

## Подсказки

- Обработайте все строки разом матрично: H = tanh(X·W1ᵀ + b1), где X — матрица n×2.
- `json.load(open('weights.json'))` → словарь со списками; превратите их в `np.array`.
- Сколько параметров у этой сети? (Ответ: 3·2 + 3 + 1·3 + 1 = 13.)

## Ожидаемый формат выходного файла

CSV с колонками `id, h1, h2, h3, p, pred`; значения округлить до 4 знаков.

## Разбор

> Читайте после своей попытки — в портале разбор открывается, когда упражнение решено.

**Идея.** Прямой проход — чередование «линейный слой → нелинейность». Матрично для всех объектов сразу: H = tanh(X·W1ᵀ + b1), p = σ(H·W2ᵀ + b2).

**Типичные ошибки:**
- X·W1 вместо X·W1ᵀ — ошибка размерности или (при квадратных матрицах) неверные числа.
- Сигмоида в скрытом слое вместо tanh.
- Порог `p > 0.5` вместо `p ≥ 0.5` — расхождение только на граничных объектах.

**Что вынести:** у сети 2 → 3 → 1 13 параметров. Без нелинейности стопка линейных слоёв схлопнулась бы в один линейный — tanh даёт сети гнуть разделяющую границу. → шпаргалка «Архитектура MLP».
