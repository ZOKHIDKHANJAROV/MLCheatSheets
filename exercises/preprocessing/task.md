# Упражнение: Предобработка данных (Preprocessing)

## Задание

Дан файл `input.csv` с данными о клиентах: `age`, `income`, `education` и целевая переменная `purchased`.

1. Отделите признаки `age, income, education` от целевой переменной `purchased`.
2. Стандартизируйте числовые признаки `age` и `income`: z = (x − μ) / σ, где μ — среднее,
   σ — стандартное отклонение **генеральной совокупности** (ddof = 0, как в `StandardScaler`).
3. Закодируйте `education` числами в алфавитном порядке: Bachelor = 0, Master = 1, PhD = 2 (как `LabelEncoder`).

## Подсказки

- Сначала посчитайте μ и σ вручную через NumPy, а потом сверьтесь со `StandardScaler` — числа должны совпасть.
- У pandas `df['age'].std()` по умолчанию считает с ddof = 1, а у NumPy и `StandardScaler` — с ddof = 0. Разница видна уже в третьем знаке.
- `LabelEncoder` сортирует категории по алфавиту: `sorted(df['education'].unique())` даст порядок кодов.

## Ожидаемый формат выходного файла

CSV с колонками `age_scaled, income_scaled, education_encoded` в исходном порядке строк;
числа округлить до 4 знаков.

## Разбор

> Читайте после своей попытки — в портале разбор открывается, когда упражнение решено.

**Идея.** Стандартизация переводит признаки в общую шкалу «сколько стандартных отклонений от среднего», чтобы доход в десятках тысяч не заглушал возраст в десятках лет. Порядковое кодирование превращает категории в числа.

**Типичные ошибки:**
- `std()` из pandas (ddof = 1) — все значения отличаются в √(n/(n−1)) раза; проверка распознает это.
- Стандартизировать и `purchased` — целевую переменную не масштабируют.
- Кодировать в порядке появления в данных (`pd.factorize`), а не по алфавиту — коды переставлены.

**Что вынести:** в реальной задаче скейлер обучают только на train (`fit` на train, `transform` на test) — иначе утечка данных. А `LabelEncoder` предназначен для целевой переменной: для признаков без естественного порядка лучше one-hot (упражнение `categorical_encoding`). → шпаргалка «Предобработка данных».
