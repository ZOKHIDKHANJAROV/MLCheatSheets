# 🏗 Мини-проекты

Сквозные задачи по одной на учебный путь: от сырых данных до итоговой модели. В отличие от упражнений, правильного ответа
нет — вы строите свою модель, делаете прогнозы для `test.csv` и проверяете качество на скрытых метках.

| Проект | Путь | Задача | Метрика |
|---|---|---|---|
| [churn_prediction](churn_prediction/README.md) | 1 · Новичок | отток клиентов: пропуски, категории, бустинг, интерпретация | ROC-AUC |
| [digits_recognition](digits_recognition/README.md) | 2 · Deep Learning | рукописные цифры: MLP, регуляризация, бонус — CNN | accuracy |
| [credit_scoring](credit_scoring/README.md) | 3 · Production | скоринг с ценой ошибок: пайплайн, калибровка, выбор порога | средняя стоимость ошибок |
| [demand_forecast](demand_forecast/README.md) | 4 · Временные ряды | прогноз продаж на 28 дней: сезонность, акции, валидация по времени | MAE |

## Как работать

1. Прочитайте `README.md` проекта — там данные, шаги и формат ответа.
2. Решайте в своём ноутбуке или скрипте; оценивайте модель на кросс-валидации или отложенной части **train**, а не на test.
3. Сохраните прогнозы в `my_predictions.csv` в папке проекта и проверьте:

```bash
python tools/check_mini_project.py projects/churn_prediction
```

Скрипт покажет метрику и уровень: **базовый** (простой бейзлайн), **хорошо**, **отлично** (близко к эталонному решению).

`answer.csv` — скрытые метки для проверки: не открывайте его, иначе проект теряет смысл. Эталонное решение — `solution.py`.

Данные синтетические и создаются `tools/generate_projects.py` (повторный запуск даёт те же файлы и пороги).
