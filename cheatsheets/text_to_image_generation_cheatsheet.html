📅 Январь 2026

🔷 1. Суть и эволюция

Text-to-image — генерация изображения x по текстовому описанию (промпту) c, т.е. сэмплирование из p(x | c). Сегодня доминируют диффузионные модели с текстовым условием (основы — в шпаргалке Diffusion Models).

🔷 2. Текстовые энкодеры

  • CLIP text encoder: обучен контрастивно на парах картинка–текст (CLIP); SD 1.x — CLIP ViT-L/14 (эмбеддинги 77×768), SD 2.x — OpenCLIP ViT-H, SDXL — два CLIP-энкодера
  • T5 (T5-XXL): чисто языковая модель; Imagen показал, что масштаб текстового энкодера сильно улучшает следование промпту и отрисовку текста; SD3/FLUX используют CLIP + T5
  • Лимит токенов: у CLIP — 77 токенов, хвост длинного промпта обрезается
  • Энкодер обычно заморожен; в денойзер подаётся последовательность эмбеддингов токенов (а не один вектор)
CLIP плохо кодирует композицию и счёт: «красный куб на синем шаре» и наоборот дают близкие эмбеддинги — отсюда перепутанные атрибуты.

🔷 3. Stable Diffusion: архитектура

промпт ──► CLIP text encoder ──► эмбеддинги c (77×768)
                                     │ cross-attention
шум z_T (4×64×64) ──► U-Net ε_θ(z_t, t, c) ──► ... ──► z_0
                       (T шагов сэмплера)
z_0 ──► VAE decoder ──► изображение 512×512×3
  • VAE (VAE): сжатие в 8 раз по стороне, 512×512×3 → 64×64×4 (~48× меньше значений) — диффузия на порядки дешевле, чем в пикселях
  • U-Net: предсказывает шум ε; ResNet-блоки + self-attention + cross-attention
  • Cross-attention: Q — из пространственных признаков изображения, K и V — из эмбеддингов токенов: Attn = softmax(QKᵀ/√d)·V — каждая область «смотрит» на нужные слова
  • Время t: синусоидальный эмбеддинг, добавляется в ResNet-блоки
  • Обучение: L = E‖ε − ε_θ(z_t, t, c)‖², z_t = √ᾱ_t·z_0 + √(1−ᾱ_t)·ε

🔷 4. Classifier-free guidance (CFG)

При обучении условие c с вероятностью ~10% заменяется на пустой промпт → одна модель умеет и условное, и безусловное предсказание. При генерации:

ε̂ = ε_θ(z_t, ∅) + w · (ε_θ(z_t, c) − ε_θ(z_t, ∅))
guidance_scale wРезультат
1обычное условное сэмплирование, слабое следование тексту
5–9 (типично 7.5)баланс качества и соответствия промпту
> 12–15пересыщенные цвета, артефакты, низкое разнообразие
  • Стоимость: два прохода U-Net на шаг (батчем условный + безусловный)
  • Компромисс: ↑w — выше CLIP score, но хуже FID и разнообразие
  • Distilled-модели (SDXL-Turbo, LCM) работают с w ≈ 0–2

🔷 5. Сэмплеры, шаги, негативные промпты

Сэмплер (scheduler)ШаговОсобенности
DDPM~1000стохастический, исходный, медленный
DDIM25–50детерминированный, инверсия изображения
Euler / Euler a20–40просты; «a» (ancestral) добавляет шум — не сходится к одному результату
DPM-Solver++ (2M, Karras)15–30качество при малом числе шагов, частый выбор
LCM / Turbo / Lightning1–8требуют дистиллированной модели или LoRA
  • Больше шагов → больше деталей до насыщения; после ~30–50 прирост мал
  • Seed (generator) фиксирует начальный шум → воспроизводимость
  • Негативный промпт: подставляется вместо пустого ∅ в CFG — генерация отталкивается от «blurry, lowres, extra fingers, watermark»
  • Разрешение: генерируйте в родном разрешении модели (SD 1.5 — 512, SDXL — 1024), иначе дубли объектов

🔷 6. Код: diffusers

import torch
from diffusers import StableDiffusionPipeline, DPMSolverMultistepScheduler

pipe = StableDiffusionPipeline.from_pretrained(
    "stable-diffusion-v1-5/stable-diffusion-v1-5",
    torch_dtype=torch.float16).to("cuda")
pipe.scheduler = DPMSolverMultistepScheduler.from_config(pipe.scheduler.config)
pipe.enable_attention_slicing()            # экономия памяти

g = torch.Generator("cuda").manual_seed(42)
image = pipe(
    prompt="a cozy wooden cabin in snowy mountains, golden hour, photo",
    negative_prompt="blurry, lowres, watermark, text",
    num_inference_steps=25,
    guidance_scale=7.5,
    height=512, width=512,
    generator=g,
).images[0]
image.save("cabin.png")
  • SDXL: StableDiffusionXLPipeline, универсально — AutoPipelineForText2Image
  • fp16 + enable_model_cpu_offload() — запуск на GPU с малой памятью

🔷 7. img2img и inpainting

  • img2img: исходное изображение кодируется VAE, зашумляется до шага t = strength·T и расшумляется по промпту. strength 0.3 — лёгкая стилизация, 0.8 — почти новая картинка
  • Inpainting: перерисовка области под маской; спец. модели с доп. входными каналами (маска + замаскированное изображение)
  • Outpainting: расширение холста = inpainting за краями
from diffusers import StableDiffusionImg2ImgPipeline
from PIL import Image

img2img = StableDiffusionImg2ImgPipeline(**pipe.components)   # те же веса
init = Image.open("sketch.png").convert("RGB").resize((512, 512))
out = img2img(prompt="watercolor painting of a cabin",
              image=init, strength=0.6, guidance_scale=7.5).images[0]
# inpainting: StableDiffusionInpaintPipeline(..)(prompt, image=init, mask_image=mask)

🔷 9. Метрики качества

  • FID: расстояние Фреше между гауссианами признаков Inception для реальных и сгенерированных изображений — реализм + разнообразие (↓ лучше); нужны тысячи изображений, зависит от реализации
  • CLIP score: косинус CLIP-эмбеддингов текста и изображения ×100 — соответствие промпту (↑ лучше)
  • Композиция: GenEval, T2I-CompBench — счёт объектов, цвета, взаимное расположение
  • Предпочтения людей: ImageReward, PickScore, HPS — модели, обученные на человеческих оценках; финальное слово — side-by-side оценка людьми
from torchmetrics.multimodal.clip_score import CLIPScore
from torchmetrics.image.fid import FrechetInceptionDistance

clip = CLIPScore(model_name_or_path="openai/clip-vit-base-patch16")
score = clip(images_uint8, prompts)          # images: (N, 3, H, W) uint8

🔷 10. Ограничения и типичные проблемы

  • Счёт и пространственные отношения: «три кошки слева от собаки» — частые ошибки
  • Связывание атрибутов: цвета/свойства «перетекают» между объектами
  • Текст на изображении: слабое место моделей с CLIP; лучше у моделей с T5 (Imagen, SD3, FLUX)
  • Руки, пальцы, анатомия, дублирование объектов при нестандартном разрешении
  • Слишком большой guidance → пересвет и артефакты; слишком мало шагов → «мыло»
  • Промпт длиннее 77 токенов обрезается (у CLIP-энкодеров)

🔷 11. Этика и безопасность

  • Дипфейки и дезинформация: реалистичные изображения реальных людей и событий
  • Авторское право: обучение на веб-данных (LAION), копирование стиля художников, меморизация обучающих изображений
  • Смещения: стереотипы по профессии, полу, этносу из обучающих данных
  • Защиты: safety checker / NSFW-фильтры, фильтрация данных, концепт-эрейзинг, водяные знаки (invisible watermark, C2PA-метаданные)
  • Соблюдайте лицензию модели (например, CreativeML OpenRAIL-M) и правила платформы
