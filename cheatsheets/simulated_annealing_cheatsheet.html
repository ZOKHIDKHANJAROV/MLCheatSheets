🔥 Simulated Annealing (имитация отжига)

📅 Январь 2026

🔷 1. Суть и интуиция

Simulated annealing (SA) — метаэвристика глобальной оптимизации, вдохновлённая отжигом металла: при медленном остывании атомы успевают уложиться в состояние с минимальной энергией.

  • Энергия E(x): минимизируемая функция (длина маршрута, штраф расписания, ошибка на валидации)
  • Состояние x: текущее решение; сосед x' — небольшое изменение x
  • Температура T: управляет готовностью принимать ухудшения
  • Идея: при высокой T — почти случайное блуждание (исследование), при низкой T — жадный спуск (эксплуатация)
Ключевое отличие от hill climbing: SA иногда делает шаг «в гору», чтобы выбраться из локального минимума.

🔷 2. Критерий Метрополиса

Для кандидата x' считаем ΔE = E(x') − E(x):

  • ΔE ≤ 0 (улучшение или равенство): принимаем всегда
  • ΔE > 0 (ухудшение): принимаем с вероятностью P = exp(−ΔE / T)

🔷 3. Алгоритм по шагам

x = начальное решение;  best = x;  T = T0
while T > T_min and не исчерпан бюджет:
    for i in range(L):              # L шагов на одной температуре
        x' = neighbor(x)
        dE = E(x') - E(x)
        if dE <= 0 or rand() < exp(-dE / T):
            x = x'
            if E(x) < E(best): best = x
    T = cool(T)                     # расписание охлаждения
return best
  • Длина цепи L: число попыток на температуре (часто ∝ размеру окрестности)
  • Всегда храните best: текущий x может «уплыть» от лучшего найденного решения
  • Критерии остановки: T < T_min, лимит итераций, нет улучшений N эпох, доля принятых ходов ≈ 0

🔷 4. Расписания охлаждения

РасписаниеФормулаСвойства
ЛинейноеT_k = T0 − η·kпросто, нужно заранее знать бюджет
ГеометрическоеT_k = α^k·T0, α ≈ 0.9–0.999стандарт на практике
ЛогарифмическоеT_k = c / log(1 + k)гарантия сходимости к глобальному оптимуму (Geman & Geman), но крайне медленно
Быстрое (Cauchy)T_k = T0 / (1 + k)для «быстрого отжига» с тяжёлыми хвостами шагов
Адаптивноеменяем T по доле принятых ходовдержит acceptance rate в целевом коридоре
  • Слишком быстрое охлаждение = «закалка» (quenching): застревание в первом локальном минимуме
  • Слишком медленное: долго бродит случайно, тратит бюджет
  • Reheating: при стагнации поднимаем T снова

🔷 5. Начальная температура и параметры

  • T0: чтобы в начале принималось ~80% ухудшений. Оцениваем среднее ΔE⁺ на случайных ходах: T0 = −ΔE⁺ / ln(0.8)
  • T_min: когда exp(−ΔE_min / T) ничтожно мало (ходы почти не принимаются)
  • α: компромисс качество/время; при α = 0.99 температура падает в 10 раз примерно за 230 шагов охлаждения
  • Масштаб E: T измеряется в единицах E — при нормировке целевой функции настройки переносимы между задачами
Мониторьте долю принятых ходов: она должна плавно падать от ~0.8 до ~0.01.

  • Инкрементальный ΔE: для 2-opt ΔE считается за O(1), а не пересчётом всего маршрута

  • Ограничения: запрещённые решения либо не генерировать, либо штрафовать в E

🔷 7. Код: TSP с 2-opt на numpy

import numpy as np

rng = np.random.default_rng(0)
pts = rng.random((60, 2))
D = np.linalg.norm(pts[:, None] - pts[None], axis=-1)

def length(route):
    return D[route, np.roll(route, -1)].sum()

def anneal_tsp(T0=1.0, alpha=0.995, L=200, T_min=1e-4):
    x = rng.permutation(len(pts))
    e = length(x)
    best, best_e, T = x.copy(), e, T0
    while T > T_min:
        for _ in range(L):
            i, j = sorted(rng.choice(len(x), 2, replace=False))
            if j - i < 2:
                continue
            a, b = x[i - 1], x[i]
            c, d = x[j - 1], x[j % len(x)]
            dE = D[a, c] + D[b, d] - D[a, b] - D[c, d]   # 2-opt, O(1)
            if dE <= 0 or rng.random() < np.exp(-dE / T):
                x[i:j] = x[i:j][::-1]
                e += dE
                if e < best_e:
                    best, best_e = x.copy(), e
        T *= alpha                                     # геометрическое
    return best, best_e

route, L_best = anneal_tsp()
print(f"длина маршрута: {L_best:.3f}")

🔷 8. Код: функция Растригина и scipy

Растригин f(x) = 10n + Σ(xᵢ² − 10·cos 2πxᵢ) — множество локальных минимумов, глобальный минимум 0 в точке x = 0.

import numpy as np
from scipy.optimize import dual_annealing

def rastrigin(x):
    return 10 * len(x) + np.sum(x**2 - 10 * np.cos(2 * np.pi * x))

bounds = [(-5.12, 5.12)] * 10
res = dual_annealing(rastrigin, bounds, maxiter=1000)
print(res.x.round(3), res.fun, res.nfev)
  • dual_annealing: обобщённый SA (Tsallis) + локальный поиск (L-BFGS-B) из лучших точек
  • Параметры: maxiter, initial_temp (по умолчанию 5230), restart_temp_ratio (reheating), visit, accept, no_local_search=True — «чистый» SA
  • Нужны только ограничения-коробка (bounds) и значения функции — градиент не требуется

🔷 10. Применение

  • TSP и маршрутизация: классический пример (Kirkpatrick et al., 1983 — размещение элементов на чипе)
  • Расписания: занятия, смены персонала, загрузка станков — E = сумма штрафов за нарушения
  • Размещение и трассировка VLSI, раскрой, упаковка
  • Подбор гиперпараметров: дискретные/смешанные пространства (есть в некоторых AutoML-библиотеках), см. тюнинг гиперпараметров
  • Отбор признаков: бинарная маска, E = ошибка на CV + штраф за число признаков
  • Квантовый отжиг: аппаратный аналог (D-Wave) для QUBO-задач

🔷 11. Типичные ошибки

  • ❌ T0 подобран «на глаз» без учёта масштаба E → либо случайное блуждание, либо жадный спуск
  • ❌ Возврат последнего x вместо лучшего best
  • ❌ Слишком «большие» ходы — пропадает локальность
  • ❌ Пересчёт всей E вместо инкрементального ΔE — в десятки раз медленнее
  • ❌ Шумная E (например, CV-оценка) без усреднения — критерий принимает шум за улучшение
  • ❌ Один прогон и выводы о качестве: SA стохастичен, сравнивайте по нескольким seed

🔷 12. Чек-лист

  • ☐ Определить E и ход-соседа, ΔE считается быстро
  • ☐ Откалибровать T0 по доле принятых ухудшений (~0.8)
  • ☐ Геометрическое охлаждение α ≈ 0.95–0.999, длина цепи L
  • ☐ Сохранять best, логировать acceptance rate и E
  • ☐ Несколько перезапусков / reheating при стагнации
  • ☐ Сравнить с hill climbing и GA на том же бюджете вычислений E
