🔷 2. Задачи (MIR и генерация)

  • Генерация: символьная (мелодии, аккомпанемент, гармонизация) и аудио (text-to-music, продолжение трека)
  • Транскрипция (AMT): аудио → ноты/MIDI (Onsets and Frames, MT3, Basic Pitch)
  • Разделение источников: вокал / барабаны / бас / прочее (Spleeter, Open-Unmix, Demucs)
  • Классификация жанров, настроения, инструментов
  • Авто-тегирование: multi-label теги (rock, female vocal, guitar)
  • Ритм и гармония: детекция битов и темпа, распознавание аккордов, тональности
  • Рекомендации и поиск: эмбеддинги треков, cover song detection, текст↔аудио (CLAP, MuLan)

🔷 3. Почему сырое аудио — трудно

  • 44.1 кГц: 1 секунда = 44 100 отсчётов, 3 минуты ≈ 8 млн шагов
  • Структура музыки — на масштабе минут (куплет, припев), детали — на микросекундах
  • Решение: нейронный кодек сжимает аудио в токены. EnCodec 32 кГц (для MusicGen): 50 кадров/с × 4 кодбука → 200 токенов/с вместо 32 000 отсчётов
  • RVQ (residual vector quantization): каждый следующий кодбук кодирует остаток предыдущего; первые — грубая структура, последние — детали
  • Альтернатива — латентная диффузия по непрерывным латентам VAE (Stable Audio)

🔷 4. Символьные модели

  • RNN/LSTM (Magenta MelodyRNN, Performance RNN): предсказание следующего события; хороши локально, теряют форму
  • MusicVAE: иерархический VAE, латентное пространство мелодий, интерполяция
  • Music Transformer (Huang et al., 2018): относительное позиционное внимание — музыка держится на повторах и интервалах, важна относительная дистанция, а не абсолютная позиция. Трюк «skewing» снижает память с O(L²D) до O(LD)
  • Pop Music Transformer (REMI-токены с тактами и позициями), MuseNet (GPT-подобная, много инструментов)

Почему next-note даёт «музыку без формы»: модель учит локальные переходы, а не крупную структуру. Помогают длинный контекст, иерархия (такты → фразы), условия на аккорды/секции, относительное внимание.

🔷 6. Код: признаки с librosa

import numpy as np
import librosa

y, sr = librosa.load("track.wav", sr=22050, mono=True)

tempo, beats = librosa.beat.beat_track(y=y, sr=sr)
beat_times = librosa.frames_to_time(beats, sr=sr)

mel = librosa.feature.melspectrogram(y=y, sr=sr, n_fft=2048,
                                     hop_length=512, n_mels=128)
mel_db = librosa.power_to_db(mel, ref=np.max)   # вход для CNN
mfcc = librosa.feature.mfcc(y=y, sr=sr, n_mfcc=20)
chroma = librosa.feature.chroma_cqt(y=y, sr=sr)  # 12 классов высот
onset_env = librosa.onset.onset_strength(y=y, sr=sr)

print(mel_db.shape, mfcc.shape, chroma.shape)   # (128, T) (20, T) (12, T)

Для MIDI: pretty_midi.PrettyMIDI("song.mid").get_piano_roll(fs=16) → матрица 128 × T.

🔷 7. Код: MusicGen (transformers)

import scipy.io.wavfile
from transformers import AutoProcessor, MusicgenForConditionalGeneration

processor = AutoProcessor.from_pretrained("facebook/musicgen-small")
model = MusicgenForConditionalGeneration.from_pretrained(
    "facebook/musicgen-small")

inputs = processor(text=["lo-fi hip hop beat with mellow piano"],
                   padding=True, return_tensors="pt")
audio = model.generate(**inputs, do_sample=True,
                       guidance_scale=3, max_new_tokens=256)  # ~5 c

sr = model.config.audio_encoder.sampling_rate        # 32000
scipy.io.wavfile.write("musicgen.wav", rate=sr,
                       data=audio[0, 0].numpy())

Через audiocraft: MusicGen.get_pretrained("facebook/musicgen-small"), model.set_generation_params(duration=8), model.generate([...]). Разделение: demucs --two-stems=vocals song.mp3.

Объективные метрики показывают близость к данным, но не музыкальность → обязательны слушательские тесты (MOS, A/B). Проверяйте запоминание: поиск совпадений сгенерированного с обучающими треками. GTZAN содержит дубликаты и повторяющихся исполнителей — разбивайте по артистам.

🔷 9. Авторские права и этика

  • Данные: обучение на защищённых записях — предмет исков (RIAA против Suno и Udio, 2024); MusicGen обучен на ~20 тыс. часов лицензированной музыки
  • Лицензии весов: веса MusicGen — CC-BY-NC 4.0 (некоммерческое использование)
  • Запоминание: модель может воспроизвести фрагменты мелодий или текстов из обучения
  • Голоса артистов: клонирование голоса без согласия — правовой и этический риск
  • Прозрачность: водяные знаки (AudioSeal), маркировка ИИ-контента

🔷 10. Типичные ошибки

Плохо

  • Сплит по трекам, когда в train и test один артист/альбом
  • Смешивать частоты дискретизации без ресемплинга
  • Судить о качестве генерации только по FAD
  • Генерировать сырые отсчёты без кодека

Хорошо

  • Сплит по артистам, аугментации (pitch shift, time stretch, mixup)
  • log-mel + предобученные эмбеддинги (PANNs, CLAP, MERT)
  • Слушательские тесты и проверка запоминания
  • Проверять лицензии данных и весов
