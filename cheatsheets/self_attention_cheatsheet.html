🎯 Self-Attention

📅 Январь 2026

🔷 1. Суть

Self-attention (внутреннее внимание) — каждый токен последовательности «смотрит» на все токены той же последовательности и собирает из них взвешенную смесь. Результат — контекстное представление каждого токена.

  • Вход: X ∈ ℝn×d — n токенов по d признаков
  • Выход: Z ∈ ℝn×d_v — тот же порядок, но каждый токен «знает» о контексте
  • Связи: любые два токена связаны за 1 шаг (в RNN — за n шагов)
  • Параллельность: все позиции считаются одним матричным умножением
Общая идея внимания в seq2seq (Bahdanau, Luong: декодер смотрит на энкодер) — в шпаргалке Attention Mechanism. Здесь — внимание последовательности к самой себе, основа Transformer. Поиграть: интерактив «Внимание».

🔷 2. Q, K, V из одной последовательности

Три обучаемые проекции одного и того же X:

Q = X·W_Q   (n×d_k)  — «что я ищу»
K = X·W_K   (n×d_k)  — «что я предлагаю»
V = X·W_V   (n×d_v)  — «что я отдам»
  • Query: запрос токена i; сравнивается со всеми ключами
  • Key: «метка» токена j; совпадение qi·kj = релевантность
  • Value: содержимое, которое смешивается с весами внимания
  • Разные W нужны, чтобы отношение «i смотрит на j» могло быть несимметричным

🔷 3. Scaled dot-product attention

Attention(Q, K, V) = softmax(Q·Kᵀ / √d_k + M) · V
  1. Оценки: S = Q·Kᵀ (n×n) — сходство каждого с каждым
  2. Масштаб: S / √d_k
  3. Маска: + M (0 или −∞)
  4. Softmax по строкам: A — веса, сумма по строке = 1
  5. Смесь: Z = A·V; zi = Σj aij·vj

Зачем √d_k: если компоненты q, k ~ N(0,1), то Var(q·k) = d_k. При больших d_k оценки огромные → softmax почти one-hot → градиенты ≈ 0. Деление возвращает дисперсию к ≈1.

  • Маска добавляется к оценкам до softmax: −∞ → вес 0
  • Causal-маска — верхний треугольник n×n: torch.triu(ones, diagonal=1)
  • Если в строке всё замаскировано → softmax даёт NaN; следите за полностью пустыми последовательностями
  • В fp16 вместо −∞ часто используют большое отрицательное число (например, torch.finfo(dtype).min)

🔷 5. Multi-head (кратко)

Вместо одного внимания размерности d — h «голов» размерности d/h со своими W_Q, W_K, W_V; выходы конкатенируются и проецируются W_O.

head_i = Attention(X·W_Q^i, X·W_K^i, X·W_V^i)
MHA(X) = Concat(head_1..head_h)·W_O
  • Головы ловят разные типы связей (синтаксис, кореференция, позиция)
  • Стоимость ≈ как у одной головы полной размерности
  • Варианты: MQA, GQA (общие K/V для групп голов → меньше KV-кэш)

Подробно: Multi-Head Attention.

🔷 6. Порядок токенов и позиционное кодирование

🔷 7. Сложность и эффективные варианты

  • Время: O(n²·d) — матрица Q·Kᵀ
  • Память: O(n²) на матрицу внимания (на голову и пример)
  • RNN: O(n·d²), но последовательно; свёртка: O(n·k·d)
  • При n ≫ d квадрат по длине доминирует — длинный контекст дорог
ПодходСложностьПримеры

🔷 9. PyTorch: с нуля

import math
import torch
import torch.nn as nn
import torch.nn.functional as F

class SelfAttention(nn.Module):
    def __init__(self, d_model, d_k=None):
        super().__init__()
        d_k = d_k or d_model
        self.q = nn.Linear(d_model, d_k, bias=False)
        self.k = nn.Linear(d_model, d_k, bias=False)
        self.v = nn.Linear(d_model, d_k, bias=False)
        self.scale = 1 / math.sqrt(d_k)

    def forward(self, x, causal=False, pad_mask=None):
        # x: (B, n, d_model); pad_mask: (B, n), True = PAD
        q, k, v = self.q(x), self.k(x), self.v(x)
        scores = q @ k.transpose(-2, -1) * self.scale   # (B, n, n)
        n = x.size(1)
        if causal:
            future = torch.triu(torch.ones(n, n, dtype=torch.bool,
                                           device=x.device), 1)
            scores = scores.masked_fill(future, float("-inf"))
        if pad_mask is not None:
            scores = scores.masked_fill(pad_mask[:, None, :], float("-inf"))
        attn = F.softmax(scores, dim=-1)
        return attn @ v, attn

x = torch.randn(2, 5, 32)
out, attn = SelfAttention(32)(x, causal=True)
print(out.shape, attn.shape)   # (2, 5, 32) (2, 5, 5)

🔷 10. PyTorch: готовые модули

mha = nn.MultiheadAttention(embed_dim=32, num_heads=4,

causal = torch.triu(torch.ones(n, n, dtype=torch.bool), 1)
pad = torch.zeros(2, n, dtype=torch.bool)  # True = игнорировать

🔷 11. Типичные ошибки

Плохо

  • Забыть деление на √d_k — обучение «застревает»
  • Softmax не по той оси (по ключам нужно: dim=-1)
  • Нет causal-маски в языковой модели → утечка будущего, идеальный train loss
  • Перепутать смысл маски (True = «можно» vs «нельзя»)
  • Не передать padding-маску — модель смотрит на PAD
  • Забыть позиционное кодирование — модель видит «мешок слов»

Хорошо

  • Проверять формы: (B, h, n, n) для весов
  • Использовать F.scaled_dot_product_attention для скорости и памяти
  • Тест на causal: изменение токена t не меняет выходы < t
  • Визуализировать карты внимания (но помнить: внимание ≠ объяснение)
