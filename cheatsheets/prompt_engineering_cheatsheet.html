💬 Prompt Engineering

📅 Январь 2026

🔷 1. Основы

Prompt — текстовая инструкция для LLM.

Компоненты:

  • Instruction: что делать
  • Context: доп. информация
  • Input Data: данные
  • Output Format: формат ответа
# Плохо
"Расскажи про ML"

# Хорошо
"Ты ML-инженер. Объясни Gradient Descent 
студенту простыми словами. Используй аналогии. 
Не более 150 слов."

Определи sentiment: "{text}"

🔷 3. Chain-of-Thought

Q: У Роджера 5 мячей. Купил 2 банки по 3. 
Сколько всего?

A: Давайте пошагово:
1. Было: 5
2. Купил: 2 × 3 = 6
3. Всего: 5 + 6 = 11

Ответ: 11

Zero-shot CoT:

Q: {question}
A: Давайте подумаем шаг за шагом.

🔷 4. Role Prompting

System: "Ты опытный Python-разработчик 
с 10-летним стажем."

User: "Напиши код для binary search"

Примеры ролей:

  • Data Scientist
  • Эксперт по безопасности
  • Преподаватель
  • Детский психолог

🔷 5. Structured Output

Проанализируй отзыв. Ответь в JSON:
{
  "sentiment": "positive/negative/neutral",
  "confidence": 0.0-1.0,
  "keywords": ["word1", "word2"],
  "summary": "краткое резюме"
}

Отзыв: "{text}"

🔷 6. Self-Consistency

# Генерируем несколько ответов
responses = []
for _ in range(5):
    response = llm(prompt)
    responses.append(response)

# Выбираем самый частый
final = most_common(responses)

🔷 7. ReAct (Reasoning + Acting)

Вопрос: Какой рост у президента страны, 
где был изобретен Python?

Thought: Нужно узнать, где изобретен Python
Action: search("Python programming language creator")
Observation: Guido van Rossum, Netherlands

Thought: Теперь нужен президент Netherlands
Action: search("Netherlands president")
Observation: Mark Rutte (Prime Minister)

Thought: Узнать рост Mark Rutte
Action: search("Mark Rutte height")
Observation: 1.93 m

Answer: 1.93 метра

🔷 8. API Usage

import openai

openai.api_key = "YOUR_KEY"

response = openai.ChatCompletion.create(
    model="gpt-4",
    messages=[
        {"role": "system", "content": "Ты AI ассистент"},
        {"role": "user", "content": "Объясни ML"}
    ],
    temperature=0.7,
    max_tokens=150
)

print(response.choices[0].message.content)

🔷 9. Best Practices

  • Будьте конкретны
  • Задавайте роль
  • Используйте примеры (few-shot)
  • Просите пошаговые решения
  • Указывайте формат output
  • Итерируйте промпты
  • Тестируйте на разных примерах

🔷 10. Частые ошибки

  • ❌ Слишком расплывчато
  • ❌ Нет примеров
  • ❌ Не указан формат
  • ❌ Противоречивые инструкции
  • ❌ Слишком длинный prompt
«Prompt engineering — искусство правильно формулировать задачу для LLM. Хороший промпт = чёткая инструкция + примеры + формат ответа».
