🐝 Swarm Intelligence (роевой интеллект)

📅 Январь 2026

🔷 1. Суть и интуиция

Роевой интеллект — семейство метаэвристик, где много простых агентов с локальными правилами и обменом информацией коллективно находят хорошие решения без центрального управления.

  • Самоорганизация: глобальное поведение возникает из локальных взаимодействий
  • Стигмергия: косвенное общение через среду (феромоны у муравьёв)
  • Баланс: исследование (exploration) ↔ эксплуатация (exploitation)
  • Главные алгоритмы: PSO (стая птиц/косяк рыб), ACO (муравьиная колония)
  • Другие: ABC (пчелиная колония), firefly, cuckoo search, grey wolf — часто вариации тех же идей
Методы безградиентные: нужна только возможность вычислить качество решения f(x).

🔷 2. PSO: формулы

Каждая частица i имеет позицию xᵢ, скорость vᵢ, личный рекорд pbestᵢ; рой знает gbest (или lbest в окрестности).

v ← w·v + c₁·r₁·(pbest − x) + c₂·r₂·(gbest − x)
x ← x + v
r₁, r₂ ~ U(0, 1)  (покомпонентно)
  • w·v — инерция: продолжать лететь в том же направлении
  • c₁r₁(pbest − x) — когнитивная составляющая: тяга к своему лучшему положению
  • c₂r₂(gbest − x) — социальная составляющая: тяга к лучшему положению роя
  • После шага: если f(x) < f(pbest) → pbest = x; обновить gbest

🔷 3. PSO: гиперпараметры и топологии

ПараметрТипичноЭффект
w (инерция)0.7298 или 0.9 → 0.4 линейнобольшой — исследование, малый — уточнение
c₁ (cognitive)1.49618 / 2.0индивидуальный поиск
c₂ (social)1.49618 / 2.0скорость схождения роя
Размер роя20–50больше — надёжнее, дороже
v_max10–50% диапазонапредотвращает «взрыв» скоростей
  • Constriction (Clerc–Kennedy): χ = 0.7298 при c₁ = c₂ = 2.05 — устойчивость без v_max
  • gbest (звезда): все видят лучшего — быстро сходится, риск преждевременной сходимости
  • lbest (кольцо): соседи по кольцу — медленнее, но лучше на мультимодальных функциях
  • Von Neumann (решётка): компромисс; также случайные/динамические топологии
  • Границы: clip, отражение или поглощение (скорость = 0) при выходе за bounds

🔷 4. Код PSO на numpy

import numpy as np

def rastrigin(X):                       # X: (n_particles, dim)
    return 10 * X.shape[1] + (X**2 - 10 * np.cos(2 * np.pi * X)).sum(1)

def pso(f, dim, lo, hi, n=40, iters=500, w_max=0.9, w_min=0.4,
        c1=2.0, c2=2.0, seed=0):
    rng = np.random.default_rng(seed)
    x = rng.uniform(lo, hi, (n, dim))
    v = np.zeros((n, dim))
    vmax = 0.2 * (hi - lo)
    pbest, pbest_f = x.copy(), f(x)
    g = pbest[pbest_f.argmin()].copy()
    for t in range(iters):
        w = w_max - (w_max - w_min) * t / iters      # убывающая инерция
        r1, r2 = rng.random((n, dim)), rng.random((n, dim))
        v = w * v + c1 * r1 * (pbest - x) + c2 * r2 * (g - x)
        v = np.clip(v, -vmax, vmax)
        x = np.clip(x + v, lo, hi)
        fx = f(x)
        better = fx < pbest_f
        pbest[better], pbest_f[better] = x[better], fx[better]
        g = pbest[pbest_f.argmin()].copy()
    return g, pbest_f.min()

best_x, best_f = pso(rastrigin, dim=10, lo=-5.12, hi=5.12)
print(best_f)

🔷 6. ACO: муравьиные алгоритмы

Муравьи строят решение пошагово на графе; вероятность перехода из i в j:

p_ij = τ_ij^α · η_ij^β / Σ_{k ∈ допустимые} τ_ik^α · η_ik^β
  • τ_ij — феромон: «память» колонии о хороших рёбрах
  • η_ij — эвристика: априорная привлекательность, в TSP η = 1/d_ij
  • α, β: вес феромона и эвристики (типично α = 1, β = 2–5)

Обновление после итерации (Ant System):

τ_ij ← (1 − ρ)·τ_ij + Σ_ants Δτ_ij,   Δτ_ij = Q / L_k, если муравей k прошёл ребро
  • Испарение ρ (0.1–0.5): забывание старых путей, без него — преждевременная сходимость к первым найденным решениям
  • Варианты: Elitist AS (усиление лучшего пути), MAX-MIN AS (τ ∈ [τ_min, τ_max]), Ant Colony System (локальное обновление + правило q₀)

🔷 7. Код ACO для TSP (компактно)

import numpy as np

def aco_tsp(D, n_ants=30, iters=200, alpha=1, beta=3, rho=0.3, Q=1.0, seed=0):
    rng = np.random.default_rng(seed)
    n = len(D)
    eta = 1.0 / (D + np.eye(n))           # эвристика, без деления на 0
    tau = np.ones((n, n))
    best, best_len = None, np.inf
    for _ in range(iters):
        tours = []
        for _ in range(n_ants):
            tour = [rng.integers(n)]
            visited = np.zeros(n, bool); visited[tour[0]] = True
            for _ in range(n - 1):
                i = tour[-1]
                p = tau[i]**alpha * eta[i]**beta
                p[visited] = 0
                j = rng.choice(n, p=p / p.sum())
                tour.append(j); visited[j] = True
            L = D[tour, np.roll(tour, -1)].sum()
            tours.append((tour, L))
            if L < best_len:
                best, best_len = tour, L
        tau *= (1 - rho)                     # испарение
        for tour, L in tours:                # отложение феромона
            a, b = np.array(tour), np.roll(tour, -1)
            tau[a, b] += Q / L; tau[b, a] += Q / L
    return best, best_len

  • PSO: мало параметров, быстро сходится, но склонен к преждевременной сходимости; на сложных непрерывных задачах CMA-ES часто надёжнее
  • ACO: силён там, где решение собирается из компонентов и есть хорошая эвристика η
  • Все методы легко параллелятся по агентам (кроме SA)

🔷 9. Применение

  • PSO: подбор вещественных гиперпараметров (C, γ SVM; learning rate), обучение весов малых сетей, калибровка моделей, управление (PID), антенны
  • Binary PSO: отбор признаков (маска 0/1)
  • ACO: TSP, маршрутизация транспорта (VRP), сетевая маршрутизация (AntNet), расписания, раскраска графа
  • Робототехника: управление роями дронов и роботов (те же принципы локальных правил)
  • Для гиперпараметров ML обычно сначала стоит попробовать байесовскую оптимизацию — она экономнее по числу оценок

🔷 10. Типичные ошибки

  • ❌ Нет ограничения скорости / constriction → частицы улетают за границы
  • ❌ gbest-топология на сильно мультимодальной функции → весь рой схлопывается в локальный минимум
  • ❌ ACO без испарения или с ρ ≈ 0 → стагнация на первом пути; с ρ ≈ 1 → нет памяти
  • ❌ Признаки разного масштаба в PSO без нормировки пространства
  • ❌ Сравнение алгоритмов по одному запуску: нужно несколько seed и одинаковый бюджет вычислений f
  • ❌ Использование для задач с доступным градиентом — градиентные методы почти всегда быстрее

🔷 11. Чек-лист

  • ☐ Непрерывная задача → PSO (или CMA-ES); дискретная на графе → ACO
  • ☐ Нормировать пространство поиска, задать bounds
  • ☐ PSO: w убывает 0.9 → 0.4 или constriction; c₁ ≈ c₂
  • ☐ ACO: α = 1, β = 2–5, ρ = 0.1–0.5, сильная эвристика η
  • ☐ Логировать лучшее значение и разнообразие роя по итерациям
  • ☐ Несколько перезапусков, сравнение с ГА/ES/SA на равном бюджете
