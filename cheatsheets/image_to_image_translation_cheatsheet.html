🖼️ Image-to-image translation

📅 Январь 2026

🔷 1. Что такое Image-to-Image Translation

  • Определение: преобразование изображения из одного домена в другой
  • Задача: сохранить содержание, изменить стиль/модальность
  • Примеры: скетч→фото, день→ночь, лошадь→зебра, МРТ→КТ
  • Применение: компьютерное зрение, графика, медицина

🔷 2. Типы задач

Paired translation (парные данные):

  • Есть пары (x, y) — входное и целевое изображения
  • Пример: карта→спутниковый снимок, сегментация→фото

Unpaired translation (непарные данные):

  • Два набора изображений без соответствий
  • Пример: домен лошадей и домен зебр

🔷 3. Pix2Pix — условный GAN

Архитектура: условный GAN с парными данными

  • Generator: U-Net с skip connections
  • Discriminator: PatchGAN (классифицирует патчи)
  • Loss: adversarial loss + L1 reconstruction loss
L = L_GAN(G, D) + λ * L_L1(G)

L_L1 = E[||y - G(x)||₁]

🔷 4. U-Net Generator

Структура: encoder-decoder с skip connections

  • Encoder: сверточные слои, downsampling
  • Bottleneck: самое сжатое представление
  • Decoder: upsampling, восстановление деталей
  • Skip connections: передают детали напрямую
Skip connections помогают сохранить мелкие детали входного изображения

🔷 5. PatchGAN Discriminator

  • Идея: классифицировать не всё изображение, а патчи
  • Выход: N×N карта реальности
  • Преимущество: меньше параметров, лучше детали
  • Размер патча: обычно 70×70 пикселей
D_output = Conv layers → N×N map
Loss = mean(log(D(x,y)) + log(1-D(x,G(x))))

🔷 6. CycleGAN — без парных данных

Проблема: нет пар (x, y), только домены X и Y

Решение: cycle consistency loss

  • Два генератора: G: X→Y и F: Y→X
  • Два дискриминатора: D_X и D_Y
  • Идея: F(G(x)) ≈ x (cycle consistency)
L_cyc = E[||F(G(x)) - x||₁] + E[||G(F(y)) - y||₁]

L_total = L_GAN + λ_cyc * L_cyc

🔷 7. Cycle Consistency

Интуиция: перевод туда-обратно должен вернуть оригинал

x (лошадь) → G(x) (зебра) → F(G(x)) ≈ x (лошадь)
y (зебра)  → F(y) (лошадь) → G(F(y)) ≈ y (зебра)

Зачем: предотвращает mode collapse и бессмысленные переводы

🔷 8. Другие архитектуры

Модель Особенность Применение
StarGAN Multi-domain, 1 генератор Много доменов одновременно
UNIT Shared latent space Unpaired translation
MUNIT Content + style разделение Multimodal output
SPADE Spatial normalization Semantic synthesis

🔷 9. Функции потерь

  • Adversarial loss: GAN loss для реализма
  • L1/L2 loss: pixel-wise разница (для paired)
  • Cycle consistency: для unpaired translation
  • Perceptual loss: разница в feature space (VGG)
  • Identity loss: G(y)≈y для сохранения домена

🔷 10. Практические советы

  • Paired данные: используйте Pix2Pix
  • Unpaired данные: используйте CycleGAN
  • Data augmentation: случайные flip, crop
  • Learning rate: начните с 2e-4, decay после 50 эпох
  • λ_cyc: обычно 10.0 для cycle consistency
  • Batch size: 1-4 (из-за памяти GPU)

🔷 11. Применения

✅ Успешные кейсы:

  • Стилизация изображений (художественный стиль)
  • Улучшение качества (super-resolution)
  • Semantic segmentation → реальное фото
  • Медицинская визуализация (MRI ↔ CT)
  • День→ночь, лето→зима

❌ Сложные задачи:

  • Сильные геометрические изменения
  • Генерация новых объектов
  • Очень разные домены
