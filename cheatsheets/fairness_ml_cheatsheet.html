⚖️ Fairness в ML (справедливость моделей)

📅 Январь 2026

🔷 1. Что такое Fairness в ML

Fairness (справедливость) — отсутствие дискриминации в решениях модели по защищённым признакам A (пол, раса, возраст, религия, национальность, инвалидность).

  • Проблема: модели учатся на исторических данных и могут автоматизировать и масштабировать дискриминацию
  • Где критично: кредитование, найм, медицина, суд, страхование
  • Group fairness: равенство статистик (доля одобрений, TPR, FPR, PPV) между группами
  • Individual fairness: похожие люди → похожие предсказания (условие Липшица: d(f(x), f(x′)) ≤ L·d(x, x′))
  • Counterfactual fairness: прогноз не меняется, если «переключить» A при прочих равных (в причинной модели)
  • Последствия: вред людям, юридические и репутационные риски

🔷 3. Критерии справедливости

КритерийФормулаСмысл
Demographic (statistical) parityP(Ŷ=1|A=0) = P(Ŷ=1|A=1)Равная доля положительных решений (Ŷ ⊥ A)
Disparate impact ratioP(Ŷ=1|A=unpriv) / P(Ŷ=1|A=priv)Правило 80%: ≥ 0.8
Equal opportunityP(Ŷ=1|Y=1, A=0) = P(Ŷ=1|Y=1, A=1)Равный TPR: достойные имеют равные шансы
Equalized oddsP(Ŷ=1|Y=y, A=0) = P(Ŷ=1|Y=y, A=1), y∈{0,1}Равные TPR и FPR (Ŷ ⊥ A | Y)
Predictive parityP(Y=1|Ŷ=1, A=0) = P(Y=1|Ŷ=1, A=1)Равный PPV (precision)
Calibration within groupsP(Y=1|S=s, A=a) = sСкор означает одно и то же в каждой группе

На практике считают разность (difference, цель ≈ 0, часто < 0.1) или отношение (ratio, цель ≈ 1) метрики между группами; для нескольких групп — max − min.

🔷 4. Несовместимость критериев и выбор

  • Теоремы невозможности (Kleinberg et al.; Chouldechova, 2016–2017): если базовые доли P(Y=1|A) в группах различаются, калибровка (predictive parity) и равенство FPR/FNR одновременно невозможны — кроме идеального классификатора
  • Demographic parity vs точность: при разных базовых долях равенство одобрений достигается ценой ошибок (кредиты тем, кто не вернёт) — это может навредить самой группе; parity можно выполнить формально, случайно выбирая людей
  • COMPAS: модель была откалибрована по группам, но FPR для афроамериканцев был выше — спор ProPublica vs Northpointe иллюстрирует несовместимость
СитуацияКритерий
Важен равный доступ к благу, метки исторически смещеныDemographic parity
Важно не упустить достойных (найм, кредит)Equal opportunity
Важны оба типа ошибок (суд, медицина)Equalized odds

🔷 5. Измерение bias вручную

import numpy as np
import pandas as pd

def group_report(y_true, y_pred, a):
    """Метрики по группам защищённого признака a."""
    rows = {}
    for g in np.unique(a):
        m = a == g
        yt, yp = y_true[m], y_pred[m]
        tp = np.sum((yt == 1) & (yp == 1)); fn = np.sum((yt == 1) & (yp == 0))
        fp = np.sum((yt == 0) & (yp == 1)); tn = np.sum((yt == 0) & (yp == 0))
        rows[g] = {
            'n': m.sum(),
            'base_rate': yt.mean(),
            'selection_rate': yp.mean(),
            'TPR': tp / max(tp + fn, 1),
            'FPR': fp / max(fp + tn, 1),
            'PPV': tp / max(tp + fp, 1),
        }
    df = pd.DataFrame(rows).T
    summary = {
        'dp_difference': df.selection_rate.max() - df.selection_rate.min(),
        'di_ratio': df.selection_rate.min() / df.selection_rate.max(),
        'eo_difference': df.TPR.max() - df.TPR.min(),
        'eodds_difference': max(df.TPR.max() - df.TPR.min(),
                                df.FPR.max() - df.FPR.min()),
    }
    return df, summary

🔷 7. Pre-processing: исправляем данные

  • Reweighing: вес w(a, y) = P(A=a)·P(Y=y) / P(A=a, Y=y) — делает A и Y независимыми во взвешенных данных
  • Resampling: over/under-sampling групп и комбинаций (A, Y)
  • Disparate Impact Remover: выравнивает распределения признаков между группами (repair_level ∈ [0, 1])
  • Learning Fair Representations (LFR): латентное представление, сохраняющее информацию о Y и скрывающее A
from aif360.algorithms.preprocessing import (Reweighing,
    DisparateImpactRemover, LFR)

rw = Reweighing(unprivileged_groups=unpriv, privileged_groups=priv)
ds_rw = rw.fit_transform(ds_train)
model.fit(X_train, y_train, sample_weight=ds_rw.instance_weights)

ds_dir = DisparateImpactRemover(repair_level=1.0).fit_transform(ds_train)
ds_lfr = LFR(unprivileged_groups=unpriv, privileged_groups=priv).fit_transform(ds_train)

🔷 8. In-processing: справедливое обучение

  • Reductions (Fairlearn): задача с ограничением min loss s.t. |disparity| ≤ ε сводится к последовательности взвешенных задач классификации
  • Prejudice Remover: штраф η·MI(Ŷ; A) в loss
  • Adversarial debiasing: предиктор минимизирует loss, а adversary пытается восстановить A из выхода; предиктор учится его «обманывать»: L = L_pred − λ·L_adv
from fairlearn.reductions import ExponentiatedGradient, DemographicParity, EqualizedOdds
from sklearn.linear_model import LogisticRegression

mitigator = ExponentiatedGradient(LogisticRegression(max_iter=1000),
                                  constraints=EqualizedOdds(difference_bound=0.05))
mitigator.fit(X_train, y_train, sensitive_features=A_train)
y_pred_fair = mitigator.predict(X_test)

from aif360.algorithms.inprocessing import PrejudiceRemover

for x, y, a in loader:                         # a — защищённый признак (float)
    logit = pred(x).squeeze(1)
    # 1) шаг adversary: угадать A по выходу предиктора
    loss_a = bce(adv(logit.detach().unsqueeze(1)).squeeze(1), a)
    opt_a.zero_grad(); loss_a.backward(); opt_a.step()
    # 2) шаг предиктора: точность минус успех adversary
    loss_p = bce(logit, y) - lam * bce(adv(logit.unsqueeze(1)).squeeze(1), a)
    opt_p.zero_grad(); loss_p.backward(); opt_p.step()
# Для equalized odds adversary получает ещё и y: adv([logit, y])

🔷 9. Post-processing: коррекция предсказаний

  • Threshold Optimizer (Hardt et al., 2016): свой (иногда рандомизированный) порог для каждой группы, выравнивающий TPR/FPR или доли одобрений
  • Calibrated Equalized Odds: сохраняет калибровку, выравнивая взвешенную стоимость ошибок (cost_constraint 'fpr' / 'fnr' / 'weighted')
  • Reject Option Classification: в зоне неопределённости около порога решения меняются в пользу непривилегированной группы
  • Плюс: не нужно переобучать модель. Минус: нужен A на инференсе (в ряде юрисдикций запрещено) и явное разное обращение с группами
from fairlearn.postprocessing import ThresholdOptimizer

to = ThresholdOptimizer(estimator=model, constraints="equalized_odds",

🔷 10. Workflow и trade-off accuracy vs fairness

  1. Определить защищённые признаки и вредные исходы; выбрать критерий (блок 4)
  2. Проверить данные: размеры групп, base rates, прокси-признаки
  3. Обучить baseline, измерить метрики по группам
  4. Применить mitigation (pre / in / post) и сравнить
  5. Построить кривую trade-off и выбрать компромисс вместе с бизнесом
import matplotlib.pyplot as plt
from sklearn.metrics import accuracy_score

accs, gaps = [], []
for eps in [0.01, 0.02, 0.05, 0.1, 0.2]:
    mit = ExponentiatedGradient(LogisticRegression(max_iter=1000),
                                constraints=EqualizedOdds(difference_bound=eps))
    mit.fit(X_train, y_train, sensitive_features=A_train)
    yp = mit.predict(X_test)
    accs.append(accuracy_score(y_test, yp))
    gaps.append(equalized_odds_difference(y_test, yp, sensitive_features=A_test))

plt.plot(gaps, accs, 'o-')
plt.xlabel('Equalized odds difference'); plt.ylabel('Accuracy')
plt.title('Fairness–accuracy trade-off (Pareto front)'); plt.show()

Улучшение fairness обычно стоит немного accuracy; иногда — почти ничего, если bias вызван недопредставленностью группы (тогда помогают данные).

🔷 11. Intersectionality и мониторинг

Intersectionality: модель может быть справедлива по полу и по расе отдельно, но не для пересечения (например, тёмнокожие женщины — Gender Shades). Анализируйте подгруппы, следя за их размером (доверительные интервалы).

mf = MetricFrame(metrics=accuracy_score, y_true=y_test, y_pred=y_pred,
                 sensitive_features=df_test[['gender', 'race']])  # пересечения
print(mf.by_group.sort_values())
print('gap:', mf.difference())

# Мониторинг в продакшене: метрики по окнам времени
def fairness_snapshot(y_true, y_pred, A):
    return {'dp': demographic_parity_difference(y_true, y_pred, sensitive_features=A),
            'eo': equalized_odds_difference(y_true, y_pred, sensitive_features=A)}

history = []   # history.append({'ts': ts, **fairness_snapshot(...)})
def check_drift(history, threshold=0.05):
    base, last = history[0], history[-1]
    return {k: last[k] - base[k] for k in ('dp', 'eo')
            if abs(last[k] - base[k]) > threshold}

Метки в проде приходят с задержкой и только для одобренных (selective labels) — учитывайте это при оценке TPR/FPR.

🔷 12. Право, кейсы, практики, чек-лист

  • Регулирование: GDPR (автоматизированные решения, право на объяснение), EU AI Act (high-risk системы), ECOA и Fair Housing Act (США), трудовое право
  • Disparate impact: непрямая дискриминация незаконна, даже если A не используется напрямую
  • Кейсы: COMPAS (рецидивизм), Amazon hiring (дискриминация женщин), распознавание лиц (низкая точность для тёмнокожих женщин), healthcare-алгоритм (недооценка риска чёрных пациентов из-за метки «расходы»)
