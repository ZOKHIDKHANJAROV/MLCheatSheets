🛡️ Adversarial Training

📅 Январь 2026

🔷 1. Что такое Adversarial Training

  • Определение: метод обучения модели на adversarial примерах
  • Цель: повысить устойчивость к adversarial атакам
  • Идея: обучить модель на специально искажённых данных
  • Применение: безопасность ML-систем, защита от атак

🔷 2. Adversarial примеры

  • Что это: входные данные с небольшими возмущениями
  • Особенность: незаметны для человека, но обманывают модель
  • Пример: изображение панды → модель видит гиббона
  • Возмущение: δ с ограничением ||δ|| ≤ ε
x_adv = x + δ
где ||δ||_∞ ≤ ε (обычно ε = 8/255 для изображений)

🔷 3. Зачем нужен Adversarial Training

  • Безопасность: защита от целенаправленных атак
  • Надёжность: стабильная работа на зашумлённых данных
  • Критичные приложения: автопилоты, медицина, финансы
  • Соответствие стандартам: требования к robustness моделей

🔷 4. Основной алгоритм

  1. Взять батч: обычные тренировочные данные (x, y)
  2. Создать adversarial примеры: x_adv = Attack(x, model)
  3. Обучить на обоих: минимизировать loss на x и x_adv
  4. Повторить: до конца обучения
for batch in data_loader:
  x, y = batch
  x_adv = generate_adversarial(x, y, model)
  
  loss = criterion(model(x), y) + 
         criterion(model(x_adv), y)
  
  loss.backward()
  optimizer.step()

🔷 5. Методы генерации adversarial примеров

FGSM (Fast Gradient Sign Method):

x_adv = x + ε * sign(∇_x Loss(x, y, θ))

PGD (Projected Gradient Descent):

x_adv = x
for i in range(steps):
  x_adv = Proj(x_adv + α * sign(∇Loss))
  x_adv = clip(x_adv, x-ε, x+ε)

PGD — более сильная атака, лучше для обучения

🔷 6. FGSM — быстрый метод

import torch

def fgsm_attack(image, epsilon, data_grad):
  # Берём знак градиента
  sign_data_grad = data_grad.sign()
  
  # Создаём adversarial пример
  perturbed_image = image + epsilon * sign_data_grad
  
  # Ограничиваем в [0,1]
  perturbed_image = torch.clamp(perturbed_image, 0, 1)
  
  return perturbed_image

🔷 7. PGD — итеративный метод

def pgd_attack(model, images, labels, eps, alpha, steps):
  delta = torch.zeros_like(images).uniform_(-eps, eps)
  delta.requires_grad = True
  
  for _ in range(steps):
    outputs = model(images + delta)
    loss = criterion(outputs, labels)
    loss.backward()
    
    # Градиентный шаг
    delta.data = (delta + alpha * delta.grad.sign()).clamp(-eps, eps)
    delta.grad.zero_()
    
  return images + delta.detach()

🔷 8. Гиперпараметры

Параметр Типичное значение Назначение

α (alpha) 2/255 Размер шага PGD
steps 7-10 Итераций PGD
λ 0.5-1.0 Вес adv. loss

🔷 9. Преимущества и недостатки

✅ Плюсы:

  • Повышает robustness к атакам
  • Улучшает генерализацию
  • Простая идея, легко реализовать
  • Работает для многих задач

❌ Минусы:

  • Сильно замедляет обучение (2-10x)
  • Может снизить accuracy на чистых данных
  • Требует больше GPU памяти
  • Трудно подобрать гиперпараметры

🔷 10. Метрики robustness

  • Clean accuracy: точность на обычных данных
  • Robust accuracy: точность на adversarial примерах
  • Attack success rate: % успешных атак
  • Certified robustness: гарантированная устойчивость

Баланс: обычно есть trade-off между clean и robust accuracy

🔷 11. Практические советы

  • Начните с FGSM, потом переходите на PGD
  • Early stopping: следите за robust accuracy
  • Больше эпох: нужно 2-3x больше обучения
  • Learning rate schedule: cosine annealing работает хорошо
  • Data augmentation: комбинируйте с adversarial training
  • Библиотеки: используйте Foolbox, ART, Advertorch
