🌊 Нормализующие потоки (Normalizing Flows)

📅 Январь 2026

🔷 1. Идея

Нормализующий поток — генеративная модель, которая превращает простое распределение (z ~ N(0, I)) в сложное распределение данных цепочкой обратимых дифференцируемых преобразований:

x = f(z) = f_K ∘ … ∘ f_2 ∘ f_1(z),   z = f⁻¹(x)
  • Генерация: z ~ N(0,I) → x = f(z)
  • Плотность: x → z = f⁻¹(x) → точный log p(x)
  • Обучение: максимизация точного правдоподобия (без ELBO и дискриминатора)
  • «Нормализующий» — обратное направление x → z приводит данные к нормальному распределению
  • dim(z) = dim(x) — без сжатия

🔷 2. Замена переменных

Для обратимого f: z → x с якобианом J = ∂f/∂z:

p_x(x) = p_z(f⁻¹(x)) · |det ∂f⁻¹/∂x|
log p(x) = log p_z(z) − log|det ∂f/∂z|
         = log p_z(z) + Σ_k log|det ∂f_k⁻¹/∂h_k|
  • Log-det якобиана — «поправка на объём»: где f растягивает пространство, плотность падает
  • Для композиции log-det складываются по слоям
  • 1D-интуиция: p_x(x) = p_z(z)·|dz/dx|
  • Loss: NLL = −mean log p(x); для изображений — в bits/dim = NLL / (D·ln 2)

🔷 3. Главное требование: дешёвый якобиан

det произвольной матрицы D×D — O(D³); для картинки 64×64×3 (D≈12 тыс.) — неприемлемо. Поэтому слои проектируют так, чтобы:

  • f легко обращалась
  • якобиан был треугольным → det = произведение диагонали, O(D)
  • слой оставался выразительным (произвольные нейросети внутри)

🔷 4. Coupling layers: NICE и RealNVP

Делим вход на две части x = [x₁, x₂]:

NICE (аддитивный, 2014):
  y₁ = x₁
  y₂ = x₂ + t(x₁)                 log det = 0 (сохраняет объём)

RealNVP (аффинный, 2016):
  y₁ = x₁
  y₂ = x₂ ⊙ exp(s(x₁)) + t(x₁)
  log det = Σ s(x₁)

Обращение:  x₂ = (y₂ − t(y₁)) ⊙ exp(−s(y₁))
  • s и t — любые сети (MLP, ResNet), их не нужно обращать
  • Якобиан = [[I, 0], [∂y₂/∂x₁, diag(exp s)]] — треугольный
  • Части нужно чередовать (перестановка / reverse), иначе x₁ никогда не изменится
  • Маски для картинок: шахматная (checkerboard) и по каналам; squeeze 2×2×c → 1×1×4c; multi-scale — часть размерностей «выводится» раньше
  • Стабилизация: s = scale·tanh(·), инициализация s, t ≈ 0 (слой ≈ тождество)

🔷 5. Glow (Kingma & Dhariwal, 2018)

Шаг потока = ActNorm → 1×1 invertible conv → affine coupling, повторённый K раз на L масштабах.

  • ActNorm: поканальное y = s ⊙ x + b; s, b инициализируются по первому батчу (data-dependent init) так, чтобы выход имел среднее 0 и дисперсию 1; замена BatchNorm при малых батчах. log det = h·w·Σ log|s|
  • Обратимая 1×1 свёртка: обучаемая перестановка каналов W (c×c). log det = h·w·log|det W|. LU-параметризация W = P·L·(U + diag(s)) делает det за O(c)
  • Affine coupling: как в RealNVP, разбиение по каналам
  • Температура при сэмплинге: z ~ N(0, T²I), T≈0.7 — качественнее, менее разнообразно
  • Точное латентное пространство: интерполяции, манипуляция атрибутами

🔷 6. Autoregressive flows: MAF и IAF

Каждая координата преобразуется с параметрами, зависящими от предыдущих (сеть MADE с масками):

MAF:  x_i = z_i·exp(α_i) + μ_i,   (μ_i, α_i) = g(x_{1:i−1})
IAF:  x_i = z_i·exp(α_i) + μ_i,   (μ_i, α_i) = g(z_{1:i−1})
log det = Σ α_i
MAFIAF
Плотность p(x)быстро: 1 проход (все x известны)медленно: D последовательных шагов
Сэмплингмедленно: D шаговбыстро: 1 проход
Гдеоценка плотностиапостериор в VAE, Parallel WaveNet
  • Coupling = частный случай autoregressive с двумя «блоками» — быстро в обе стороны, но менее выразительно
  • Neural Spline Flows: монотонные rational-quadratic сплайны вместо аффинного преобразования — сильнее при той же цене

🔷 7. Непрерывные потоки (кратко)

  • Динамика dz/dt = f(z(t), t; θ) — Neural ODE; обратимость гарантирована (интегрируем назад)
  • Мгновенная замена переменных: d log p(z(t))/dt = −tr(∂f/∂z)
  • FFJORD (2018): несмещённая оценка следа Хатчинсона tr(A) ≈ εᵀAε → O(D); архитектура f без ограничений
  • Минус: медленно (ODE-солвер, адаптивное число шагов)
  • Наследник: Flow Matching / Rectified Flow — обучение векторного поля регрессией без симуляции ODE; основа Stable Diffusion 3, Flux

🔷 9. Код: RealNVP-слой на PyTorch

import torch
import torch.nn as nn

class AffineCoupling(nn.Module):
    def __init__(self, dim, hidden=128, flip=False):
        super().__init__()
        self.flip = flip
        self.d = dim // 2
        n_in = dim - self.d if flip else self.d    # размер условной части
        self.net = nn.Sequential(
            nn.Linear(n_in, hidden), nn.ReLU(),
            nn.Linear(hidden, hidden), nn.ReLU(),
            nn.Linear(hidden, 2 * (dim - n_in)))
        nn.init.zeros_(self.net[-1].weight)   # старт ≈ тождество
        nn.init.zeros_(self.net[-1].bias)

    def _split(self, v):
        a, b = v[:, :self.d], v[:, self.d:]
        return (b, a) if self.flip else (a, b)

    def _merge(self, a, b):
        return torch.cat([b, a] if self.flip else [a, b], dim=1)

    def forward(self, x):                      # x -> z, для плотности
        x1, x2 = self._split(x)
        s, t = self.net(x1).chunk(2, dim=1)
        s = torch.tanh(s)
        z2 = (x2 - t) * torch.exp(-s)
        return self._merge(x1, z2), -s.sum(1)  # log|det dz/dx|

    def inverse(self, z):                      # z -> x, для сэмплинга
        z1, z2 = self._split(z)
        s, t = self.net(z1).chunk(2, dim=1)
        s = torch.tanh(s)
        return self._merge(z1, z2 * torch.exp(s) + t)

🔷 10. Код: поток и обучение

import math

class RealNVP(nn.Module):
    def __init__(self, dim, n_layers=6):
        super().__init__()
        self.layers = nn.ModuleList(
            [AffineCoupling(dim, flip=i % 2 == 1) for i in range(n_layers)])
        self.dim = dim

    def log_prob(self, x):
        log_det = torch.zeros(x.size(0), device=x.device)
        for layer in self.layers:
            x, ld = layer(x)
            log_det = log_det + ld
        log_pz = -0.5 * (x ** 2).sum(1) - 0.5 * self.dim * math.log(2 * math.pi)
        return log_pz + log_det

    @torch.no_grad()
    def sample(self, n):
        z = torch.randn(n, self.dim)
        for layer in reversed(self.layers):
            z = layer.inverse(z)
        return z

from sklearn.datasets import make_moons
data = torch.tensor(make_moons(4000, noise=0.05)[0], dtype=torch.float32)
flow = RealNVP(dim=2)
opt = torch.optim.Adam(flow.parameters(), lr=1e-3)
for step in range(2000):
    batch = data[torch.randint(0, len(data), (256,))]
    loss = -flow.log_prob(batch).mean()
    opt.zero_grad(); loss.backward(); opt.step()
samples = flow.sample(1000)

🔷 11. Практика и ошибки

  • Дискретные данные (пиксели 0..255): нужен dequantization — x + U(0,1), иначе плотность «схлопывается» в точки и NLL → −∞
  • Логит-преобразование пикселей перед потоком (учесть его log det!)
  • Забыть знак или слой в сумме log-det — модель «обманывает» loss
  • Не чередовать разбиение — половина размерностей не преобразуется
  • Неограниченный s → exp взрывается: tanh-ограничение, gradient clipping
  • Проверка обратимости: ‖inverse(forward(x)) − x‖ ≈ 1e-5
  • Высокое правдоподобие ≠ хороший OOD-детектор: потоки часто дают высокую плотность чужим данным (SVHN при обучении на CIFAR)

🔷 12. Где применяются

  • Оценка плотности и детекция аномалий на табличных данных
  • Вариационный вывод: гибкий апостериор в VAE (IAF, planar/radial flows) — см. Variational Inference
  • Simulation-based inference в физике (нейронная оценка апостериора)
  • Сэмплинг в физике: Boltzmann generators, решёточные модели
  • Речь: WaveGlow, Parallel WaveNet; компоненты в VITS
  • Генерация через flow matching — современная форма идеи «поток от шума к данным»
