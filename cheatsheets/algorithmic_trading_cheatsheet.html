🔷 1. Суть алгоритмического трейдинга

Автоматизированная торговля на основе алгоритмов и ML

  • Автоматизация: исполнение сделок по заранее заданным правилам без участия человека
  • Скорость: анализ данных и принятие решений за миллисекунды
  • Бэктестинг: тестирование стратегий на исторических данных
  • Риск-менеджмент: автоматический контроль рисков и позиций
  • Масштабируемость: возможность торговать множеством инструментов одновременно
  • Устранение эмоций: решения основаны на данных, не на страхе или жадности
💡 Алгоритмический трейдинг составляет более 70% объема торгов на современных биржах

🔷 2. Типы стратегий

Trend following, Mean reversion, Statistical arbitrage, Market making

  • Trend following: следование за трендом с использованием moving averages
  • Mean reversion: ставка на возврат цены к среднему значению
  • Statistical arbitrage: эксплуатация статистических зависимостей между инструментами
  • Market making: предоставление ликвидности, заработок на спреде
  • Momentum trading: торговля на импульсах и продолжении движения
  • High-frequency trading: сверхбыстрые стратегии на микросекундах
💡 Выбор стратегии зависит от таймфрейма, ликвидности инструмента и толерантности к риску

🔷 3. Признаки (features)

Price, Volume, Technical indicators, Sentiment, Macroeconomic

  • Price features: OHLC (Open, High, Low, Close), returns, log-returns
  • Volume: объем торгов, volume profile, VWAP
  • Technical indicators: RSI, MACD, Bollinger Bands, ATR
  • Order book: bid-ask spread, depth, imbalance
  • Sentiment: новости, соцсети, индексы настроения
  • Macroeconomic: процентные ставки, инфляция, экономические индикаторы

🔷 4. Технические индикаторы

Moving averages, RSI, MACD, Bollinger Bands, ATR

  • Moving Averages (SMA/EMA): сглаживание цены, определение тренда
  • RSI (Relative Strength Index): перекупленность/перепроданность (0-100)
  • MACD: конвергенция/дивергенция скользящих средних
  • Bollinger Bands: волатильность и уровни поддержки/сопротивления
  • ATR (Average True Range): измерение волатильности
  • Volume indicators: OBV, MFI для анализа денежных потоков
💡 Комбинация индикаторов работает лучше, чем один индикатор в изоляции

🔷 5. ML модели

Linear Regression, Random Forest, XGBoost, Neural Networks, Reinforcement Learning

  • Linear/Logistic Regression: базовый бейзлайн для направления движения
  • Random Forest/XGBoost: работа с нелинейностями и важность признаков
  • LSTM/Transformer: обработка временных последовательностей
  • Reinforcement Learning: обучение через взаимодействие с рынком (Q-learning, PPO)
  • Ensemble methods: комбинирование нескольких моделей
  • Online learning: адаптация к изменяющимся условиям
💡 Простые модели часто работают лучше сложных из-за переобучения на исторических данных

🔷 6. Прогнозирование

Price prediction, Direction prediction, Volatility forecasting

  • Price prediction: регрессия для предсказания будущей цены
  • Direction prediction: классификация (вверх/вниз/боковик)
  • Volatility forecasting: GARCH, исторический vol, implied vol
  • Time horizons: intraday, daily, weekly predictions
  • Проблема нестационарности: рынки постоянно меняются
  • Walk-forward optimization: переобучение модели на новых данных
💡 Прогнозирование направления часто эффективнее прогнозирования точной цены 
from sklearn.ensemble import GradientBoostingClassifier
import pandas as pd

# Создание таргета: будет ли цена выше через N периодов
horizon = 5  # 5 периодов вперед
df['target'] = (df['close'].shift(-horizon) > df['close']).astype(int)

# Признаки
features = ['returns', 'RSI', 'MACD', 'volume_ratio', 'ATR']
X = df[features].iloc[:-horizon]
y = df['target'].iloc[:-horizon]

# Walk-forward валидация
train_size = int(len(X) * 0.8)
X_train, X_test = X[:train_size], X[train_size:]
y_train, y_test = y[:train_size], y[train_size:]

# Gradient Boosting
gb = GradientBoostingClassifier(n_estimators=100, max_depth=3)
gb.fit(X_train, y_train)

# Предсказания вероятностей
proba = gb.predict_proba(X_test)[:, 1]
print(f"Direction Accuracy: {gb.score(X_test, y_test):.3f}")

🔷 7. Reinforcement Learning

Agent-based trading, Q-learning, Policy gradients

  • Agent: принимает решения (buy/sell/hold) на основе state
  • State: текущая позиция, баланс, рыночные данные
  • Action: покупка, продажа, удержание, размер позиции
  • Reward: прибыль/убыток, Sharpe ratio, drawdown penalty
  • Q-learning/DQN: обучение value function
  • Policy Gradient (PPO/A3C): прямая оптимизация policy
💡 RL естественно моделирует последовательные решения и управление капиталом

🔷 8. Backtesting

Исторические данные, метрики (Sharpe ratio, max drawdown)

  • Historical simulation: запуск стратегии на прошлых данных
  • Transaction costs: комиссии, проскальзывание, spread
  • Realistic assumptions: ликвидность, market impact
  • Look-ahead bias: использование будущей информации — частая ошибка
  • Overfitting: переобучение на исторических данных
  • Out-of-sample testing: валидация на holdout периоде
💡 Хороший backtest не гарантирует будущую прибыль, но плохой точно укажет на проблемы

🔷 9. Риск-менеджмент

Position sizing, stop-loss, portfolio optimization

  • Position sizing: Kelly criterion, fixed fractional, volatility-based
  • Stop-loss/Take-profit: автоматические уровни выхода
  • Max drawdown limit: ограничение максимальной просадки
  • Diversification: распределение риска между инструментами
  • VaR (Value at Risk): оценка потенциальных убытков
  • Risk/Reward ratio: соотношение потенциального риска к прибыли
💡 Управление рисками важнее прогнозирования: выживание критичнее прибыли 
import numpy as np

def kelly_criterion(win_rate, avg_win, avg_loss):
    """Оптимальный размер позиции по Kelly"""
    return win_rate - ((1 - win_rate) / (avg_win / avg_loss))

def position_size_volatility(capital, risk_per_trade, volatility):
    """Position sizing на основе волатильности"""
    risk_amount = capital * risk_per_trade
    shares = risk_amount / (2 * volatility)  # 2 sigma stop
    return int(shares)

# Пример
capital = 100000
risk_per_trade = 0.02  # 2% на сделку
current_volatility = 1.5  # ATR или std dev

size = position_size_volatility(capital, risk_per_trade, current_volatility)
print(f"Position size: {size} shares")

# Kelly на основе статистики
win_rate = 0.55
avg_win = 150
avg_loss = 100
kelly_fraction = kelly_criterion(win_rate, avg_win, avg_loss)
print(f"Kelly fraction: {kelly_fraction:.2%}")

🔷 10. Проблемы

Overfitting, look-ahead bias, transaction costs, slippage

  • Overfitting: переобучение на истории — главная причина неудач
  • Look-ahead bias: использование будущей информации при обучении
  • Survivor bias: анализ только "выживших" компаний
  • Transaction costs: комиссии съедают прибыль от частых сделок
  • Slippage: разница между ожидаемой и реальной ценой исполнения
  • Regime changes: рынки меняются, модели устаревают
💡 Большинство стратегий проваливаются из-за недооценки транзакционных издержек

🔷 11. High-frequency trading

Latency, order book dynamics

  • Ultra-low latency: торговля в микро/наносекундах
  • Co-location: серверы рядом с биржей для минимизации задержки
  • Order book dynamics: анализ потока заявок в реальном времени
  • Market making: предоставление ликвидности, заработок на спреде
  • Spoofing detection: выявление манипуляций с заявками
  • FPGA/Hardware acceleration: аппаратная оптимизация
💡 HFT требует огромных инвестиций в инфраструктуру и недоступен большинству

🔷 12. Практический пример

Simple momentum strategy с ML

  • Стратегия: торговля на momentum с ML фильтром
  • Признаки: returns, RSI, MACD, volume за разные периоды
  • Модель: XGBoost для предсказания направления
  • Размер позиции: на основе уверенности модели (predict_proba)
  • Риск-менеджмент: stop-loss на 2%, take-profit на 4%
  • Библиотеки: pandas, talib, xgboost, backtrader
💡 Начните с простой стратегии и постепенно усложняйте, тестируя каждое изменение 
import pandas as pd
import xgboost as xgb
from sklearn.model_selection import TimeSeriesSplit

# Загрузка данных и feature engineering
df = pd.read_csv('btc_usdt_1h.csv')
df['returns'] = df['close'].pct_change()
df['momentum_5'] = df['close'] / df['close'].shift(5) - 1
df['momentum_10'] = df['close'] / df['close'].shift(10) - 1
df['RSI'] = talib.RSI(df['close'])
df['volume_ratio'] = df['volume'] / df['volume'].rolling(20).mean()

# Таргет: направление через 3 периода
df['target'] = (df['close'].shift(-3) > df['close']).astype(int)

# Признаки и таргет
features = ['returns', 'momentum_5', 'momentum_10', 'RSI', 'volume_ratio']
X = df[features].fillna(0).iloc[:-3]
y = df['target'].iloc[:-3]

# Walk-forward валидация
tscv = TimeSeriesSplit(n_splits=5)
for train_idx, test_idx in tscv.split(X):
    X_train, X_test = X.iloc[train_idx], X.iloc[test_idx]
    y_train, y_test = y.iloc[train_idx], y.iloc[test_idx]
    
    # XGBoost
    model = xgb.XGBClassifier(n_estimators=100, max_depth=3)
    model.fit(X_train, y_train)
    
    # Предсказания
    proba = model.predict_proba(X_test)[:, 1]
    
    # Торговые сигналы (только с высокой уверенностью)
    signals = pd.Series(0, index=X_test.index)
    signals[proba > 0.6] = 1  # Buy
    signals[proba < 0.4] = -1  # Sell
    
    print(f"Accuracy: {model.score(X_test, y_test):.3f}")
