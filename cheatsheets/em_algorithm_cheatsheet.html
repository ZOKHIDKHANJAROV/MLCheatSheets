🔄 EM-алгоритм (Expectation-Maximization)

📅 Январь 2026

🔷 1. Суть

  • Задача: оценка максимального правдоподобия (MLE) в моделях со скрытыми переменными Z или пропущенными данными
  • Проблема: log p(X|θ) = log Σ_Z p(X, Z|θ) — сумма под логарифмом, замкнутых формул нет
  • Идея: если бы Z были известны, полное правдоподобие log p(X, Z|θ) распалось бы на простые слагаемые → подставляем вместо Z их апостериорное ожидание
  • E-шаг: оценить распределение скрытых переменных при текущих θ
  • M-шаг: обновить θ, максимизируя ожидаемое полное правдоподобие
  • Гарантия: правдоподобие не убывает; сходимость к локальному максимуму (или седловой точке)
  • Применения: GMM, HMM, missing data, тематические модели
EM решает проблему курицы и яйца: чтобы найти скрытые переменные, нужны параметры, а чтобы найти параметры — скрытые переменные.

🔷 2. Алгоритм и формулы

E-шаг:  q(Z) = P(Z | X, θ⁽ᵗ⁾)
        Q(θ|θ⁽ᵗ⁾) = E_{Z|X,θ⁽ᵗ⁾}[ log P(X, Z|θ) ]
M-шаг:  θ⁽ᵗ⁺¹⁾ = argmax_θ Q(θ|θ⁽ᵗ⁾)
  1. Инициализация: θ⁽⁰⁾ (k-means, несколько стартов)
  2. E-шаг: апостериорное распределение Z (для GMM — «ответственности»)
  3. M-шаг: максимизация Q по θ (часто в замкнутом виде)
  4. Проверка сходимости: прирост log-likelihood < tol → стоп, иначе к шагу 2
θ = initialize()
L_old = -inf
while True:
    resp = e_step(X, θ)        # E: q(Z)
    θ = m_step(X, resp)        # M: argmax Q
    L = log_likelihood(X, θ)
    if L - L_old < tol: break
    L_old = L

🔷 3. Почему работает: ELBO и монотонность

Для любого распределения q(Z):

log p(X|θ) = ELBO(q, θ) + KL(q(Z) ‖ p(Z|X,θ))
ELBO(q, θ) = E_q[log p(X, Z|θ)] − E_q[log q(Z)]
           = Q(θ|θ⁽ᵗ⁾) + H(q)
  • KL ≥ 0 ⇒ ELBO — нижняя оценка log-правдоподобия
  • E-шаг: q = p(Z|X,θ⁽ᵗ⁾) ⇒ KL = 0, оценка касается log p(X|θ⁽ᵗ⁾)
  • M-шаг: максимизирует ELBO по θ (H(q) от θ не зависит)
  • Итог: L(θ⁽ᵗ⁺¹⁾) ≥ ELBO(q, θ⁽ᵗ⁺¹⁾) ≥ ELBO(q, θ⁽ᵗ⁾) = L(θ⁽ᵗ⁾)
  • EM = координатный подъём по ELBO: попеременно по q и по θ

Если точный E-шаг невозможен — q ищут в простом семействе (Variational EM), и KL уже не обнуляется.

🔷 4. EM для смеси гауссиан (GMM)

Модель: p(x) = Σₖ πₖ N(x | μₖ, Σₖ), скрытая zᵢ ∈ {1..K} — номер компоненты.

E-шаг — ответственности:

γᵢₖ = P(zᵢ = k | xᵢ, θ) = πₖ N(xᵢ|μₖ, Σₖ) / Σⱼ πⱼ N(xᵢ|μⱼ, Σⱼ)

M-шаг — взвешенные MLE, где Nₖ = Σᵢ γᵢₖ (эффективный размер компоненты):

πₖ = Nₖ / N
μₖ = Σᵢ γᵢₖ xᵢ / Nₖ
Σₖ = Σᵢ γᵢₖ (xᵢ − μₖ)(xᵢ − μₖ)ᵀ / Nₖ  (+ εI для устойчивости)

Log-likelihood: L = Σᵢ log Σₖ πₖ N(xᵢ|μₖ, Σₖ) — считать через log-sum-exp.

k-means (hard EM)GMM (soft EM)
НазначениеЖёсткое: точка в одном кластереМягкое: вероятности γᵢₖ
Форма кластеровСферы одинакового размераЭллипсы разного размера и веса
Связьk-means — предел GMM при Σₖ = σ²I, σ → 0

🔷 5. GMM с нуля (numpy)

import numpy as np
from scipy.stats import multivariate_normal
from scipy.special import logsumexp
from sklearn.cluster import KMeans

class GaussianMixtureEM:
    def __init__(self, K, max_iter=100, tol=1e-4, reg=1e-6):
        self.K, self.max_iter, self.tol, self.reg = K, max_iter, tol, reg

    def _log_prob(self, X):  # (n, K): log πₖ + log N(x|μₖ,Σₖ)
        return np.column_stack([
            np.log(self.weights_[k]) +
            multivariate_normal.logpdf(X, self.means_[k], self.covs_[k])
            for k in range(self.K)])

    def fit(self, X):
        n, d = X.shape
        lab = KMeans(self.K, n_init=10, random_state=0).fit_predict(X)
        self.means_ = np.array([X[lab == k].mean(0) for k in range(self.K)])
        self.covs_ = np.array([np.cov(X[lab == k].T) + self.reg * np.eye(d)
                               for k in range(self.K)])
        self.weights_ = np.bincount(lab, minlength=self.K) / n
        L_old = -np.inf
        for it in range(self.max_iter):
            # E-шаг (в лог-пространстве)
            lp = self._log_prob(X)
            L = logsumexp(lp, axis=1).sum()
            resp = np.exp(lp - logsumexp(lp, axis=1, keepdims=True))
            # M-шаг
            Nk = resp.sum(0)
            self.weights_ = Nk / n
            self.means_ = resp.T @ X / Nk[:, None]
            for k in range(self.K):
                diff = X - self.means_[k]
                self.covs_[k] = (resp[:, k] * diff.T) @ diff / Nk[k] \
                                + self.reg * np.eye(d)
            if L - L_old < self.tol:
                break
            L_old = L
        self.n_iter_, self.log_likelihood_ = it + 1, L
        return self

    def predict_proba(self, X):
        lp = self._log_prob(X)
        return np.exp(lp - logsumexp(lp, axis=1, keepdims=True))

🔷 7. EM для пропущенных данных

Многомерная нормаль N(μ, Σ) с пропусками: скрытые переменные — пропущенные значения.

  • E-шаг: для строки i пропуски m при наблюдаемых o заменяются условным ожиданием: E[xₘ|xₒ] = μₘ + Σₘₒ Σₒₒ⁻¹ (xₒ − μₒ); условная ковариация Σₘₘ − Σₘₒ Σₒₒ⁻¹ Σₒₘ добавляется к Σ на M-шаге
  • M-шаг: μ и Σ пересчитываются по заполненным данным (с поправкой ковариации)
  • Предполагается MAR (missing at random)
import numpy as np

def em_impute_gaussian(X, max_iter=100, tol=1e-6):
    X = X.astype(float)
    miss = np.isnan(X)
    Xf = np.where(miss, np.nanmean(X, axis=0), X)   # старт: средние
    for _ in range(max_iter):
        mu = Xf.mean(0)
        C = np.zeros((X.shape[1],) * 2)              # поправка ковариации
        S = np.cov(Xf.T, bias=True)
        X_old = Xf.copy()
        for i in np.where(miss.any(1))[0]:
            m, o = miss[i], ~miss[i]
            S_oo_inv = np.linalg.pinv(S[np.ix_(o, o)])
            S_mo = S[np.ix_(m, o)]
            Xf[i, m] = mu[m] + S_mo @ S_oo_inv @ (Xf[i, o] - mu[o])  # E
            C[np.ix_(m, m)] += S[np.ix_(m, m)] - S_mo @ S_oo_inv @ S_mo.T
        S = np.cov(Xf.T, bias=True) + C / len(X)                    # M
        if np.abs(Xf - X_old).max() < tol:
            break
    return Xf, Xf.mean(0), S

🔷 8. EM для HMM (Baum-Welch)

  • Скрытые: последовательность состояний s₁..s_T
  • E-шаг: Forward-Backward → P(s_t = i | X) и P(s_t = i, s_t+1 = j | X)
  • M-шаг: стартовые вероятности, матрица переходов, параметры эмиссий — нормированные ожидаемые счётчики
  • Декодирование: Viterbi — наиболее вероятная последовательность состояний
import numpy as np
from hmmlearn import hmm

X = np.random.randn(500, 2)                # наблюдения (T, d)
model = hmm.GaussianHMM(n_components=3, covariance_type="full",
                        n_iter=100, random_state=0)
model.fit(X)                               # Baum-Welch = EM
print(model.startprob_, model.transmat_, model.means_)
log_prob, states = model.decode(X)         # Viterbi
print(model.monitor_.converged)

🔷 12. Плюсы, минусы, чек-лист

✅ Плюсы

  • Гарантия неубывания likelihood
  • Простая реализация, интерпретируемость
  • Естественно работает с пропусками

❌ Минусы

  • Только локальный максимум, зависимость от инициализации
  • Медленная сходимость
  • Нужно задать вероятностную модель
  • [ ] Данные стандартизованы, выбросы обработаны
  • [ ] K выбрано по BIC/AIC; сравнены типы ковариаций
  • [ ] n_init ≥ 5–10, random_state задан
  • [ ] reg_covar > 0, вычисления в лог-пространстве
  • [ ] Проверены converged_ и кривая log-likelihood
  • [ ] Результаты визуализированы, проверены на отложенных данных
