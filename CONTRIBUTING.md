## Как внести вклад

1. **Fork репозитория** - создайте свою копию проекта
2. **Создайте ветку** - используйте описательное имя:
   ```bash
   git checkout -b feature/new-cheatsheet-name
   ```
3. **Внесите изменения** - следуйте нашим стандартам
4. **Протестируйте** - убедитесь, что всё работает. Одна команда проверяет ссылки, темы шпаргалок, вопросы, интерактивы и решения упражнений:
   ```bash
   python tools/check_project.py
   ```
   Новую шпаргалку подключите к теме оформления (`python tools/apply_theme.py`), добавьте ей вопросы в `questions/`, связи в `prerequisites.md` и, если нужно, термины в `glossary.md` (`### English (русский)`, определение, строка `→ стем`); новому упражнению создайте тетрадку (`python tools/make_notebooks.py`).
5. **Commit изменений** - используйте понятные сообщения:
   ```bash
   git commit -m "Add: Новый cheatsheet про XYZ"
   ```
6. **Push в свой fork**:
   ```bash
   git push origin feature/new-cheatsheet-name
   ```
7. **Создайте Pull Request** - опишите ваши изменения

## Стандарты кода

### Cheatsheets (HTML)

- Используйте единообразный стиль оформления
- Включайте примеры кода на Python
- Добавляйте визуализации там, где это уместно
- Используйте понятный русский язык
- Проверяйте математические формулы

### Python код

- Следуйте PEP 8
- Добавляйте docstrings
- Комментируйте сложную логику
- Используйте type hints где возможно

### Упражнения

- Входные данные (input.csv) — синтетические, с фиксированным seed
- Условие (task.md) с однозначным форматом ответа: столбцы, порядок строк, округление
- Подсказки — 3 штуки, от лёгкой к сильной; разбор — идея, типичные ошибки, что вынести
- Эталонное решение (solution.py); эталонный ответ хранится закодированным в answer.key

## Создание новых cheatsheets

1. **Выберите тему** - убедитесь, что она еще не покрыта
2. **Используйте шаблон** - `cheatsheets/template.html`
3. **Структура cheatsheet должна включать:**
   - Краткое описание метода
   - Математические основы
   - Примеры кода на Python
   - Визуализацию (если применимо)
   - Преимущества и недостатки
   - Когда использовать
   - Связанные темы и ссылки
4. **Добавьте ссылку** - обновите README.md
5. **Проверьте HTML** - убедитесь, что файл открывается корректно
6. **Добавьте схему** — рисунки описываются в `tools/visuals/*.py` (SVG-схема или график matplotlib) и вставляются в шпаргалку командой `python tools/add_visuals.py`; образец — `tools/visuals/examples.py`. Цвета SVG задавайте классами `c1…c6`, `s1…s6`, `t1…t6` — тогда схема подстроится под тёмную тему

### Пример структуры cheatsheet:

```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <title>Название метода - ML Cheatsheet</title>
</head>
<body>
    <h1>Название метода</h1>
    
    <h2>Описание</h2>
    <p>Краткое объяснение...</p>
    
    <h2>Математические основы</h2>
    <!-- Формулы -->
    
    <h2>Пример кода</h2>
    <pre><code class="python">
# Пример на Python
    </code></pre>
    
    <h2>Визуализация</h2>
    <!-- SVG или изображение -->
    
    <h2>Преимущества и недостатки</h2>
    
    <h2>Когда использовать</h2>
    
    <h2>Связанные темы</h2>
</body>
</html>
```

## Добавление упражнений

Упражнения создаются генераторами `tools/generate_*_exercises.py` — добавьте словарь в `EXERCISE_LIST` подходящего генератора
(`name` = имя шпаргалки, `title`, `data`, `task`, `solution`, `review`) и запустите его. Генератор запишет
`input.csv`, `task.md` (с разделами «Проверка» и «Разбор»), `solution.py` и закодированный эталон `answer.key`.

1. **Имя папки** — `exercises/<тема>/`, где `cheatsheets/<тема>_cheatsheet.html` существует (так портал связывает упражнение с теорией).
   Задание «Найди ошибку» — папка `exercises/bug_<имя>/` с файлом `buggy.py` и строкой `<!-- шпаргалка: <тема> -->` в условии.
2. **Привяжите к этапу** — добавьте имя в строку `**Упражнения:** …` нужного этапа в `ROADMAP.md`.
3. **Тетрадка** — `python tools/make_notebooks.py`.
4. **Проверьте** — `python tools/check_project.py` запустит решение и сравнит его с эталоном.

Задачи на понимание («Предскажи результат», «Выбери подход») — в `understanding/predict.md` и `understanding/cases.md`:
`## вопрос`, `<!-- демо: файл.html | темы: стемы -->`, условие, варианты (верный помечен ✅), `**Почему.** разбор`.

Лекции — `lectures/<тема>.md`, где `<тема>` совпадает с именем шпаргалки: `# Название`, строка `<!-- время: N мин -->`,
разделы `## Зачем это нужно`, `## Интуиция…`, `## Как это работает`, `## Пример на Python`, `## Подводные камни`, `## Итоги`, `## Проверьте себя`.
Образец — `lectures/gradient_descent.md`. Формулы — юникодом (портал не отображает LaTeX); `check_project.py` проверяет формат и синтаксис примеров кода.

### Пример task.md:

```markdown
# Название упражнения

## Описание
Подробное описание задачи...

## Входные данные
Описание структуры input.csv...

## Задание
1. Шаг 1
2. Шаг 2
...

## Ожидаемый формат выходного файла
Столбцы, порядок строк, округление...

## Подсказки
- Подсказка 1
- Подсказка 2
```

## Создание анимаций

Для создания визуализаций и анимаций:

1. **Используйте matplotlib** для статичных изображений
2. **Используйте manim** для анимаций (опционально)
3. **Сохраняйте в** `animations/output/`
4. **Документируйте** в README.md внутри animations/
