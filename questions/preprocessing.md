# Предобработка данных — вопросы для самопроверки

### Из каких основных шагов состоит предобработка табличных данных?
Анализ данных (типы, распределения, пропуски), обработка пропусков, обработка выбросов, кодирование категориальных признаков, масштабирование числовых, создание и отбор признаков, разбиение на train/validation/test.

### Почему предобработку нужно обучать только на обучающей выборке?
Параметры преобразований (среднее, медиана, словарь категорий) — тоже «знание о данных». Если вычислить их по всей выборке, информация из теста попадёт в обучение (утечка данных), и оценка качества будет завышена.

### Зачем нужен `Pipeline` в scikit-learn?
Он объединяет предобработку и модель в один объект: `fit` обучает все шаги на train, `predict` применяет их к новым данным. Это защищает от утечек при кросс-валидации и упрощает развёртывание.

### Как обработать числовые и категориальные столбцы по-разному в одном конвейере?
Через `ColumnTransformer`: например, `StandardScaler` для числовых столбцов и `OneHotEncoder` для категориальных, затем результат передаётся модели внутри `Pipeline`.

### Каким моделям масштабирование признаков нужно, а каким нет?
Нужно — моделям, основанным на расстояниях и градиентах: k-NN, SVM, линейные модели с регуляризацией, нейросети, PCA. Не нужно — деревьям и ансамблям на деревьях: разбиения по порогу не зависят от масштаба.
