# Transfer learning для CNN — вопросы для самопроверки

### Почему признаки сети, обученной на ImageNet, полезны для другой задачи?
Ранние слои учат универсальные признаки — края, текстуры, простые формы, — которые встречаются почти на любых изображениях. Чем глубже слой, тем специфичнее признаки исходной задаче.

### Чем feature extraction отличается от fine-tuning?
Feature extraction: веса предобученной сети замораживаются, обучается только новая «голова» (классификатор). Fine-tuning: часть или все слои размораживаются и дообучаются с небольшим learning rate.

### Какую стратегию выбрать при маленьком датасете, похожем на ImageNet?
Заморозить основу и обучить только голову: данных мало, и полный fine-tuning быстро переобучится. При большом датасете или сильно отличающемся домене (медицинские снимки, спутники) размораживают больше слоёв.

### Почему при fine-tuning используют маленький learning rate?
Предобученные веса уже хорошие; большой шаг может разрушить полезные признаки («катастрофическое забывание»). Часто используют разные lr: меньше для основы, больше для новой головы.

### Что обязательно нужно сделать с входными изображениями при использовании предобученной модели?
Привести их к тому же формату, что при предобучении: размер, порядок каналов и нормализация теми же средними и стандартными отклонениями (для ImageNet — mean = [0.485, 0.456, 0.406], std = [0.229, 0.224, 0.225]).
