# Target Encoding — вопросы для самопроверки

### Почему наивное target encoding (среднее таргета по категории на всём train) приводит к переобучению?
Значение признака для объекта содержит его собственный таргет. Для редких категорий кодировка почти равна ответу, и модель «подглядывает» в метку — отличный train, плохой тест.

### Как правильно вычислять target encoding на обучающей выборке?
**Out-of-fold**: разбить train на K фолдов и кодировать каждый фолд статистиками, посчитанными по остальным. Тест кодируется статистиками по всему train. В sklearn ≥ 1.3 так делает `TargetEncoder` при `fit_transform`.

### Зачем нужно сглаживание (smoothing) и как оно работает?
Среднее по категории с 2–3 объектами очень шумное. Сглаживание смешивает его с глобальным средним: enc = (n·mean_cat + m·mean_global) / (n + m). Чем меньше n, тем ближе кодировка к глобальному среднему.

### Когда target encoding лучше one-hot?
При **высокой кардинальности** (тысячи городов, ID товаров): one-hot даёт огромную разреженную матрицу, а target encoding — один числовой столбец. Для категорий с малым числом значений one-hot проще и безопаснее.

### Как применять target encoding в многоклассовой задаче?
Создают отдельный столбец для каждого класса — долю этого класса в категории (one-vs-rest). Одно среднее по меткам классов бессмысленно, так как номера классов не упорядочены.
