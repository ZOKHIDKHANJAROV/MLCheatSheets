# Bootstrap — вопросы для самопроверки

### В чём основная идея бутстрепа?
Неизвестное распределение генеральной совокупности заменяется эмпирическим распределением выборки. Многократно извлекая выборки того же размера **с возвращением** и пересчитывая статистику, получают её выборочное распределение — стандартную ошибку и доверительные интервалы без аналитических формул.

### Почему выборки извлекаются с возвращением и того же размера n?
С возвращением — чтобы выборки различались (без возвращения получалась бы та же выборка в другом порядке). Размер n — чтобы разброс статистики соответствовал исходному объёму данных: дисперсия оценки зависит от n.

### Чем перцентильный интервал отличается от BCa?
**Перцентильный** берёт квантили бутстреп-распределения напрямую (например, 2.5% и 97.5%). **BCa** (bias-corrected and accelerated) корректирует их с учётом смещения и асимметрии распределения статистики и точнее при скошенных данных и малых выборках.

### В каких случаях обычный бутстреп даёт неверный результат?
Для зависимых данных (временные ряды) — нужен блочный бутстреп, сохраняющий автокорреляцию. Также для экстремальных статистик (максимум, минимум), при очень малых выборках и для данных с тяжёлыми хвостами, где оценки дисперсии неустойчивы.

### Сколько бутстреп-итераций нужно?
Для стандартной ошибки обычно хватает 200–1000, для доверительных интервалов по перцентилям — 1000–10 000, так как оценка хвостовых квантилей требует больше повторений. Число итераций уменьшает только шум Монте-Карло, но не компенсирует малый размер исходной выборки.
