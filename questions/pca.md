# PCA (Principal Component Analysis) — вопросы для самопроверки

### Какие направления находит PCA?
Ортогональные направления максимальной дисперсии данных: первая компонента — направление наибольшей дисперсии, каждая следующая — максимальной дисперсии среди ортогональных предыдущим. Это собственные векторы ковариационной матрицы, а собственные значения равны дисперсиям вдоль них.

### Почему перед PCA данные центрируют и обычно стандартизируют?
Без центрирования первая компонента будет указывать на среднее данных, а не на направление разброса. Без стандартизации признаки с большим масштабом доминируют в дисперсии и захватывают первые компоненты просто из-за единиц измерения.

### Собственные значения ковариационной матрицы равны 6, 3 и 1. Какую долю дисперсии объясняют две первые компоненты?
(6 + 3) / (6 + 3 + 1) = 0.9, то есть 90%. Доля дисперсии компоненты равна её собственному значению, делённому на сумму всех собственных значений.

### Как связаны PCA и SVD?
Для центрированной матрицы X = UΣVᵀ столбцы V — главные направления, а собственные значения ковариации равны σᵢ² / (n − 1). На практике PCA считают через SVD, не формируя матрицу XᵀX явно: это численно устойчивее.

### Когда PCA не помогает или вредит?
Когда структура данных нелинейна (данные на искривлённом многообразии) или когда информативные для задачи направления имеют маленькую дисперсию — PCA не учитывает таргет и может выбросить именно их. Кроме того, компоненты — смеси всех признаков, и их трудно интерпретировать.
