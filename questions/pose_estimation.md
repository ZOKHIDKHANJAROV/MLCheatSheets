# Оценка позы человека — вопросы для самопроверки

### Что предсказывают модели оценки позы?
Координаты ключевых точек тела (суставы: плечи, локти, колени и т.д.) в 2D на изображении или в 3D. Соединение точек даёт «скелет» человека.

### Чем top-down подход отличается от bottom-up?
Top-down: сначала детектор находит людей, затем для каждого отдельно ищутся ключевые точки — точно, но время растёт с числом людей. Bottom-up: сначала находятся все ключевые точки на изображении, потом группируются по людям (как в OpenPose) — скорость почти не зависит от числа людей.

### Почему ключевые точки часто предсказывают через тепловые карты, а не прямой регрессией координат?
Сеть выдаёт для каждой точки карту вероятностей её положения. Такое представление сохраняет пространственную структуру и обучается устойчивее, чем регрессия двух чисел, и естественно выражает неопределённость.

### Как OpenPose связывает найденные точки в скелеты разных людей?
С помощью Part Affinity Fields — векторных полей, кодирующих направление конечностей между парами точек. По ним оценивается, какие точки принадлежат одной конечности одного человека.

### Какая метрика используется для оценки позы на COCO?
OKS (Object Keypoint Similarity) — аналог IoU для ключевых точек, учитывающий масштаб человека и разную точность разметки для разных суставов; по ней считается AP.
