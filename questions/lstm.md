# LSTM — вопросы для самопроверки

### Какие гейты есть в LSTM и что делает каждый?
Forget gate решает, что стереть из состояния ячейки; input gate — какую новую информацию записать; output gate — какую часть состояния выдать наружу как скрытое состояние hₜ. Каждый гейт — сигмоида со значениями от 0 до 1.

### Чем состояние ячейки (cell state) отличается от скрытого состояния?
Cell state cₜ — «долговременная память», которая обновляется в основном сложением и поэлементным умножением на гейты. Скрытое состояние hₜ = oₜ · tanh(cₜ) — отфильтрованный выход на текущем шаге.

### Почему LSTM лучше простой RNN справляется с длинными зависимостями?
Cell state обновляется аддитивно: cₜ = fₜ·cₜ₋₁ + iₜ·c̃ₜ. Если forget gate близок к 1, градиент проходит через много шагов почти без затухания.

### Зачем forget gate часто инициализируют смещением около 1?
Чтобы в начале обучения сеть по умолчанию сохраняла информацию, а не стирала её. Это облегчает обучение длинным зависимостям.

### Сколько параметров у слоя LSTM по сравнению с простой RNN того же размера?
Примерно в 4 раза больше: у LSTM четыре набора весов (три гейта и кандидат в состояние), у простой RNN — один.
