# Байесовский вывод — вопросы для самопроверки

### Чем байесовская оценка параметра отличается от оценки максимального правдоподобия (MLE)?
MLE даёт одну точку θ, максимизирующую P(D|θ). Байесовский вывод даёт **всё апостериорное распределение** P(θ|D) ∝ P(D|θ)·P(θ), учитывая априорные знания и позволяя оценить неопределённость (например, достоверный интервал).

### Почему при большом количестве данных выбор prior перестаёт сильно влиять на результат?
Правдоподобие — произведение по всем наблюдениям, и с ростом n оно становится всё более острым и доминирует над фиксированным prior. Апостериорное распределение концентрируется около MLE (если prior не обнуляет эту область).

### Что такое сопряжённый prior и зачем он нужен?
Prior, при котором posterior остаётся в том же семействе распределений: например, **Beta** для биномиального правдоподобия, **Gamma** для пуассоновского, нормальное для среднего нормального распределения. Это даёт аналитический posterior без MCMC.

### Посчитайте: prior Beta(2, 2), наблюдали 8 успехов из 10. Какой posterior и его среднее?
Posterior = Beta(2 + 8, 2 + 2) = **Beta(10, 4)**, среднее = 10 / 14 ≈ 0.71. Для сравнения, MLE = 0.8 — prior слегка «стягивает» оценку к 0.5.

### Почему знаменатель P(D) в теореме Байеса часто не вычисляют?
P(D) = ∫P(D|θ)P(θ)dθ — обычно трудный интеграл, но он не зависит от θ и лишь нормирует posterior. Для MAP-оценки и для MCMC достаточно ненормированного P(D|θ)P(θ); P(D) нужен только для сравнения моделей (байесовский фактор).
