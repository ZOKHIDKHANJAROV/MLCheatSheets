# Self-attention — вопросы для самопроверки

### Откуда в self-attention берутся Q, K и V?
Из одной и той же последовательности: каждый токен умножается на три обучаемые матрицы — Q = XW_Q, K = XW_K, V = XW_V. Так каждый токен формирует «запрос», «ключ» и «значение».

### Запишите формулу scaled dot-product attention.
Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V. Матрица QKᵀ содержит сходство каждого токена с каждым, softmax по строкам даёт веса, и они смешивают векторы значений.

### Зачем делить на √d_k?
При большой размерности скалярные произведения растут по величине, softmax становится почти one-hot и даёт крошечные градиенты. Деление на √d_k удерживает дисперсию оценок около 1.

### Какова вычислительная сложность self-attention по длине последовательности n?
O(n²·d) по времени и O(n²) по памяти на матрицу внимания: каждый токен сравнивается с каждым. Поэтому длинные контексты дороги, и существуют эффективные варианты (sparse, linear attention, FlashAttention).

### Знает ли self-attention о порядке токенов сам по себе?
Нет: операция инвариантна к перестановке входов (точнее, эквивариантна). Информацию о позиции добавляют отдельно — позиционными кодированиями (синусоидальными, обучаемыми, RoPE).
