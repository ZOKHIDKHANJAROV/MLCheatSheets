# Constrained optimization в ML — вопросы для самопроверки

### Зачем в ML нужны ограничения, если можно просто минимизировать ошибку?
Бизнес-, физические или этические требования не выражаются в loss напрямую: монотонность по признаку, справедливость между группами, неотрицательность весов, бюджет ресурсов. Ограничения гарантируют, что решение допустимо, а не только точно.

### Как метод множителей Лагранжа превращает задачу с ограничениями в задачу без них?
Строится лагранжиан L(x, λ, μ) = f(x) + ∑λᵢgᵢ(x) + ∑μⱼhⱼ(x) с λᵢ ≥ 0 для неравенств gᵢ(x) ≤ 0. Оптимум — седловая точка: минимум по x и максимум по множителям; необходимые условия оптимальности — условия KKT.

### Что означает условие дополняющей нежёсткости в KKT?
λᵢ·gᵢ(x*) = 0: либо ограничение активно (gᵢ = 0), либо его множитель равен нулю. В SVM это значит, что ненулевые множители αᵢ есть только у опорных векторов — точек на границе или нарушающих её.

### Чем штрафной метод отличается от барьерного?
Штрафной метод добавляет ρ·∑max(0, gᵢ(x))² и допускает нарушение ограничений, которое уменьшается с ростом ρ. Барьерный добавляет, например, −μ·∑log(−gᵢ(x)), который уходит в бесконечность у границы, поэтому решение остаётся строго внутри допустимой области.

### Как обеспечить простые ограничения на веса при градиентном спуске?
Проецированным градиентным спуском: после каждого шага проецировать веса на допустимое множество — обрезать до [a, b] для box-ограничений, обнулять отрицательные для неотрицательности, нормировать на шар для ограничения нормы.
