# Метод опорных векторов (SVM) — вопросы для самопроверки

### Почему SVM максимизирует отступ (margin) и что такое опорные векторы?
Широкая разделяющая полоса даёт лучшую обобщающую способность: модель устойчивее к шуму около границы. Опорные векторы — объекты на границе полосы или внутри неё; только они определяют решение, остальные точки можно удалить без изменения модели.

### Как параметр C влияет на модель?
C — штраф за нарушение отступа. Большое C почти не допускает ошибок на обучении — узкая полоса и риск переобучения; малое C разрешает больше нарушений — широкая полоса и более сильная регуляризация.

### В чём суть kernel trick?
Двойственная задача SVM зависит от данных только через скалярные произведения ⟨xᵢ, xⱼ⟩. Заменив их ядром K(xᵢ, xⱼ) (например, RBF: exp(−γ‖xᵢ − xⱼ‖²)), получаем линейный классификатор в неявном многомерном пространстве признаков, не вычисляя само отображение.

### Что будет при слишком большом γ в RBF-ядре?
Ядро становится очень «узким»: каждая точка влияет только на ближайшую окрестность, граница огибает отдельные объекты, и модель переобучается. Малое γ, наоборот, даёт почти линейную гладкую границу. C и γ подбирают совместно по сетке.

### Почему SVM чувствителен к масштабу признаков и плохо масштабируется на большие выборки?
И отступ, и RBF-ядро опираются на расстояния, поэтому признак с большим масштабом доминирует — нужна стандартизация. Ядерный SVM работает с матрицей ядра n×n, и обучение растёт примерно как O(n²)–O(n³), поэтому на сотнях тысяч объектов используют `LinearSVC` или `SGDClassifier`.
