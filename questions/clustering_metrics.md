# Метрики оценки кластеризации — вопросы для самопроверки

### Чем внутренние метрики отличаются от внешних?
Внутренние (силуэт, Calinski–Harabasz, Davies–Bouldin) оценивают кластеризацию только по данным — компактность и разделённость. Внешние (ARI, NMI, homogeneity, completeness) сравнивают результат с известной истинной разметкой и применимы, только когда она есть.

### Как считается коэффициент силуэта и как его интерпретировать?
Для объекта s = (b − a) / max(a, b), где a — среднее расстояние до объектов своего кластера, b — среднее расстояние до объектов ближайшего чужого. Значение близко к 1 — объект хорошо в своём кластере, около 0 — на границе, меньше 0 — скорее всего, отнесён не туда.

### Почему для сравнения с истинной разметкой нельзя просто посчитать accuracy?
Номера кластеров произвольны: разбиение с метками {0, 1} и то же разбиение с переставленными метками {1, 0} одинаково хороши. ARI и NMI инвариантны к перестановке меток и сравнивают сами разбиения.

### Почему ARI предпочитают обычному Rand index?
Rand index для случайного разбиения может быть заметно больше 0 и зависит от числа кластеров. Adjusted Rand Index скорректирован на случайность: ≈ 0 для случайной разметки и 1 для полного совпадения (может быть и отрицательным).

### Какая ловушка есть у силуэта и Calinski–Harabasz при оценке DBSCAN?
Эти метрики предполагают выпуклые, «шаровидные» кластеры, поэтому кластеры невыпуклой формы (полумесяцы, кольца) могут получить низкую оценку, даже если они найдены правильно. Кроме того, шумовые точки (метка −1) нужно исключать или учитывать отдельно.
