# Сегментация изображений — вопросы для самопроверки

### Чем семантическая сегментация отличается от instance- и panoptic-сегментации?
Семантическая присваивает класс каждому пикселю, не различая объекты одного класса. Instance выделяет каждый объект отдельно. Panoptic объединяет оба подхода: отдельные экземпляры для «вещей» (люди, машины) и классы для «фона» (небо, дорога).

### Как устроена U-Net и зачем в ней skip-связи?
Энкодер сжимает изображение и извлекает признаки, декодер восстанавливает разрешение. Skip-связи передают карты признаков энкодера в декодер на том же уровне, возвращая мелкие пространственные детали, потерянные при сжатии.

### Какие функции потерь используют для сегментации и почему не только кросс-энтропию?
Попиксельную кросс-энтропию, а также Dice loss и IoU (Jaccard) loss, которые напрямую оптимизируют перекрытие масок. Они устойчивее к дисбалансу, когда объект занимает малую долю изображения.

### Как вычисляется метрика mIoU?
Для каждого класса считается IoU = |предсказание ∩ разметка| / |предсказание ∪ разметка| по пикселям, затем значения усредняются по классам.

### Как Mask R-CNN решает задачу instance-сегментации?
Расширяет детектор Faster R-CNN: для каждой найденной рамки дополнительная ветка предсказывает бинарную маску объекта. RoIAlign точно выравнивает признаки области без грубого округления координат.
