# Neural Style Transfer — вопросы для самопроверки

### В чём идея переноса стиля по Gatys?
Оптимизируется само изображение (не веса сети): оно должно совпадать с изображением-содержанием по глубоким признакам предобученной CNN (обычно VGG) и с изображением-стилем — по статистикам признаков нескольких слоёв.

### Что такое матрица Грама и почему она описывает стиль?
G = FFᵀ — попарные корреляции между каналами карты признаков, усреднённые по всем позициям. Она отражает, какие текстуры и цвета встречаются вместе, но теряет информацию о том, где именно, — это и есть стиль без содержания.

### Почему content loss берут с глубоких слоёв?
Глубокие слои кодируют объекты и их расположение, но не точные пиксели. Совпадение по ним сохраняет структуру сцены, оставляя свободу для изменения текстуры.

### Чем быстрый перенос стиля (Johnson et al.) отличается от исходного метода?
Вместо долгой оптимизации каждого изображения обучается отдельная сеть-преобразователь, которая переносит один стиль за один прямой проход — в реальном времени. Обучается она с теми же perceptual losses.

### Как AdaIN позволяет переносить произвольный стиль одной моделью?
Adaptive Instance Normalization выравнивает среднее и стандартное отклонение каждого канала признаков содержания под статистики признаков стиля. Стиль задаётся на лету, переобучать модель под каждый стиль не нужно.
