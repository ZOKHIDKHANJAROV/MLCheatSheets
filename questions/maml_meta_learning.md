# Model-agnostic meta-learning (MAML) — вопросы для самопроверки

### Что именно оптимизирует MAML?
Не веса под одну задачу, а **начальную инициализацию** θ, из которой несколько шагов градиентного спуска на support set дают хорошее качество на query set новой задачи. Мета-цель — ∑ L_τ(θ − α∇L_τ(θ)) по задачам τ.

### Чем отличаются внутренний и внешний циклы MAML?
Внутренний цикл адаптирует копию параметров к конкретной задаче на её support set (шаг α). Внешний цикл обновляет общую инициализацию θ по ошибке адаптированных моделей на query set (шаг β), усредняя по батчу задач.

### Почему полный MAML дорог и что такое first-order MAML?
Мета-градиент проходит через шаги внутреннего цикла и требует производных второго порядка (гессиан-векторных произведений) и хранения графа вычислений. FOMAML отбрасывает вторые производные и использует градиент на адаптированных весах — дешевле и часто почти так же хорошо.

### Почему MAML называется model-agnostic?
Он требует только, чтобы модель обучалась градиентным спуском, и не накладывает ограничений на архитектуру или loss. Его применяют к CNN для классификации, к регрессии и к политикам в обучении с подкреплением.

### Когда MAML может работать плохо?
Если задачи в распределении слишком разные, единая инициализация не подходит всем; если новая задача вне обучающего распределения задач — адаптации за несколько шагов не хватает. Также MAML нестабилен в обучении и чувствителен к гиперпараметрам (MAML++ решает часть проблем).
