# Kernel CCA — вопросы для самопроверки

### Зачем нужен Kernel CCA, если есть обычный CCA?
Обычный CCA находит только линейные связи между представлениями. Kernel CCA отображает каждое представление в пространство признаков ядра (RBF, полиномиальное) и ищет корреляции там, что позволяет находить нелинейные зависимости.

### Почему Kernel CCA без регуляризации даёт бессмысленный результат?
При обратимых матрицах Грама (например, у RBF-ядра) всегда найдутся направления с корреляцией ровно 1 — модель идеально подгоняется под любые данные. Поэтому обязательна регуляризация: Kₓ + κI в знаменателе.

### Как растёт вычислительная сложность Kernel CCA с числом объектов?
Нужно хранить матрицы Грама n×n (O(n²) памяти) и решать обобщённую задачу на собственные значения размера порядка 2n (O(n³) времени). Для больших n используют низкоранговые приближения: неполное разложение Холецкого, метод Нистрёма, случайные признаки Фурье.

### Чем Deep CCA отличается от Kernel CCA?
Deep CCA обучает две нейросети, отображающие представления в пространство, где их выходы максимально коррелированы. Он масштабируется на большие данные лучше ядерного метода, поскольку обучается минибатчами, и выучивает гибкие нелинейные преобразования.

### Какие гиперпараметры нужно подбирать в Kernel CCA?
Тип и параметры ядра для каждого представления (например, ширина RBF), коэффициент регуляризации κ и число компонент. Подбирают по корреляции на отложенных данных: на обучающей выборке корреляция почти всегда завышена.
