# Методы на основе скользящих средних — вопросы для самопроверки

### Почему простое скользящее среднее (SMA) запаздывает за трендом?
Оно усредняет последние k точек с равными весами, поэтому «центр тяжести» окна отстаёт на (k − 1)/2 шагов. Чем длиннее окно, тем сильнее сглаживание и тем позже реакция на смену тренда.

### Чем экспоненциальное скользящее среднее (EMA) отличается от SMA?
EMA даёт экспоненциально убывающие веса прошлым наблюдениям: sₜ = α·xₜ + (1 − α)·sₜ₋₁. Она быстрее реагирует на свежие изменения и не требует хранить окно; при α = 2/(k + 1) её среднее запаздывание совпадает с SMA окна k.

### Какая утечка данных возможна при расчёте скользящего среднего как признака?
Использование **центрированного** окна (`center=True`) или окна, включающего текущее значение целевой переменной: признак «видит» будущее или сам таргет. Для прогноза окно сдвигают: `series.shift(1).rolling(k).mean()`.

### Как выбрать ширину окна для удаления сезонности?
Окно должно совпадать с периодом сезонности (7 для дневных данных с недельным циклом, 12 для месячных с годовым), тогда сезонные колебания внутри окна взаимно гасятся. Для чётного периода используют центрированное 2×m-MA, чтобы окно оставалось симметричным.

### Чем MA-компонента модели ARIMA отличается от скользящего среднего для сглаживания?
Это разные вещи. Сглаживающее MA усредняет **наблюдения** ряда, а MA(q) в ARIMA выражает текущее значение через **прошлые ошибки** (шоки): yₜ = μ + εₜ + θ₁εₜ₋₁ + … + θ_q·εₜ₋q.
