# Логистическая регрессия — вопросы для самопроверки

### Как логистическая регрессия получает вероятность из линейной комбинации признаков?
Применяет сигмоиду к линейной части: p = σ(z) = 1 / (1 + e⁻ᶻ), где z = wᵀx + b. Сигмоида переводит любое число в интервал (0, 1).

### Какую функцию потерь минимизирует логистическая регрессия?
Логистическую потерю (log loss, бинарную кросс-энтропию): −[y·log p + (1 − y)·log(1 − p)]. Она сильно штрафует уверенные неверные прогнозы. MSE не используют, потому что с сигмоидой задача становится невыпуклой.

### Как интерпретировать коэффициент wⱼ?
Увеличение признака на единицу меняет логарифм шансов log(p / (1 − p)) на wⱼ, т.е. умножает шансы на e^wⱼ при прочих равных. Положительный вес увеличивает вероятность класса 1.

### Почему порог 0.5 не всегда правильный?
При несбалансированных классах или разной цене ошибок (пропустить болезнь хуже, чем ложная тревога) порог подбирают под задачу — по ROC- или PR-кривой либо по нужному соотношению precision и recall.

### Какой формы граница между классами у логистической регрессии?
Линейная: гиперплоскость wᵀx + b = 0. Для нелинейных границ нужно добавлять признаки (полиномиальные, взаимодействия) или использовать другие модели.
