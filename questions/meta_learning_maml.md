# Meta-learning (MAML, Prototypical Networks) — вопросы для самопроверки

### В чём идея meta-learning («learning to learn»)?
Модель обучается на **множестве задач**, чтобы быстро адаптироваться к новой задаче по нескольким примерам. Обучающая единица — не отдельный пример, а эпизод: support set для адаптации и query set для оценки.

### Как устроены внутренний и внешний циклы MAML?
**Внутренний** цикл: для каждой задачи из общих параметров θ делается несколько шагов градиентного спуска на support set, получаются θ'ᵢ. **Внешний** цикл: θ обновляется по loss на query set, посчитанному с адаптированными θ'ᵢ, то есть ищется инициализация, из которой несколько шагов дают хороший результат.

### Почему полный MAML дорог и что такое FOMAML?
Градиент внешнего цикла проходит через шаги внутреннего, что требует **вторых производных** (произведения гессиана на вектор) и хранения всего графа адаптации. First-order MAML игнорирует вторые производные и использует градиент в точке θ'; Reptile упрощает ещё сильнее. Качество при этом часто почти не падает.

### Чем optimization-based мета-обучение (MAML) отличается от metric-based (Prototypical Networks)?
MAML **адаптирует веса** под новую задачу градиентными шагами и не зависит от архитектуры, поэтому подходит и для регрессии, и для RL. ProtoNets не дообучаются на новой задаче — они сравнивают эмбеддинги с прототипами классов, что быстрее и стабильнее, но рассчитано на классификацию.

### Какая ошибка в протоколе оценки мета-обучения встречается чаще всего?
Пересечение **классов** между meta-train и meta-test (например, разные изображения тех же классов). В few-shot тестовые классы должны быть новыми, иначе измеряется обычная классификация. Также результат нужно усреднять по сотням или тысячам эпизодов и приводить доверительный интервал.
