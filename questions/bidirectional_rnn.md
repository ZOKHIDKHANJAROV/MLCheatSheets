# Двунаправленные RNN — вопросы для самопроверки

### Как устроена двунаправленная RNN?
Две независимые RNN читают последовательность слева направо и справа налево, а их скрытые состояния на каждом шаге конкатенируются. Каждое представление учитывает и прошлый, и будущий контекст.

### Когда двунаправленную RNN использовать нельзя?
Когда нужен онлайн-прогноз или авторегрессивная генерация: будущих элементов на момент предсказания ещё нет. Например, при прогнозе временного ряда на следующий шаг или генерации текста слово за словом это утечка будущего.

### Для каких задач она особенно полезна?
Для задач, где вся последовательность доступна сразу: NER, POS-тегирование, классификация текста, распознавание речи офлайн, энкодер в seq2seq. Значение слова часто определяется правым контекстом.

### Как меняется размер выхода при `bidirectional` с hidden_size = 128?
При конкатенации выход на каждом шаге имеет размер 2·128 = 256; следующий слой должен ожидать 256 входов. В PyTorch финальное `h_n` содержит отдельные состояния для каждого направления.

### Какая ловушка при использовании финального состояния для классификации?
Для обратного направления «финальное» состояние соответствует **первому** токену, а не последнему. Если брать выход `output[:, -1]`, то обратная часть видела только последний токен; правильнее брать `h_n` обоих направлений или делать пулинг.
