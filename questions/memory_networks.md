# Memory networks — вопросы для самопроверки

### Какую проблему решают memory networks по сравнению с RNN?
RNN хранит всё в скрытом векторе фиксированного размера, и информация о дальних фактах теряется. Memory networks имеют явную внешнюю память, к которой модель обращается по содержимому, что помогает в задачах вопрос-ответ по множеству фактов.

### Как в end-to-end memory network происходит чтение из памяти?
Запрос u сравнивается с ключами памяти mᵢ, веса внимания pᵢ = softmax(uᵀmᵢ), а результат — взвешенная сумма значений o = ∑ pᵢcᵢ. Мягкое внимание делает чтение дифференцируемым, и модель обучается без разметки нужных фактов.

### Зачем делать несколько «хопов» (hops) обращения к памяти?
Для вопросов, требующих цепочки рассуждений: первый хоп находит один факт, обновлённый запрос позволяет найти следующий связанный факт. Например, «где мяч?» → «Джон взял мяч» → «Джон пошёл на кухню».

### Чем исходные Memory Networks (Weston et al.) отличались от End-to-End Memory Networks?
Исходная версия использовала жёсткий выбор памяти (argmax) и требовала разметки поддерживающих фактов. End-to-End версия (Sukhbaatar et al.) заменила это мягким вниманием и обучается только по парам вопрос–ответ.

### Как memory networks связаны с современными трансформерами и RAG?
Внимание по ключам и значениям — та же идея адресации памяти по содержимому, а трансформер можно рассматривать как многократное чтение из памяти токенов. **RAG** расширяет это до внешней базы документов, найденных ретривером.
