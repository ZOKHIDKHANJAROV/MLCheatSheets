# Temporal Convolutional Networks (TCN) — вопросы для самопроверки

### Что такое каузальная свёртка и зачем она в TCN?
Выход в момент t зависит только от входов в моменты ≤ t: паддинг добавляется только слева. Это исключает утечку будущего при прогнозировании.

### Зачем нужны dilated свёртки?
Dilation d вставляет промежутки между элементами ядра, и при удвоении d на каждом слое рецептивное поле растёт экспоненциально с глубиной, а не линейно. Так покрываются длинные истории малым числом слоёв.

### Посчитайте рецептивное поле TCN: ядро k = 3, dilation 1, 2, 4, 8, по одной свёртке на уровень.
R = 1 + (k − 1)·∑d = 1 + 2·(1 + 2 + 4 + 8) = 31 шаг. В оригинальной TCN в каждом residual-блоке две свёртки, тогда R = 1 + 2·2·15 = 61.

### Какие преимущества TCN перед LSTM?
Параллельная обработка всей последовательности при обучении, стабильные градиенты благодаря residual-связям, контролируемый размер памяти. Во многих бенчмарках TCN сравнима с LSTM или лучше её.

### В чём ограничения TCN?
История за пределами рецептивного поля полностью недоступна, а при переносе на задачу с более длинными зависимостями архитектуру надо менять. На инференсе по шагам нужно хранить окно истории, тогда как RNN хранит только скрытое состояние.
