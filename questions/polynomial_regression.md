# Полиномиальная регрессия — вопросы для самопроверки

### Почему полиномиальная регрессия всё ещё считается линейной моделью?
Она линейна по **параметрам**: признаки x, x², x³… создаются заранее (`PolynomialFeatures`), а затем обучается обычная линейная регрессия на расширенном наборе признаков.

### Что происходит при слишком большой степени полинома?
Модель начинает проходить почти через каждую точку обучающей выборки и сильно колеблется между ними — классическое переобучение (высокая дисперсия), особенно на краях диапазона.

### Как выбрать степень полинома?
Перебрать несколько степеней и сравнить ошибку на кросс-валидации; выбрать степень с минимальной ошибкой на валидации, а не на обучении.

### Сколько признаков даст `PolynomialFeatures(degree=2)` для 3 исходных признаков?
10: константа (1), 3 исходных признака, 3 квадрата и 3 попарных произведения. С ростом степени и числа признаков их количество растёт комбинаторно.

### Почему перед полиномиальными признаками важно масштабирование?
Степени больших значений (например, 1000³) дают огромные числа: страдает численная устойчивость, а при регуляризации признаки разных масштабов штрафуются несопоставимо.
