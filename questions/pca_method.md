# Метод главных компонент (PCA) — вопросы для самопроверки

### Почему перед PCA признаки обычно стандартизируют?
PCA ищет направления максимальной дисперсии. Признак в больших единицах (зарплата в рублях) имеет огромную дисперсию и «захватывает» первую компоненту независимо от важности. После стандартизации все признаки вносят сопоставимый вклад.

### Как выбрать число компонент?
По накопленной доле объяснённой дисперсии (`explained_variance_ratio_`), например 90–95%, по «локтю» на графике собственных значений или по качеству итоговой модели на кросс-валидации. В sklearn можно задать `n_components=0.95`.

### Почему PCA может ухудшить качество классификации?
PCA не использует целевую переменную: направления с малой дисперсией, отбрасываемые им, могут быть именно теми, что разделяют классы. Для учёта меток есть LDA.

### Как PCA связан с SVD?
Главные компоненты — правые сингулярные векторы центрированной матрицы X = UΣVᵀ, а собственные значения ковариации равны σᵢ²/(n − 1). Через SVD считать численно устойчивее, чем через явную матрицу ковариации.

### Что будет, если применить PCA к данным с нелинейной структурой (например, «швейцарский рулет»)?
PCA — линейный метод, он лишь поворачивает и проецирует данные, поэтому развернуть нелинейное многообразие не сможет. Нужны Kernel PCA, t-SNE, UMAP, Isomap.
