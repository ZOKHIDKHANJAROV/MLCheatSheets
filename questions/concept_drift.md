# Дрейф данных — вопросы для самопроверки

### Чем data drift отличается от concept drift?
Data (covariate) drift — меняется распределение входных признаков P(X), а зависимость остаётся прежней. Concept drift — меняется сама зависимость P(y|X): одни и те же признаки теперь означают другое (например, мошенники сменили тактику).

### Какие виды дрейфа по характеру изменения бывают?
Внезапный (резкий скачок, например после пандемии), постепенный, инкрементный (медленное смещение), повторяющийся (сезонность).

### Какие статистические инструменты используют для обнаружения дрейфа признаков?
Тест Колмогорова–Смирнова и Population Stability Index (PSI) для числовых признаков, хи-квадрат для категориальных, расстояния между распределениями (Вассерштейна, Йенсена–Шеннона). Есть и подход «классификатор отличает старые данные от новых».

### Как обнаружить concept drift, если метки приходят с задержкой?
По мере поступления меток отслеживать качество модели во времени; использовать детекторы на потоке ошибок (DDM, ADWIN, Page-Hinkley). До прихода меток — смотреть на дрейф прогнозов и уверенности модели как косвенный сигнал.

### Что делать при обнаружении дрейфа?
Проверить, не ошибка ли это в данных (сломанный источник). Если дрейф настоящий — переобучить модель на свежих данных, взвесить новые наблюдения сильнее, пересмотреть признаки; при регулярном дрейфе — настроить автоматическое переобучение.
