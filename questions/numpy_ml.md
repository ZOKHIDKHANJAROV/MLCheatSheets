# NumPy для ML — вопросы для самопроверки

### Чем массив NumPy отличается от списка Python и почему он быстрее?
Массив хранит элементы **одного типа** в непрерывном блоке памяти, а операции над ним выполняются в скомпилированном C-коде сразу над всем массивом (векторизация). Список хранит ссылки на отдельные объекты Python, и цикл по нему интерпретируется поэлементно.

### Что такое broadcasting? Приведите пример.
Правило, по которому NumPy выполняет операции над массивами разной формы: размерности сравниваются с конца, и измерение длины 1 «растягивается». Пример: `X - X.mean(axis=0)` — из матрицы `(n, d)` вычитается вектор средних `(d,)`, и каждая строка центрируется.

### Что означает `axis=0` в `X.sum(axis=0)` для матрицы «объекты × признаки»?
Суммирование **вдоль** оси 0, т.е. по строкам: результат — по одному числу на каждый столбец (признак), форма `(d,)`. `axis=1` даёт сумму по каждой строке (объекту).

### Чем отличаются `A * B` и `A @ B`?
`A * B` — поэлементное умножение (с broadcasting). `A @ B` — матричное умножение: число столбцов `A` должно совпадать с числом строк `B`.

### Почему изменение среза `b = a[1:3]` может изменить исходный массив `a`?
Обычный срез возвращает **представление** (view) на те же данные, а не копию. Чтобы получить независимый массив, нужен `a[1:3].copy()`. Индексация списком или маской (`a[[0, 2]]`, `a[a > 0]`) всегда создаёт копию.
