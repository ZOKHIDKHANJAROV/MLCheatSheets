# BERT и языковые модели — вопросы для самопроверки

### Какую часть Transformer использует BERT?
Только энкодер. Модель двунаправленная: каждый токен видит контекст и слева, и справа.

### Как устроена задача предобучения Masked Language Modeling?
Около 15% токенов выбирают для маскирования, и модель предсказывает исходные токены по контексту. Из выбранных: 80% заменяются на [MASK], 10% — на случайный токен, 10% остаются без изменений, чтобы не было расхождения с дообучением, где [MASK] нет.

### Для чего нужен токен [CLS]?
Специальный токен в начале входа; его итоговое представление используется как вектор всей последовательности для задач классификации при дообучении.

### Почему BERT плохо подходит для генерации текста?
Он обучен восстанавливать пропуски с двусторонним контекстом, а не предсказывать следующий токен слева направо. Для генерации используют декодерные модели (GPT) или encoder-decoder (T5).

### Какие улучшения BERT вы знаете?
RoBERTa — больше данных и шагов, без задачи NSP, динамическое маскирование. DistilBERT — дистилляция в модель меньше и быстрее. ALBERT — разделение параметров между слоями. DeBERTa — раздельное кодирование содержания и позиции.
