# Деревья решений для регрессии — вопросы для самопроверки

### Что предсказывает лист регрессионного дерева и по какому критерию выбирается разбиение?
Лист предсказывает среднее значение таргета попавших в него объектов (для критерия MAE — медиану). Разбиение выбирается так, чтобы максимально уменьшить взвешенную сумму MSE (дисперсии) в дочерних узлах.

### Почему регрессионное дерево не умеет экстраполировать?
Предсказание — среднее по обучающим объектам листа, поэтому оно всегда лежит в диапазоне таргета обучающей выборки. При x за пределами обучающих данных дерево вернёт значение крайнего листа — константу, даже если тренд явно растёт.

### Как выглядит функция предсказания дерева и чем это плохо?
Это кусочно-постоянная «ступенчатая» функция с разрывами. Гладкие зависимости приближаются грубо, а для точности нужно много листьев, что ведёт к переобучению.

### Какие гиперпараметры помогают бороться с переобучением дерева?
`max_depth`, `min_samples_leaf`, `min_samples_split`, `max_leaf_nodes` ограничивают рост, а `ccp_alpha` включает cost-complexity pruning (обрезку). Без ограничений дерево растёт до одного объекта в листе и запоминает шум.

### Нужно ли масштабировать признаки для дерева решений?
Нет: разбиения вида xⱼ ≤ t инвариантны к монотонным преобразованиям признака, поэтому стандартизация и логарифмирование признаков не меняют структуру дерева. А вот преобразование **таргета** (например, log y) на результат влияет.
