# Градиентный бустинг для регрессии — вопросы для самопроверки

### Почему при MSE каждое новое дерево обучается на остатках?
Антиградиент MSE/2 по предсказанию равен yᵢ − F(xᵢ), то есть остатку. Значит, подгонка дерева к остаткам — частный случай общего правила бустинга: каждое дерево аппроксимирует антиградиент функции потерь.

### Зачем нужен learning rate и как он связан с числом деревьев?
Шаг ν (shrinkage) уменьшает вклад каждого дерева: F_m = F_{m−1} + ν·h_m. Малый ν даёт лучшее обобщение, но требует больше деревьев; поэтому обычно фиксируют небольшой learning rate (0.01–0.1) и подбирают число деревьев ранней остановкой.

### Какую функцию потерь выбрать при выбросах в целевой переменной?
MSE сильно штрафует большие ошибки, и выбросы тянут модель на себя. **Huber** или **MAE** устойчивее: для MAE антиградиент — sign(y − F), и значения в листьях становятся медианами остатков, а не средними.

### Как с помощью градиентного бустинга построить интервал прогноза?
Обучить две модели с **квантильной** функцией потерь (pinball loss), например для α = 0.05 и α = 0.95, — получится 90%-ный интервал. В sklearn это `loss="quantile"` с параметром `alpha`, в LightGBM — `objective="quantile"`.

### Почему бустинг на деревьях не экстраполирует, и когда это важно?
Каждое дерево выдаёт константы в листьях, поэтому прогноз ограничен диапазоном значений, встреченных на обучении. При трендовом таргете (цены, продажи с ростом) модель на новых данных «упрётся в потолок»; помогает предсказание разностей или отношений, либо линейная базовая модель с бустингом остатков.
