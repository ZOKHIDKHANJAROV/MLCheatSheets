# Квантовые алгоритмы для ML — вопросы для самопроверки

### Почему утверждение «n кубитов обрабатывают 2ⁿ состояний одновременно» не означает экспоненциального ускорения для любой задачи?
Измерение даёт лишь один случайный результат, и извлечь все 2ⁿ амплитуд нельзя. Ускорение возможно только там, где интерференция усиливает нужный ответ — в специально устроенных алгоритмах (Гровер, Шор, некоторые задачи линейной алгебры).

### Кубит в состоянии |ψ⟩ = 0.6|0⟩ + 0.8|1⟩. С какой вероятностью измерение даст 1?
Вероятность равна |β|² = 0.8² = **0.64**, а для 0 — 0.6² = 0.36; в сумме 1, как и требует нормировка |α|² + |β|² = 1.

### Какое ускорение даёт алгоритм Гровера и для чего он полезен в ML?
**Квадратичное**: поиск в неструктурированном пространстве из N элементов за O(√N) обращений вместо O(N). В ML его рассматривают для ускорения поиска и оптимизации, но экспоненциального выигрыша он не даёт.

### Что такое «узкое место загрузки данных» (data loading problem) в квантовом ML?
Многие алгоритмы с экспоненциальным ускорением (например, HHL, quantum PCA) предполагают, что классические данные уже эффективно закодированы в амплитуды (QRAM). Само кодирование может стоить O(N) и съесть всё ускорение.

### Что такое «деквантизация» квантовых алгоритмов?
Это построение классических алгоритмов с похожей асимптотикой при аналогичных предположениях о доступе к данным (работы Ewin Tang для рекомендательных систем). Она показала, что часть заявленных экспоненциальных ускорений для ML не уникальна для квантовых компьютеров.
