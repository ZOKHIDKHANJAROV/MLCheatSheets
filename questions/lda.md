# LDA (Linear Discriminant Analysis) — вопросы для самопроверки

### Чем LDA отличается от PCA?
PCA — метод без учителя, ищет направления максимальной общей дисперсии. LDA использует метки классов и ищет направления, максимизирующие отношение межклассового разброса к внутриклассовому (критерий Фишера), то есть наилучшую разделимость классов.

### Сколько компонент может дать LDA?
Не больше min(C − 1, d), где C — число классов, d — число признаков. Например, для бинарной классификации LDA проецирует данные на одну прямую, сколько бы признаков ни было.

### Какие предположения лежат в основе LDA как классификатора?
Классы распределены нормально с общей ковариационной матрицей и разными средними. Тогда граница между классами линейна. Если ковариации разных классов сильно различаются, лучше подходит QDA с квадратичной границей.

### Что будет, если признаков больше, чем объектов?
Внутриклассовая ковариационная матрица станет вырожденной, и её нельзя обратить. Помогает shrinkage-регуляризация ковариации (в sklearn — `solver='lsqr'` или `'eigen'` с `shrinkage='auto'`) или предварительное снижение размерности с помощью PCA.

### Как не перепутать LDA из этой темы с LDA в анализе текстов?
Linear Discriminant Analysis — линейный метод классификации и снижения размерности с учителем. Latent Dirichlet Allocation — вероятностная тематическая модель для текстов, никак не связанная с ним, кроме аббревиатуры.
