# SHAP для нейросетей — вопросы для самопроверки

### На чём основаны значения SHAP?
На **значениях Шепли** из теории кооперативных игр: вклад признака — средний прирост выхода модели при его добавлении к всевозможным коалициям остальных признаков. Сумма SHAP-значений всех признаков равна f(x) − E[f(x)], то есть разности прогноза и базового значения.

### Почему точные значения Шепли для нейросети не считают напрямую?
Нужно перебрать все **2ᵈ** подмножеств признаков — для изображения из тысяч пикселей это невозможно. Используют приближения: KernelSHAP (выборка коалиций), DeepSHAP (на основе DeepLIFT), GradientSHAP (ожидание градиентов, связан с Integrated Gradients).

### Чем DeepExplainer и GradientExplainer в библиотеке shap отличаются от KernelExplainer?
KernelExplainer — model-agnostic, требует только функции предсказания, но очень медленный. **DeepExplainer** и **GradientExplainer** используют внутреннее устройство сети (обратное распространение) и работают гораздо быстрее, но применимы только к дифференцируемым моделям TensorFlow и PyTorch.

### Зачем SHAP для нейросети нужен фоновый набор данных (background)?
Отсутствие признака моделируется заменой его значения на значения из фона, а базовое значение — это средний прогноз на фоне. Выбор фона (случайная выборка train, нули, размытые изображения) **меняет** объяснения; обычно берут 100–1000 типичных примеров, а слишком маленький фон даёт шумные оценки.

### Почему большое SHAP-значение не означает причинное влияние признака?
SHAP объясняет **модель**, а не реальный мир: он показывает, как признак влияет на прогноз этой модели. При коррелированных признаках вклад делится между ними условно, а замена признака фоном создаёт нереалистичные комбинации, поэтому выводы о причинности по SHAP делать нельзя.
