# Метрики классификации — вопросы для самопроверки

### Почему accuracy может обманывать?
При дисбалансе классов: если мошеннических операций 1%, модель «всегда не мошенничество» получит accuracy 99%, не найдя ни одного мошенника.

### Запишите precision и recall через TP, FP, FN.
Precision = TP / (TP + FP) — какая доля найденных положительных действительно положительна. Recall = TP / (TP + FN) — какую долю всех положительных модель нашла.

### Когда важнее precision, а когда recall?
Recall — когда дорого пропустить положительный случай (диагностика болезней, мошенничество). Precision — когда дороги ложные срабатывания (спам-фильтр, удаляющий важные письма).

### Что такое F1 и почему это гармоническое, а не обычное среднее?
F1 = 2·P·R / (P + R). Гармоническое среднее близко к меньшему из двух значений, поэтому высокий F1 возможен только при одновременно высоких precision и recall.

### Чем macro-усреднение отличается от weighted в многоклассовой задаче?
Macro — простое среднее метрик по классам: все классы равноправны, редкие влияют сильно. Weighted — среднее с весами по числу объектов класса: доминируют частые классы.
