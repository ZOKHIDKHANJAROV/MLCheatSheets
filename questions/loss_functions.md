# Функции потерь — вопросы для самопроверки

### Какие функции потерь используют для регрессии и чем они отличаются?
MSE — сильно штрафует большие ошибки, чувствительна к выбросам. MAE — устойчива к выбросам, но у неё постоянный по величине градиент и излом в нуле. Huber — квадратичная для малых ошибок и линейная для больших, компромисс между ними.

### Почему для классификации используют кросс-энтропию, а не MSE?
Кросс-энтропия −Σ yₖ log pₖ сильно штрафует уверенные неверные прогнозы и в паре с softmax/сигмоидой даёт хорошие градиенты (p − y). MSE с сигмоидой в зоне насыщения даёт почти нулевой градиент, и обучение застревает.

### Почему в PyTorch в `nn.CrossEntropyLoss` подают логиты, а не вероятности?
Функция сама применяет log-softmax численно устойчивым способом. Если заранее применить softmax, он будет применён дважды, и обучение испортится.

### Чем binary cross-entropy отличается от categorical cross-entropy?
Бинарная — для одного выхода с вероятностью класса 1 (а также для multi-label, где каждый класс — отдельная бинарная задача). Категориальная — для одного верного класса из нескольких, с softmax по всем классам.

### Как функцией потерь учесть дисбаланс классов?
Задать веса классов (`weight` в `CrossEntropyLoss`, `pos_weight` в `BCEWithLogitsLoss`) или использовать focal loss, которая уменьшает вклад лёгких, уже хорошо классифицированных примеров.
