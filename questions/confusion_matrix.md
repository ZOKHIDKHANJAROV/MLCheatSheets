# Матрица ошибок — вопросы для самопроверки

### Что означают TP, FP, FN, TN?
TP — положительный объект предсказан положительным; FP — отрицательный ошибочно предсказан положительным (ложная тревога, ошибка I рода); FN — положительный пропущен (ошибка II рода); TN — отрицательный верно предсказан отрицательным.

### Как расположены ячейки в `sklearn.metrics.confusion_matrix` для бинарной задачи?
Строки — истинные классы, столбцы — предсказанные: `[[TN, FP], [FN, TP]]` при метках 0 и 1. Поэтому удобно `tn, fp, fn, tp = confusion_matrix(y, y_pred).ravel()`.

### Тест на болезнь нашёл 90 из 100 больных и дал 30 ложных тревог на 900 здоровых. Чему равны recall и precision?
TP = 90, FN = 10, FP = 30. Recall = 90 / 100 = 0.9; precision = 90 / (90 + 30) = 0.75.

### Что такое специфичность (specificity)?
TN / (TN + FP) — доля верно распознанных отрицательных объектов. Вместе с recall (чувствительностью) она часто используется в медицине.

### Зачем нормировать матрицу ошибок?
При дисбалансе классов абсолютные числа трудно сравнивать. Нормировка по строкам (`normalize='true'`) показывает, какая доля объектов каждого истинного класса куда попала, — сразу видно recall каждого класса.
