# Частичные зависимости — вопросы для самопроверки

### Что показывает график частичной зависимости (PDP)?
Как в среднем меняется прогноз модели при изменении одного (или двух) признаков, когда остальные признаки берутся из данных и усредняются.

### Как строится PDP?
Для каждого значения признака из сетки оно подставляется всем объектам выборки вместо настоящего, считаются прогнозы и усредняются. Получается одна кривая.

### Что такое ICE-кривые и что они показывают сверх PDP?
Individual Conditional Expectation — такие же кривые, но для каждого объекта отдельно, без усреднения. PDP — их среднее. Если ICE-кривые идут в разные стороны, значит, есть взаимодействия признаков, которые усреднение скрывает.

### Чем опасен PDP при коррелированных признаках?
Подстановка значений создаёт нереалистичные объекты (например, рост 2 м при весе 40 кг), и модель экстраполирует. ALE-графики (Accumulated Local Effects) решают эту проблему, используя только локальные изменения в реалистичных областях.

### Как построить PDP в scikit-learn?
`from sklearn.inspection import PartialDependenceDisplay` и `PartialDependenceDisplay.from_estimator(model, X, features=['age'])`; параметр `kind='both'` рисует и PDP, и ICE.
