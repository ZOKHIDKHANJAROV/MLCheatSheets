# State space models — вопросы для самопроверки

### Из каких двух уравнений состоит модель в пространстве состояний и что они описывают?
**Уравнение перехода** описывает эволюцию скрытого состояния: xₜ = F·xₜ₋₁ + wₜ, **уравнение наблюдения** — как наблюдение связано с состоянием: yₜ = H·xₜ + vₜ. Шумы wₜ и vₜ отвечают за неопределённость динамики и ошибки измерений.

### Почему ARIMA и экспоненциальное сглаживание можно записать как state space модели и что это даёт?
Любая линейная модель с конечной памятью представима через вектор состояния (например, уровень, тренд, сезонность в ETS). Это даёт единый аппарат: фильтр Калмана для вычисления правдоподобия, оценку параметров методом максимального правдоподобия, естественную обработку пропусков и интервалы прогноза.

### Как state space модели справляются с пропусками в данных?
На шаге с пропуском выполняется только предсказание состояния, а шаг коррекции по наблюдению пропускается. Неопределённость состояния при этом растёт, но ряд не нужно предварительно заполнять, и оценка остаётся корректной.

### Чем модель локального уровня (local level) отличается от простого среднего ряда?
В ней уровень — это случайное блуждание: μₜ = μₜ₋₁ + ηₜ, yₜ = μₜ + εₜ. Отношение дисперсий шумов σ²_η / σ²_ε определяет, насколько быстро уровень следует за данными; при σ²_η → 0 модель вырождается в константное среднее, а прогноз совпадает с простым экспоненциальным сглаживанием.

### Что будет, если неверно задать дисперсии шумов процесса и наблюдения?
При завышенном шуме наблюдения модель будет слишком «инертной» и запаздывать за изменениями, при завышенном шуме процесса — следовать за каждым выбросом. Поэтому дисперсии обычно оценивают по данным методом максимального правдоподобия, а не задают вручную.
