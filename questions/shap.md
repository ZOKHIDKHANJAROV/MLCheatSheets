# SHAP — вопросы для самопроверки

### На какой идее основаны значения SHAP?
На значениях Шепли из теории кооперативных игр: вклад признака — его средний маргинальный вклад в прогноз по всем возможным порядкам добавления признаков. Признаки — «игроки», прогноз — «выигрыш».

### Какое свойство аддитивности есть у SHAP?
Прогноз для объекта равен базовому значению (среднему прогнозу) плюс сумма SHAP-значений всех признаков: f(x) = E[f(X)] + Σφᵢ. Каждый прогноз раскладывается на вклады признаков без остатка.

### Чем отличаются локальные и глобальные объяснения SHAP?
Локальное — разложение прогноза одного объекта (waterfall и force plot). Глобальное — агрегирование по многим объектам: среднее |φᵢ| как важность (bar plot) и распределение вкладов (beeswarm).

### Почему TreeSHAP популярен для бустинга и лесов?
Точное вычисление значений Шепли экспоненциально по числу признаков. TreeSHAP использует структуру деревьев и считает точные значения за полиномиальное время — быстро даже для больших ансамблей.

### Какие ограничения у SHAP стоит помнить?
При коррелированных признаках результат зависит от того, как моделируется «отсутствие» признака, и может давать нереалистичные комбинации. KernelSHAP медленный. И, как любая важность, SHAP объясняет модель, а не причинность в данных.
