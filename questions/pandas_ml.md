# Pandas для ML — вопросы для самопроверки

### Чем отличаются `df.loc` и `df.iloc`?
`loc` выбирает по **меткам** индекса и названиям столбцов (срез `loc[a:b]` включает правую границу), `iloc` — по **целочисленным позициям** (правая граница не включается).

### Как найти и посчитать пропуски в DataFrame?
`df.isna().sum()` — число пропусков в каждом столбце, `df.isna().mean()` — их доля. Строки с пропусками: `df[df.isna().any(axis=1)]`.

### Что делает `groupby` и как посчитать средний чек по городам?
`groupby` разбивает таблицу на группы по значениям ключа, применяет к каждой агрегирующую функцию и собирает результат: `df.groupby('city')['amount'].mean()`. Несколько метрик сразу: `.agg(['mean', 'count'])`.

### Чем `merge` отличается от `concat`?
`merge` соединяет таблицы **по ключу** (как SQL JOIN: `inner`, `left`, `outer`). `concat` просто склеивает таблицы вдоль оси — друг под другом или рядом — без сопоставления по ключу.

### Почему предупреждение `SettingWithCopyWarning` стоит воспринимать всерьёз?
Присваивание вида `df[df.a > 0]['b'] = 1` может изменить временную копию, а не исходную таблицу, — и изменение молча потеряется. Правильно: `df.loc[df.a > 0, 'b'] = 1`.
