# Сериализация моделей — вопросы для самопроверки

### Чем опасна загрузка модели из pickle/joblib-файла из недоверенного источника?
При распаковке pickle может выполнить произвольный код. Загружать такие файлы можно только из доверенных источников; для обмена весами нейросетей безопаснее формат safetensors.

### Почему вместе с моделью нужно сохранять предобработку?
Новые данные должны проходить те же преобразования с теми же параметрами (средние скейлера, словарь кодировщика). Проще всего сериализовать весь sklearn `Pipeline` целиком.

### Почему модель, сохранённая через joblib, может не загрузиться после обновления библиотек?
Pickle хранит ссылки на классы и их внутреннюю структуру конкретной версии библиотеки. При смене версии sklearn или Python структура может измениться. Поэтому фиксируют версии окружения рядом с моделью.

### Чем в PyTorch сохранение `state_dict` лучше сохранения всей модели?
`torch.save(model.state_dict(), path)` хранит только тензоры весов; класс модели создаётся кодом, и веса загружаются в него. Сохранение объекта целиком через pickle жёстко привязано к структуре кода и путям модулей и ломается при рефакторинге.

### Зачем нужен ONNX?
Открытый формат представления моделей, независимый от фреймворка. Позволяет обучить модель в PyTorch или sklearn и запускать её в ONNX Runtime на другом языке или устройстве, часто с ускорением инференса.
