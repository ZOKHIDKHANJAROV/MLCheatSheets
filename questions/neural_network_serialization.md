# Сериализация нейросетей — вопросы для самопроверки

### Чем в PyTorch сохранение state_dict отличается от сохранения всей модели через torch.save(model)?
`state_dict` — это словарь тензоров весов; для загрузки нужен код класса модели, но формат устойчив к рефакторингу. Сохранение всей модели использует pickle и привязано к путям классов и модулей: при переименовании или переносе кода загрузка ломается.

### Почему загрузка pickle-файлов модели из непроверенных источников опасна?
Pickle при десериализации может выполнить произвольный код. Поэтому появился формат **safetensors**, хранящий только тензоры, а в новых версиях PyTorch `torch.load` по умолчанию использует `weights_only=True`.

### Что нужно сохранять в чекпоинте, чтобы продолжить обучение, а не только сделать инференс?
Кроме весов — состояние оптимизатора (моменты Adam), scheduler, номер эпохи/шага, состояние GradScaler при AMP и генераторов случайных чисел. Без состояния оптимизатора обучение продолжится с «холодного» старта и может скакнуть по лоссу.

### Зачем экспортировать модель в TorchScript, ONNX или SavedModel, если есть state_dict?
Эти форматы сохраняют **граф вычислений** вместе с весами, поэтому модель можно запустить без исходного Python-кода — в C++, на мобильных устройствах или в inference-серверах, с оптимизациями.

### Какая типичная ошибка возникает при загрузке state_dict после обучения через DataParallel?
Ключи получают префикс `module.`, и загрузка в обычную модель падает с ошибкой несовпадения ключей. Решение — сохранять `model.module.state_dict()` или удалить префикс из ключей перед загрузкой.
