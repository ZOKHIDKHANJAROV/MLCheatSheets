# Кодирование категориальных признаков — вопросы для самопроверки

### Чем One-Hot Encoding отличается от Label (Ordinal) Encoding?
One-Hot создаёт отдельный бинарный столбец для каждой категории. Label/Ordinal заменяет категории числами 0, 1, 2… в одном столбце.

### Почему Label Encoding опасен для линейных моделей на неупорядоченных категориях?
Модель воспримет числа как упорядоченные значения: «Москва=0 < Казань=1 < Омск=2», хотя порядка нет, и будет искать линейную зависимость от этого номера. Для деревьев это обычно не так страшно.

### В чём проблема One-Hot Encoding для признака с тысячами категорий?
Получается тысячи разреженных столбцов: растут память и время обучения, редкие категории почти не дают сигнала. Альтернативы — target encoding, frequency encoding, хэширование, эмбеддинги, группировка редких категорий.

### Что такое target encoding и чем он опасен?
Категория заменяется средним значением целевой переменной для этой категории. Без мер предосторожности это прямая утечка целевой переменной: нужно считать кодировку out-of-fold (по фолдам) и сглаживать для редких категорий.

### Что делать с категорией, которая появилась в тесте, но не встречалась в обучении?
Заранее предусмотреть обработку: в `OneHotEncoder(handle_unknown='ignore')` такой объект получит все нули; при других кодировках — отдельная категория «прочее» или глобальное среднее.
