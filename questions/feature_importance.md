# Важность признаков — вопросы для самопроверки

### Как вычисляется permutation importance?
Значения одного признака случайно перемешиваются на валидационной выборке, и измеряется падение качества модели. Чем сильнее падение, тем важнее признак. Метод подходит для любой модели.

### Чем опасна встроенная важность деревьев (по уменьшению impurity)?
Она считается на обучающих данных и завышает важность признаков с большим числом уникальных значений (ID, непрерывные признаки с шумом), даже если они бесполезны для обобщения.

### Как коррелированные признаки искажают важность?
При перемешивании одного из двух сильно коррелированных признаков модель берёт информацию из второго, и оба выглядят неважными. Во встроенной важности деревьев значимость произвольно делится между ними.

### Можно ли сравнивать коэффициенты линейной модели как важность признаков?
Только после масштабирования признаков к одной шкале, иначе величина коэффициента зависит от единиц измерения. И даже тогда мультиколлинеарность делает коэффициенты неустойчивыми.

### Означает ли высокая важность признака, что он причина целевой переменной?
Нет. Важность показывает, насколько модель опирается на признак для прогноза, а не причинно-следственную связь. Признак может быть следствием цели или коррелировать с настоящей причиной (а иногда — утечкой данных).
