# ROC и AUC — вопросы для самопроверки

### Что откладывается по осям ROC-кривой?
По оси X — FPR = FP / (FP + TN) (доля ложных срабатываний), по оси Y — TPR = TP / (TP + FN) (recall). Каждая точка соответствует одному порогу классификации.

### Как интерпретировать значение ROC-AUC?
Вероятность того, что случайно выбранный положительный объект получит более высокую оценку, чем случайно выбранный отрицательный. 0.5 — случайное угадывание, 1.0 — идеальное ранжирование.

### Почему ROC-AUC считают по вероятностям, а не по предсказанным классам?
ROC-кривая строится перебором порогов, для этого нужна непрерывная оценка (вероятность или score). По меткам 0/1 получится всего одна точка, и AUC будет некорректен.

### Почему при сильном дисбалансе классов лучше смотреть на PR-кривую?
FPR делится на огромное число отрицательных объектов, поэтому даже много ложных срабатываний почти не ухудшает ROC-AUC. PR-кривая (precision-recall) и PR-AUC честнее показывают качество на редком классе.

### Что означает ROC-AUC = 0.3?
Модель ранжирует хуже случайного — чаще всего перепутаны метки классов или знак оценки. Если инвертировать прогноз, получится AUC = 0.7.
