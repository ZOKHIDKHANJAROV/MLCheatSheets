# CNN для временных рядов (TCN) — вопросы для самопроверки

### Что такое каузальная свёртка?
Свёртка, в которой выход в момент t зависит только от входов в моменты ≤ t. Реализуется дополнением (padding) только слева. Так модель не «видит» будущее.

### Зачем в TCN дилатированные (dilated) свёртки?
Ядро применяется к элементам с пропусками (dilation 1, 2, 4, 8…). Рецептивное поле растёт экспоненциально с числом слоёв, и сеть охватывает длинную историю без огромного числа параметров.

### Как посчитать рецептивное поле TCN с ядром 3 и дилатациями 1, 2, 4, 8 (по одной свёртке на уровень)?
1 + (k − 1)·Σd = 1 + 2·(1 + 2 + 4 + 8) = 31 шаг.

### В чём преимущества TCN перед RNN?
Параллельные вычисления по всей последовательности (быстрее обучение), стабильные градиенты (residual-блоки, нет рекуррентности), гибко настраиваемая длина памяти через рецептивное поле.

### Какое ограничение у TCN по сравнению с RNN?
Память ограничена рецептивным полем: события старше него модель не видит. RNN в теории может хранить информацию сколько угодно долго (на практике — хуже). При инференсе TCN нужно хранить окно истории размером с рецептивное поле.
