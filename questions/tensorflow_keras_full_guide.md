# TensorFlow / Keras — вопросы для самопроверки

### Чем отличаются Sequential API, Functional API и наследование от `keras.Model`?
Sequential — простая цепочка слоёв. Functional — произвольный граф: несколько входов и выходов, ветвления, skip-связи. Наследование от `Model` с методом `call` — полная гибкость для нестандартной логики.

### Что делает `model.compile()`?
Задаёт оптимизатор, функцию потерь и метрики. Только после компиляции можно вызывать `fit`, `evaluate` и `predict` со стандартным циклом обучения.

### Что такое callbacks и какие самые полезные?
Объекты, которые вызываются в определённые моменты обучения. Самые полезные: `EarlyStopping` (с `restore_best_weights=True`), `ModelCheckpoint`, `ReduceLROnPlateau`, `TensorBoard`.

### Чем `sparse_categorical_crossentropy` отличается от `categorical_crossentropy`?
Sparse принимает метки как номера классов (0, 1, 2…), обычная — как one-hot векторы. Математически это одна и та же функция потерь.

### Зачем нужен `tf.data`?
Для эффективного конвейера загрузки данных: `map` для предобработки, `batch`, `shuffle`, `prefetch(tf.data.AUTOTUNE)`, чтобы подготовка следующего батча шла параллельно с обучением на текущем.
