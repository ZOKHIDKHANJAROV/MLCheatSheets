# CatBoost — вопросы для самопроверки

### Какая главная особенность CatBoost?
Встроенная качественная работа с категориальными признаками: они кодируются через упорядоченные целевые статистики (ordered target statistics) без утечки целевой переменной. Признаки достаточно указать в `cat_features`.

### Что такое ordered boosting и какую проблему он решает?
При обычном target encoding и бустинге значение для объекта вычисляется с использованием его же целевой переменной — возникает утечка и смещение прогноза. CatBoost использует случайную перестановку объектов и для каждого объекта учитывает только «предшествующие» ему.

### Что такое симметричные (oblivious) деревья?
Деревья, в которых на каждом уровне все узлы используют **одно и то же** разбиение. Такие деревья проще, меньше переобучаются и очень быстро применяются при прогнозе.

### Почему CatBoost часто хорошо работает «из коробки»?
Удачные параметры по умолчанию, встроенная обработка категорий и пропусков, устойчивость к переобучению за счёт ordered boosting и симметричных деревьев — поэтому требуется меньше ручного подбора.

### Какие параметры CatBoost настраивают в первую очередь?
`iterations` и `learning_rate` (с ранней остановкой через `eval_set`), `depth`, `l2_leaf_reg`; для категорий — `one_hot_max_size`.
