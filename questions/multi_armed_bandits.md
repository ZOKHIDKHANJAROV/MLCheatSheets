# Многорукие бандиты — вопросы для самопроверки

### Чем задача многорукого бандита отличается от полной задачи RL?
Нет состояний и последствий действий для будущего: на каждом шаге выбирается одна «рука» и сразу получается награда. Остаётся только дилемма exploration vs exploitation.

### Что такое regret?
Разница между суммарной наградой, которую дала бы всегда лучшая рука, и реально полученной. Хорошие алгоритмы обеспечивают регрет, растущий логарифмически по числу шагов.

### Как работает алгоритм UCB?
Выбирает руку с максимальной верхней границей доверия: среднее награды + c·√(ln t / nₐ). Редко пробованные руки получают бонус за неопределённость — это «оптимизм перед лицом неопределённости».

### Как работает Thompson Sampling?
Для каждой руки поддерживается апостериорное распределение её средней награды (например, Beta для бинарных наград). На каждом шаге из каждого распределения сэмплируется значение и выбирается рука с максимальным сэмплом.

### Что такое контекстные бандиты и где их применяют?
Перед выбором руки наблюдается контекст (признаки пользователя, времени, страницы), и лучшая рука зависит от него. Применяют в персонализированных рекомендациях, рекламе и выборе вариантов интерфейса (LinUCB и подобные).
