# Статистические тесты (t-test, McNemar) — вопросы для самопроверки

### Почему для сравнения двух моделей по фолдам используют парный, а не независимый t-тест?
Обе модели оцениваются на одних и тех же фолдах, и сложность фолда влияет на обе одинаково. Парный тест анализирует разности по фолдам, убирая эту общую вариацию, и поэтому намного чувствительнее.

### Какое допущение t-теста нарушается при k-fold кросс-валидации и чем это грозит?
Допущение независимости наблюдений: обучающие выборки фолдов перекрываются, и результаты коррелированы. Дисперсия недооценивается, p-value получаются заниженными, и тест слишком часто находит несуществующие различия. Решения — поправка Надо–Бенджио или тест 5×2cv.

### Какие числа использует тест Макнемара?
Только объекты, на которых модели расходятся: b — первая права, вторая ошибается; c — наоборот. Статистика χ² = (|b − c| − 1)² / (b + c) с поправкой на непрерывность, 1 степень свободы; при малых b + c используют точный биномиальный тест.

### Модели расходятся на 30 объектах: b = 20, c = 10. Значима ли разница по Макнемару при α = 0.05?
χ² = (|20 − 10| − 1)² / 30 = 81 / 30 = 2.7, что меньше критического значения 3.84 для одной степени свободы. Разница не значима, хотя первая модель вдвое чаще оказывается права в спорных случаях.

### Почему тест Макнемара не учитывает объекты, где обе модели правы или обе ошибаются?
Такие объекты не несут информации о различии моделей: на них модели ведут себя одинаково. Нулевая гипотеза формулируется как равенство вероятностей двух типов расхождений, то есть b и c должны быть примерно равны.
