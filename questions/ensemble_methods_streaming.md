# Ensemble methods для streaming — вопросы для самопроверки

### Как online bagging имитирует bootstrap без хранения данных?
В bootstrap число копий примера в выборке при большом n приближённо распределено по Poisson(1). Online bagging (Oza и Russell) для каждой модели и каждого примера сэмплирует k ~ Poisson(1) и обучает модель на примере k раз (или с весом k).

### Чем Leveraging Bagging отличается от обычного online bagging?
Использует Poisson(λ) с λ > 1 (обычно 6), что увеличивает разнообразие моделей и вес примеров, а также добавляет детектор дрейфа ADWIN для замены худших моделей.

### Как Adaptive Random Forest реагирует на concept drift?
Для каждого дерева работают детекторы: при «предупреждении» начинает обучаться фоновое дерево, при подтверждённом дрейфе оно заменяет старое. Разнообразие обеспечивают случайные подмножества признаков в узлах и Poisson-перевзвешивание примеров.

### Почему ансамбли особенно полезны в потоковых данных с дрейфом?
Модели разного «возраста» помнят разные периоды, и можно быстро переключать веса или заменять отдельные модели, не перестраивая весь ансамбль. Это сглаживает переходы и даёт устойчивость к шуму.

### Как в ансамблях для потоков обычно взвешивают модели?
По недавней точности: например, Dynamic Weighted Majority уменьшает вес модели при ошибке (умножением на β < 1), удаляет модели с малым весом и добавляет новые при ошибке всего ансамбля. Так старые неактуальные модели быстро теряют влияние.
