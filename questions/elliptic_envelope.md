# Elliptic Envelope — вопросы для самопроверки

### Какое предположение о данных делает Elliptic Envelope?
Что нормальные данные распределены приблизительно по **многомерному гауссовскому** закону. Модель оценивает центр и ковариационную матрицу и считает аномальными точки с большим расстоянием Махаланобиса — граница нормы имеет форму эллипсоида.

### Почему используется робастная оценка ковариации (MCD), а не обычная?
Выбросы сильно искажают выборочные среднее и ковариацию, «растягивая» эллипс в свою сторону, и сами перестают выделяться (маскировка). **Minimum Covariance Determinant** оценивает параметры по подмножеству точек с минимальным определителем ковариации, игнорируя выбросы.

### Чем расстояние Махаланобиса лучше евклидова для поиска аномалий?
Оно учитывает масштаб признаков и корреляции между ними: d² = (x − μ)ᵀΣ⁻¹(x − μ). Точка может быть близка к центру по евклидову расстоянию, но лежать поперёк направления корреляции — Махаланобис покажет её как выброс.

### Когда Elliptic Envelope работает плохо?
При многомодальных данных (несколько кластеров), сильно скошенных или нелинейно связанных признаках — один эллипс не описывает такую форму. Также при высокой размерности (особенно когда признаков сравнимо с объектами) оценка ковариации становится неустойчивой.

### Как можно задать порог аномальности статистически?
Для гауссовских данных квадрат расстояния Махаланобиса распределён по **χ²** с p степенями свободы (p — число признаков). Например, точки с d² выше 97.5-го перцентиля χ²(p) можно считать выбросами; в sklearn порог задаётся через `contamination`.
