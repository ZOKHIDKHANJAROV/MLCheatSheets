# Алгоритмы на графах (кластеризация, поиск путей) — вопросы для самопроверки

### Почему Dijkstra не работает с отрицательными весами рёбер?
Dijkstra окончательно фиксирует вершину, как только достаёт её из очереди, считая, что более короткий путь не появится. Отрицательное ребро может позже уменьшить расстояние до уже зафиксированной вершины. В таких случаях используют Bellman-Ford, который ещё и обнаруживает отрицательные циклы.

### Когда для кратчайшего пути достаточно BFS?
Когда граф невзвешенный (или все веса равны): BFS обходит вершины слоями по числу рёбер и за O(V + E) находит путь с минимальным числом рёбер.

### Чем A* отличается от Dijkstra и что требуется от эвристики?
A* выбирает вершину по g(n) + h(n), где h — оценка оставшегося расстояния, поэтому идёт в сторону цели и раскрывает меньше вершин. Для оптимальности h должна быть **допустимой** — никогда не переоценивать реальное расстояние (например, евклидово расстояние на карте).

### Когда выбрать Floyd-Warshall, а когда — запуск Dijkstra из каждой вершины?
Floyd-Warshall находит кратчайшие пути для всех пар за O(V³) и прост — хорош для небольших плотных графов. Для больших разреженных графов с неотрицательными весами запуск Dijkstra из каждой вершины, O(V·(V + E)·log V), обычно быстрее.

### Как спектральная кластеризация использует граф?
Строят граф сходства, вычисляют лапласиан L = D − A и берут собственные векторы при наименьших собственных значениях; в этом пространстве точки кластеризуют k-means. Метод находит невыпуклые кластеры, которые обычный k-means в исходном пространстве не разделит.
