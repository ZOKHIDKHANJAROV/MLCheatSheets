# OPTICS — вопросы для самопроверки

### Какую проблему DBSCAN решает OPTICS?
DBSCAN использует один порог плотности ε и плохо находит кластеры разной плотности. OPTICS не фиксирует ε, а строит упорядочение точек, из которого можно извлечь кластеры для разных уровней плотности.

### Что такое core distance и reachability distance?
Core distance точки p — расстояние до её `min_samples`-го ближайшего соседа (наименьший радиус, при котором p — core-точка). Reachability distance точки o от p — max(core_dist(p), d(p, o)), то есть не меньше «плотностного радиуса» p.

### Как читать reachability plot?
По оси X — точки в порядке обхода OPTICS, по оси Y — их reachability distance. Кластеры выглядят как «долины» (низкая достижимость), границы между ними — как пики. Чем глубже долина, тем плотнее кластер.

### Как из OPTICS получить конкретные кластеры?
Либо горизонтальным «срезом» reachability plot на уровне ε — это даёт результат, близкий к DBSCAN с этим ε (`cluster_method='dbscan'` в sklearn), либо методом ξ (`cluster_method='xi'`), который выделяет долины по относительной крутизне спадов и подъёмов и находит кластеры разной плотности.

### Чем OPTICS уступает DBSCAN на практике?
Он обычно медленнее и требует настройки параметра извлечения (`xi` или порога среза), а интерпретация reachability plot требует опыта. Если плотность кластеров примерно одинакова, DBSCAN проще и быстрее.
