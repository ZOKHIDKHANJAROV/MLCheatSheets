# ❓ Вопросы для самопроверки

Вопросы к шпаргалкам, которые показываются в учебном портале (`python start.py`): кнопка **❓ Вопросы** при просмотре темы и режим **🔁 Повторение**.

## Формат

Один файл на тему: `questions/<тема>.md`, где `<тема>` — имя шпаргалки без `_cheatsheet.html`
(для `cheatsheets/linreg_cheatsheet.html` — `questions/linreg.md`).

```markdown
# Линейная регрессия — вопросы для самопроверки

### Текст вопроса?
Ответ: обычный markdown — **жирный**, `код`, списки.

### Следующий вопрос?
Ответ…
```

- Каждый заголовок `### ` — это вопрос, весь текст под ним до следующего `### ` — ответ.
- Заголовок `#` в начале файла — для удобства чтения, портал его не показывает.
- Хорошо работают 4–6 вопросов на тему: на понимание («почему?», «что будет, если…?»), а не на заучивание определений.

После добавления или изменения вопросов пересоберите портал: `python tools/build_portal.py`
(`python start.py` делает это автоматически).

## Как работает повторение

Когда вы отмечаете тему как изученную, портал планирует её повторение через 1, 3, 7, 16, 35 и 90 дней.
В режиме повторения ответьте на вопросы и нажмите **Помню** (интервал увеличится) или **Забыл** (тема вернётся через день).
