# Глоссарий ML

Краткие определения ключевых терминов машинного обучения — от математики и классических алгоритмов до трансформеров, генеративных моделей и MLOps. Стрелка → указывает шпаргалки, где тема разобрана подробнее.

## A

### A/B testing (A/B-тестирование)
Контролируемый эксперимент: пользователи случайно делятся на группы со старой (A) и новой (B) моделью, а разница в бизнес-метриках проверяется статистическим тестом. Требует заранее рассчитанного размера выборки и одной основной метрики.
→ model_monitoring_ab_testing, hypothesis_testing

### Accuracy (доля правильных ответов)
Доля верно классифицированных объектов: (TP + TN) / (TP + TN + FP + FN). При сильном дисбалансе классов вводит в заблуждение: константный классификатор может иметь accuracy 99 %.
→ classification_metrics, confusion_matrix

### Activation function (функция активации)
Нелинейная функция, применяемая к выходу нейрона. Без неё композиция слоёв остаётся линейным преобразованием.
→ activation_functions

### Active learning (активное обучение)
Стратегия, в которой модель сама выбирает объекты для разметки экспертом — например, с наибольшей неопределённостью. Снижает стоимость разметки при той же точности.
→ active_learning

### Actor-critic (актор–критик)
Метод RL, в котором актор (политика) обновляется по градиенту политики, а критик (функция ценности) оценивает действия, снижая дисперсию; часто используется функция преимущества A(s, a) = Q(s, a) − V(s).
→ actor_critic

### AdaBoost (адаптивный бустинг)
Алгоритм бустинга, который после каждой итерации увеличивает веса неверно классифицированных объектов, а итоговое предсказание — взвешенное голосование слабых моделей. Чувствителен к выбросам и шуму в метках.
→ adaboost

### Adam (адаптивная оценка моментов)
Оптимизатор, сочетающий моменты первого (как Momentum) и второго (как RMSprop) порядка с коррекцией смещения. Стандартный выбор для нейросетей; типичные β₁ = 0,9, β₂ = 0,999.
→ optimizers

### AdamW (Adam с раздельным затуханием весов)
Вариант Adam, где weight decay применяется к весам напрямую, а не через градиент L2-штрафа. Это даёт корректную регуляризацию при адаптивных шагах; стандарт для трансформеров.
→ optimizers_advanced, optimizers

### Adversarial example (состязательный пример)
Вход с малым, часто незаметным для человека возмущением, специально подобранным так, чтобы модель ошиблась.
→ adversarial_attacks, adversarial_attacks_deep_learning

### Adversarial training (состязательное обучение)
Обучение на смеси обычных и состязательных примеров, сгенерированных на лету (часто PGD). Основной эмпирический способ повышения робастности.
→ adversarial_training, adversarial_robustness

### Agent memory (память агента)
Механизмы, позволяющие агенту помнить прошлое: кратковременная память (контекстное окно) и долговременная (внешнее хранилище, часто векторное). Включает суммаризацию истории, выбор того, что записывать, и политику забывания.
→ agent_memory

### AI agent (ИИ-агент)
Система, где языковая модель в цикле сама выбирает следующий шаг: рассуждает, вызывает инструменты, получает наблюдения и повторяет, пока не решит задачу или не упрётся в лимит шагов. Отличается от обычного чат-бота автономностью и доступом к действиям во внешнем мире.
→ ai_agents_basics, react_agents

### Algorithmic fairness (алгоритмическая справедливость)
Область, изучающая и устраняющая систематическую дискриминацию моделей по защищённым признакам (пол, раса, возраст). Методы делятся на пред-, внутри- и постобработку; разные критерии справедливости в общем случае несовместимы.
→ fairness_ml, fairness_constraints

### Anomaly detection (обнаружение аномалий)
Поиск объектов, существенно отличающихся от основной массы данных. Подходы: статистические, на расстояниях и плотности (LOF), изолирующие (Isolation Forest), одноклассовые модели и автоэнкодеры.
→ statistical_anomaly_detection, isolation_forest, time_series_anomalies

### ANOVA (дисперсионный анализ)
Метод проверки равенства средних в трёх и более группах через сравнение межгрупповой и внутригрупповой дисперсии (F-статистика). Также используется для отбора признаков (F-test).
→ anova

### Approximate nearest neighbors, ANN (приближённый поиск ближайших соседей)
Поиск почти ближайших векторов за сублинейное время ценой небольшой потери полноты (recall). Типичные индексы: IVF, HNSW, квантизация произведением (PQ).
→ vector_search

### ARIMA (авторегрессионная интегрированная модель скользящего среднего)
Модель временного ряда ARIMA(p, d, q): авторегрессия порядка p, дифференцирование d раз, скользящее среднее ошибок порядка q. SARIMA добавляет сезонные компоненты.
→ box_jenkins

### Attention mechanism (механизм внимания)
Способ вычислять выход как взвешенную сумму значений, где веса зависят от сходства запроса с ключами. Позволяет модели динамически выбирать релевантные части входа.
→ attention_mechanism, vision_attention_mechanisms

### AUC-ROC (площадь под ROC-кривой)
Площадь под ROC-кривой, равная вероятности того, что случайный положительный объект получит более высокую оценку, чем случайный отрицательный. Не зависит от порога, но при сильном дисбалансе может быть излишне оптимистичной.
→ roc_auc, classification_metrics

### Autocorrelation function (автокорреляционная функция, ACF)
Корреляция ряда с самим собой со сдвигом k как функция лага. Вместе с частной автокорреляцией (PACF) используется для выбора порядков ARIMA и обнаружения сезонности.
→ box_jenkins, time_series

### Autoencoder (автоэнкодер)
Нейросеть из энкодера, сжимающего вход в низкоразмерный код, и декодера, восстанавливающего вход по коду; обучается минимизировать ошибку реконструкции. Применяется для снижения размерности, шумоподавления и поиска аномалий.
→ autoencoders, linear_autoencoders

### Automatic differentiation (автоматическое дифференцирование)
Вычисление точных производных программы по её вычислительному графу путём применения цепного правила к элементарным операциям. Обратный режим (reverse mode) даёт градиент по всем параметрам за один обратный проход — так работают PyTorch, JAX, TensorFlow.
→ differentiable_programming, jax_flax, backpropagation

### AutoML (автоматическое машинное обучение)
Автоматизация выбора препроцессинга, модели, гиперпараметров и ансамблирования под заданный бюджет вычислений.
→ automl, automl_neural_networks

## B

### Backpropagation (обратное распространение ошибки)
Алгоритм вычисления градиентов функции потерь по всем весам сети: ошибка распространяется от выхода к входу по цепному правилу. Стоимость сравнима с прямым проходом.
→ backpropagation

### Backpropagation through time (обратное распространение во времени, BPTT)
Применение backpropagation к RNN, развёрнутой по шагам времени. Усечённый вариант (TBPTT) ограничивает число шагов обратного прохода.
→ rnn_basics

### Bagging (бэггинг)
Bootstrap aggregating: обучение моделей на бутстреп-выборках и усреднение их предсказаний. Уменьшает дисперсию, эффективен для нестабильных моделей вроде глубоких деревьев.
→ bagging

### Batch normalization (пакетная нормализация)
Нормализация активаций по статистикам мини-батча с обучаемыми масштабом γ и сдвигом β. Ускоряет и стабилизирует обучение; на инференсе использует накопленные скользящие средние, плохо работает с маленькими батчами.
→ batch_normalization

### Bayes' theorem (теорема Байеса)
Формула пересчёта вероятности гипотезы по данным: P(θ | D) = P(D | θ) · P(θ) / P(D). Связывает априорное распределение, правдоподобие и апостериорное распределение.
→ bayesian_approach, naive_bayes, bayesian_inference

### Bayesian neural network (байесовская нейросеть)
Нейросеть с распределениями вместо точечных весов; предсказание усредняется по апостериорному распределению, что даёт оценку неопределённости. На практике аппроксимируется вариационным выводом или MC Dropout.
→ bayesian_neural_networks

### Bayesian optimization (байесовская оптимизация)
Оптимизация дорогой функции «чёрного ящика» с помощью суррогатной модели (гауссовский процесс, TPE) и функции приобретения (EI, UCB), выбирающей следующую точку для вычисления. Стандарт для подбора гиперпараметров.
→ bayesian_optimization, bayesian_hyperparameter_optimization, optuna_hyperopt

### Beam search (лучевой поиск)
Алгоритм декодирования, сохраняющий на каждом шаге k наиболее вероятных частичных последовательностей. Находит более вероятные последовательности, чем жадное декодирование, но не гарантирует оптимум.
→ encoder_decoder, gpt_architectures

### Bellman equation (уравнение Беллмана)
Рекуррентное соотношение для функции ценности: V(s) = E[r + γ V(s′)]; уравнение оптимальности Q*(s, a) = E[r + γ maxₐ′ Q*(s′, a′)]. Основа динамического программирования и TD-методов.
→ dynamic_programming_rl, markov_decision_processes

### BERT (двунаправленный энкодер-трансформер)
Bidirectional Encoder Representations from Transformers — энкодерная модель, предобученная на маскированном языковом моделировании. Дообучается под классификацию, NER, вопросно-ответные задачи.
→ bert_language_models, bert_finetuning

### Bias-variance tradeoff (компромисс смещения и дисперсии)
Разложение ожидаемой ошибки на квадрат смещения, дисперсию и неустранимый шум. Простые модели имеют высокое смещение (недообучение), сложные — высокую дисперсию (переобучение).
→ bias_variance, bias_variance_decomposition

### Bidirectional RNN (двунаправленная RNN)
Две RNN, обрабатывающие последовательность в прямом и обратном направлении, чьи состояния объединяются. Применима, когда вся последовательность известна заранее (разметка текста), но не для генерации.
→ bidirectional_rnn

### Binning (дискретизация)
Разбиение непрерывного признака на интервалы (равной ширины, по квантилям, по дереву). Помогает линейным моделям улавливать нелинейность и снижает влияние выбросов.
→ binning_discretization

### Boosting (бустинг)
Последовательное построение слабых моделей, каждая из которых исправляет ошибки предыдущих. Уменьшает в первую очередь смещение.
→ boosting

### Bootstrap (бутстреп)
Метод оценки распределения статистики путём многократного формирования выборок с возвращением из исходных данных. Даёт доверительные интервалы для метрик и лежит в основе бэггинга.
→ bootstrap_methods, bagging

### Byte pair encoding (кодирование парами байтов, BPE)
Алгоритм субсловной токенизации: начиная с символов, итеративно сливает самую частую пару соседних единиц в новый токен, пока не наберётся словарь нужного размера. Используется в GPT.
→ tokenization

## C

### Canary deployment (канареечное развёртывание)
Постепенный выкат новой версии модели на небольшую долю трафика с мониторингом и последующим расширением или откатом.
→ model_deployment, cicd_ml

### Canonical correlation analysis (канонический корреляционный анализ, CCA)
Поиск линейных проекций двух наборов переменных, максимально коррелирующих друг с другом. Kernel CCA и Deep CCA — нелинейные обобщения.
→ canonical_correlation_analysis, kernel_cca

### CatBoost (библиотека CatBoost)
Реализация градиентного бустинга от Яндекса с симметричными деревьями, упорядоченным бустингом и встроенной обработкой категориальных признаков через упорядоченное target-кодирование.
→ catboost

### Causal mask (каузальная маска)
Маска внимания, запрещающая токену смотреть на последующие позиции. Нужна для авторегрессионной генерации в декодерах (GPT).
→ gpt_architectures, self_attention

### Central limit theorem (центральная предельная теорема)
Утверждение, что нормированная сумма большого числа независимых одинаково распределённых величин с конечной дисперсией сходится к нормальному распределению. Обосновывает доверительные интервалы и многие статистические тесты.
→ probability_theory, statistical_methods

### Chain rule (цепное правило)
Правило дифференцирования сложной функции: d f(g(x))/dx = f′(g(x)) · g′(x). Математическая основа обратного распространения ошибки.
→ backpropagation

### Chain-of-thought (цепочка рассуждений)
Приём, при котором модель выписывает промежуточные шаги рассуждения перед ответом. Повышает качество на арифметических и логических задачах.
→ prompt_engineering

### Chi-squared test (критерий хи-квадрат)
Непараметрический тест для категориальных данных: сравнивает наблюдаемые частоты с ожидаемыми, χ² = Σ (O − E)² / E. Применяется для проверки независимости признака и целевой переменной.
→ statistical_tests, feature_selection

### Chunking (чанкинг)
Разбиение документов на фрагменты (чанки) для индексации в RAG. Размер и перекрытие (overlap) чанков влияют на полноту поиска и на то, насколько связным получится контекст для модели.
→ rag

### Class imbalance (дисбаланс классов)
Ситуация, когда один класс встречается намного реже других (мошенничество, болезни). Требует подходящих метрик (PR-AUC, F1, MCC), перевзвешивания, ресэмплинга или настройки порога.
→ imbalanced_data, imbalanced_algorithms, imbalanced_metrics

### Classifier-free guidance (управление без классификатора)
Приём условной диффузии: модель обучается с условием и без него, а при генерации предсказания экстраполируются в сторону условного с коэффициентом w. Усиливает соответствие промпту ценой разнообразия.
→ diffusion_models, text_to_image_generation

### CLIP (контрастивное предобучение текста и изображений)
Contrastive Language-Image Pre-training — пара энкодеров изображения и текста, обученных контрастивно на парах «картинка — подпись». Даёт общее пространство эмбеддингов и zero-shot классификацию.
→ clip_multimodal_models

### Clustering (кластеризация)
Разбиение объектов на группы так, чтобы объекты внутри группы были похожи, а между группами — различались. Результат зависит от выбранной меры сходства и алгоритма.
→ kmeans, clustering_metrics, cluster_visualization

### Co-training (совместное обучение)
Метод частичного обучения с двумя моделями на разных, условно независимых представлениях (видах) данных, которые размечают неразмеченные объекты друг для друга.
→ cotraining, multi_view_learning

### Cold start (проблема холодного старта)
Невозможность качественных коллаборативных рекомендаций для новых пользователей или объектов без истории взаимодействий. Решается контентными признаками, гибридными моделями, популярными объектами.
→ hybrid_recommender_systems, content_based_filtering

### Collaborative filtering (коллаборативная фильтрация)
Рекомендации на основе поведения похожих пользователей или похожих товаров по матрице взаимодействий, без использования содержимого объектов.
→ collaborative_filtering, collaborative_filtering_user_item_based

### Computational graph (вычислительный граф)
Ориентированный ациклический граф, узлы которого — операции, а рёбра — тензоры. Фреймворки строят его при прямом проходе и обходят в обратном порядке для вычисления градиентов.
→ backpropagation, differentiable_programming

### Concept drift (дрейф концепции)
Изменение со временем зависимости P(y | x) между признаками и целевой переменной, из-за которого модель устаревает. Бывает внезапным, постепенным, повторяющимся; обнаруживается мониторингом качества и детекторами (ADWIN, DDM).
→ concept_drift, adaptive_windowing

### Conditional GAN (условная GAN)
GAN, в которой генератор и дискриминатор получают дополнительное условие (метку класса, текст, изображение), что позволяет управлять генерацией.
→ dcgan_conditional_gan, image_to_image_translation

### Conditional probability (условная вероятность)
Вероятность события A при условии, что произошло B: P(A | B) = P(A ∩ B) / P(B). Классификаторы оценивают условную вероятность класса при данных признаках.
→ probability_theory, bayesian_approach

### Conditional random field (условное случайное поле, CRF)
Дискриминативная графовая модель P(y | x) для разметки последовательностей, учитывающая зависимости между соседними метками. Часто используется как выходной слой над BiLSTM или BERT в NER.
→ crf_conditional_random_fields

### Confidence interval (доверительный интервал)
Интервал, построенный по выборке так, что при многократном повторении эксперимента он накрывает истинный параметр с заданной частотой (например, 95 %). Для метрик моделей часто строится бутстрепом.
→ statistical_methods, bootstrap_methods

### Confusion matrix (матрица ошибок)
Таблица, сопоставляющая истинные и предсказанные классы; для бинарной задачи содержит TP, FP, FN, TN. Из неё вычисляется большинство метрик классификации.
→ confusion_matrix

### Content-based filtering (контентная фильтрация)
Рекомендации объектов, похожих по признакам (тексту, жанру, атрибутам) на те, что пользователь уже оценил положительно.
→ content_based_filtering

### Context window (контекстное окно)
Максимальное число токенов, которое модель обрабатывает за один проход. Всё за его пределами модель не видит.
→ efficient_transformers, gpt_architectures

### Contrastive learning (контрастивное обучение)
Обучение представлений, сближающее эмбеддинги положительных пар (разных аугментаций одного объекта, картинки и подписи) и отдаляющее отрицательные (функция потерь InfoNCE). Примеры — SimCLR, CLIP.
→ contrastive_learning, clip_multimodal_models

### Convex function (выпуклая функция)
Функция, для которой отрезок между любыми двумя точками графика лежит не ниже графика: f(λx + (1−λ)y) ≤ λf(x) + (1−λ)f(y). У выпуклой задачи любой локальный минимум глобален (линейная и логистическая регрессия, SVM), у нейросетей потери невыпуклы.
→ linear_algebra_optimization, constrained_optimization_ml

### Convolution (свёртка)
Операция скольжения небольшого обучаемого ядра по входу с вычислением скалярного произведения в каждой позиции. Размер выхода задают размер ядра, шаг (stride) и дополнение краёв (padding); свёртка обеспечивает локальность, разделение весов и эквивариантность к сдвигу.
→ cnn_basics

### Convolutional neural network (свёрточная нейросеть, CNN)
Нейросеть из свёрточных слоёв, слоёв пулинга и (обычно) полносвязной головы. Стандарт для изображений; одномерные свёртки применяются к сигналам и последовательностям.
→ cnn_basics, cnn_architectures, 1d_3d_cnn

### Correlation coefficient (коэффициент корреляции)
Нормированная ковариация: ρ = Cov(X, Y) / (σ_X σ_Y), лежит в [−1, 1]. Коэффициент Пирсона ловит только линейную связь, Спирмена — монотонную; корреляция не означает причинность.
→ statistical_methods, probability_theory

### Cosine similarity (косинусное сходство)
cos(a, b) = a · b / (‖a‖ ‖b‖), значения в [−1, 1]. Стандартная мера сходства эмбеддингов, не зависящая от их длины.
→ word_embeddings, metric_learning

### Cost-sensitive learning (обучение с учётом стоимости ошибок)
Обучение, в котором ошибки разных типов имеют разную цену: через веса классов в функции потерь, матрицу стоимостей или сдвиг порога.
→ cost_sensitive_learning, imbalanced_algorithms

### Covariance (ковариация)
Мера совместной изменчивости двух величин: Cov(X, Y) = E[(X − E[X])(Y − E[Y])]. Ковариационная матрица признаков — основа PCA и многомерного нормального распределения.
→ probability_theory, pca

### Cross-entropy (кросс-энтропия)
H(p, q) = −Σ p(x) log q(x) — среднее число бит для кодирования данных из p кодом, оптимальным для q. Как функция потерь сравнивает истинные метки p с предсказанными вероятностями q; стандарт для классификации.
→ loss_functions, information_theory_ml

### Cross-validation (кросс-валидация)
Оценка обобщающей способности многократным разбиением данных на обучающую и проверочную части с усреднением метрики. Даёт более надёжную оценку, чем одно разбиение.
→ cross_validation

### Curse of dimensionality (проклятие размерности)
Совокупность эффектов высокой размерности: объём пространства растёт экспоненциально, данные становятся разреженными, расстояния между точками выравниваются. Особенно вредит kNN и методам на основе плотности.
→ dimensionality_reduction, knn

### Cyclical encoding (циклическое кодирование)
Представление периодических признаков (час, день недели, месяц) парой sin(2πx / T) и cos(2πx / T), чтобы соседние значения на границе цикла (23 ч и 0 ч) оставались близкими.
→ date_time_features

## D

### Data augmentation (аугментация данных)
Расширение обучающей выборки преобразованиями, сохраняющими метку: повороты и обрезка изображений, шум и сдвиг аудио, перефразирование текстов. Работает как регуляризация.
→ data_augmentation

### Data drift (дрейф данных)
Изменение распределения входных признаков P(x) в продакшене относительно обучающих данных. Обнаруживается статистическими тестами (KS), PSI, расстояниями между распределениями.
→ model_monitoring, concept_drift

### Data leakage (утечка данных)
Попадание в обучение информации, недоступной в момент реального предсказания: признаки из будущего, статистики, посчитанные на всём датасете до разбиения, дубликаты между train и test. Даёт завышенные метрики, которые не воспроизводятся в продакшене.
→ cross_validation, preprocessing, target_encoding

### DBSCAN (кластеризация на основе плотности)
Алгоритм, объединяющий в кластеры области высокой плотности: точка ядровая, если в радиусе eps у неё не меньше min_samples соседей. Находит кластеры произвольной формы и помечает шум, но плохо работает при разной плотности.
→ dbscan

### Decision theory (теория принятия решений)
Раздел, формализующий выбор действия при неопределённости через функцию потерь и минимизацию ожидаемого риска. Байесовское решающее правило выбирает действие с минимальным апостериорным ожидаемым риском, например оптимальный порог классификации при разной стоимости ошибок.
→ decision_theory, cost_sensitive_learning

### Decision threshold (порог классификации)
Значение, с которым сравнивается предсказанная вероятность для присвоения класса. Порог 0,5 не всегда оптимален: его подбирают под нужный баланс точности и полноты или стоимость ошибок.
→ classification_metrics, cost_sensitive_learning

### Decision tree (дерево решений)
Модель, разбивающая пространство признаков последовательностью пороговых условий; листья содержат предсказание. Интерпретируемо, не требует масштабирования, но склонно к переобучению.
→ decision_trees, decision_trees_regression

### Deep Q-network (глубокая Q-сеть, DQN)
Q-learning с нейросетевой аппроксимацией Q-функции, стабилизированный буфером воспроизведения опыта (experience replay) и отдельной целевой сетью с редко обновляемыми весами.
→ dqn

### Demographic parity (демографический паритет)
Критерий справедливости: доля положительных предсказаний одинакова во всех группах, P(ŷ = 1 | A = a) = P(ŷ = 1 | A = b). Не учитывает истинные метки.
→ fairness_ml, fairness_constraints

### Depthwise separable convolution (глубинно-разделимая свёртка)
Разложение свёртки на поканальную (depthwise) пространственную свёртку и поточечную свёртку 1 × 1. Многократно сокращает параметры и вычисления; используется в MobileNet и EfficientNet.
→ inception_efficientnet, cnn_architectures

### Differential privacy (дифференциальная приватность)
Формальная гарантия, что результат алгоритма почти не меняется от добавления или удаления одной записи; уровень задаётся параметром ε. В обучении реализуется через DP-SGD — обрезку градиентов по объектам и добавление шума.
→ differential_privacy

### Diffusion model (диффузионная модель)
Генеративная модель, обученная обращать процесс постепенного зашумления данных: сеть (часто U-Net или трансформер) предсказывает добавленный шум, а генерация идёт итеративным расшумлением из чистого шума. Стабильно обучается и даёт высокое качество, но сэмплирование требует многих шагов. Латентная диффузия (Stable Diffusion) работает в сжатом пространстве автоэнкодера, а не в пикселях.
→ diffusion_models

### Dilated convolution (расширенная свёртка)
Свёртка с пропусками между элементами ядра (коэффициент dilation). Экспоненциально расширяет рецептивное поле без роста числа параметров; основа TCN и WaveNet.
→ tcn, cnn_time_series_tcn

### Dimensionality reduction (снижение размерности)
Преобразование данных в пространство меньшей размерности с сохранением существенной структуры. Линейные методы — PCA, SVD; нелинейные — t-SNE, UMAP, Isomap, автоэнкодеры.
→ dimensionality_reduction

### Distributed training (распределённое обучение)
Обучение на нескольких устройствах: параллелизм по данным (копии модели на разных батчах с усреднением градиентов), по модели или тензорам и конвейерный параллелизм.
→ distributed_training

### Domain adaptation (адаптация к домену)
Перенос модели из исходного домена с разметкой в целевой домен с другим распределением данных, где разметки мало или нет (например, синтетика → реальные изображения).
→ domain_adaptation

### DPO (прямая оптимизация предпочтений)
Direct Preference Optimization — альтернатива RLHF, оптимизирующая языковую модель напрямую на парах «предпочтительный — отвергнутый ответ» классификационной функцией потерь, без отдельной модели вознаграждения и RL.

### Dropout (дропаут)
Регуляризация, при которой на обучении случайно обнуляется доля p нейронов (оставшиеся масштабируются на 1 / (1 − p)), а на инференсе используются все нейроны. Препятствует коадаптации нейронов.
→ dropout_regularization

## E

### Early stopping (ранняя остановка)
Прекращение обучения, когда метрика на валидации перестаёт улучшаться заданное число эпох (patience), с возвратом к лучшим весам.
→ early_stopping

### Efficient attention (эффективное внимание)
Методы снижения квадратичной стоимости внимания: разреженные и локальные паттерны (Longformer), низкоранговые и ядерные аппроксимации (Linformer, Performer), IO-оптимизированные вычисления (FlashAttention).
→ efficient_transformers

### Eigenvector (собственный вектор)
Ненулевой вектор v, который линейное преобразование A лишь масштабирует: Av = λv, где λ — собственное значение. Собственные векторы ковариационной матрицы задают главные компоненты в PCA.
→ pca, linear_algebra_optimization

### Elastic Net (эластичная сеть)
Линейная регрессия с комбинацией L1- и L2-штрафов. Сочетает отбор признаков лассо с устойчивостью ridge к коррелированным признакам.
→ ridge_lasso_elasticnet

### ELBO (нижняя вариационная граница)
Evidence lower bound: ELBO = E_q[log p(x | z)] − KL(q(z | x) ‖ p(z)) ≤ log p(x). Максимизируется в вариационном выводе и при обучении VAE.
→ vae, variational_inference

### Elbow method (метод локтя)
Эвристика выбора числа кластеров: строится зависимость внутрикластерной суммы квадратов от k и выбирается точка перегиба кривой.
→ choosing_clusters_number

### EM algorithm (EM-алгоритм)
Итеративный метод максимизации правдоподобия моделей со скрытыми переменными: E-шаг вычисляет апостериорное распределение скрытых переменных, M-шаг обновляет параметры. Гарантирует неубывание правдоподобия, но сходится к локальному максимуму; обучает GMM и HMM.
→ em_algorithm, gmm

### Embedding (эмбеддинг, векторное представление)
Отображение дискретного объекта (слова, токена, пользователя, товара) в плотный вектор фиксированной размерности, обучаемый так, что похожие объекты получают близкие векторы.
→ word_embeddings, graph_embeddings

### Encoder-decoder (энкодер–декодер, seq2seq)
Архитектура, в которой энкодер преобразует входную последовательность в представление, а декодер генерирует по нему выходную последовательность. Применяется в машинном переводе и суммаризации.
→ encoder_decoder

### Ensemble learning (ансамблевое обучение)
Объединение предсказаний нескольких моделей для повышения качества и устойчивости. Основные схемы — бэггинг, бустинг, стекинг и голосование; выигрыш тем больше, чем менее коррелированы ошибки моделей.
→ ensemble_methods, ensemble_diversification

### Entropy (энтропия)
Мера неопределённости распределения: H(p) = −Σ p(x) log p(x). Максимальна у равномерного распределения; используется как критерий разбиения в деревьях решений.
→ information_theory_ml, decision_trees

### Epoch (эпоха)
Один полный проход по всей обучающей выборке. Число эпох — гиперпараметр, часто ограничиваемый ранней остановкой.
→ neural_network_training_dynamics

### Equalized odds (уравненные шансы)
Критерий справедливости: TPR и FPR равны во всех группах защищённого признака. Ослабленная версия equal opportunity требует равенства только TPR.
→ fairness_ml, fairness_constraints

### Expected value (математическое ожидание)
Среднее значение случайной величины, взвешенное по вероятностям: E[X] = Σ xᵢ p(xᵢ) или ∫ x p(x) dx. Функция потерь в обучении — оценка ожидаемого риска по выборке.
→ probability_theory

### Explainable AI (объяснимый ИИ, XAI)
Методы, делающие предсказания моделей понятными человеку: глобальные (важности признаков, PDP) и локальные (SHAP, LIME, контрфактические объяснения) объяснения.
→ explainable_ai_xai, explainability_accountability

### Exploding gradient (взрыв градиента)
Экспоненциальный рост градиентов в глубоких сетях и RNN, приводящий к расходимости и NaN. Лечится gradient clipping, правильной инициализацией и нормализацией.
→ vanishing_gradient, rnn_regularization

### Exploration-exploitation tradeoff (компромисс исследования и использования)
Дилемма между выбором лучшего известного действия и пробой других ради информации. Простейшая стратегия ε-greedy выбирает случайное действие с вероятностью ε; другие — UCB и сэмплирование Томпсона.
→ multi_armed_bandits, reinforcement_learning_basics

### Exponential smoothing (экспоненциальное сглаживание)
Прогноз как взвешенное среднее прошлых наблюдений с экспоненциально убывающими весами. Модель Хольта добавляет тренд, Хольта–Винтерса — тренд и сезонность.
→ exponential_smoothing

## F

### F1-score (F1-мера)
Гармоническое среднее точности и полноты: F1 = 2 · P · R / (P + R). Обобщение Fβ придаёт полноте в β раз больший вес.
→ classification_metrics, imbalanced_metrics

### Feature engineering (конструирование признаков)
Создание новых признаков из исходных данных на основе знаний о предметной области: агрегаты, отношения, взаимодействия, временные и текстовые признаки. Часто даёт больший прирост, чем выбор модели.
→ feature_engineering, feature_interaction

### Feature importance (важность признаков)
Оценка вклада признаков в предсказания модели: по уменьшению неопределённости в деревьях (MDI), по перестановкам, по SHAP. Импурити-важность смещена в пользу признаков с большим числом значений.
→ feature_importance, shap

### Feature interaction (взаимодействие признаков)
Эффект, при котором влияние одного признака на ответ зависит от значения другого. Линейные модели улавливают взаимодействия только через явные признаки-произведения, деревья — автоматически.
→ feature_interaction

### Feature selection (отбор признаков)
Выбор подмножества информативных признаков: фильтровые методы (корреляция, взаимная информация), обёрточные (RFE) и встроенные (L1, важности деревьев). Снижает переобучение и стоимость модели.
→ feature_selection

### Feature store (хранилище признаков)
Система для единообразного вычисления, хранения и выдачи признаков в обучении (офлайн) и инференсе (онлайн). Устраняет расхождение train/serve и обеспечивает корректность на момент времени (point-in-time).
→ feature_stores

### Federated learning (федеративное обучение)
Обучение модели на данных, распределённых по устройствам или организациям, без передачи сырых данных: клиенты обучаются локально, сервер агрегирует обновления (FedAvg).
→ federated_learning

### Few-shot learning (обучение по нескольким примерам)
Обучение распознаванию новых классов по 1–5 размеченным примерам на класс. Решается метаобучением, метрическими методами (прототипные сети) или большими предобученными моделями.
→ few_shot_learning, few_shot_learning_traditional

### FID (расстояние Фреше по Inception)
Fréchet Inception Distance — метрика качества генерации: расстояние Фреше между гауссовыми аппроксимациями признаков Inception для реальных и сгенерированных изображений. Чем ниже, тем лучше.
→ gan, dcgan_conditional_gan

### Fine-tuning (дообучение)
Продолжение обучения предобученной модели на данных целевой задачи — всех весов или их части, обычно с небольшой скоростью обучения.
→ transfer_learning, bert_finetuning

### Fully connected layer (полносвязный слой)
Слой, в котором каждый выход зависит от всех входов: y = Wx + b. Число параметров равно произведению размерностей входа и выхода плюс смещения.
→ mlp

### Function calling (вызов функций)
Режим, в котором модель возвращает не текст, а структурированный вызов инструмента: имя функции и аргументы в JSON по заданной схеме. Приложение выполняет вызов и возвращает результат модели.
→ tool_use_function_calling

## G

### Gaussian mixture model (смесь гауссовских распределений, GMM)
Модель плотности в виде взвешенной суммы нормальных распределений, обучаемая EM-алгоритмом. Даёт мягкую кластеризацию с эллиптическими кластерами.
→ gmm, em_algorithm

### Gaussian process (гауссовский процесс)
Распределение над функциями, у которого любой конечный набор значений имеет совместное нормальное распределение; задаётся средним и ядром ковариации. В регрессии даёт предсказание вместе с неопределённостью, но стоит O(n³) по числу объектов.
→ gaussian_processes, bayesian_optimization

### GELU (гауссова линейная единица ошибки)
GELU(x) = x · Φ(x), где Φ — функция распределения стандартного нормального закона. Гладкая альтернатива ReLU, стандарт в трансформерах (BERT, GPT).
→ activation_functions

### Generalization (обобщающая способность)
Способность модели давать качественные предсказания на новых данных из того же распределения. Разность ошибок на тесте и обучении называют generalization gap.
→ generalization_theory_neural_networks, overfitting_underfitting

### Generalized linear model (обобщённая линейная модель, GLM)
Модель, в которой g(E[y]) = wᵀx, где g — функция связи, а y имеет распределение из экспоненциального семейства. Линейная, логистическая и пуассоновская регрессии — частные случаи.
→ glm

### Generative adversarial network (генеративно-состязательная сеть, GAN)
Пара сетей: генератор превращает случайный шум в объекты, дискриминатор отличает их от реальных; обучаются как минимаксная игра. Даёт резкие изображения, но обучение нестабильно; вариант WGAN использует расстояние Вассерштейна для стабилизации.
→ gan, dcgan_conditional_gan

### Generative model (генеративная модель)
Модель, описывающая распределение данных p(x) или p(x, y) и способная порождать новые объекты. Дискриминативная модель, напротив, моделирует только p(y | x).
→ generative_models_classical, gan, vae

### Gini impurity (неопределённость Джини)
Критерий разбиения в деревьях: G = 1 − Σ pₖ², где pₖ — доля класса k в узле. Равна нулю для чистого узла; вычисляется быстрее энтропии.
→ decision_trees

### GPT (генеративный предобученный трансформер)
Generative Pre-trained Transformer — семейство декодерных трансформеров, предобученных предсказывать следующий токен и генерирующих текст авторегрессионно.
→ gpt_architectures

### Grad-CAM (градиентная карта активации классов)
Метод визуализации CNN: карты признаков последнего свёрточного слоя взвешиваются усреднёнными градиентами оценки класса, что даёт тепловую карту значимых областей изображения.
→ grad_cam, cnn_visualization_techniques

### Gradient (градиент)
Вектор частных производных скалярной функции по всем её аргументам: ∇f = (∂f/∂x₁, …, ∂f/∂xₙ). Указывает направление наискорейшего роста функции; в обучении параметры сдвигают против градиента функции потерь.
→ gradient_descent, linear_algebra_optimization

### Gradient boosting (градиентный бустинг)
Бустинг, в котором каждая новая модель (обычно дерево) аппроксимирует антиградиент функции потерь по предсказаниям текущего ансамбля. Ключевые гиперпараметры — learning rate, число и глубина деревьев.
→ boosting, gradient_boosting_hyperparameters, gradient_boosting_regression

### Gradient clipping (обрезка градиента)
Ограничение нормы градиента порогом: если ‖g‖ > c, то g ← c · g / ‖g‖. Защищает от взрыва градиентов, стандарт при обучении RNN и трансформеров.
→ vanishing_gradient, rnn_regularization

### Gradient descent (градиентный спуск)
Итеративный метод минимизации: θ ← θ − η ∇L(θ), где η — скорость обучения. Сходится к минимуму для выпуклых гладких функций при подходящем η; основа обучения большинства моделей.
→ gradient_descent

### Graph convolutional network (графовая свёрточная сеть, GCN)
GNN, в которой слой усредняет признаки соседей с нормализацией по степеням узлов: H′ = σ(D̃^(−1/2) Ã D̃^(−1/2) H W).
→ gcn

### Graph neural network (графовая нейросеть, GNN)
Нейросеть для данных в виде графа: представления узлов обновляются агрегацией сообщений от соседей. Решает задачи классификации узлов, рёбер и графов целиком.
→ gnn_basics, gnn_applications

### Grid search (поиск по сетке)
Перебор всех комбинаций гиперпараметров из заданной сетки с оценкой каждой на кросс-валидации. Число комбинаций растёт экспоненциально с числом гиперпараметров.
→ hyperparameter_tuning

### GRU (управляемый рекуррентный блок)
Упрощённая альтернатива LSTM с двумя гейтами (обновления и сброса) и без отдельной ячейки памяти; меньше параметров при сопоставимом качестве.
→ gru

### Guardrails (ограничители)
Проверки на входе и выходе агента: фильтры запросов, валидация вызовов инструментов, запрет опасных действий, проверка формата ответа. Дополняют, но не заменяют принцип наименьших привилегий.
→ agent_safety

## H

### Hallucination (галлюцинация)
Генерация моделью правдоподобного, но фактически неверного или не подкреплённого источниками содержания. Снижается RAG, требованием ссылок на источники и проверкой фактов.
→ gpt_architectures, modern_trends_deep_learning

### HDBSCAN (иерархический DBSCAN)
Иерархическое расширение DBSCAN, выделяющее наиболее устойчивые кластеры по дереву плотности. Справляется с кластерами разной плотности и не требует параметра eps.
→ hdbscan

### Hessian (гессиан)
Матрица вторых частных производных скалярной функции, H_ij = ∂²f/∂x_i∂x_j. Описывает кривизну: положительно определённый гессиан в стационарной точке означает локальный минимум; используется в методах второго порядка (Ньютон).
→ linear_algebra_optimization, optimizers_advanced

### Hidden Markov model (скрытая марковская модель, HMM)
Вероятностная модель последовательности, в которой ненаблюдаемые состояния образуют марковскую цепь, а наблюдения зависят только от текущего состояния. Задачи: оценка правдоподобия (forward), декодирование (Витерби), обучение (Баум–Велш).
→ hmm

### Hierarchical clustering (иерархическая кластеризация)
Построение дерева вложенных кластеров: агломеративно (снизу вверх, слияние ближайших кластеров) или дивизимно (сверху вниз). Способ связи (single, complete, average, Ward) определяет форму кластеров.
→ hierarchical_clustering

### Hinge loss (кусочно-линейная функция потерь)
L = max(0, 1 − y · f(x)) для y ∈ {−1, +1}. Не штрафует объекты, классифицированные с запасом; функция потерь SVM.
→ svm, loss_functions

### HNSW (иерархические навигируемые малые миры)
Индекс ANN на основе многоуровневого графа: поиск начинается на разреженном верхнем уровне и спускается к плотному нижнему, жадно двигаясь к ближайшим соседям. Даёт высокий recall и скорость, но требует много памяти.
→ vector_search

### Huber loss (функция потерь Хьюбера)
Функция потерь, квадратичная при |e| ≤ δ и линейная при больших ошибках. Сочетает гладкость MSE и устойчивость MAE к выбросам.
→ loss_functions, regression_metrics

### Human-in-the-loop (человек в контуре)
Схема, где необратимые или рискованные действия агента выполняются только после подтверждения человеком. Ограничивает ущерб от ошибок и prompt injection.
→ agent_safety, agent_planning

### Hyperparameter (гиперпараметр)
Параметр, задаваемый до обучения и не настраиваемый градиентом: глубина дерева, скорость обучения, коэффициент регуляризации, размер батча. Подбирается на валидации.
→ hyperparameter_tuning, hyperparameter_strategies

### Hypothesis testing (проверка статистических гипотез)
Процедура, решающая по данным, отвергнуть ли нулевую гипотезу H₀ в пользу альтернативной H₁ при заданном уровне значимости α. Применяется для сравнения моделей и анализа A/B-тестов.
→ hypothesis_testing, statistical_tests

## I

### Imitation learning (обучение по демонстрациям)
Обучение политики по демонстрациям эксперта: behavioral cloning сводит задачу к обучению с учителем, DAgger и обратное RL борются с накоплением ошибок вне демонстраций.
→ imitation_learning, inverse_rl

### Imputation (заполнение пропусков)
Замена пропущенных значений оценками: средним, медианой, модой, предсказанием модели (KNN, итеративное заполнение). Полезно добавлять индикатор пропуска; статистики считаются только по обучающей части.
→ data_preprocessing_missing_encoding, preprocessing

### In-context learning (обучение в контексте)
Способность LLM решать новую задачу по инструкции и нескольким примерам в промпте (few-shot prompting) без обновления весов.
→ prompt_engineering, gpt_architectures

### Information gain (прирост информации)
Уменьшение энтропии целевой переменной после разбиения узла: IG = H(родитель) − Σ (nᵢ / n) H(потомокᵢ). Критерий выбора разбиения в ID3/C4.5.
→ decision_trees, information_theory_ml

### Instruction tuning (дообучение на инструкциях)
Supervised fine-tuning языковой модели на парах «инструкция — желаемый ответ», учащий модель следовать указаниям пользователя.
→ gpt_architectures

### Integrated gradients (интегрированные градиенты)
Метод атрибуции для нейросетей: важность признака — интеграл градиента вдоль прямого пути от базового входа (baseline) к реальному, умноженный на разность входов. Удовлетворяет аксиоме полноты.
→ integrated_gradients

### Intersection over Union (пересечение над объединением, IoU)
Мера совпадения двух областей: площадь пересечения, делённая на площадь объединения. Используется для сопоставления предсказанных рамок с истинными и в метриках сегментации.
→ object_detection, image_segmentation

### Isolation Forest (изолирующий лес)
Алгоритм поиска аномалий: случайные деревья изолируют точки случайными разбиениями, и аномалии отделяются за меньшее число разбиений (короче средний путь).
→ isolation_forest

## J

### Jacobian (якобиан)
Матрица частных производных векторной функции f: ℝⁿ → ℝᵐ размера m × n, J_ij = ∂f_i/∂x_j. Обратное распространение ошибки — последовательное умножение векторов на якобианы слоёв.
→ backpropagation, differentiable_programming

## K

### K-fold cross-validation (кросс-валидация по k блокам)
Данные делятся на k блоков; модель обучается k раз, каждый раз проверяясь на одном блоке. Стратифицированный вариант сохраняет доли классов в каждом блоке, leave-one-out — случай k = n.
→ cross_validation

### K-means (метод k-средних)
Алгоритм кластеризации, чередующий назначение точек ближайшему центроиду и пересчёт центроидов; минимизирует внутрикластерную сумму квадратов. Предполагает выпуклые кластеры похожего размера, требует заранее задать k.
→ kmeans

### K-nearest neighbors (метод k ближайших соседей, kNN)
Ленивый алгоритм: предсказание — голосование или среднее по k ближайшим объектам обучающей выборки. Требует масштабирования признаков и плохо работает в высокой размерности.
→ knn

### Kalman filter (фильтр Калмана)
Рекурсивный алгоритм оценки скрытого состояния линейной динамической системы с гауссовым шумом: чередует шаг предсказания и шаг коррекции по новому наблюдению. Оптимален в классе линейных оценок при этих предположениях.
→ kalman_filters, state_space_models

### Kernel trick (ядерный трюк)
Замена скалярного произведения в признаковом пространстве функцией ядра K(x, x′) = ⟨φ(x), φ(x′)⟩, что позволяет строить нелинейные модели без явного вычисления φ. Используется в SVM, kernel PCA, гауссовских процессах.
→ svm, kernel_pca

### KL divergence (дивергенция Кульбака–Лейблера)
Несимметричная мера отличия распределения q от p: D_KL(p ‖ q) = Σ p(x) log(p(x) / q(x)) ≥ 0, равна нулю только при p = q. Входит в ELBO вариационного автоэнкодера, в RLHF и дистилляцию.
→ information_theory_ml, vae, variational_inference

### Knowledge distillation (дистилляция знаний)
Обучение компактной модели-ученика воспроизводить мягкие вероятности (с температурой) большой модели-учителя.
→ model_compression

### KV cache (кэш ключей и значений)
Сохранение ключей и значений внимания уже обработанных токенов при авторегрессионной генерации, чтобы не пересчитывать их на каждом шаге. Ускоряет инференс, но занимает память пропорционально длине контекста.
→ gpt_architectures, multi_head_attention

## L

### L1 regularization (L1-регуляризация)
Добавление к потерям штрафа λ Σ|wᵢ|. Зануляет часть весов, то есть выполняет отбор признаков.
→ ridge_lasso_elasticnet, regularization

### L2 regularization (L2-регуляризация)
Добавление к потерям штрафа λ Σwᵢ². Равномерно уменьшает веса, не зануляя их; при обычном SGD эквивалентна weight decay.
→ ridge_lasso_elasticnet, regularization

### Label propagation (распространение меток)
Графовый метод частичного обучения: метки размеченных узлов итеративно распространяются по рёбрам графа сходства на неразмеченные узлы.
→ label_propagation, graph_based_ssl

### Lag feature (лаговый признак)
Значение временного ряда в предыдущие моменты времени (yₜ₋₁, yₜ₋ₖ), используемое как признак. Вместе со скользящими статистиками сводит прогнозирование к задаче регрессии.
→ time_series_feature_engineering

### Lagrange multipliers (множители Лагранжа)
Метод поиска экстремума функции при ограничениях-равенствах через лагранжиан L = f(x) + Σλᵢgᵢ(x); обобщается условиями Каруша–Куна–Таккера на неравенства. Используется при выводе двойственной задачи SVM.
→ constrained_optimization_ml, svm

### Language model (языковая модель)
Модель, задающая распределение вероятностей над последовательностями токенов, обычно через P(xₜ | x₁, …, xₜ₋₁). Качество оценивают перплексией.
→ gpt_architectures, transformer_nlp

### Large language model (большая языковая модель, LLM)
Трансформерная языковая модель с миллиардами параметров, предобученная на огромных корпусах текста. Способна к обучению в контексте и выполнению инструкций после дообучения.
→ gpt_architectures, modern_trends_deep_learning

### Lasso (лассо-регрессия)
Линейная регрессия с L1-штрафом. Даёт разреженные решения; из группы коррелированных признаков обычно оставляет один.
→ ridge_lasso_elasticnet

### Latent space (латентное пространство)
Пространство внутренних представлений модели, например кодов автоэнкодера или шумовых векторов генератора. Близкие точки в хорошем латентном пространстве соответствуют похожим объектам.
→ vae, autoencoders

### Layer normalization (нормализация по слою)
Нормализация активаций по признакам каждого объекта отдельно, без зависимости от батча. Стандарт в трансформерах и RNN.
→ batch_normalization, transformers

### Learning curve (кривая обучения)
График ошибки на обучении и валидации в зависимости от объёма обучающих данных (или числа эпох). Показывает, поможет ли сбор новых данных и есть ли переобучение.
→ learning_curves, learning_validation_curves

### Learning rate (скорость обучения)
Множитель η, определяющий размер шага оптимизатора. Слишком большая скорость вызывает расходимость, слишком маленькая — медленную сходимость; обычно меняется по расписанию.
→ gradient_descent, learning_rate_scheduling

### Learning rate schedule (расписание скорости обучения)
Правило изменения скорости обучения в процессе обучения: ступенчатое снижение, экспоненциальное, косинусное, one-cycle, снижение на плато.
→ learning_rate_scheduling

### Lemmatization (лемматизация)
Приведение слова к словарной форме (лемме) с учётом морфологии и части речи. Точнее стемминга, особенно для русского языка.
→ stemming_lemmatization

### LightGBM (библиотека LightGBM)
Реализация градиентного бустинга от Microsoft с гистограммным поиском разбиений, листовым (leaf-wise) ростом деревьев, GOSS и EFB; особенно быстра на больших данных.
→ lightgbm

### Likelihood (правдоподобие)
Вероятность (или плотность) наблюдённых данных как функция параметров: L(θ) = P(D | θ). В отличие от вероятности, рассматривается при фиксированных данных и меняющихся параметрах.
→ bayesian_inference, loss_functions

### LIME (локальные интерпретируемые модельно-независимые объяснения)
Local Interpretable Model-agnostic Explanations: объяснение одного предсказания простой (обычно линейной) моделью, обученной на возмущённых копиях объекта, взвешенных по близости к нему. Результат может быть нестабилен.
→ lime, lime_neural_networks

### Linear discriminant analysis (линейный дискриминантный анализ, LDA)
Метод, находящий проекцию, максимизирующую отношение межклассового разброса к внутриклассовому; также генеративный классификатор с гауссовыми классами и общей ковариацией. Не путать с латентным размещением Дирихле.
→ lda, lda_method

### Linear regression (линейная регрессия)
Модель ŷ = w₀ + w₁x₁ + … + wₙxₙ, параметры которой обычно находят методом наименьших квадратов. Интерпретируема, но описывает только линейные по признакам зависимости.
→ linreg, multiple_regression

### LLM-as-a-judge (LLM как судья)
Оценка ответов или траекторий агента другой языковой моделью по рубрике. Дёшево масштабируется, но имеет смещения: предпочтение длинных ответов, своей модели, первой позиции в сравнении.
→ agent_evaluation

### Local outlier factor (локальный фактор выброса, LOF)
Метрика аномальности, сравнивающая локальную плотность точки с плотностью её соседей; LOF заметно больше 1 указывает на выброс.
→ local_outlier_factor

### Log loss (логарифмическая функция потерь)
Средняя бинарная или категориальная кросс-энтропия между метками и предсказанными вероятностями: −(1/n) Σ [y log p + (1 − y) log(1 − p)]. Сильно штрафует уверенные ошибки.
→ loss_functions, classification_metrics

### Logistic regression (логистическая регрессия)
Линейный классификатор, моделирующий вероятность класса через сигмоиду: P(y = 1 | x) = σ(wᵀx + b). Обучается минимизацией логистических потерь (кросс-энтропии).
→ logreg

### LoRA (низкоранговая адаптация)
Low-Rank Adaptation — метод параметрически-эффективного дообучения: исходные веса W заморожены, обучается низкоранговая добавка ΔW = BA с рангом r ≪ d. Сокращает число обучаемых параметров на порядки.
→ multimodal_transformers, modern_trends_deep_learning

### Loss function (функция потерь)
Функция, измеряющая расхождение предсказания и правильного ответа на объекте; её среднее по выборке минимизируется при обучении. Выбор зависит от задачи: MSE для регрессии, кросс-энтропия для классификации.
→ loss_functions

### LSTM (долгая краткосрочная память)
Рекуррентная ячейка с состоянием памяти и тремя гейтами (входным, забывания, выходным), регулирующими поток информации. Аддитивное обновление памяти позволяет учить долгие зависимости.
→ lstm, rnn_lstm_nlp, rnn_lstm_time_series

## M

### MAML (модельно-независимое метаобучение)
Model-Agnostic Meta-Learning: поиск начальных весов, из которых несколько шагов градиентного спуска на новой задаче дают хорошее качество. Требует градиентов второго порядка (или их приближения).
→ maml_meta_learning, meta_learning_maml

### Manifold learning (обучение многообразий)
Группа методов, исходящих из гипотезы, что высокоразмерные данные лежат вблизи многообразия малой размерности, и восстанавливающих его координаты (Isomap, LLE, t-SNE, UMAP).
→ manifold_learning

### MAPE (средняя абсолютная процентная ошибка)
MAPE = (100 % / n) Σ |yᵢ − ŷᵢ| / |yᵢ|. Интерпретируема, но не определена при yᵢ = 0 и асимметрично штрафует завышение и занижение.
→ regression_metrics, time_series

### Margin (зазор)
Расстояние от разделяющей гиперплоскости до ближайших объектов обучающей выборки. SVM максимизирует зазор, что улучшает обобщающую способность.
→ svm

### Markov chain (марковская цепь)
Случайный процесс, в котором следующее состояние зависит только от текущего: P(xₜ₊₁ | xₜ, …, x₀) = P(xₜ₊₁ | xₜ). Основа MCMC, скрытых марковских моделей и MDP.
→ mcmc_bayesian_inference, hmm, markov_decision_processes

### Markov chain Monte Carlo (MCMC, методы Монте-Карло по марковским цепям)
Семейство алгоритмов (Метрополис–Гастингс, Гиббс, HMC), строящих марковскую цепь со стационарным распределением, равным целевому апостериорному. Позволяет сэмплировать из распределений, известных с точностью до константы.
→ mcmc_bayesian_inference

### Markov decision process (марковский процесс принятия решений, MDP)
Формальная модель RL: множества состояний и действий, вероятности переходов P(s′ | s, a), функция вознаграждения и коэффициент дисконтирования γ ∈ [0, 1), уменьшающий вес будущих наград. Предполагается марковость переходов.
→ markov_decision_processes

### Masked language modeling (маскированное языковое моделирование)
Задача предобучения: часть токенов (в BERT — 15 %) маскируется, модель предсказывает их по контексту с обеих сторон.
→ bert_language_models

### Matrix factorization (матричная факторизация)
Приближение разреженной матрицы «пользователь — объект» произведением низкоранговых матриц эмбеддингов пользователей и объектов: r̂ᵤᵢ = pᵤ · qᵢ. Обучается SGD или ALS (поочерёдными наименьшими квадратами).
→ matrix_factorization_svd, als_recommender

### Matthews correlation coefficient (коэффициент корреляции Мэтьюса, MCC)
MCC = (TP·TN − FP·FN) / √((TP+FP)(TP+FN)(TN+FP)(TN+FN)), лежит в [−1, 1]. Учитывает все четыре клетки матрицы ошибок и устойчив к дисбалансу.
→ imbalanced_metrics

### Maximum a posteriori estimation (оценка апостериорного максимума, MAP)
Точечная оценка θ̂ = argmax [log P(D | θ) + log P(θ)], т. е. MLE с добавкой логарифма априорного распределения. Гауссов априор даёт L2-, лапласовский — L1-регуляризацию.
→ bayesian_inference, regularization

### Maximum likelihood estimation (оценка максимального правдоподобия, MLE)
Выбор параметров, максимизирующих правдоподобие данных: θ̂ = argmax Σ log p(xᵢ | θ). Минимизация MSE и кросс-энтропии — частные случаи MLE при гауссовом и категориальном шуме.
→ bayesian_inference, logreg, loss_functions

### McNemar's test (критерий Макнемара)
Тест для сравнения двух классификаторов на одной тестовой выборке по таблице 2 × 2 расхождений: статистика (b − c)² / (b + c), где b и c — объекты, на которых ошибся только один из классификаторов.
→ statistical_tests_t_test_mcnemar

### Mean absolute error (средняя абсолютная ошибка, MAE)
MAE = (1/n) Σ |yᵢ − ŷᵢ|. Устойчивее MSE к выбросам, измеряется в единицах целевой переменной.
→ regression_metrics

### Mean average precision (средняя точность по классам, mAP)
Основная метрика детекции: average precision (площадь под PR-кривой) усредняется по классам и часто по порогам IoU (mAP@0.5:0.95).
→ object_detection

### Mean squared error (среднеквадратичная ошибка, MSE)
MSE = (1/n) Σ (yᵢ − ŷᵢ)². Сильно штрафует большие ошибки; стандартная функция потерь регрессии.
→ regression_metrics, loss_functions

### Meta-learning (метаобучение)
«Обучение учиться»: модель обучается на множестве задач так, чтобы быстро адаптироваться к новой задаче по немногим примерам.
→ meta_learning_maml, optimization_based_meta_learning

### Metric learning (обучение метрики)
Обучение пространства эмбеддингов, в котором расстояние отражает семантическое сходство объектов. Используется в поиске, верификации лиц, few-shot.
→ metric_learning, metric_based_learning_siamese

### Mini-batch (мини-батч)
Небольшое подмножество обучающей выборки, по которому вычисляется одна оценка градиента. Размер батча влияет на шум градиента, использование памяти и подходящую скорость обучения.
→ gradient_descent, neural_network_training_dynamics

### Mixed precision training (обучение со смешанной точностью)
Обучение с вычислениями в FP16/BF16 и хранением мастер-копии весов в FP32; для FP16 добавляется масштабирование потерь против потери малых градиентов. Ускоряет обучение и экономит память.
→ mixed_precision_training

### Mixture of Experts (смесь экспертов, MoE)
Архитектура, в которой маршрутизатор направляет каждый токен лишь к нескольким из множества подсетей-экспертов. Увеличивает число параметров без пропорционального роста вычислений на токен.
→ modern_trends_deep_learning

### ML pipeline (конвейер машинного обучения)
Последовательность шагов предобработки и модели, обучаемая и применяемая как единое целое (например, sklearn Pipeline). Предотвращает утечку данных при кросс-валидации и упрощает развёртывание.
→ ml_pipelines, sklearn_overview

### MLOps (операционализация машинного обучения)
Практики и инструменты для надёжной разработки, развёртывания и сопровождения ML-моделей: версионирование данных и моделей, трекинг экспериментов, CI/CD, мониторинг, автоматическое переобучение.
→ mlops_best_practices, cicd_ml, production_ml_best_practices

### Mode collapse (коллапс мод)
Сбой обучения GAN, при котором генератор выдаёт лишь небольшое разнообразие объектов, покрывая несколько мод распределения данных вместо всех.
→ gan

### Model calibration (калибровка модели)
Соответствие предсказанных вероятностей наблюдаемым частотам: среди объектов с p = 0,8 положительных должно быть около 80 %. Проверяется reliability-диаграммой, исправляется Platt scaling, изотонической регрессией или temperature scaling.
→ model_calibration

### Model Context Protocol, MCP (протокол контекста модели)
Открытый стандарт подключения инструментов и данных к ИИ-приложениям: клиент общается с серверами по JSON-RPC (stdio или HTTP), а серверы предоставляют tools, resources и prompts. Снимает проблему N×M интеграций.
→ mcp_protocol

### Model monitoring (мониторинг моделей)
Отслеживание модели в продакшене: качества предсказаний (когда известны метки), дрейфа входных данных и предсказаний, задержки и ошибок сервиса. Срабатывание алертов запускает анализ или переобучение.
→ model_monitoring, model_monitoring_ab_testing

### Model registry (реестр моделей)
Централизованное хранилище версий моделей с метаданными, метриками и стадиями жизненного цикла (staging, production, archived), например MLflow Model Registry.
→ model_registries

### Model serving (сервинг моделей)
Развёртывание модели как сервиса для получения предсказаний — онлайн по запросу (REST/gRPC) или пакетно. Важные характеристики — задержка, пропускная способность, масштабирование.
→ model_deployment, tensorflow_serving, torchserve

### Momentum (метод моментов)
Модификация SGD, накапливающая экспоненциальное среднее градиентов: v ← βv + ∇L, θ ← θ − ηv. Сглаживает колебания и ускоряет движение вдоль устойчивых направлений; вариант Нестерова вычисляет градиент в «заглянутой вперёд» точке.
→ optimizers

### Monotonic constraint (ограничение монотонности)
Требование, чтобы предсказание модели монотонно росло или убывало по выбранному признаку. Поддерживается в градиентном бустинге; повышает доверие и соответствие предметной логике (например, в кредитном скоринге).
→ monotonic_constraints, shape_constraints

### Monte Carlo method (метод Монте-Карло)
Приближённое вычисление интегралов и ожиданий усреднением по случайным выборкам: E[f(X)] ≈ (1/N) Σ f(xᵢ). Погрешность убывает как 1/√N независимо от размерности.
→ monte_carlo_methods

### Multi-agent system (мультиагентная система)
Несколько агентов с разными ролями, которые решают задачу совместно: оркестратор и исполнители, конвейер, дебаты, передача управления (handoff). Выигрыш в специализации оплачивается стоимостью координации.
→ multi_agent_systems

### Multi-armed bandit (многорукий бандит)
Упрощённая задача RL без состояний: на каждом шаге выбирается одна из k «ручек» с неизвестным распределением награды, цель — минимизировать сожаление (regret). Применяется в онлайн-экспериментах и рекомендациях.
→ multi_armed_bandits

### Multi-head attention (многоголовое внимание)
Параллельное вычисление нескольких независимых attention в разных подпространствах с конкатенацией результатов и линейной проекцией. Головы улавливают разные типы связей.
→ multi_head_attention

### Multi-task learning (многозадачное обучение)
Совместное обучение одной модели нескольким задачам с общими слоями. Общие представления действуют как регуляризация; проблема — конфликт градиентов задач.
→ multi_task_learning, multi_task_learning_deep_dive

### Multicollinearity (мультиколлинеарность)
Сильная линейная зависимость между признаками регрессии. Делает оценки коэффициентов неустойчивыми и неинтерпретируемыми; диагностируется через VIF, лечится регуляризацией или удалением признаков.
→ multiple_regression, ridge_lasso_elasticnet

### Multilayer perceptron (многослойный перцептрон, MLP)
Нейросеть из последовательных полносвязных слоёв с нелинейными активациями. Базовая архитектура глубокого обучения, применяется и к табличным данным.
→ mlp, mlp_tabular_data

### Multimodal model (мультимодальная модель)
Модель, совместно обрабатывающая несколько модальностей — текст, изображения, аудио, видео — в общем пространстве представлений.
→ multimodal_transformers, image_text_models

### Mutual information (взаимная информация)
Количество информации об одной величине, содержащееся в другой: I(X; Y) = H(X) − H(X | Y). В отличие от корреляции ловит любые, в том числе нелинейные, зависимости; применяется для отбора признаков.
→ information_theory_ml, feature_selection

## N

### Naive Bayes (наивный байесовский классификатор)
Классификатор по теореме Байеса с допущением условной независимости признаков при заданном классе: P(y | x) ∝ P(y) Π P(xᵢ | y). Быстр и хорошо работает на текстах.
→ naive_bayes, naive_bayes_bayesian_method

### Named entity recognition (распознавание именованных сущностей, NER)
Задача разметки последовательности: выделение в тексте имён людей, организаций, мест, дат и т. п. Обычно формулируется как пометка токенов в схеме BIO.
→ nlp_tasks_ner_classification_summarization, crf_conditional_random_fields

### NDCG (нормализованный дисконтированный совокупный выигрыш)
Метрика ранжирования: релевантности позиций суммируются с дисконтом 1 / log₂(i + 1) и делятся на значение для идеального порядка. Лежит в [0, 1], учитывает порядок выдачи.
→ sequence_aware_recommendations, collaborative_filtering_user_item_based

### Non-maximum suppression (подавление немаксимумов, NMS)
Постобработка детектора: из перекрывающихся рамок (IoU выше порога) одного класса оставляется рамка с наибольшей уверенностью.
→ object_detection, yolo

### Non-negative matrix factorization (неотрицательное матричное разложение, NMF)
Разложение неотрицательной матрицы V ≈ WH с неотрицательными сомножителями. Даёт аддитивные интерпретируемые части; применяется в тематическом моделировании и рекомендациях.
→ matrix_factorization_svd_nmf, topic_modeling_lda_nmf

### Norm (норма)
Функция, задающая «длину» вектора. L1-норма ‖x‖₁ = Σ|xᵢ|, L2-норма ‖x‖₂ = √(Σxᵢ²); нормы весов используются в регуляризации, нормы градиента — в gradient clipping.
→ linear_algebra_optimization, regularization

### Normal distribution (нормальное распределение)
Непрерывное распределение с плотностью (1 / σ√(2π)) · exp(−(x − μ)² / 2σ²), задаваемое средним μ и дисперсией σ². Предельное распределение сумм в ЦПТ; предположение о нормальном шуме эквивалентно MSE-потерям.
→ probability_theory

### Normalizing flow (нормализующий поток)
Генеративная модель из цепочки обратимых преобразований простого распределения в сложное; точное правдоподобие вычисляется по формуле замены переменных через определитель якобиана.
→ normalizing_flows

## O

### Object detection (детекция объектов)
Задача нахождения объектов на изображении с указанием класса и ограничивающей рамки. Двухэтапные детекторы (Faster R-CNN) сначала предлагают регионы, одноэтапные (YOLO, SSD) предсказывают рамки сразу.
→ object_detection, yolo

### One-class SVM (одноклассовый SVM)
Вариант SVM, строящий границу вокруг «нормальных» данных в ядровом пространстве; объекты вне границы считаются аномалиями.
→ one_class_svm

### One-hot encoding (унитарное кодирование)
Представление категориального признака с k значениями бинарным вектором длины k с одной единицей. Увеличивает размерность при большом числе категорий.
→ categorical_encoding

### Online learning (онлайн-обучение)
Обновление модели по мере поступления новых объектов или небольших порций данных без полного переобучения. Нужно для потоковых данных и адаптации к дрейфу.
→ online_learning, incremental_learning

### ONNX (открытый формат нейросетей)
Open Neural Network Exchange — открытый формат представления моделей в виде графа операций, позволяющий переносить модели между фреймворками и запускать их в оптимизированных средах (ONNX Runtime).
→ onnx_format, model_serialization

### Optimizer (оптимизатор)
Алгоритм обновления параметров модели по градиентам: SGD, Momentum, RMSprop, Adam и их варианты.
→ optimizers, optimizers_advanced

### Ordinary least squares (метод наименьших квадратов, OLS)
Оценка параметров линейной модели минимизацией суммы квадратов остатков; аналитическое решение w = (XᵀX)⁻¹Xᵀy. При мультиколлинеарности XᵀX плохо обусловлена.
→ linreg

### Outlier (выброс)
Наблюдение, аномально далёкое от остальных. Может быть ошибкой измерения или ценным сигналом; обрабатывается удалением, винзоризацией или робастными методами.
→ outliers_handling

### Overfitting (переобучение)
Ситуация, когда модель запоминает шум и особенности обучающей выборки: ошибка на обучении мала, а на новых данных велика. Лечится регуляризацией, увеличением данных, упрощением модели, ранней остановкой.
→ overfitting_underfitting, regularization

## P

### P-value (p-значение)
Вероятность получить статистику не менее экстремальную, чем наблюдаемая, при условии истинности нулевой гипотезы. Это не вероятность того, что H₀ верна; при p < α нулевую гипотезу отвергают.
→ hypothesis_testing, statistical_tests

### Partial dependence plot (график частичной зависимости, PDP)
График среднего предсказания модели при изменении одного или двух признаков с усреднением по остальным. ICE-кривые показывают ту же зависимость для отдельных объектов; при коррелированных признаках PDP может вводить в заблуждение.
→ partial_dependence

### pass@k
Вероятность, что среди k независимых попыток есть хотя бы одна успешная. Несмещённая оценка по n попыткам и c успехам: 1 − C(n−c, k) / C(n, k). Для надёжности агента используют также pass^k — все k попыток успешны.
→ agent_evaluation

### PEFT (параметрически-эффективное дообучение)
Parameter-Efficient Fine-Tuning — подходы, обучающие малую долю параметров большой модели: адаптеры, LoRA, prefix- и prompt-tuning.
→ modern_trends_deep_learning, hugging_face_transformers

### Perceptron (перцептрон)
Линейный классификатор Розенблатта: y = sign(wᵀx + b), веса обновляются только на ошибках. Сходится лишь для линейно разделимых данных; не решает XOR.
→ perceptron

### Permutation importance (перестановочная важность)
Падение метрики модели после случайного перемешивания значений одного признака на валидации. Модельно-независима, но занижает важность коррелированных признаков.
→ feature_importance

### Perplexity (перплексия)
Экспонента средней кросс-энтропии языковой модели на тексте: PPL = exp(−(1/N) Σ log p(xₜ | x<ₜ)). Чем ниже, тем лучше модель предсказывает текст; сравнима только при одинаковой токенизации.
→ gpt_architectures, information_theory_ml

### Policy (политика)
Правило выбора действий агентом: детерминированное a = π(s) или стохастическое π(a | s).
→ reinforcement_learning_basics, policy_gradient

### Policy gradient (градиент по политике)
Семейство методов, напрямую оптимизирующих параметризованную политику по градиенту ожидаемой награды: ∇J = E[∇ log π(a | s) · Gₜ] (REINFORCE). Работают с непрерывными действиями, но имеют высокую дисперсию оценок.
→ policy_gradient

### Polynomial regression (полиномиальная регрессия)
Линейная регрессия на полиномиальных признаках x, x², …, xᵈ и их произведениях. Моделирует нелинейность, но при большой степени легко переобучается.
→ polynomial_regression

### Pooling (пулинг, субдискретизация)
Агрегация значений в окне (максимум — max pooling, среднее — average pooling) для уменьшения пространственного размера и повышения устойчивости к малым сдвигам. Global average pooling усредняет всю карту признаков в одно число на канал.
→ pooling_layers

### Positional encoding (позиционное кодирование)
Добавление информации о позиции токена, так как внимание само по себе перестановочно-инвариантно. Бывает синусоидальным, обучаемым или относительным (RoPE, ALiBi).
→ positional_encoding

### Posterior distribution (апостериорное распределение)
Распределение параметров после учёта данных, P(θ | D) ∝ P(D | θ) · P(θ). Даёт не только точечную оценку, но и неопределённость параметров.
→ bayesian_inference, mcmc_bayesian_inference

### PPO (проксимальная оптимизация политики)
Proximal Policy Optimization — actor-critic алгоритм, ограничивающий изменение политики за обновление обрезкой отношения вероятностей новой и старой политики. Стабилен и прост, используется в RLHF.
→ ppo_reinforcement_learning

### Precision (точность)
Доля действительно положительных среди предсказанных положительными: TP / (TP + FP). Важна, когда дорого ложное срабатывание.
→ classification_metrics, confusion_matrix

### Precision-recall curve (кривая точность–полнота)
График точности от полноты при изменении порога; площадь под ней (average precision, PR-AUC) информативнее ROC-AUC при редком положительном классе.
→ imbalanced_metrics, metrics_visualization

### Pretraining (предобучение)
Начальное обучение модели на большом неразмеченном или слабо размеченном корпусе (часто самоконтролируемой задачей) перед дообучением на целевых задачах.
→ transfer_learning_deep, bert_language_models

### Principal component analysis (метод главных компонент, PCA)
Линейное снижение размерности проекцией на направления максимальной дисперсии — собственные векторы ковариационной матрицы. Требует центрирования и обычно масштабирования признаков.
→ pca, pca_method

### Prior distribution (априорное распределение)
Распределение параметров модели до наблюдения данных, P(θ). Кодирует предварительные знания; например, гауссов априор на веса эквивалентен L2-регуляризации.
→ bayesian_inference, bayesian_approach

### Probabilistic graphical model (вероятностная графическая модель)
Представление совместного распределения графом, где узлы — случайные величины, а рёбра — зависимости. Направленные графы — байесовские сети, ненаправленные — марковские случайные поля (в том числе CRF).
→ graphical_models

### Probability distribution (распределение вероятностей)
Закон, задающий вероятности значений случайной величины: функция вероятности для дискретного случая, плотность — для непрерывного. Модели ML по сути оценивают распределения p(y | x) или p(x).
→ probability_theory

### Prompt (промпт)
Входной текст (инструкция, контекст, примеры), который задаёт LLM задачу и формат ответа.
→ prompt_engineering

### Prompt engineering (промпт-инжиниринг)
Проектирование промптов для получения нужного поведения модели без изменения весов: чёткие инструкции, роли, примеры, требования к формату, разбиение задачи на шаги.
→ prompt_engineering

### Prompt injection (инъекция промпта)
Атака, в которой текст в запросе или в стороннем контенте (страница, письмо, документ) заставляет модель выполнить чужие инструкции. Косвенная инъекция особенно опасна для агентов с инструментами.
→ agent_safety

### Pruning (прунинг, обрезка)
Удаление частей модели для упрощения: в деревьях — ветвей, не улучшающих качество на валидации (например, cost-complexity pruning); в нейросетях — малозначимых весов, нейронов или каналов для сжатия модели.
→ decision_trees, model_compression

## Q

### Q-learning (Q-обучение)
Off-policy TD-алгоритм: Q(s, a) ← Q(s, a) + α [r + γ maxₐ′ Q(s′, a′) − Q(s, a)]. On-policy аналог SARSA вместо максимума использует действие, реально выбранное текущей политикой.
→ q_learning_sarsa

### Quantile regression (квантильная регрессия)
Регрессия, оценивающая заданный квантиль условного распределения целевой переменной через минимизацию pinball loss. Позволяет строить интервалы предсказания.
→ quantile_regression

### Quantization (квантизация)
Представление весов и активаций в низкой разрядности (INT8, INT4) вместо FP32. Уменьшает размер модели и ускоряет инференс ценой небольшой потери точности; бывает пост-тренировочной и с учётом квантизации при обучении (QAT).
→ model_compression

## R

### R-squared (коэффициент детерминации, R²)
R² = 1 − Σ (yᵢ − ŷᵢ)² / Σ (yᵢ − ȳ)² — доля дисперсии целевой переменной, объяснённая моделью. Равен 1 при идеальном прогнозе, 0 — для предсказания средним, на тесте может быть отрицательным.
→ regression_metrics, linreg

### RAG, Retrieval-Augmented Generation (генерация с дополнением поиском)
Подход, где перед ответом система находит релевантные фрагменты во внешней базе знаний и подставляет их в промпт. Уменьшает галлюцинации и позволяет работать со свежими и приватными данными без дообучения.
→ rag, vector_search

### Random forest (случайный лес)
Бэггинг деревьев решений с дополнительной рандомизацией: в каждом разбиении рассматривается случайное подмножество признаков. Устойчив к переобучению, даёт OOB-оценку и важность признаков.
→ random_forest, random_forest_regression

### Random search (случайный поиск)
Выбор случайных комбинаций гиперпараметров из заданных распределений. При том же бюджете обычно эффективнее поиска по сетке, так как лучше покрывает важные измерения.
→ hyperparameter_tuning, hyperparameter_strategies

### RBF kernel (радиальное базисное ядро)
Гауссово ядро K(x, x′) = exp(−γ‖x − x′‖²). Соответствует бесконечномерному признаковому пространству; параметр γ задаёт ширину влияния объекта.
→ svm, gaussian_processes

### ReAct (рассуждение и действие)
Паттерн агента: модель чередует рассуждение (Thought), действие с инструментом (Action) и наблюдение результата (Observation). Рассуждения помогают планировать, наблюдения — опираться на факты, а не на догадки.
→ react_agents

### Recall (полнота)
Доля найденных положительных объектов среди всех положительных: TP / (TP + FN); то же, что чувствительность (TPR). Важна, когда дорого пропустить положительный объект.
→ classification_metrics, confusion_matrix

### Receptive field (рецептивное поле)
Область входа, влияющая на значение конкретного нейрона. Растёт с глубиной сети, размером ядер, шагом и расширением (dilation).
→ cnn_basics, cnn_architectures

### Recurrent neural network (рекуррентная нейросеть, RNN)
Сеть для последовательностей, обновляющая скрытое состояние на каждом шаге: hₜ = f(W·hₜ₋₁ + U·xₜ + b). Веса общие для всех шагов; простая RNN страдает от затухания градиента.
→ rnn_basics

### Reflexion (рефлексия)
Приём, в котором агент после неудачной попытки словесно анализирует ошибку и сохраняет вывод в память, чтобы учесть его в следующей попытке без изменения весов модели.
→ agent_planning

### Regularization (регуляризация)
Любое изменение обучения, снижающее переобучение: штраф за сложность в функции потерь (L1, L2), dropout, ранняя остановка, аугментация. Уменьшает дисперсию ценой некоторого смещения.
→ regularization, regularization_methods

### Reinforcement learning (обучение с подкреплением)
Постановка, в которой агент взаимодействует со средой, выполняя действия и получая вознаграждения, и учится политике, максимизирующей ожидаемую суммарную награду.
→ reinforcement_learning_basics, classical_rl_tabular

### ReLU (выпрямленная линейная функция)
ReLU(x) = max(0, x). Дешёвая, не насыщается при x > 0 и снижает затухание градиента; недостаток — «мёртвые» нейроны с постоянно нулевым выходом.
→ activation_functions

### Reparameterization trick (трюк репараметризации)
Запись случайной величины как z = μ + σ ⊙ ε, ε ~ N(0, I), что выносит случайность из вычислительного графа и позволяет дифференцировать по μ и σ. Ключевой приём обучения VAE.
→ vae, variational_inference

### Reranking (реранкинг)
Второй этап поиска: более точная, но дорогая модель (например, кросс-энкодер) пересортировывает короткий список кандидатов, найденных быстрым векторным или BM25-поиском.
→ rag

### Resampling (ресэмплинг классов)
Изменение распределения классов в обучающей выборке: oversampling дублирует или синтезирует объекты редкого класса, undersampling удаляет объекты частого класса. Применяется только к обучающей части, не к тесту.
→ imbalanced_data, smote_imbalanced

### Residual connection (остаточная связь)
Соединение, прибавляющее вход блока к его выходу: y = F(x) + x. Обеспечивает прямой путь градиента и позволяет обучать сети из сотен слоёв (ResNet, трансформеры).
→ resnet, vanishing_gradient

### ResNet (остаточная сеть)
Архитектура CNN (2015) из остаточных блоков с обходными связями; позволила обучать сети глубиной 50–152 слоя и более.
→ resnet

### Retrieval-augmented generation (генерация с извлечением, RAG)
Подход, при котором по запросу из внешней базы знаний извлекаются релевантные фрагменты (обычно поиском по эмбеддингам), которые подаются в контекст LLM вместе с вопросом. Даёт актуальные знания и снижает галлюцинации.
→ modern_trends_deep_learning, memory_networks

### Ridge regression (гребневая регрессия)
Линейная регрессия с L2-штрафом: решение w = (XᵀX + λI)⁻¹Xᵀy устойчиво даже при мультиколлинеарности.
→ ridge_lasso_elasticnet

### RLHF (обучение с подкреплением на основе обратной связи от человека)
Метод выравнивания LLM: по попарным предпочтениям людей обучается модель вознаграждения, затем языковая модель оптимизируется под неё (обычно PPO) со штрафом KL к исходной модели.
→ gpt_architectures, ppo_reinforcement_learning

### ROC curve (ROC-кривая)
График зависимости TPR от FPR при изменении порога классификации. Диагональ соответствует случайному классификатору.
→ roc_auc, metrics_visualization

### RoPE (ротационные позиционные эмбеддинги)
Rotary Position Embedding: кодирование позиции поворотом пар координат векторов запросов и ключей на угол, пропорциональный позиции, так что их скалярное произведение зависит от относительного расстояния. Используется в LLaMA и многих современных LLM.
→ positional_encoding

## S

### Saliency map (карта значимости)
Карта, показывающая, какие пиксели входа сильнее всего влияют на предсказание; в простейшем виде — модуль градиента выхода по входу.
→ saliency_maps

### Scaled dot-product attention (масштабированное скалярное внимание)
Attention(Q, K, V) = softmax(QKᵀ / √d_k) · V. Деление на √d_k не даёт softmax насыщаться при большой размерности.
→ self_attention, attention_mechanism

### Scaling laws (законы масштабирования)
Эмпирические степенные зависимости ошибки языковой модели от числа параметров, объёма данных и вычислений. Используются для выбора оптимального соотношения размера модели и данных (Chinchilla).
→ modern_trends_deep_learning

### Seasonal decomposition (сезонная декомпозиция)
Разложение ряда на тренд, сезонность и остаток — аддитивно (y = T + S + R) или мультипликативно; устойчивый метод — STL.
→ seasonal_decomposition

### Self-attention (самовнимание)
Внимание, где запросы, ключи и значения получаются из одной последовательности, так что каждый токен учитывает все остальные. Сложность O(n²) по длине последовательности.
→ self_attention

### Self-supervised learning (самоконтролируемое обучение)
Обучение представлений на неразмеченных данных за счёт вспомогательных задач, метки для которых берутся из самих данных: предсказание маскированных токенов, следующего токена, контрастивное сопоставление аугментаций.
→ self_supervised_learning

### Self-training (самообучение)
Метод частичного обучения: модель, обученная на размеченных данных, размечает неразмеченные, наиболее уверенные предсказания добавляются в обучающую выборку, и цикл повторяется. Опасен закреплением собственных ошибок.
→ self_training, pseudo_labeling

### Semantic segmentation (семантическая сегментация)
Присвоение класса каждому пикселю изображения без разделения отдельных экземпляров. Instance segmentation дополнительно разделяет объекты одного класса.
→ image_segmentation

### Semi-supervised learning (частичное обучение)
Обучение на небольшом размеченном и большом неразмеченном наборе данных. Опирается на предположения о гладкости, кластерности или многообразии данных.
→ semi_supervised_learning, graph_based_ssl

### SHAP (аддитивные объяснения Шепли)
SHapley Additive exPlanations — метод локальной интерпретации, распределяющий предсказание между признаками по значениям Шепли из теории кооперативных игр. Вклады в сумме дают разницу между предсказанием и средним предсказанием.
→ shap, shap_neural_networks

### Siamese network (сиамская сеть)
Архитектура из двух или более ветвей с общими весами, сравнивающая эмбеддинги входов. Обучается на парах (contrastive loss) или тройках (triplet loss).
→ metric_based_learning_siamese

### Sigmoid (сигмоида)
Функция σ(x) = 1 / (1 + e⁻ˣ), отображающая ℝ в (0, 1). Используется для вероятности в бинарной классификации и в гейтах LSTM/GRU; в скрытых слоях глубоких сетей вызывает затухание градиента.
→ activation_functions, logreg

### Silhouette score (коэффициент силуэта)
Метрика кластеризации s = (b − a) / max(a, b), где a — среднее расстояние до своего кластера, b — до ближайшего чужого. Лежит в [−1, 1]; близкие к 1 значения означают хорошо отделённые кластеры.
→ clustering_metrics, choosing_clusters_number

### Singular value decomposition (сингулярное разложение, SVD)
Разложение любой матрицы A = UΣVᵀ, где U и V ортогональны, а Σ диагональна с неотрицательными сингулярными числами. Лежит в основе PCA, LSA и низкоранговых аппроксимаций.
→ svd, matrix_factorization_svd

### SMOTE (синтетическая передискретизация меньшинства)
Метод oversampling, создающий синтетические объекты редкого класса интерполяцией между объектом и одним из его k ближайших соседей того же класса.
→ smote_imbalanced

### Softmax (функция softmax)
Преобразование вектора логитов z в распределение вероятностей: softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ). Применяется на выходе многоклассовых классификаторов и в механизме внимания.
→ activation_functions, logreg

### Spectral clustering (спектральная кластеризация)
Кластеризация по собственным векторам лапласиана графа сходства с последующим k-means в полученном пространстве. Находит невыпуклые кластеры.
→ spectral_clustering

### Stacking (стекинг)
Ансамбль, в котором метамодель обучается на out-of-fold предсказаниях базовых моделей. Для избежания утечки предсказания для метамодели получают кросс-валидацией.
→ voting_stacking, ensemble_methods_voting_stacking

### Standardization (стандартизация)
Преобразование признака к нулевому среднему и единичному стандартному отклонению: z = (x − μ) / σ. Необходимо для методов, чувствительных к масштабу (kNN, SVM, PCA, градиентный спуск).
→ scaling_normalization

### State space model (модель пространства состояний)
Модель последовательности через скрытое состояние с линейной динамикой xₜ₊₁ = Axₜ + Buₜ, yₜ = Cxₜ. Классически — основа фильтра Калмана; современные глубокие SSM (S4, Mamba) — альтернатива трансформерам с линейной сложностью по длине.
→ state_space_models, kalman_filters

### Stationarity (стационарность)
Свойство временного ряда, при котором среднее, дисперсия и автоковариация не зависят от времени. Многие модели (ARMA) требуют стационарности; проверяется тестами ADF и KPSS, достигается дифференцированием.
→ box_jenkins, time_series

### Statistical power (мощность теста)
Вероятность отвергнуть нулевую гипотезу, когда она ложна: 1 − β. Зависит от размера эффекта, объёма выборки и α; по ней рассчитывают необходимый размер выборки A/B-теста.
→ hypothesis_testing, model_monitoring_ab_testing

### Stemming (стемминг)
Эвристическое отсечение окончаний и суффиксов для приведения слов к общей основе (стеммер Портера). Быстро, но может давать несуществующие формы.
→ stemming_lemmatization

### Stochastic gradient descent (стохастический градиентный спуск, SGD)
Вариант градиентного спуска, где градиент на каждом шаге оценивается по одному объекту или мини-батчу: θ ← θ − η ∇L_batch(θ). Дешевле полного спуска, а шум оценки помогает выходить из плохих областей.
→ gradient_descent, optimizers

### Student's t-test (t-критерий Стьюдента)
Параметрический тест равенства средних (одной выборки, двух независимых или парных выборок) при предположении о приблизительной нормальности. Парный t-тест применяют к метрикам моделей на одних и тех же фолдах с поправками на их зависимость.
→ statistical_tests_t_test_mcnemar, statistical_tests

### Supervised learning (обучение с учителем)
Постановка, в которой модель учится по парам «объект — правильный ответ» предсказывать ответ для новых объектов. Основные задачи — классификация и регрессия.
→ sklearn_overview

### Support vector machine (метод опорных векторов, SVM)
Классификатор, строящий разделяющую гиперплоскость с максимальным зазором между классами; с ядрами решает нелинейные задачи. Параметр C балансирует ширину зазора и штраф за ошибки.
→ svm

## T

### t-SNE (стохастическое вложение соседей с t-распределением)
Нелинейный метод визуализации, сохраняющий локальные окрестности: сходства в исходном пространстве моделируются гауссианами, в двумерном — t-распределением Стьюдента, и минимизируется KL-дивергенция. Расстояния между кластерами и их размеры на картинке не интерпретируются.
→ tsne

### Target encoding (кодирование целевой переменной)
Замена категории средним значением целевой переменной по этой категории. Требует сглаживания и вычисления out-of-fold, иначе приводит к утечке и переобучению.
→ target_encoding, categorical_encoding

### Teacher forcing (принудительное обучение учителем)
Режим обучения декодера, при котором на вход следующего шага подаётся истинный предыдущий токен, а не предсказанный. Ускоряет обучение, но создаёт расхождение с инференсом (exposure bias).
→ encoder_decoder, rnn_basics

### Temperature (температура сэмплирования)
Параметр T, на который делятся логиты перед softmax: T < 1 делает распределение острее и генерацию детерминированнее, T > 1 — разнообразнее. При T → 0 сэмплирование вырождается в жадное декодирование.
→ gpt_architectures

### Temporal convolutional network (временная свёрточная сеть, TCN)
Архитектура для последовательностей на причинных расширенных свёртках с остаточными связями. Параллелится лучше RNN и имеет контролируемое рецептивное поле.
→ tcn, cnn_time_series_tcn

### Temporal difference learning (обучение на временных разностях, TD)
Обновление оценки ценности по разности r + γV(s′) − V(s) после каждого шага, без ожидания конца эпизода. Сочетает идеи Монте-Карло и динамического программирования.
→ td_learning

### TF-IDF (частота слова — обратная частота документа)
Вес слова в документе tf(t, d) · log(N / df(t)): частые в документе, но редкие в корпусе слова получают высокий вес. Улучшает «мешок слов» — вектор простых частот слов без учёта порядка.
→ tfidf

### Time series cross-validation (валидация временных рядов)
Разбиение с соблюдением хронологии: модель всегда обучается на прошлом и проверяется на будущем (расширяющееся или скользящее окно, walk-forward). Случайное перемешивание временного ряда даёт утечку.
→ time_series_validation

### Tokenization (токенизация)
Разбиение текста на единицы (токены) — слова, подслова или символы, — которым сопоставляются индексы словаря. От токенизатора зависят длина контекста и обработка редких слов.
→ tokenization

### Tool use (использование инструментов)
Способность модели вызывать внешние функции: поиск, калькулятор, код, API, базы данных. Расширяет возможности модели за пределы её параметров и контекста.
→ tool_use_function_calling, ai_agents_basics

### Top-p sampling (ядерное сэмплирование)
Nucleus sampling: выбор следующего токена из минимального набора самых вероятных токенов с суммарной вероятностью ≥ p. Top-k sampling аналогично ограничивает выбор k самыми вероятными токенами.
→ gpt_architectures, hugging_face_transformers

### Topic modeling (тематическое моделирование)
Выделение скрытых тем в коллекции документов: каждая тема — распределение над словами, каждый документ — смесь тем. Основные методы — LDA (латентное размещение Дирихле) и NMF.
→ topic_modeling_lda_nmf, latent_semantic_analysis

### Train-test split (разбиение на обучающую и тестовую выборки)
Разделение данных на обучающую, валидационную (для подбора гиперпараметров) и тестовую (для финальной оценки) части. Тестовая выборка не должна влиять ни на одно решение при обучении.
→ cross_validation

### Training-serving skew (расхождение обучения и инференса)
Различие между данными или обработкой признаков на обучении и в продакшене (разный код, задержки данных), из-за которого модель работает хуже ожидаемого.
→ feature_stores, production_ml_best_practices

### Transfer learning (перенос обучения)
Использование модели, обученной на одной задаче (часто на большом датасете), как отправной точки для другой задачи. Резко снижает потребность в данных.
→ transfer_learning, transfer_learning_cnn, transfer_learning_deep

### Transformer (трансформер)
Архитектура (2017) из блоков многоголового внимания и полносвязных слоёв с остаточными связями и нормализацией, без рекуррентности. Основа современных NLP-моделей, LLM и ViT.
→ transformers, transformer_nlp

### Type I error (ошибка первого рода)
Отвержение верной нулевой гипотезы (ложное срабатывание); её вероятность ограничена уровнем значимости α. Ошибка второго рода — неотвержение ложной H₀, её вероятность обозначают β.
→ hypothesis_testing, confusion_matrix

## U

### U-Net (архитектура U-Net)
Архитектура сегментации из сжимающего энкодера и расширяющего декодера с пропускными связями между уровнями одинакового разрешения. Изначально создана для медицинских снимков, используется также в диффузионных моделях.
→ image_segmentation, image_to_image_translation

### UMAP (равномерная аппроксимация и проекция многообразия)
Нелинейный метод снижения размерности на основе нечёткого графа соседей; быстрее t-SNE, лучше сохраняет глобальную структуру и умеет проецировать новые точки.
→ umap

### Underfitting (недообучение)
Ситуация, когда модель слишком проста или недостаточно обучена и не улавливает закономерности: ошибка высока и на обучении, и на валидации.
→ overfitting_underfitting

### Universal approximation theorem (теорема об универсальной аппроксимации)
Утверждение, что нейросеть с одним скрытым слоем достаточной ширины и неполиномиальной активацией может сколь угодно точно приблизить любую непрерывную функцию на компакте. Теорема не говорит, как найти такие веса и сколько нужно данных.
→ universal_approximation_theorem

### Unsupervised learning (обучение без учителя)
Поиск структуры в данных без размеченных ответов: кластеризация, снижение размерности, оценка плотности, поиск аномалий.
→ kmeans, dimensionality_reduction

## V

### Value function (функция ценности)
Ожидаемая дисконтированная сумма наград при следовании политике π: из состояния — V^π(s), из состояния с конкретным первым действием — Q^π(s, a).
→ dynamic_programming_rl, q_learning_sarsa

### Vanishing gradient (затухание градиента)
Экспоненциальное уменьшение градиентов при распространении через много слоёв или шагов времени, из-за чего ранние слои почти не обучаются. Смягчается ReLU, остаточными связями, нормализацией, LSTM/GRU.
→ vanishing_gradient, rnn_basics

### Variance (дисперсия)
Мера разброса случайной величины вокруг среднего: Var(X) = E[(X − E[X])²]. Квадратный корень из дисперсии — стандартное отклонение.
→ probability_theory, statistical_methods

### Variational autoencoder (вариационный автоэнкодер, VAE)
Генеративный автоэнкодер, энкодер которого выдаёт параметры распределения q(z | x), а обучение максимизирует ELBO: ошибка реконструкции плюс KL к априорному N(0, I). Даёт гладкое латентное пространство, но более размытые образцы, чем GAN.
→ vae

### Variational inference (вариационный вывод)
Приближение трудного апостериорного распределения p(z | x) распределением q(z) из простого семейства через максимизацию ELBO (эквивалентно минимизации KL(q ‖ p)). Быстрее MCMC, но смещено к выбранному семейству.
→ variational_inference, bayesian_neural_networks

### Vector database (векторная база данных)
Хранилище эмбеддингов с индексами приближённого поиска ближайших соседей (HNSW, IVF). Используется в RAG, семантическом поиске и рекомендациях.
→ modern_trends_deep_learning, cross_modal_retrieval

### Vision Transformer (визуальный трансформер, ViT)
Трансформер для изображений: картинка делится на патчи (например, 16 × 16), каждый линейно проецируется в токен, добавляются позиционные эмбеддинги и класс-токен. Требует больших данных или предобучения.
→ vision_transformers_vit

## W

### Warmup (прогрев скорости обучения)
Постепенное увеличение скорости обучения от малого значения в первые шаги обучения. Стабилизирует начало обучения, особенно для трансформеров и больших батчей.
→ learning_rate_scheduling

### Weight decay (затухание весов)
Уменьшение весов на каждом шаге: θ ← θ − ηλθ. При SGD эквивалентно L2-регуляризации, при адаптивных оптимизаторах — нет (см. AdamW).
→ optimizers_advanced, regularization

### Weight initialization (инициализация весов)
Выбор начальных значений весов так, чтобы дисперсия активаций и градиентов сохранялась от слоя к слою. Схема Ксавье–Глоро (дисперсия 2 / (n_in + n_out)) рассчитана на tanh, схема Хе (2 / n_in) — на ReLU; нулевая инициализация не работает из-за симметрии нейронов.
→ weight_initialization

### Word2Vec (модель Word2Vec)
Неглубокая модель обучения эмбеддингов слов по контексту: CBOW предсказывает слово по окружению, skip-gram — окружение по слову (обычно с негативным сэмплированием). Векторы отражают семантические аналогии.
→ word_embeddings

## X

### XGBoost (библиотека XGBoost)
Реализация градиентного бустинга с регуляризацией листьев, разложением потерь второго порядка, обработкой пропусков и параллельным построением деревьев.
→ xgboost

## Y

### YOLO (детектор «смотришь один раз»)
You Only Look Once — семейство одноэтапных детекторов, предсказывающих рамки и классы за один проход сети; ориентировано на работу в реальном времени.
→ yolo

## Z

### Zero-shot learning (обучение без примеров)
Распознавание классов, не встречавшихся при обучении, через вспомогательное описание (атрибуты, текст). Например, CLIP классифицирует изображения по текстовым названиям классов.
→ zero_shot_learning, clip_multimodal_models
