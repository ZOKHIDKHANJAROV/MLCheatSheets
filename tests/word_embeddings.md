# Векторные представления слов (Word2Vec, GloVe, FastText) — мини-тест

## Почему one-hot векторы «кошка» и «котёнок» не отражают их смысловой близости?
- [ ] Потому что one-hot вектор имеет слишком малую размерность для хранения смысла слова в признаках
- [x] Потому что любые два разных one-hot вектора ортогональны, и сходство равно нулю
- [ ] Потому что one-hot векторы нельзя подавать в нейросеть из-за большой разреженности
- [ ] Потому что one-hot вектор кодирует только длину слова и его первую букву

**Почему.** One-hot вектор длиной со словарь имеет единственную единицу, поэтому для любых разных слов сходство нулевое: «кошка» так же далека от «котёнка», как от «бетономешалки». Эмбеддинг — плотный вектор (50–300 чисел), где близкие по смыслу слова расположены рядом.

## Как FastText строит вектор для слова, которого не было в обучающем корпусе?
- [x] Суммирует векторы его символьных n-грамм, которые встречались в других словах
- [ ] Подставляет нулевой вектор и помечает слово как `[UNK]`, после чего игнорирует его
- [ ] Берёт вектор самого частого слова из словаря с похожей длиной и первой буквой
- [ ] Усредняет векторы всех слов предложения, в котором оно встретилось, и нормирует

**Почему.** FastText представляет слово как сумму векторов символьных n-грамм (обычно n = 3–6) и вектора самого слова, поэтому может собрать вектор для незнакомой словоформы из известных кусочков. Word2Vec и GloVe для слов вне словаря вектора не имеют.

## Векторы a = (1, 2, 2) и b = (2, 1, 2). Чему равно косинусное сходство cos(a, b)?
- [ ] 8/3 ≈ 2.667
- [ ] 0
- [x] 8/9 ≈ 0.89
- [ ] 2/3 ≈ 0.67

**Почему.** a·b = 1·2 + 2·1 + 2·2 = 8, ‖a‖ = √9 = 3, ‖b‖ = √9 = 3, поэтому cos = 8 / (3·3) = 8/9 ≈ 0.89. Значение 8/3 получится, если поделить только на одну из норм, а косинус всегда лежит в [−1, 1].

## Зачем в Word2Vec используют negative sampling?
- [ ] Чтобы увеличить размерность эмбеддингов за счёт «шумовых» координат, добавляемых к каждому вектору
- [x] Чтобы не считать softmax по всему словарю, а решать задачу «настоящая пара или случайная»
- [ ] Чтобы удалить из корпуса слишком частые слова вроде предлогов и союзов до обучения
- [ ] Чтобы получать разные векторы для разных смыслов одного слова в разных контекстах

**Почему.** Знаменатель в p(o | c) — сумма по всему словарю, что дорого на каждом шаге. Negative sampling заменяет его классификацией настоящей пары против k случайных «шумовых» слов. Отбрасыванием частых слов занимается subsampling, а разные смыслы слова даёт только контекстный эмбеддинг.

## Какие утверждения верны? (выберите все верные)
- [x] Skip-gram по центральному слову предсказывает слова контекста и лучше работает на редких словах
- [ ] Word2Vec даёт слову «ключ» разный вектор в зависимости от предложения
- [x] GloVe подбирает векторы так, чтобы скалярное произведение приближало логарифм счётчиков совместной встречаемости
- [ ] Для сравнения эмбеддингов лучше евклидово расстояние, поскольку длина вектора несёт смысл слова

**Почему.** Skip-gram и GloVe описаны верно. Word2Vec, GloVe и FastText — статические эмбеддинги: один вектор на слово (контекстные дают BERT и подобные модели). Длина вектора связана с частотой слова, а смысл — с направлением, поэтому используют косинусное сходство.
