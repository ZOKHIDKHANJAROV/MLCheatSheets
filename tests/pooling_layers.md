# Пулинг-слои (Max, Average, Global Pooling) — мини-тест

## Сколько обучаемых параметров у слоя `nn.MaxPool2d(2)` и что он делает с числом каналов?
- [ ] Столько же, сколько в окне — четыре веса на канал; число каналов уменьшается вдвое
- [ ] Один параметр на канал; число каналов не меняется
- [x] Ноль параметров; число каналов не меняется, уменьшаются только высота и ширина
- [ ] Ноль параметров; число каналов уменьшается вдвое вместе с размерами карты

**Почему.** Пулинг — фиксированная операция (максимум или среднее), обучаемых весов в нём нет. Окно скользит по каждой карте признаков отдельно, поэтому каналы сохраняются; уменьшать их число — задача свёртки 1×1.

## Через окно 2×2 max pooling проходит градиент 4 от следующего слоя. Окно содержит значения [[1, 3], [5, 6]]. Как он распределится при обратном распространении?
- [ ] Поровну по 1 на каждый элемент окна
- [ ] Весь градиент 4 получит элемент 1, потому что он первый в окне
- [x] Весь градиент 4 получит элемент 6, остальные получат 0
- [ ] Градиент разделится пропорционально значениям: 1/15, 3/15, 5/15, 6/15 от 4

**Почему.** Max pooling передаёт градиент только в тот элемент окна, который оказался максимальным (здесь 6). Равное деление по 1 — это поведение average pooling.

## Почему сеть с global average pooling перед классификатором может принимать картинки разного размера, а сеть с `Flatten` — нет?
- [x] После GAP длина вектора равна числу каналов и не зависит от H и W, а после Flatten она равна C·H·W
- [ ] Global average pooling масштабирует любое изображение до фиксированного размера ещё до первого слоя
- [ ] У Flatten нет весов, поэтому он не умеет работать с изменяющимся размером
- [ ] Global average pooling добавляет к маленьким картинкам нулевой паддинг до нужного размера

**Почему.** GAP усредняет каждую карту целиком, и на выходе получается вектор из C чисел при любых H и W. После Flatten размер C·H·W определяет число входов полносвязного слоя, поэтому сеть привязана к одному размеру входа (и параметров у головы больше).

## Карта признаков размером 7×7 проходит через `MaxPool2d(kernel_size=2, stride=2)` без паддинга. Каков размер выхода?
- [ ] 4×4
- [ ] 3.5×3.5
- [x] 3×3
- [ ] 2×2

**Почему.** Размер выхода равен ⌊(7 − 2)/2⌋ + 1 = 3. Последние строка и столбец не попадают ни в одно окно и отбрасываются; чтобы их сохранить, используют `ceil_mode=True` (тогда получится 4×4).

## Нужно получить для каждого канала одно число, показывающее, есть ли признак хоть где-нибудь на карте, не важно где именно. Какую операцию взять?
- [ ] `AvgPool2d` с окном 2×2
- [ ] `Flatten` с последующим полносвязным слоем
- [x] Global max pooling
- [ ] Свёртку 1×1

**Почему.** Максимум по всей карте сильный, если признак проявился хотя бы в одной точке: результат — одно число на канал. `AvgPool2d` 2×2 лишь сжимает карту, `Flatten` сохраняет все позиции, а свёртка 1×1 меняет число каналов, но не сворачивает карту.
