# Тесты

`tests/<тема>.md` — мини-тест к теме (имя совпадает с именем шпаргалки без `_cheatsheet.html`). Портал показывает его
кнопкой «📝 Тест» у шпаргалки и собирает из вопросов всех тем этапа итоговый тест этапа.

Формат:

```markdown
# Название — мини-тест

## Текст вопроса (можно с `кодом` и с блоком кода до вариантов)
- [ ] неверный вариант
- [x] верный вариант
- [ ] неверный вариант

**Почему.** Разбор: почему верный вариант верен и в чём ошибка у остальных (1–3 предложения).
```

Правила (проверяет `python tools/check_project.py`):

- 4–12 вопросов на тему (обычно 5), у вопроса 3–6 вариантов;
- хотя бы один верный и один неверный вариант; если верных несколько, портал попросит выбрать все (в тексте вопроса напишите «(выберите все верные)»);
- варианты одной строкой, без повторов; порядок портал перемешивает сам, поэтому верный вариант не должен «выдавать себя» длиной или словами «все перечисленные»;
- у каждого вопроса есть «**Почему.**»;
- Python-код в вопросах должен разбираться (`ast.parse`); формулы — юникодом, LaTeX портал не показывает.

Образец — [gradient_descent.md](gradient_descent.md).
