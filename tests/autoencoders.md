# Автоэнкодеры — мини-тест

## Почему автоэнкодер, у которого код z той же длины, что и вход, и достаточно мощные слои, обычно бесполезен?
- [ ] Без узкого слоя энкодер не может обучаться градиентным спуском
- [ ] Для такой сети нельзя посчитать ошибку восстановления входа
- [ ] При совпадении размеров входа и кода автоэнкодеру требуется разметка классов
- [x] Сеть может выучить тождественное отображение и ничего не извлечь

**Почему.** Цель автоэнкодера — восстановить свой вход, и без ограничения проще всего скопировать его. Поэтому нужно «горлышко» (короткий код), шум на входе (denoising) или штраф за активность нейронов (sparse). Метки автоэнкодеру не нужны вообще, а градиентный спуск работает при любой ширине слоя.

## Как построить детектор аномалий на автоэнкодере, если в данных нет размеченных аномалий?
- [ ] Обучить на всех данных и считать аномалиями объекты, восстановленные почти идеально
- [x] Обучить на нормальных примерах и отмечать объекты с ошибкой выше порога
- [ ] Обучить классификатор на размеченных аномалиях, взяв энкодер как источник признаков
- [ ] Увеличить размер кода z до размера входа, чтобы лучше выделять выбросы

**Почему.** Сеть, обученная на нормальных данных, хорошо восстанавливает похожее и плохо — непохожее. Порог берут, например, как 99-й перцентиль ошибки на обучающих данных. Идеально восстановленные объекты — как раз типичные, а расширение кода только помогает сети копировать любой вход.

## Энкодер 784 → 128 → 32 состоит из двух полносвязных слоёв со смещениями (bias). Сколько у него обучаемых параметров?
- [x] 104 608
- [ ] 104 448
- [ ] 100 480
- [ ] 25 088

**Почему.** Первый слой: 784·128 + 128 = 100 480, второй: 128·32 + 32 = 4 128. Всего 104 608. Значение 104 448 получается без смещений, 100 480 — это только первый слой, а 25 088 = 784·32 — прямое отображение вход → код, которого в сети нет.

## Нужно генерировать новые изображения, подавая в декодер случайные точки латентного пространства. Какой автоэнкодер подойдёт?
- [ ] Обычный (undercomplete) с узким кодом
- [ ] Denoising: он устойчив к шуму, поэтому случайная точка тоже сработает
- [x] Вариационный (VAE): энкодер выдаёт распределение, а не одну точку
- [ ] Contractive: штраф на чувствительность кода делает пространство плотным

**Почему.** У обычного автоэнкодера латентное пространство «дырявое»: случайный z обычно даёт «кашу». VAE учит распределение в латентном пространстве, поэтому из него можно сэмплировать. Denoising и contractive меняют регуляризацию, но не делают латентное пространство пригодным для сэмплирования.

## Какие утверждения верны? (выберите все верные)
- [x] Автоэнкодер с одним линейным слоем кода и MSE находит то же подпространство, что и PCA
- [ ] Sparse-автоэнкодер требует, чтобы код был короче входа
- [x] В denoising-автоэнкодере на вход подают зашумлённый x, а восстанавливать нужно чистый x
- [ ] Ошибка восстановления — это вероятность того, что объект является аномалией

**Почему.** Линейный автоэнкодер эквивалентен PCA, а denoising-вариант восстанавливает чистый вход по испорченному. Sparse-автоэнкодер, наоборот, допускает длинный код: ограничением служит штраф за число активных нейронов. Ошибка восстановления не вероятность, порог приходится подбирать на валидации.
