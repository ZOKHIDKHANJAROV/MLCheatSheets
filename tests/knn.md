# k-ближайших соседей (k-NN) — мини-тест

## Что делает метод `fit` у `KNeighborsClassifier`?
- [x] Запоминает обучающую выборку (и, возможно, строит структуру для поиска соседей)
- [ ] Подбирает веса признаков градиентным спуском, минимизируя ошибку на обучающей выборке
- [ ] Вычисляет центры классов (центроиды) и сохраняет только их, а саму выборку отбрасывает
- [ ] Заранее считает и кэширует попарные расстояния между всеми тестовыми и обучающими объектами

**Почему.** k-NN — «ленивое» обучение: настоящей оптимизации нет, `fit` хранит данные (иногда строит KD-дерево или Ball tree). Вся работа — расстояния, выбор k соседей и голосование — происходит в момент прогноза.

## Новый клиент: возраст 30 лет, доход 50 000 ₽. В обучающей выборке два кандидата: A — (31 год, 60 000 ₽), B — (60 лет, 50 500 ₽). Какой из них окажется ближайшим по евклидову расстоянию на сырых данных и почему это проблема?
- [ ] A, потому что возраст у него почти совпадает с возрастом клиента; проблема масштаба признаков не возникает
- [ ] A, потому что евклидово расстояние сравнивает только возраст, а доход учитывается лишь при равенстве возрастов
- [x] B, потому что разница в доходе (10 000) полностью перевешивает разницу в возрасте и определяет расстояние
- [ ] Расстояния до A и B равны, так как оба признака учитываются в формуле одинаково, независимо от масштаба

**Почему.** До A: √(1² + 10000²) ≈ 10 000, до B: √(30² + 500²) ≈ 501. Признак с крупным масштабом (рубли) полностью определяет расстояние, поэтому признаки нужно приводить к одному масштабу (`StandardScaler`, `MinMaxScaler`).

## Как меняется поведение k-NN при увеличении k от 1 до размера обучающей выборки?
- [ ] Граница становится более изрезанной: дисперсия падает, смещение остаётся прежним, а при k = n модель запоминает все точки
- [x] Граница сглаживается: дисперсия падает, смещение растёт, при k = n выдаётся самый частый класс
- [ ] Ошибка на обучающей выборке растёт, а на новых данных падает, поэтому лучшим считается k = n
- [ ] Качество не меняется, k влияет только на скорость прогноза, так как соседи всё равно голосуют одинаково

**Почему.** При k = 1 модель повторяет ближайший пример (ошибка на обучении нулевая, высокая дисперсия, переобучение). При большом k усреднение идёт по огромной окрестности — недообучение. Оптимальное k ищут кросс-валидацией.

## Какие утверждения о k-NN верны? (выберите все верные)
- [ ] Для высокоразмерных сырых данных k-NN особенно надёжен, так как соседей становится больше
- [x] Для каждого нового объекта нужно считать расстояния до всей обучающей выборки, поэтому прогноз на больших данных медленный
- [x] В пространстве высокой размерности расстояния до ближайшего и до дальнего объекта становятся почти одинаковыми
- [ ] Косинусное расстояние сильно зависит от длины векторов, а не от их направления

**Почему.** Это два главных практических недостатка: стоимость прогноза и проклятие размерности (помогают PCA, отбор признаков, приближённый поиск FAISS/Annoy/HNSW). Косинусное расстояние учитывает направление, поэтому подходит для текстов и эмбеддингов.

## Для объекта найдены 3 соседа с ответами 10, 20 и 60 на расстояниях 1, 1 и 2. Каким будет прогноз регрессии при весах, обратно пропорциональных расстоянию (вес = 1/d)?
- [ ] 30
- [ ] 20
- [ ] 37.5
- [x] 24

**Почему.** Веса: 1, 1, 0.5. Прогноз = (10·1 + 20·1 + 60·0.5) / (1 + 1 + 0.5) = 60 / 2.5 = 24. Обычное среднее без весов дало бы 30: далёкий сосед с большим ответом влиял бы сильнее. Значение 37.5 получится, если взять веса, пропорциональные расстоянию, а не обратные ему.
