# Многорукие бандиты — мини-тест

## У трёх баннеров истинные конверсии 0.04, 0.05 и 0.07 (агенту неизвестны). За 1000 показов стратегия показала их 500, 300 и 200 раз соответственно. Чему равен regret R(T) = T·μ* − Σ μ(aₜ)?
- [ ] 0.021
- [x] 21
- [ ] 49
- [ ] 30

**Почему.** Лучшая рука даёт μ* = 0.07, поэтому «идеальная» сумма 1000·0.07 = 70. Реальная ожидаемая сумма: 500·0.04 + 300·0.05 + 200·0.07 = 20 + 15 + 14 = 49. Regret = 70 − 49 = 21. Значение 49 — это полученная ожидаемая награда, а не недополученная, а 0.021 — средний regret за один показ, а не суммарный.

## В чём главная слабость ε-жадной стратегии с постоянным ε?
- [x] Она исследует вслепую: доля ε попыток уходит на уже изученные руки, поэтому regret растёт линейно
- [ ] Она не исследует вообще: берёт руку с лучшим средним и поэтому может надолго застрять на плохой руке после неудачных первых показов
- [ ] Она не может работать с бинарными конверсиями, так как требует непрерывных наград с нормальным шумом
- [ ] Она выбирает руку с наименьшим числом показов, а не с лучшим средним, поэтому медленно сходится

**Почему.** С вероятностью ε выбирается случайная рука, независимо от накопленных знаний, поэтому потери примерно ε·T·(средний разрыв) растут линейно. UCB и Thompson Sampling направляют исследование туда, где неопределённость велика, и получают логарифмический regret.

## Алгоритм UCB(a) = Q̂(a) + c·√(ln t / N(a)) при c = 1 и ln t ≈ 4. У руки A среднее Q̂ = 0.50 и N = 100 показов, у руки B среднее Q̂ = 0.40 и N = 16 показов. Какую руку выберет UCB?
- [ ] Руку A, так как у неё выше среднее вознаграждение: 0.50 против 0.40 у руки B
- [ ] Руку A, так как у неё больше показов, а значит оценка среднего надёжнее и бонус больше
- [x] Руку B: UCB(B) = 0.40 + 0.5 = 0.90 больше, чем UCB(A) = 0.50 + 0.2 = 0.70
- [ ] Обе руки с равной вероятностью, так как UCB выбирает руку случайно при близких значениях

**Почему.** Бонус за неопределённость уменьшается с ростом N(a): для A он √(4/100) = 0.2, для B √(4/16) = 0.5. Рука с малым числом наблюдений может оказаться лучшей, поэтому UCB «оптимистично» проверяет её. Жадный выбор взял бы A.

## В Thompson Sampling для конверсий используется априорное распределение Beta(1, 1). Какое распределение будет у руки после 3 кликов и 7 некликов?
- [ ] Beta(3, 7)
- [x] Beta(4, 8)
- [ ] Beta(10, 10)
- [ ] Beta(8, 4)

**Почему.** После s успехов и f неудач апостериорное распределение равно Beta(1 + s, 1 + f) = Beta(1 + 3, 1 + 7) = Beta(4, 8). Из него на каждом шаге сэмплируют правдоподобную конверсию для каждой руки и выбирают руку с максимальным сэмплом.

## Какие утверждения о бандитах и A/B-тестах верны? (выберите все верные)
- [x] Бандит постепенно отдаёт больше показов лучшим вариантам, поэтому во время эксперимента теряет меньше, чем фиксированный A/B-сплит
- [ ] Из-за адаптивного распределения трафика бандит надёжнее A/B-теста даёт строгий вывод о разнице вариантов
- [x] Контекстный бандит (например, LinUCB) учитывает признаки пользователя при выборе руки
- [ ] Для выбора баннера нужен A/B-тест, а бандиты применимы только к игровым автоматам

**Почему.** Бандит максимизирует награду во время обучения, но неравное распределение трафика усложняет строгий статистический вывод об эффекте; для знания нужен эксперимент. Выбор заголовков, баннеров и рекомендаций — типичные применения бандитов.
