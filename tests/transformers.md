# Архитектура Transformer — мини-тест

## Зачем к эмбеддингам токенов добавляют позиционное кодирование?
- [x] Потому что само по себе внимание не знает порядка слов
- [ ] Чтобы замаскировать будущие токены в декодере и скрыть padding
- [ ] Чтобы увеличить размерность эмбеддингов до d_model
- [ ] Чтобы нормализовать длину векторов токенов

**Почему.** Self-attention обрабатывает множество токенов и не различает их порядок: перестановка слов даёт те же связи. Поэтому к эмбеддингам добавляют информацию о позиции (синусоиды в исходной статье, обучаемые позиции в BERT, RoPE в современных LLM). Маскирует будущее каузальная маска, а не позиционное кодирование.

## Что произойдёт при обучении декодера, если убрать каузальную маску в self-attention?
- [ ] Обучение станет заметно медленнее, но итоговое качество генерации не изменится
- [x] Токен сможет смотреть на будущие позиции и подглядывать ответ, поэтому модель ничему не научится
- [ ] Модель перестанет учитывать предыдущие токены и будет опираться только на текущий
- [ ] Внимание станет считаться только по соседним токенам в окне из нескольких позиций

**Почему.** При обучении правильная последовательность известна целиком, и без маски предсказание следующего токена опирается на сам этот токен. Метрики на обучении выглядят невероятно хорошими, а при генерации модель бесполезна. Предыдущие токены маска не скрывает.

## Какое утверждение о семействах трансформеров верно?
- [ ] Decoder-only модели вроде GPT используют cross-attention к выходу энкодера
- [ ] Encoder-only модели вроде BERT обучаются предсказывать следующий токен с каузальной маской
- [ ] Encoder–decoder модели вроде T5 не содержат self-attention
- [x] Encoder-only модели видят весь текст в обе стороны и подходят для классификации и NER

**Почему.** BERT-подобные энкодеры смотрят на контекст слева и справа и обучаются восстанавливать замаскированные токены, поэтому хороши для понимания текста. GPT — это декодер с каузальной маской без cross-attention, а в T5 есть и self-attention, и cross-attention.

## Длину входа увеличили с 512 до 1024 токенов. Во сколько раз вырастет размер матрицы весов внимания (токены × токены) в одной голове одного слоя?
- [ ] В 2 раза, линейно по n
- [ ] В 3 раза
- [x] В 4 раза
- [ ] В 8 раз, кубически по n

**Почему.** Матрица внимания имеет размер n × n, то есть растёт как n²: 512² = 262 144, а 1024² = 1 048 576, то есть ровно в 4 раза. Именно квадратичная стоимость ограничивает длину контекста у многих моделей.

## Какая формула описывает блок Pre-LN, который используют в большинстве современных моделей?
- [x] x + Sublayer(LayerNorm(x))
- [ ] Sublayer(x) + LayerNorm(x)
- [ ] LayerNorm(x + Sublayer(x))
- [ ] LayerNorm(Sublayer(x)) без остаточной связи

**Почему.** В Pre-LN нормализуется вход подслоя, а остаточная «основная дорога» x остаётся чистой, поэтому глубокие модели обучаются стабильнее. Вариант LayerNorm(x + Sublayer(x)) — это Post-LN из исходной статьи, он требует аккуратного warmup.
