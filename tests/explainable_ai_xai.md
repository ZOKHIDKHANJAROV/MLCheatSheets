# Explainable AI (XAI) — мини-тест

## Что такое контрфактическое объяснение?
- [x] Минимальное изменение входа, после которого решение модели меняется
- [ ] Список признаков, перемешивание которых сильнее всего ухудшает качество
- [ ] Простое дерево, обученное повторять ответы чёрного ящика
- [ ] Средняя зависимость прогноза от одного признака по всей выборке

**Почему.** Контрфактическое объяснение отвечает на вопрос «что нужно изменить, чтобы решение стало другим», например «кредит одобрили бы при доходе на 15% выше». Список признаков по ухудшению качества — это permutation importance, обученное дерево — глобальный суррогат, а средняя зависимость — PDP.

## Дерево глубины 3 обучено повторять ответы случайного леса (глобальный суррогат). Его верность (fidelity) на тесте равна 0.89. Что это значит?
- [ ] Дерево правильно классифицирует 89% объектов тестовой выборки
- [ ] Лес правильно предсказывает 89% истинных меток
- [x] Для около 89% объектов дерево даёт тот же ответ, что и лес
- [ ] Дерево объясняет 89% суммарной важности признаков леса

**Почему.** Fidelity измеряет согласие суррогата с чёрным ящиком, а не с истинными метками, так как суррогат учится на ответах модели. Для остальных 11% объектов его правила описывают лес неверно, и об этом нужно говорить честно: суррогат — приблизительная копия, а не сама модель.

## Модель сильно опирается на признак X, и это показал и SHAP, и permutation importance. Какой вывод корректен?
- [ ] Признак X — причина целевого события, и изменение X в реальности изменит исход
- [x] Модель использует X для прогноза, но причинной связи в мире отсюда не следует
- [ ] Признак X нужно считать защищённым, так как он важен для модели
- [ ] Остальные признаки можно удалить: они не влияют на качество

**Почему.** Объяснение описывает модель, а не мир: X может быть коррелирован с настоящей причиной или быть её заменителем. Для причинных выводов нужны эксперименты или методы причинного вывода. Важность X ничего не говорит о его защищённом статусе и не означает, что остальные признаки бесполезны.

## Для кредитного скоринга под жёстким регулированием логистическая регрессия даёт качество, сравнимое с градиентным бустингом. Что разумнее выбрать?
- [ ] Бустинг с LIME, потому что объяснение пост-фактум всегда точнее собственных коэффициентов модели
- [ ] Бустинг с SHAP, потому что SHAP-вклады делают модель интерпретируемой и точной одновременно
- [ ] Бустинг с глобальным суррогатом, потому что суррогат полностью воспроизводит все решения бустинга
- [x] Логистическую регрессию, потому что её объяснение (коэффициенты) точно описывает саму модель

**Почему.** Если интерпретируемая модель даёт сравнимое качество, это лучший выбор: её объяснение точное по определению. Внешние методы объясняют чёрный ящик приближённо: LIME нестабилен, а суррогат совпадает с моделью лишь в доле случаев (fidelity).

## Какие методы относятся к локальным, то есть объясняют конкретное предсказание? (выберите все верные)
- [ ] PDP
- [x] LIME
- [x] ICE
- [ ] Permutation importance

**Почему.** LIME строит локальную линейную аппроксимацию вокруг одного объекта, а ICE показывает зависимость прогноза от признака для каждого объекта отдельно. PDP усредняет эту зависимость по выборке, а permutation importance оценивает вклад признака в качество модели в целом — оба метода глобальные.
