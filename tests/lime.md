# LIME — мини-тест

## Как LIME объясняет предсказание модели-«чёрного ящика» для объекта x₀?
- [x] Генерирует возмущённые точки около x₀ и подгоняет по ответам модели простую линейную модель
- [ ] Оценивает глобальную важность признаков, перемешивая их значения по всей выборке и измеряя падение качества на отложенных данных
- [ ] Вычисляет вклад каждого признака как значение Шепли, усредняя по всем коалициям признаков с фоновыми значениями
- [ ] Берёт градиенты выхода модели по входам, поэтому требует доступа к её весам и архитектуре

**Почему.** LIME нужен только доступ к `predict` / `predict_proba` (model-agnostic): ответы модели на возмущениях приближаются линейной моделью, веса которой — локальные вклады признаков. Значения Шепли — это SHAP, перемешивание признаков — permutation importance.

## В LIME возмущённые точки взвешиваются ядром π(z) = exp(−d²/σ²), где d — расстояние от z до x₀. Каков вес точки при σ = 2 и d = 2?
- [ ] 1
- [ ] около 0.61
- [x] около 0.37
- [ ] около 0.135

**Почему.** d²/σ² = 4/4 = 1, поэтому π = e⁻¹ ≈ 0.37. Вес убывает с расстоянием: близкие к x₀ точки важнее для подгонки, потому что линейное приближение хорошо только рядом с объясняемым объектом.

## Два запуска LIME для одного и того же объекта дали разные веса признаков. Почему так бывает и что делать?
- [ ] Модель недетерминирована между запусками; нужно переобучить её с другим `random_state` и сравнить результаты
- [x] Возмущения генерируются случайно; помогают фиксированный `random_state` и увеличение числа возмущений `num_samples`
- [ ] LIME считает значения Шепли приближённо методом Монте-Карло; нужно увеличить число признаков в объяснении и глубину перебора коалиций
- [ ] Это ошибка реализации библиотеки, при корректной работе результат для одного объекта должен быть полностью идентичен

**Почему.** Случайность — в выборке возмущений, поэтому объяснения нестабильны (SHAP для деревьев в этом смысле детерминирован). Стабильность повышают зафиксированный seed, большее `num_samples` и проверка устойчивости результата.

## Для объяснения LIME сообщает низкий `score` (R² локальной модели на возмущениях, например 0.1). Что это значит?
- [ ] Объясняемое предсказание чёрного ящика, скорее всего, неверно, и модель нужно переобучить
- [ ] Признаки в объяснении почти не влияют на предсказание, поэтому объяснение считается надёжным и стабильным
- [ ] Число возмущений слишком велико, и его нужно уменьшить, чтобы линейная модель лучше сошлась
- [x] Линейная модель плохо приближает чёрный ящик даже рядом с x₀, объяснению доверять нельзя

**Почему.** R² показывает, насколько локальная линейная модель воспроизводит ответы чёрного ящика на возмущениях. Низкое значение означает, что рядом с x₀ поведение сильно нелинейно (например, резкий скачок у порога дерева). Это не оценка правильности самого предсказания.

## Какие утверждения о подводных камнях LIME верны? (выберите все верные)
- [x] Результат заметно зависит от ширины ядра: слишком широкое ядро делает объяснение не локальным
- [ ] Веса LIME показывают причинное влияние признаков на исход в реальном мире
- [x] Шум, добавленный к признакам независимо, может создавать нереалистичные объекты, например при коррелированных признаках
- [ ] Для работы LIME нужны веса и архитектура объясняемой модели

**Почему.** Ядро определяет, что считать окрестностью, а независимые возмущения не учитывают корреляции признаков. LIME описывает, на что реагирует модель, а не причинность, и использует только её ответы.
