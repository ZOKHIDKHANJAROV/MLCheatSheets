# ResNet — мини-тест

## Обычная сеть из 56 слоёв показала большую ошибку, чем сеть из 20 слоёв. Почему это не называют переобучением?
- [ ] Потому что переобучение возникает только у сетей с BatchNorm, а в обычной сети его нет
- [ ] Потому что у 56-слойной сети слишком мало параметров, чтобы переобучиться на выборке
- [x] Потому что ошибка выросла уже на обучающей выборке, а при переобучении она падает
- [ ] Потому что 56 слоёв — меньше порога в сотню слоёв, после которого начинается переобучение

**Почему.** Это проблема деградации: глубокую обычную сеть сложно оптимизировать, и она хуже подгоняется даже под train. При переобучении ошибка на обучении низкая, а на тесте высокая. Параметров у глубокой сети, наоборот, больше.

## Что даёт слагаемое 1 в формуле ∂y/∂x = 1 + ∂F/∂x для блока y = x + F(x)?
- [x] Прямой путь для градиента, не затухающий в ветви F
- [ ] Уменьшение числа параметров блока за счёт общих весов
- [ ] Гарантию, что ∂F/∂x равно нулю на всём протяжении обучения
- [ ] Нормировку градиента к единичной длине на каждом слое

**Почему.** Сложение пропускает градиент назад «как есть», поэтому он доходит до ранних слоёв, даже если вклад ветви F мал. Skip-связь не уменьшает число параметров и ничего не нормирует; ветвь F продолжает обучаться.

## Вход блока: 64 канала, 56×56. Блок должен выдать 128 каналов размером 28×28 (stride 2). Что нужно поставить на skip-связь, чтобы сложение F(x) + x было возможным?
- [ ] Ничего: тождественное отображение, форма выровняется при сложении
- [ ] Max pooling 2×2 со stride 2
- [ ] Свёртку 3×3 со stride 1 и 64 фильтрами
- [x] Свёртку 1×1 со stride 2 и 128 фильтрами

**Почему.** Складывать можно только тензоры одинаковой формы. Проекция 1×1 со stride 2 уменьшает размер вдвое и приводит число каналов к 128. Max pooling изменил бы лишь размер, а не число каналов, а тождественное отображение даст ошибку несовпадения форм.

## В bottleneck-блоке 3×3-свёртка работает на 64 каналах (64 → 64), тогда как «прямая» 3×3-свёртка на 256 каналах (256 → 256). Во сколько раз у первой меньше весов (смещения не считаем)?
- [ ] В 4 раза
- [x] В 16 раз
- [ ] В 8 раз
- [ ] В 64 раза

**Почему.** Число весов 3×3-свёртки равно 9·c_in·c_out: 9·64·64 = 36 864 против 9·256·256 = 589 824. Отношение равно (256/64)² = 16. Именно поэтому bottleneck сжимает каналы 1×1-свёрткой перед дорогой свёрткой 3×3.

## Какие утверждения о ResNet верны? (выберите все верные)
- [x] Блок учит остаток F(x) = H(x) − x, а его выход равен F(x) + x
- [ ] Благодаря skip-связям BatchNorm в ResNet не нужен
- [ ] Тождественная skip-связь добавляет столько же параметров, сколько вся ветвь F(x)
- [x] В базовом блоке ReLU применяется после сложения F(x) и x

**Почему.** В оригинальном блоке `x → Conv → BN → ReLU → Conv → BN → (+ x) → ReLU`: остаток складывается со входом, затем применяется ReLU. BatchNorm в блоках остаётся, а тождественная skip-связь параметров не содержит вовсе.
