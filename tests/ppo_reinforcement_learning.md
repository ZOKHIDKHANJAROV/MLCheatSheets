# PPO (Proximal Policy Optimization) — мини-тест

## Для ε = 0.2 в clipped-цели PPO min(r·A, clip(r, 1 − ε, 1 + ε)·A) взяли r = 0.6 и A = −2. Чему равно значение цели?
- [ ] 0.6 · (−2) = −1.2
- [x] −1.6
- [ ] −2.0
- [ ] −0.8

**Почему.** Необрезанное слагаемое: 0.6·(−2) = −1.2. Обрезанное: clip(0.6; 0.8; 1.2) = 0.8, то есть 0.8·(−2) = −1.6. Берётся минимум, то есть −1.6: при A < 0 выгода от уменьшения r ниже 1 − ε обрезается (цель не растёт дальше).

## Что происходит с градиентом clipped-цели PPO, если A > 0 и отношение вероятностей уже r > 1 + ε?
- [ ] Градиент меняет знак, и политику возвращают обратно к r = 1 до границы доверия
- [x] Градиент по этому примеру равен нулю: расти r дальше нет смысла
- [ ] Градиент увеличивается пропорционально r, чтобы быстрее довести политику до оптимума
- [ ] Пример исключается из батча до конца итерации и больше не используется

**Почему.** При A > 0 и r > 1 + ε минимум достигается на обрезанном слагаемом clip(r)·A, которое от θ не зависит, поэтому градиент нулевой. Знак он не меняет: если политика ушла в плохую сторону (A < 0, большое r), min оставляет необрезанный штраф, и градиент возвращает её.

## Чем PPO принципиально отличается от TRPO?
- [ ] PPO — off-policy метод с replay buffer, а TRPO — on-policy метод без повторного использования данных
- [ ] PPO использует вторые производные для шага и не имеет KL-ограничения, а TRPO — только первые, как SGD
- [x] PPO заменяет жёсткое ограничение на KL обрезкой в цели и обходится методом первого порядка
- [ ] PPO не использует отношение вероятностей r, а оценивает шаг по значению KL-расстояния между политиками

**Почему.** TRPO максимизирует E[r·A] при ограничении KL(π_old ‖ π_θ) ≤ δ и требует методов второго порядка (сопряжённые градиенты, линейный поиск). PPO достигает похожей устойчивости обрезкой clip(r, 1 − ε, 1 + ε) и обычным Adam; оба метода on-policy и оба используют отношение r.

## Как параметр λ влияет на оценку преимущества в GAE?
- [ ] При λ = 0 оценка несмещённая и точная, а при λ = 1 — с минимальной дисперсией и полностью без влияния критика
- [x] При λ = 0 одна TD-ошибка (малая дисперсия, смещение), при λ = 1 — возврат минус V (нет смещения, большая дисперсия)
- [ ] λ определяет, на сколько можно менять политику за один шаг обновления, и целиком заменяет собой параметр ε в обрезке цели
- [ ] λ задаёт долю энтропийного бонуса в функции потерь, поощряя исследование среды во время обучения

**Почему.** GAE — сумма Σ(γλ)ˡ·δ(t+l). При λ = 0 остаётся δ(t): шума мало, но оценка смещена неточным критиком. При λ = 1 получается G(t) − V(s(t)): смещения нет, но дисперсия большая. Шаг политики ограничивает ε, а вес энтропии задаёт c₂.

## На последнем шаге эпизода (done = 1) получена награда r = 1, критик оценивает V(s(t)) = 0.5, а ценность первого состояния следующего эпизода равна 0.5; γ = 0.99, λ = 0.95. Чему равно преимущество GAE на этом шаге?
- [ ] 0.995
- [ ] 1.0
- [ ] 0.0
- [x] 0.5

**Почему.** При done = 1 бутстрап обнуляется: δ = r + γ·V(следующее)·(1 − done) − V(s) = 1 + 0 − 0.5 = 0.5, а будущих слагаемых в сумме нет. Значение 0.995 получится, если ошибочно прибавить ценность из следующего эпизода (1 + 0.99·0.5 − 0.5).
