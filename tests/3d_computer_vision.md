# 3D Computer Vision — мини-тест

## Почему по одной обычной фотографии нельзя однозначно восстановить расстояние до объекта?
- [ ] Фокусное расстояние f у обычной камеры невозможно определить даже калибровкой по шахматной доске
- [x] Все точки на одном луче через центр камеры дают один и тот же пиксель
- [ ] Дисторсия объектива искажает пиксели настолько, что информация о расстоянии полностью пропадает
- [ ] Цветовые каналы RGB кодируют яркость слишком грубо, поэтому по ним нельзя оценить глубину сцены

**Почему.** В модели камеры-обскуры координаты делятся на глубину Z: u = f·X/Z + cx, поэтому точки (X, Y, Z) и (2X, 2Y, 2Z) попадают в один пиксель. Фокусное расстояние и дисторсию как раз определяют калибровкой, а цвет к потере глубины отношения не имеет.

## Две откалиброванные параллельные камеры: f = 800 пикселей, база B = 0.12 м. Диспаритет точки равен 16 пикселей. Какова глубина Z?
- [ ] 12 м
- [ ] 3 м
- [ ] 1.5 м
- [x] 6 м

**Почему.** Z = f·B/d = 800·0.12/16 = 96/16 = 6 м. Глубина обратно пропорциональна диспаритету: уменьшите d вдвое, и Z удвоится; поэтому на больших расстояниях ошибка в один пиксель сильно меняет оценку.

## Какой приём делает PointNet независимым от порядка точек в облаке?
- [x] Один общий MLP на каждую точку, затем максимум по каждому каналу
- [ ] Облако переводится в воксельную сетку, а порядок точек задаётся индексами ячеек
- [ ] Точки подаются в рекуррентную сеть в фиксированном порядке по координате x
- [ ] К каждой точке применяется отдельный MLP со своими весами в порядке следования точек

**Почему.** Максимум по каждому каналу — симметричная функция: от перестановки точек он не меняется, поэтому инвариантна вся сеть. Воксели — это другой подход (VoxelNet), рекуррентная сеть зависит от порядка входа, а отдельные веса для каждой позиции, наоборот, привязали бы сеть к порядку.

## Как изменится объём памяти воксельной сетки, если разрешение удвоить по каждой из трёх осей?
- [ ] Вырастет в 2 раза
- [ ] Вырастет в 4 раза
- [x] Вырастет в 8 раз
- [ ] Вырастет в 6 раз

**Почему.** Сетка трёхмерная, число ячеек пропорционально N³, поэтому при N → 2N получаем 2³ = 8. Это главный недостаток вокселей и причина, по которой для детекции используют, например, «столбики» PointPillars.

## Какие утверждения верны? (выберите все верные)
- [x] Для далёких объектов диспаритет мал, поэтому ошибка в один пиксель сильно меняет оценку глубины
- [ ] Монокулярная нейросеть надёжно оценивает абсолютный масштаб сцены в метрах
- [x] Без калибровки (матрица K и дисторсия) пиксели нельзя перевести в метры
- [ ] NeRF рендерит сцену в реальном времени быстрее, чем 3D Gaussian Splatting

**Почему.** Точность стерео падает с расстоянием, а метрические измерения требуют калибровки. По одному кадру сеть оценивает в основном относительную глубину, а NeRF как раз медленный в обучении и рендеринге, тогда как Gaussian Splatting рендерит в реальном времени.
