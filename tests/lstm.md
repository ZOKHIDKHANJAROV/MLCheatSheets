# LSTM — мини-тест

## Чем состояние ячейки Cₜ отличается от скрытого состояния hₜ в LSTM?
- [ ] Cₜ — это выход слоя на текущем шаге, который подаётся дальше, а hₜ — долгосрочная память, недоступная наружу
- [ ] Это одно и то же состояние, которое просто хранится в двух копиях для удобства реализации в PyTorch
- [x] Cₜ — долгосрочная «лента памяти», а hₜ = oₜ ⊙ tanh(Cₜ) — то, что ячейка выдаёт наружу на этом шаге и передаёт дальше
- [ ] hₜ обновляется сложением с вентилями, а Cₜ на каждом шаге полностью переписывается через tanh без забывания

**Почему.** Cₜ проходит через шаги почти без изменений и меняется только забыванием и записью. Выходной вентиль oₜ решает, какую часть tanh(Cₜ) выдать как hₜ — краткосрочное «рабочее» состояние.

## Почему градиент в LSTM затухает медленнее, чем в простой RNN?
- [ ] Потому что в LSTM нет функций активации, а значит нечему сжимать производную на каждом шаге
- [x] Потому что память обновляется сложением, и градиент по Cₜ умножается лишь на fₜ, а не на матрицу весов
- [ ] Потому что вентили зафиксированы на значении 1 и ничего не забывают, поэтому градиент не меняется
- [ ] Потому что у LSTM в четыре раза больше параметров, а значит, градиенты по ним получаются заметно больше по величине

**Почему.** В простой RNN состояние на каждом шаге проходит через умножение на матрицу и tanh, и сигнал с градиентом гаснут. У LSTM путь по Cₜ почти линейный: пока вентиль забывания близок к 1, информация и градиент сохраняются, и сеть сама учится, когда держать вентиль открытым.

## На шаге t: Cₜ₋₁ = 2, вентиль забывания fₜ = 0.5, входной вентиль iₜ = 0.8, кандидат C̃ₜ = −1. Чему равно Cₜ?
- [ ] 1.8
- [ ] 0
- [ ] −0.8
- [x] 0.2

**Почему.** Cₜ = fₜ·Cₜ₋₁ + iₜ·C̃ₜ = 0.5·2 + 0.8·(−1) = 1 − 0.8 = 0.2. Старая память умножается на fₜ, а новая порция — на iₜ, и они складываются.

## По формуле из лекции число параметров слоя LSTM равно 4·[hidden·(hidden + input) + hidden]. Сколько параметров у слоя с hidden = 10 и input = 5?
- [ ] 160
- [ ] 1 280
- [x] 640
- [ ] 480

**Почему.** Один блок: 10·(10 + 5) + 10 = 160. У LSTM четыре блока (три вентиля и кандидат в память), итого 4·160 = 640. У простой RNN того же размера было бы только 160 параметров, 480 — у слоя с тремя блоками (как у GRU), а 1 280 — у двунаправленного слоя.

## Что содержит `last` в этом коде и какова его форма?
```python
import torch
import torch.nn as nn

lstm = nn.LSTM(1, 64, num_layers=2, batch_first=True)
x = torch.randn(32, 10, 1)
out, (h_n, c_n) = lstm(x)
last = out[:, -1, :]
```
- [x] Скрытое состояние последнего слоя на последнем шаге, форма (32, 64)
- [ ] Выходы последнего слоя на всех 10 шагах для каждого окна в батче, форма (32, 10, 64)
- [ ] Состояние ячейки c_n первого слоя на последнем шаге, форма (2, 32, 64)
- [ ] Прогноз следующего значения ряда для каждого окна, форма (32, 1)

**Почему.** `out` содержит выходы последнего слоя для всех шагов, форма (batch, timesteps, hidden) = (32, 10, 64). Срез `[:, -1, :]` берёт последний шаг, остаётся (32, 64). Прогноз (32, 1) появился бы только после линейного слоя `nn.Linear(64, 1)`.
