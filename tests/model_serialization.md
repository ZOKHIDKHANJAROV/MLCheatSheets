# Сериализация моделей — мини-тест

## Почему в продакшен лучше сохранять весь `Pipeline`, а не только обученный классификатор?
- [ ] Потому что классификатор без пайплайна нельзя сохранить через `joblib`, поскольку отдельные оценщики не поддерживают сериализацию в pickle-формате
- [ ] Потому что пайплайн ускоряет предсказания в несколько раз за счёт объединения шагов в один вызов
- [ ] Потому что в пайплайне модель сохраняется без обученных весов, и поэтому файл получается меньше и безопаснее
- [x] Потому что скейлер и кодировщики с найденными на обучении параметрами сохраняются вместе с моделью

**Почему.** Если сохранить только классификатор, в сервисе придётся повторять предобработку вручную: признаки могут оказаться не масштабированы или закодированы иначе, и предсказания будут неверными без каких-либо ошибок. Внутри `Pipeline` все параметры хранятся вместе.

## Вы скачали из интернета файл `model.joblib` с готовой моделью. Чем опасно вызвать `joblib.load` на нём?
- [ ] Ничем: joblib проверяет файл на безопасность и отсутствие исполняемого кода перед загрузкой объекта
- [ ] Только тем, что модель может оказаться слишком большой и не поместиться в оперативную память сервера
- [x] Загрузка может выполнить произвольный код из файла, как и `pickle.load`, с правами вашего процесса
- [ ] Только тем, что файл не загрузится из-за другой операционной системы или разрядности Python

**Почему.** Форматы pickle и joblib могут содержать исполняемые инструкции, поэтому нельзя загружать их из недоверенных источников. Для обмена моделями безопаснее форматы без исполняемого кода (ONNX, `safetensors`, нативные форматы бустингов) и проверка контрольной суммы файла.

## Модель scikit-learn сохранили в одной версии библиотеки, а в сервисе установлена другая. Что может произойти и как это предотвратить?
- [x] Файл может не загрузиться или дать другие предсказания; помогают фиксация версий и сравнение прогнозов на контрольной выборке
- [ ] Ничего, так как файл содержит только числа весов и параметров, которые не зависят от версии библиотеки, поэтому загрузка пройдёт штатно
- [ ] Модель автоматически переобучится под новую версию библиотеки при загрузке на сохранённых обучающих данных, и качество вырастет
- [ ] Загрузка завершится ошибкой при любом расхождении версий, поэтому проблему легко заметить на этапе деплоя

**Почему.** pickle и joblib сохраняют внутреннее устройство объекта конкретной версии, а не «модель вообще». Поэтому версии пишут в метаданные и `requirements.txt`, сервис собирают в том же окружении, что и обучение, а после обновления сравнивают прогнозы.

## Сервис загрузил веса PyTorch-модели с Dropout, но предсказания для одного и того же входа от запроса к запросу различаются. Чего, скорее всего, не хватает?
```python
model = MyNet()
model.load_state_dict(torch.load("weights.pt", weights_only=True))
```
- [ ] Повторного вызова `torch.save` сразу после загрузки весов, чтобы зафиксировать их значения в файле
- [ ] Замены `state_dict` на сохранение объекта модели целиком вместе с архитектурой через pickle
- [ ] Увеличения параметра `compress` до 9 при загрузке, чтобы веса считывались точнее и без потерь
- [x] Вызова `model.eval()`, чтобы Dropout и BatchNorm перешли в режим инференса вместо режима обучения

**Почему.** Загрузка весов не меняет режим модели: по умолчанию слои Dropout и BatchNorm работают как при обучении, и прогнозы «плавают». Перед инференсом нужно вызвать `model.eval()` (обычно вместе с `torch.no_grad()`).

## Какие утверждения верны? (выберите все верные)
- [x] ONNX-модель можно запускать в ONNX Runtime без исходного фреймворка, в том числе из C++ или Java
- [ ] `state_dict` PyTorch содержит код класса модели, поэтому для загрузки достаточно одного файла
- [x] Контрольная сумма SHA-256 позволяет убедиться, что загружается именно тот файл модели, который сохраняли
- [ ] Файл `.joblib` безопасно загружать, если он получен с чужого сервера, но имеет расширение `.joblib`

**Почему.** `state_dict` хранит только тензоры весов, поэтому для загрузки нужен код класса модели. Расширение файла ничего не гарантирует о его содержимом: недоверенные pickle/joblib загружать нельзя.
