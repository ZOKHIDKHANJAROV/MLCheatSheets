# SHAP значения — мини-тест

## Базовое значение модели φ₀ = 0.30, а SHAP-вклады признаков для некоторого объекта равны +0.50, −0.20 и +0.10 (других признаков нет). Какой прогноз получен для этого объекта?
- [x] 0.70
- [ ] 0.400
- [ ] 1.100
- [ ] 0.900

**Почему.** По свойству аддитивности f(x) = φ₀ + Σφⱼ = 0.30 + 0.50 − 0.20 + 0.10 = 0.70. Вариант 0.40 получается, если забыть базовое значение, а 1.10 — если сложить вклады по модулю.

## Почему вычисление значений Шепли прямо по определению непрактично при сотне признаков?
- [ ] Формула требует обратить матрицу ковариаций признаков размера 100×100, а это численно неустойчиво
- [ ] Для каждого признака нужно заново обучать модель на всех объектах, а это занимает недели
- [x] Нужно оценить модель для 2^M подмножеств признаков — число астрономическое
- [ ] Значения Шепли определены только для моделей не более чем с десятью признаками

**Почему.** В формуле суммирование идёт по всем подмножествам остальных признаков, их 2^(M−1) на каждый признак, поэтому точный расчёт для M = 100 нереален. Поэтому используют специальные алгоритмы: `TreeExplainer` для деревьев (точно и полиномиально) и приближения вроде `KernelExplainer`.

## Что является главным подводным камнем при интерпретации SHAP для сильно коррелированных признаков?
- [ ] Свойство аддитивности перестаёт выполняться, и сумма вкладов уже не равна разности прогноза и базового значения
- [x] Признак «отключают» подстановкой фона независимо от остальных, и возникают нереалистичные объекты
- [ ] `TreeExplainer` отказывается работать с такими данными и выдаёт ошибку про мультиколлинеарность
- [ ] Вклад любого из таких признаков всегда оказывается равным нулю, так как они дублируют друг друга

**Почему.** Чтобы убрать признак, его подменяют фоновыми значениями, не учитывая связь с другими признаками; получаются комбинации вроде «рост 2 м при весе 40 кг», и распределение вкладов между коррелированными признаками выглядит странно. Аддитивность при этом сохраняется, а нулевой вклад бывает только у признака, который не влияет на модель.

## Нужно понять, почему модель выдала высокую вероятность дефолта конкретному клиенту. Какой график подходит лучше всего?
- [x] `shap.plots.waterfall` для одного объекта
- [ ] `shap.plots.beeswarm` по всей тестовой выборке
- [ ] `shap.plots.bar`, где показан средний |φ| по всем объектам
- [ ] `shap.plots.scatter` для одного признака

**Почему.** Waterfall раскладывает прогноз одного объекта: от базового значения вклады признаков шаг за шагом приводят к итоговому прогнозу. Bar и beeswarm дают глобальную картину по всем объектам, а scatter (dependence) показывает, как вклад одного признака зависит от его значения.

## Какие утверждения о SHAP верны? (выберите все верные)
- [x] Признак, который никак не влияет на модель, получает нулевой вклад
- [ ] Большой вклад признака означает, что изменение этого признака причинно изменит исход в реальном мире
- [x] Два признака, влияющих на модель одинаково, получают одинаковые вклады
- [ ] Для классификатора XGBoost `TreeExplainer` по умолчанию раскладывает вероятность, а не логит

**Почему.** Нулевой игрок и симметрия — свойства значений Шепли. SHAP объясняет, как модель использует признаки, а не причинность в мире. Для XGBoost-классификатора раскладывается логит (log-odds), вероятность получают сигмоидой.
