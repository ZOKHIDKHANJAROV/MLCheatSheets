# Полиномиальная регрессия — мини-тест

## Почему модель ŷ = β₀ + β₁x + β₂x² называют линейной, хотя график зависимости от x — парабола?
- [ ] Потому что степень полинома не превышает двух, а такие кривые считаются линейными
- [ ] Потому что признак x предварительно масштабируется до [0, 1], и парабола выглядит прямой
- [x] Потому что веса β входят в формулу линейно, а x и x² — это обычные признаки
- [ ] Потому что ошибка ε в модели имеет нормальное распределение с нулевым средним

**Почему.** Линейность понимается по параметрам: ŷ — линейная комбинация столбцов 1, x, x². Поэтому подходят МНК, регуляризация и остальные инструменты линейной регрессии, хотя по самому x зависимость нелинейна.

## Сколько столбцов (включая константу) создаст `PolynomialFeatures(degree=2)` для 4 исходных признаков?
- [ ] 14
- [x] 15
- [ ] 10
- [ ] 1 + 4 + 4 = 9

**Почему.** Число столбцов равно C(n + d, d) = C(6, 2) = 15: константа, 4 исходных признака, 4 квадрата и 6 попарных произведений (1 + 4 + 4 + 6). Число 14 получится, если забыть про константу, а 9 — если забыть про попарные произведения.

## Как правильно выбирать степень полинома?
- [ ] По минимуму ошибки на обучающей выборке: чем она меньше, тем лучше степень
- [ ] По максимуму R² на обучающей выборке, затем проверить на тесте и при необходимости увеличить степень
- [x] По ошибке на кросс-валидации, ведь на train ошибка почти всегда падает с ростом степени
- [ ] Всегда брать степень 2, потому что она универсальна для любых кривых

**Почему.** Чем выше степень, тем лучше модель подгоняется под train, вплоть до прохождения почти через каждую точку, поэтому выбор по train приводит к максимальной степени. Кросс-валидация показывает качество на данных, которых модель не видела, и обычно имеет U-образную форму.

## Полином степени 5 обучили на данных из диапазона x ∈ [0, 10] и применили для прогноза при x = 20. Что, скорее всего, произойдёт?
- [ ] Прогноз будет точным, потому что полином — гладкая бесконечно дифференцируемая функция
- [ ] Прогноз останется в пределах значений, встреченных при обучении, ведь полином ограничен
- [x] Прогноз может сильно отклониться: за пределами данных полином высокой степени быстро растёт
- [ ] Прогноз улучшится, если после обучения убрать масштабирование признаков и пересчитать степени

**Почему.** Полиномы высокой степени колеблются у границ данных и быстро растут за их пределами, поэтому экстраполировать ими не стоит. Для гладких зависимостей часто лучше подходят сплайны или регуляризация.

## Модель `PolynomialFeatures(degree=2)` + `LinearRegression` обучили на точках x = 1, 2, 3, 4, 5 с y = 2, 7, 18, 35, 58. Какой прогноз она даст при x = 6?
- [ ] 58 + 17 = 75
- [ ] 81
- [ ] 93
- [x] 87

**Почему.** Первые разности y равны 5, 11, 17, 23, вторые — постоянно 6, значит, данные точно описываются параболой y = 3x² − 4x + 3. При x = 6: 3·36 − 24 + 3 = 87. Варианты 81 и 93 получились бы при ошибочной следующей разности 23 или 35 вместо 29.
