# Частичные зависимости (PDP) — мини-тест

## Чему равна частичная зависимость PD_a(v) для признака a при v = 2?
```python
import numpy as np

f = lambda a, b: a * b           # «модель»
X = np.array([[0, 1],
              [2, 3]])           # столбцы: a, b
v = 2
```
- [x] 4
- [ ] 2 + 6 = 8
- [ ] 2
- [ ] 3

**Почему.** Во всех строках признак a заменяют на v = 2, оставляя b как есть, и усредняют прогнозы: (f(2, 1) + f(2, 3)) / 2 = (2 + 6) / 2 = 4. Значение 3 — это среднее прогнозов на исходных данных (0 и 6), то есть без подстановки v, а 8 — сумма прогнозов без деления на число строк.

## PDP по признаку получился плоским. Что из этого следует?
- [ ] Признак не влияет на прогноз, поэтому его можно удалить из модели без потерь
- [ ] Модель переобучена на этом признаке и выучила шум вместо зависимости
- [x] Эффекты могли усредниться: у одних объектов прогноз растёт, у других падает
- [ ] Сетка слишком мелкая, число её точек нужно уменьшить, чтобы убрать шум

**Почему.** PDP — среднее ICE-кривых, а усреднение может спрятать противоположные эффекты. Плоская PDP не доказывает, что признак не важен; нужно посмотреть на разброс ICE-кривых, который выявляет взаимодействия.

## Почему при сильно коррелированных признаках PDP может вводить в заблуждение?
- [ ] PDP игнорирует коррелированные признаки и показывает только их среднее
- [ ] Корреляция уменьшает число объектов, и сетка вырождается
- [ ] PDP усредняет по условному распределению, и эффект смешивается с коррелированными признаками
- [x] Подстановка создаёт нереальные объекты, где модель экстраполирует; вместо PDP берут ALE

**Почему.** PDP подставляет значение признака во все строки, поэтому появляются объекты вроде квартиры в 200 м² с одной комнатой — таких в данных нет, и модель на них предсказывает как придётся. ALE считает эффект по малым изменениям внутри реальных данных и устойчив к корреляциям. Усреднение по условному распределению — это M-plot, а не PDP.

## ICE-кривые для признака идут веером и пересекаются. О чём это говорит?
- [ ] Признак не влияет на прогноз, так как кривые не совпадают друг с другом
- [x] Признак взаимодействует с другими, одной кривой PDP недостаточно
- [ ] Модель линейная, поэтому кривые разных объектов различаются по наклону
- [ ] Сетку надо было строить по min–max значений, а не по перцентилям

**Почему.** Параллельные ICE-кривые означают, что эффект одинаков для всех объектов и PDP хорошо его описывает. Расхождение веером или пересечения — признак взаимодействия с другими признаками. У линейной модели ICE-кривые параллельны: у всех объектов наклон равен коэффициенту.

## Какие утверждения о PDP верны? (выберите все верные)
- [x] PDP model-agnostic: для построения нужен только вызов `predict`
- [ ] PDP показывает, что произойдёт в реальности, если изменить признак
- [x] Для линейной модели PDP — прямая с наклоном, равным коэффициенту при признаке
- [ ] Сетку лучше строить по min–max, чтобы покрыть все значения

**Почему.** PDP описывает поведение модели, а не причинный эффект в реальном мире. Сетку по min–max строить не стоит: выбросы растягивают ось, а на краях данных мало и кривая ненадёжна, поэтому берут перцентили (например, от 5-го до 95-го).
