# Policy Gradient методы — мини-тест

## В каких ситуациях методы градиента политики удобнее value-based методов вроде DQN?
- [ ] Когда нужно повторно использовать старые траектории из replay buffer без поправок
- [x] Когда действия непрерывные или оптимальной является стохастическая политика
- [ ] Когда нужно, чтобы метод был максимально эффективным по числу собранных данных
- [ ] Когда политика должна всегда выбираться как argmax по Q

**Почему.** Для непрерывных действий взять max по Q на каждом шаге трудно, а argmax даёт только детерминированную политику. Policy gradient параметризует распределение действий напрямую. Зато он on-policy и обычно требует больше данных, чем DQN с replay buffer.

## Зачем в REINFORCE из возврата G вычитают baseline b(s), например V(s)?
- [ ] Чтобы сделать градиент смещённым в сторону более ценных состояний, ускоряя старт
- [ ] Чтобы убрать необходимость сэмплировать эпизоды и считать возвраты по ним
- [x] Чтобы снизить дисперсию оценки градиента, не меняя его матожидание
- [ ] Чтобы политика стала детерминированной и перестала исследовать среду

**Почему.** E[∇ log π(a | s)] = 0, поэтому вычитание не зависящего от действия b(s) не смещает градиент. При этом множитель «лучше или хуже обычного» шумит заметно меньше. Эпизоды по-прежнему нужны.

## Эпизод даёт награды r₁ = 1, r₂ = 0, r₃ = 2, коэффициент дисконтирования γ = 0.5. Чему равен возврат G₀ = r₁ + γ·r₂ + γ²·r₃?
- [ ] 3.0
- [ ] 2.25
- [x] 1.5
- [ ] 1.0

**Почему.** G₀ = 1 + 0.5·0 + 0.25·2 = 1.5. Значение 3.0 получится без дисконтирования, а 2.25 — если дисконт ошибочно применить в обратном порядке (2 + 0.5·0 + 0.25·1).

## Что произойдёт, если в PyTorch минимизировать `loss = +log π(a | s) · G` вместо `−log π(a | s) · G`?
- [ ] Обучение останется корректным, изменится только масштаб градиента и скорость сходимости
- [ ] Политика станет более стохастической, но средний возврат вырастет за счёт исследования
- [ ] Градиент станет нулевым, и параметры не изменятся ни на одном шаге обучения
- [x] Вероятности действий с положительным возвратом будут падать, политика ухудшится

**Почему.** Градиент политики — это подъём по J(θ), поэтому для минимизатора нужен минус. Со знаком плюс спуск уменьшает log π для действий с большим G, то есть учит худшую политику.

## Чем actor-critic отличается от REINFORCE с baseline?
- [ ] Критик выбирает действия вместо актёра, а актёр лишь оценивает ценность состояний V(s)
- [ ] Actor-critic даёт несмещённую оценку градиента, а REINFORCE — смещённую, потому что ждёт конца эпизода
- [x] Критик оценивает V(s), поэтому преимущество считают через TD-ошибку и обновляются на каждом шаге
- [ ] В actor-critic не нужна нейросеть политики, достаточно одной таблицы ценностей состояний

**Почему.** Критик V(s; w) оценивает ценность состояния, а преимущество A ≈ r + γV(s′) − V(s) не требует ждать конца эпизода. Это ещё сильнее снижает дисперсию ценой небольшого смещения; политику по-прежнему выбирает и обновляет актёр.
