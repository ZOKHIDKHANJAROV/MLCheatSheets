# Ридж, Лассо, ElasticNet — мини-тест

## Почему Lasso может обнулить вес признака, а Ridge почти никогда этого не делает?
- [ ] Ridge штрафует только свободный член, а Lasso штрафует все веса модели
- [ ] Lasso штрафует сильнее, поэтому веса доходят до нуля даже при очень малом α
- [ ] Ridge решается лишь приближённо, поэтому точный ноль в его решении не получается
- [x] У |w| давление постоянно даже у малых весов, а у w² оно (2w) убывает вместе с весом

**Почему.** Производная L1-штрафа равна ±1 при любом w ≠ 0: если признак снижает ошибку меньше, чем это постоянное давление, вес выгодно занулить. У L2-штрафа давление 2w слабеет при приближении к нулю, поэтому вес останавливается рядом с нулём, но не в нём. Свободный член не штрафуется ни в одном методе.

## Дано: MSE = 2.0, веса w = [3, −2, 0], α = 0.5. Чему равна функция потерь Lasso, L = MSE + α · Σ|wⱼ|?
- [ ] 8.50
- [x] 4.5
- [ ] 2.50
- [ ] 7.000

**Почему.** Σ|wⱼ| = 3 + 2 + 0 = 5, штраф = 0.5·5 = 2.5, итого L = 2 + 2.5 = 4.5. Значение 8.5 — это потеря Ridge (штраф по квадратам: 0.5·13 = 6.5), 2.5 получится, если суммировать веса со знаками, а 7.0 — если забыть умножить на α.

## Признак x₁ измерен в рублях (значения порядка 10⁶), а x₂ — то же самое, но в миллионах рублей (значения порядка 1). Как поведёт себя штраф без масштабирования?
- [x] Для x₂ нужен вес в ~10⁶ раз больше, поэтому штраф давит его сильнее
- [ ] Штраф одинаков для обоих признаков, так как зависит только от значения α
- [ ] Штраф сильнее подавит x₁, потому что его значения в миллион раз больше
- [ ] Штраф не зависит от масштаба признаков, если используется Lasso, а не Ridge

**Почему.** Величина веса зависит от единиц признака: при больших числах нужен крошечный вес, при малых — большой. Поскольку штраф считается по весам, признак с малыми числами наказывается несправедливо сильно. Поэтому перед регуляризацией признаки стандартизируют, лучше внутри `Pipeline`.

## Признаков больше, чем объектов, и многие образуют группы сильно коррелированных. Нужен ещё и отбор признаков. Что выбрать?
- [ ] Ridge: он зануляет лишние признаки и тем самым отбирает полезные для модели
- [ ] Lasso: он стабильно сохраняет все признаки из каждой коррелированной группы
- [x] ElasticNet: L1 отбирает признаки, а L2 устойчиво делит вес внутри групп
- [ ] Обычную линейную регрессию без регуляризации, но с большим числом эпох

**Почему.** Lasso из группы почти одинаковых признаков оставляет один, причём выбор почти случаен и меняется от выборки к выборке. Ridge не обнуляет веса, а без регуляризации при p > n и мультиколлинеарности модель переобучается. ElasticNet совмещает отбор и устойчивость.

## Какие утверждения о регуляризации верны? (выберите все верные)
- [x] При `l1_ratio=1` штраф ElasticNet совпадает со штрафом Lasso
- [ ] Свободный член штрафуется так же, как остальные веса
- [ ] У `LogisticRegression` параметр `C` работает как `alpha`: чем больше, тем сильнее регуляризация
- [x] При α = 0 штрафа нет, и получается обычная линейная регрессия

**Почему.** `l1_ratio` — доля L1-штрафа: 1 соответствует чистому Lasso, 0 — Ridge. Свободный член не штрафуется, он отвечает только за средний уровень ответа. У `LogisticRegression` параметр обратный: C = 1/α, поэтому меньший C означает более сильную регуляризацию.
