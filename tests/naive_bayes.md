# Наивный Байес — мини-тест

## Что предполагает «наивное» допущение в наивном Байесе?
- [ ] Признаки не зависят друг от друга ни при каком условии
- [x] Признаки независимы при известном классе
- [ ] Все классы встречаются в обучающих данных одинаково часто
- [ ] Каждый признак распределён нормально внутри каждого класса

**Почему.** Допущение — условная независимость: P(x₁, …, xₙ | класс) = P(x₁ | класс) · … · P(xₙ | класс). Безусловная независимость не требуется (слова одной темы явно связаны), априорные вероятности классов оцениваются по их долям, а нормальность нужна только варианту GaussianNB.

## В классе «обычное письмо» в обучающей выборке всего 10 вхождений слов, размер словаря — 20, слово «приз» в этом классе не встречалось. Чему равна P(«приз» | обычное) со сглаживанием Лапласа при α = 1?
- [ ] 0
- [ ] 1/10 (если не добавить α · размер словаря к знаменателю)
- [x] 1/30
- [ ] 1/20 (если делить на размер словаря вместо суммы)

**Почему.** По формуле (count + α) / (всего слов в классе + α · размер словаря) = (0 + 1) / (10 + 1 · 20) = 1/30. Значения 1/10 и 1/20 получаются, если забыть добавить α · размер словаря в знаменатель или поделить на размер словаря; ноль — это ответ без сглаживания, он обнулил бы вероятность всего класса.

## Модель выдала для письма вероятность спама 0.999, хотя на отложенной выборке такие письма оказываются спамом заметно реже. Почему вероятности наивного Байеса получаются такими и что с ними делать, если они нужны для расчёта риска?
- [x] Коррелирующие признаки учитываются как независимые, вероятности слишком уверенные; их калибруют
- [ ] Модель недообучена, и вероятности получаются заниженными; нужно увеличить α и добавить признаков
- [ ] Вероятности верны, а порядок классов искажён; нужна стандартизация признаков и повторное обучение
- [ ] Сглаживание Лапласа стягивает вероятности к 0.5; нужно поставить α = 0 и пересчитать модель

**Почему.** Из-за допущения о независимости связанные слова («бесплатный», «приз») считаются как независимые улики, и модель «пересчитывает» их, отсюда близкие к 0 и 1 вероятности. Порядок классов при этом обычно сохраняется, поэтому классификация хорошая, а вероятности перед использованием нужно калибровать (например, `CalibratedClassifierCV`).

## Плотный массив счётчиков слов стандартизировали и передали в `MultinomialNB`. Что произойдёт?
```python
from sklearn.preprocessing import StandardScaler
from sklearn.naive_bayes import MultinomialNB

X_std = StandardScaler().fit_transform(X_counts)
MultinomialNB().fit(X_std, y)
```
- [ ] Модель обучится, а стандартизация улучшит качество на счётчиках слов
- [ ] Модель обучится, но будет игнорировать признаки с малой дисперсией после масштабирования
- [ ] Модель сама переключится на нормальное распределение признаков, как GaussianNB
- [x] Ошибка: стандартизация даёт отрицательные значения, а MultinomialNB их не принимает

**Почему.** `MultinomialNB` рассчитан на неотрицательные признаки (счётчики, TF-IDF), а стандартизация сдвигает значения в область отрицательных. Для непрерывных признаков нужен `GaussianNB`, которому масштабирование не требуется.

## Какие утверждения о наивном Байесе верны? (выберите все верные)
- [ ] Знаменатель P(x) нужно считать, иначе нельзя выбрать самый вероятный класс
- [x] Логарифмы вероятностей складывают, чтобы произведение тысяч малых чисел не стало машинным нулём
- [ ] При α = 0 невиданное слово лишь слегка снижает вероятность класса
- [x] Для GaussianNB стандартизация не нужна: у каждого признака в каждом классе свои среднее и дисперсия

**Почему.** P(x) одинаков для всех классов, поэтому для выбора максимума его считать не нужно. При α = 0 невиданное слово даёт нулевую вероятность и обнуляет всё произведение для класса. Сумма логарифмов спасает от потери точности, а GaussianNB оценивает среднее и дисперсию по каждому признаку отдельно.
