# Q-learning и SARSA — мини-тест

## Чем отличается TD-цель в Q-learning и SARSA?
- [ ] Q-learning берёт Q(s', a') для реально выбранного действия a', а SARSA — максимум по действиям
- [ ] Q-learning усредняет Q(s', ·) по всем действиям, а SARSA берёт максимум
- [x] Q-learning берёт максимум Q(s', ·), а SARSA — Q(s', a') для реально выбранного действия a'
- [ ] Оба берут максимум, а различаются только значением скорости обучения α

**Почему.** Q-learning использует r + γ·max Q(s', ·) и поэтому оценивает жадную политику (off-policy). SARSA использует r + γ·Q(s', a') для действия, которое агент действительно сделает, включая случайные шаги, — отсюда on-policy. Первый вариант в списке путает алгоритмы местами.

## Дано: Q(s, a) = 2, α = 0.5, γ = 0.9, r = 1, значения Q(s', ·) = [4, 6]. Каким станет Q(s, a) после обновления Q-learning (при выборе a' в s' ε-жадная политика случайно выбрала действие со значением 4)?
- [x] 4.2
- [ ] 3.3
- [ ] 6.4
- [ ] 3.25

**Почему.** Q-learning игнорирует выбранное a' и берёт максимум: цель = 1 + 0.9·6 = 6.4, TD-ошибка = 6.4 − 2 = 4.4, новое Q = 2 + 0.5·4.4 = 4.2. Значение 3.3 дал бы SARSA (цель 1 + 0.9·4 = 4.6), а 6.4 — это сама цель, без шага α.

## Почему при обучении с ε-жадным выбором действий Q-learning в cliff walking получает меньшую среднюю награду за эпизод, чем SARSA?
- [ ] Он не получает штраф за падение в обрыв и поэтому не различает опасные и безопасные клетки
- [x] Он выучивает кратчайший путь вдоль обрыва, а случайные шаги иногда сбрасывают агента вниз
- [ ] SARSA использует модель среды P(s' | s, a) и заранее знает, где именно находится обрыв
- [ ] Он обновляет таблицу Q только в конце эпизода, как Монте-Карло, поэтому учится заметно медленнее

**Почему.** Цель Q-learning не учитывает случайные шаги исследования, поэтому оптимальным кажется путь у самого края. Но во время обучения агент действует ε-жадно и временами падает, что снижает среднюю награду. SARSA учитывает исследование и выбирает безопасный, более длинный путь. Оба алгоритма model-free и обновляются на каждом шаге.

## Чему равна TD-цель, если s' — терминальное состояние?
- [ ] r + γ · max Q(s', ·)
- [ ] r + γ · Q(s', a')
- [ ] γ · max Q(s', ·)
- [x] r

**Почему.** После терминального состояния будущего нет, поэтому цель — просто полученная награда. Ошибка в этом месте (добавление γ·Q(s', ·) для терминального s') искажает все ценности.

## Какие утверждения верны? (выберите все верные)
- [ ] Для обновления SARSA необходимы вероятности переходов среды P(s' | s, a)
- [x] SARSA оценивает ценность той ε-жадной политики, которой следует сам агент
- [ ] Таблица Q(s, a) подходит и для задач с огромным числом состояний, например для шахмат
- [x] Q-learning можно учить на старых записях опыта, так как его цель не зависит от политики, выбравшей a'

**Почему.** SARSA on-policy: она учит ценность текущей политики вместе с её исследованием. Цель Q-learning использует максимум, а не действие поведенческой политики, поэтому годится и старый опыт (на этом основан replay buffer в DQN). Оба алгоритма работают без модели среды, а табличные методы не масштабируются на огромные пространства состояний.
