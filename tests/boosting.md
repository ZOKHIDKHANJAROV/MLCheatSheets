# Градиентный бустинг — мини-тест

## На что обучается каждое новое дерево в градиентном бустинге для регрессии с MSE?
- [ ] На исходные ответы y, но с повышенным весом для редких объектов выборки
- [ ] На случайную подвыборку исходных ответов y независимо от остальных деревьев
- [ ] На ответы y, предварительно умноженные на текущий learning rate
- [x] На остатки y − F(x) текущей модели, то есть антиградиент MSE

**Почему.** Для MSE остаток y − F — это (с точностью до множителя) антиградиент потерь по прогнозу, поэтому каждое дерево сдвигает прогнозы в сторону наибольшего уменьшения ошибки. Обучение на исходных y независимо — это уже бэггинг, а не бустинг.

## Бустинг для регрессии: целевые значения y = (2, 4, 12), начальный прогноз F₀ — среднее, learning rate η = 0.5. Первое дерево идеально предсказывает остатки. Какой прогноз получит объект с y = 12 после добавления дерева?
- [ ] 3
- [ ] 6
- [x] 9
- [ ] 12

**Почему.** Среднее равно 6, остаток объекта равен 12 − 6 = 6. Обновление F ← F + η·h даёт 6 + 0.5·6 = 9. Значение 12 получилось бы при η = 1, а 6 — это модель до добавления дерева. Остальные деревья будут постепенно добирать оставшуюся ошибку.

## Классификация, log loss. Для объекта с y = 1 текущий счёт модели F(x) = 0 (то есть p = σ(0) = 0.5). Чему равен антиградиент y − p, на который обучается следующее дерево?
- [x] 0.5
- [ ] −0.5
- [ ] 1
- [ ] 0.25

**Почему.** Антиградиент log loss по счёту равен y − p = 1 − 0.5 = 0.5: положительный, значит, счёт нужно увеличить. Знак −0.5 соответствует объекту класса 0, значение 1 — это просто y, а 0.25 — произведение p(1 − p), оно к антиградиенту log loss отношения не имеет.

## При обучении бустинга на 5000 деревьев качество на валидации росло до примерно 300-го дерева, затем стало падать. Что разумно сделать?
- [ ] Увеличить число деревьев ещё вдвое, чтобы модель успела дообучиться на данных
- [x] Остановить обучение около 300-го дерева по метрике на валидации
- [ ] Выбрать число деревьев по максимальному качеству на тестовой выборке
- [ ] Увеличить learning rate до 1, чтобы быстрее выйти на плато качества

**Почему.** В отличие от случайного леса, бустинг переобучается при избытке деревьев: поздние деревья подгоняют шум. Число деревьев выбирают по валидации (ранняя остановка); если подбирать его по тесту, оценка на нём станет завышенной, а слишком большой learning rate даёт грубое обучение.

## Какие утверждения верны? (выберите все верные)
- [x] Если уменьшить learning rate в 2 раза, обычно нужно примерно вдвое больше деревьев
- [ ] Бустинг снижает в основном дисперсию, а случайный лес — смещение
- [x] Стохастический бустинг (subsample 0.7–0.9) действует как регуляризация
- [ ] Для деревьев в бустинге необходимо масштабировать признаки

**Почему.** Меньший шаг означает меньший вклад каждого дерева, и компенсировать это нужно числом деревьев; случайные подвыборки объектов добавляют регуляризацию. Роли смещения и дисперсии перепутаны: бустинг последовательно снижает смещение слабых деревьев, лес — дисперсию глубоких. Деревья от масштаба признаков не зависят.
