# Neural style transfer — мини-тест

## Почему матрица Грама признаков описывает стиль изображения, но не его содержание?
- [ ] Она считается по самым ранним слоям, где ещё нет информации об объектах и их смысле
- [ ] Она хранит только средние цвета пикселей и совсем не отражает текстуры
- [x] Она суммирует произведения каналов по всем позициям, и расположение теряется
- [ ] Её нормируют так, что значения всех каналов становятся одинаковыми по величине

**Почему.** G[i, j] = Σₖ F[i, k] · F[j, k] показывает, насколько часто каналы i и j активируются вместе, а суммирование по позициям k стирает информацию о том, где именно. Остаётся статистика текстур — стиль. Перестановка позиций матрицу Грама не меняет.

## Чему равен элемент G[0, 1] в этом коде?
```python
import numpy as np

M = np.array([[1, 2],
              [3, 0]])      # 2 канала × 2 позиции
G = M @ M.T
print(G[0, 1])
```
- [x] 3
- [ ] 5
- [ ] 6
- [ ] 10

**Почему.** G[0, 1] — скалярное произведение строк 0 и 1: 1·3 + 2·0 = 3. Значение 5 — это G[0, 0] = 1² + 2², 10 — это 1² + 3² (скалярный квадрат первого столбца при ошибочном M.T @ M), а 6 — просто сумма всех элементов M.

## Что оптимизируется в методе Gatys et al.?
- [ ] Веса VGG, чтобы сеть запомнила стиль картины
- [ ] Веса сети-трансформера, которая стилизует фото за один проход
- [ ] Только коэффициенты α и β градиентным спуском
- [x] Пиксели результирующего изображения при замороженной VGG

**Почему.** Метод Gatys не обучает сеть: VGG заморожена, а градиент потери L_total = α · L_content + β · L_style через обратное распространение считается по пикселям результата. Поэтому каждое изображение требует сотен итераций и занимает от десятков секунд до минут. Сеть-трансформер — это уже метод Johnson et al., а α и β задаются вручную.

## Нужна быстрая стилизация за один проход, причём стиль может быть любым и меняться без переобучения сети. Какой метод подходит?
- [ ] Метод Gatys: оптимизация пикселей результата для каждой пары фото и картины
- [x] AdaIN: подстановка среднего и стандартного отклонения признаков стиля
- [ ] Сеть Johnson et al., обученная на одном стиле с потерей по признакам VGG
- [ ] Предобученная VGG-19 без дополнительных компонентов, только извлечение признаков

**Почему.** AdaIN нормализует признаки содержания и подставляет статистики (μ и σ по каналам) признаков новой картины, поэтому любой стиль работает без переобучения. Сеть Johnson et al. быстрая, но одна сеть переносит один стиль, а метод Gatys медленный. Одна VGG-19 лишь извлекает признаки и изображение сама не создаёт.

## Что произойдёт, если для content loss взять очень ранний слой (например, `conv1_1`) вместо `conv4_2`?
- [x] Результат будет почти копией фотографии, и стилю останется мало места
- [ ] Результат потеряет объекты: сохранится только их смысл без формы и положения
- [ ] Style loss перестанет считаться, потому что слои для двух потерь пересекаются
- [ ] Градиент по пикселям станет нулевым, и оптимизация сразу остановится

**Почему.** Ранние слои привязаны к конкретным пикселям, поэтому совпадение признаков на них означает почти буквальное совпадение изображений. Средний слой `conv4_2` описывает «что и где», но разрешает менять мелкие детали — текстуры и мазки. Style loss при этом считается независимо по своим слоям.
