# Логистическая регрессия — мини-тест

## У признака вес w = −0.7. Как изменятся шансы (odds) класса 1 при росте этого признака на единицу и неизменных остальных?
- [ ] Вероятность класса 1 уменьшится ровно на 0.7, независимо от значений других признаков
- [ ] Шансы умножатся на 0.7, то есть уменьшатся примерно на 30 %
- [x] Шансы умножатся на e⁻⁰·⁷ ≈ 0.5, то есть уменьшатся примерно вдвое
- [ ] Шансы вырастут примерно вдвое, так как берётся модуль веса

**Почему.** Вес — изменение логарифма шансов, поэтому сами шансы умножаются на e^w. При w = −0.7 получаем e⁻⁰·⁷ ≈ 0.50. Изменение вероятности при этом нелинейно и зависит от исходного значения.

## Для двух объектов модель выдала вероятности класса 1: p = 0.8 для объекта с y = 1 и p = 0.3 для объекта с y = 0. Чему примерно равен log loss на этих двух объектах (натуральный логарифм)?
- [ ] 0.357
- [x] 0.29
- [ ] 0.55
- [ ] 0.58

**Почему.** Для первого объекта −ln 0.8 ≈ 0.223, для второго −ln(1 − 0.3) = −ln 0.7 ≈ 0.357. Среднее (0.223 + 0.357) / 2 ≈ 0.29. Для объекта класса 0 штрафуется вероятность класса 0, то есть 1 − p. Значение 0.357 — потеря только второго объекта, а 0.58 — сумма потерь вместо среднего.

## Модель предсказывает наличие заболевания, пропуск больного стоит намного дороже ложной тревоги. Что разумно сделать с порогом классификации?
- [ ] Оставить 0.5, потому что при нём достигается максимальная accuracy на любых данных
- [ ] Повысить порог до 0.9, чтобы реже ошибаться
- [ ] Использовать `predict`, так как он сам подбирает порог под цену ошибок
- [x] Выбрать на валидации порог ниже 0.5, работая с вероятностями из `predict_proba`

**Почему.** Порог 0.5 — значение по умолчанию, а не закон. Если пропуск дороже ложной тревоги, порог снижают (растёт recall), а подбирают его по вероятностям `predict_proba` на валидации. `predict` жёстко использует порог 0.5.

## `LogisticRegression` переобучается. Как нужно изменить параметр `C`?
- [ ] Увеличить `C`, потому что `C` — сила регуляризации
- [ ] Оставить `C` и вместо этого убрать масштабирование признаков
- [x] Уменьшить `C`, потому что `C` обратен силе регуляризации
- [ ] Изменить `C` нельзя, регуляризация в sklearn отключена по умолчанию

**Почему.** В sklearn `C` — величина, обратная силе регуляризации: меньше `C` — сильнее штраф на веса и проще модель. L2-регуляризация в `LogisticRegression` включена по умолчанию.

## Какие утверждения о логистической регрессии верны? (выберите все верные)
- [x] Величина z = w·x + b — это логарифм шансов класса 1
- [ ] При z = 0 сигмоида σ(z) равна 0
- [x] Граница между классами задаётся уравнением w·x + b = 0 и является гиперплоскостью
- [ ] Веса находятся по явной формуле, как в нормальном уравнении линейной регрессии

**Почему.** Модель предполагает линейную зависимость log-шансов от признаков, а при P = 0.5 (то есть z = 0) получается линейная граница. σ(0) = 0.5. Явной формулы для весов нет, обучение всегда итеративное (градиентный спуск, L-BFGS).
