# Diffusion модели — мини-тест

## Что предсказывает нейросеть ε_θ(x_t, t) в стандартном обучении DDPM и какая у неё функция потерь?
- [ ] Исходную чистую картинку x₀ по зашумлённой x_t; потеря — попиксельная кросс-энтропия между x₀ и ответом сети
- [x] Шум ε, добавленный к картинке; потеря — MSE между истинным и предсказанным шумом по всем пикселям
- [ ] Вероятность того, что картинка настоящая, а не сгенерированная; потеря — состязательная, как в GAN
- [ ] Следующий шаг расписания β_t; потеря — расстояние Вассерштейна между распределениями

**Почему.** Сеть получает x_t и номер шага t и предсказывает шум ε, а обучение сводится к обычной регрессии с MSE. Именно поэтому диффузия обучается стабильнее GAN: нет состязательной игры и неустойчивого баланса двух сетей.

## Для шага t известно ᾱ_t = 0.64. Исходное значение пикселя x₀ = 2, шум ε = −1. Чему равен x_t по формуле «одного прыжка»?
- [ ] 2.2
- [x] 1.0
- [ ] 1.6
- [ ] 0.92

**Почему.** x_t = √ᾱ_t·x₀ + √(1 − ᾱ_t)·ε = 0.8·2 + 0.6·(−1) = 1.6 − 0.6 = 1.0. Значение 0.92 получится, если забыть корни, а 2.2 — если не учесть знак шума.

## Почему при обучении DDPM не нужно по шагам моделировать всю цепочку из T зашумлений?
- [ ] Потому что сеть при обучении видит только последний шаг T, где картинка уже стала шумом, а промежуточные шаги ей не нужны
- [ ] Потому что обратный процесс при генерации тоже делается за один проход сети, поэтому цепочка не нужна нигде
- [ ] Потому что шум на каждом шаге подбирается обучаемой сетью, а не задаётся расписанием, поэтому его нельзя посчитать заранее
- [x] Потому что x_t выражается через x₀ и шум ε одной закрытой формулой, поэтому на каждом шаге обучения берут случайный t

**Почему.** Из-за гауссовости прямого процесса до любого шага t можно дойти одним прыжком: x_t = √ᾱ_t·x₀ + √(1 − ᾱ_t)·ε. Поэтому на каждом шаге обучения берут картинку и случайный t. А вот генерация идёт именно по цепочке из многих шагов, а расписание β_t задано заранее и не обучается.

## В classifier-free guidance шумы без условия и с условием равны ε(∅) = 0.2 и ε(c) = 0.6, вес w = 3. Какое итоговое предсказание ε̃ используется на этом шаге?
- [ ] 1.8
- [ ] 1.2
- [x] 1.4
- [ ] 0.33

**Почему.** ε̃ = ε(∅) + w·(ε(c) − ε(∅)) = 0.2 + 3·0.4 = 1.4. При w = 1 получилось бы просто условное предсказание 0.6; чем больше w, тем сильнее следование промпту, но тем меньше разнообразие и выше риск перенасыщенных картинок.

## Какие приёмы ускоряют генерацию картинки диффузионной моделью? (выберите все верные)
- [x] Сэмплер вроде DDIM или DPM-Solver, проходящий обратный путь за 20–50 шагов
- [ ] Включение classifier-free guidance, чтобы на каждом шаге делать два предсказания
- [ ] Увеличение числа шагов T в расписании шума до нескольких тысяч
- [x] Запуск диффузии в латентном пространстве автоэнкодера, а не на пикселях

**Почему.** Быстрые сэмплеры сокращают число шагов почти без потери качества, а латентная диффузия (как в Stable Diffusion) работает с намного меньшим тензором. Guidance, наоборот, удваивает число прогонов сети на шаге, а больший T только удлиняет цепочку.
