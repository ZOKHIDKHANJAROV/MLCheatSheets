# MLP (многослойный перцептрон) — мини-тест

## Почему сеть из трёх полносвязных слоёв без функций активации не сильнее одного линейного слоя?
- [ ] Потому что при обратном распространении градиент в таких слоях равен нулю и веса вообще не обновляются
- [ ] Потому что слои без активаций нельзя обучать градиентным спуском, для них нужен только метод наименьших квадратов
- [ ] Потому что у слоёв без активаций число параметров совпадает с числом входов, и дополнительные слои ничего не добавляют
- [x] Потому что композиция линейных преобразований линейна: W₂(W₁x + b₁) + b₂ = (W₂W₁)x + (W₂b₁ + b₂)

**Почему.** Сколько линейных слоёв ни ставь, итог — одна линейная функция. Выразительность сети дают нелинейные активации (ReLU и др.) между слоями. Обучать линейные слои можно, просто выигрыша они не дают.

## Сколько обучаемых параметров (веса и смещения) у сети 784 → 128 → 10 с полносвязными слоями?
- [ ] 101 632
- [ ] 1 003 520
- [x] 101 770
- [ ] 101 760

**Почему.** Первый слой: 784·128 + 128 = 100 480. Второй: 128·10 + 10 = 1 290. Сумма равна 101 770. Значение 101 632 получается без смещений, 101 760 — если не учесть смещения выходного слоя, а 1 003 520 — если перемножить все размеры 784·128·10.

## Для какой задачи подходит такая конфигурация?
```python
import torch.nn as nn

model = nn.Sequential(nn.Linear(20, 64), nn.ReLU(), nn.Linear(64, 5))
criterion = nn.CrossEntropyLoss()
```
- [x] Классификация на пять взаимоисключающих классов, выход модели — логиты
- [ ] Бинарная классификация на пять признаков
- [ ] Multi-label классификация, где объект может иметь несколько меток из пяти
- [ ] Регрессия с пятью целевыми переменными

**Почему.** Пять выходных нейронов и `CrossEntropyLoss` — многоклассовая классификация: softmax применяется внутри функции потерь, поэтому на выходе модели логиты. Для multi-label нужна `BCEWithLogitsLoss`, для регрессии — MSE и линейный выход.

## Что утверждает теорема об универсальной аппроксимации для MLP?
- [ ] Градиентный спуск гарантированно находит веса, дающие нужную точность аппроксимации любой функции, если сеть достаточно глубокая
- [ ] Одного скрытого слоя из небольшого числа нейронов достаточно для решения любой задачи классификации и регрессии на реальных данных
- [ ] Такая сеть хорошо обобщается на новые данные, если она достаточно широкая, и поэтому регуляризация и валидация не требуются
- [x] Один скрытый слой с нелинейной активацией и достаточным числом нейронов приближает непрерывную функцию на ограниченной области с любой точностью

**Почему.** Теорема говорит о выразительности, а не об обучаемости и обобщении: она не называет нужного числа нейронов, не гарантирует, что оптимизатор найдёт подходящие веса, и не защищает от переобучения. Поэтому на практике размер сети подбирают на валидации.

## Какие утверждения о практике обучения MLP верны? (выберите все верные)
- [x] Признаки нужно масштабировать, иначе градиентный спуск сходится плохо или не сходится вовсе
- [ ] Результат не зависит от инициализации весов, поэтому `random_state` не нужен
- [x] Против переобучения помогают L2-регуляризация, dropout и ранняя остановка по валидации
- [ ] На табличных данных MLP, как правило, заметно обгоняет градиентный бустинг

**Почему.** Инициализация весов случайна, поэтому результаты нужно воспроизводить фиксацией seed и усреднять по нескольким запускам. На табличных данных MLP обычно уступает бустингу, а сильнее становится при большом объёме данных или когда признаки нужно выучить (изображения, текст, эмбеддинги).
