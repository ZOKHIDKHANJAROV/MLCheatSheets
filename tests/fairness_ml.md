# Fairness в ML (справедливость) — мини-тест

## Команда удалила из данных пол клиента и считает, что модель кредитного скоринга теперь не может дискриминировать по полу. Почему это не гарантировано?
- [ ] Потому что без защищённого признака модель всегда переобучается
- [ ] Потому что метрики справедливости определены только для моделей, где признак A есть на входе
- [ ] Потому что дискриминацию создаёт сам алгоритм обучения, а не данные
- [x] Потому что другие признаки (прокси) связаны с полом, и модель восстанавливает его косвенно

**Почему.** Почтовый индекс, покупки, имя и другие признаки часто сильно коррелируют с защищённым A, и модель использует их как прокси. Поэтому проверять нужно метрики по группам, а для этого A должен быть доступен хотя бы при аудите.

## Модель одобрила 30 из 100 заявок группы 0 и 50 из 100 заявок группы 1. Чему равно отношение долей одобрения (disparate impact, группа 0 к группе 1) и что говорит правило 4/5?
- [x] 0.6; ниже 0.8, поэтому нужна проверка
- [ ] 1.67; выше 0.8, поэтому всё в порядке
- [ ] 0.2; это разность долей, а правило 4/5 к ней не применяется
- [ ] 0.3; ниже 0.8, но это норма для разных групп

**Почему.** Доли одобрения 0.3 и 0.5, отношение 0.3 / 0.5 = 0.6. Это ниже порога 0.8, поэтому повод для проверки есть. Значение 1.67 получится, если поделить в обратную сторону, а 0.2 — это разность долей.

## Район, где модель предсказывает высокий риск правонарушений, патрулируют чаще. Там находят больше нарушений, и эти данные идут в дообучение модели. К какому типу смещения это относится в первую очередь?
- [ ] Смещение агрегации: одна модель обучена для групп с разными закономерностями
- [ ] Смещение представительности: район мало представлен в выборке
- [x] Петля обратной связи: решения модели влияют на будущие данные
- [ ] Историческое смещение: данные содержат только прошлые решения людей

**Почему.** Решения модели (где патрулировать) формируют будущую обучающую выборку, и исходный перекос подтверждает сам себя. Это обратная связь, хотя она часто усиливает и историческое смещение.

## Когда базовые доли положительного исхода в двух группах различаются, а классификатор не идеален, что утверждают теоремы о невозможности?
- [ ] Равенство TPR и равенство FPR между группами не может выполняться даже по отдельности
- [x] Калибровку по группам и равенство ошибок (TPR и FPR) нельзя выполнить одновременно
- [ ] Демографический паритет всегда нарушается, если модель точнее случайной
- [ ] Справедливость нельзя измерять без защищённого признака на входе модели

**Почему.** Kleinberg и соавторы, а также Chouldechova показали, что при разных базовых долях и неидеальной модели предиктивный паритет (калибровка) и равенство TPR/FPR несовместимы. Поэтому выбор метрики — решение о ценностях. Каждое из требований по отдельности выполнить можно.

## Для выравнивания TPR между группами подобрали разные пороги классификации для групп (например, через `ThresholdOptimizer`). К какому этапу относится метод и в чём его типичный минус?
- [ ] Pre-processing; требует переразметки исторических данных
- [ ] In-processing; требует переобучения модели с ограничениями в функции потерь
- [ ] Pre-processing; выравнивает распределения признаков и теряет информацию о целевой переменной
- [x] Post-processing; нужно знать группу A при применении, что не везде разрешено законом

**Почему.** Методы, меняющие решения уже обученной модели (групповые пороги), — это post-processing. Они просты и не требуют переобучения, но им нужен A на этапе применения, а явное разное обращение с группами в ряде юрисдикций запрещено.
