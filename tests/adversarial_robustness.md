# Adversarial robustness — мини-тест

## По какой переменной берётся градиент в атаке FGSM: x_adv = x + ε · sign(∇ L)?
- [ ] По весам модели θ: возмущение — это один шаг обучения самой модели
- [ ] По метке y: ищется метка, при которой потеря получается максимальной
- [ ] По величине ε: подбирается оптимальный размер возмущения для картинки
- [x] По входу x: меняется картинка, веса остаются прежними

**Почему.** В FGSM мы не обучаем модель, а сдвигаем вход в сторону наибольшего роста потерь, поэтому нужен ∇ₓL. Знак градиента даёт максимальный рост линейного приближения потерь при ограничении L∞: каждый пиксель меняется не больше чем на ε.

## Линейная модель считает логит z = w·x с весами w = (2, −3, 1, −4). К каждому признаку добавляют ε = 0.1 в направлении sign(w) (как в FGSM). На сколько изменится логит?
- [x] На 1.0
- [ ] На 0.4
- [ ] На 0.1
- [ ] На 0.2

**Почему.** Изменение равно ε·Σ|wᵢ| = 0.1·(2 + 3 + 1 + 4) = 1.0. Значение 0.4 получается, если сложить веса без модулей (сумма равна −4), но сдвиги идут по знаку каждого веса, поэтому вклады складываются. Именно так малые изменения тысяч пикселей дают большой сдвиг выхода.

## После «защиты» атака PGD перестала ломать модель, но случайный шум с той же максимальной амплитудой ε по каждому пикселю всё ещё сильно портит её предсказания. Какой вывод наиболее вероятен?
- [ ] Защита сработала: достаточно дополнительно проверить FGSM
- [ ] PGD не работает против защищённых моделей из-за проекции в ε-шар
- [ ] Модель стала устойчивой, а чувствительность к шуму — отдельное свойство
- [x] Градиенты, скорее всего, замаскированы, и устойчивость мнимая

**Почему.** Случайный шум в ε-шаре — лишь одно из допустимых возмущений, поэтому сильная атака в нём должна быть не слабее шума. Если PGD «слепнет», а случайный шум ломает модель, градиент стал бесполезным (gradient masking), а модель не устойчива. Защиту нужно проверять адаптивной атакой; FGSM — ещё более слабая проверка, чем PGD.

## Нужна защита, дающая доказуемую гарантию, что предсказание не изменится в заданном радиусе вокруг входа. Что выбрать?
- [ ] Adversarial training на PGD-примерах с большим запасом по ε и долгим обучением
- [x] Randomized smoothing: усреднение ответов по зашумлённым копиям входа
- [ ] Сжатие JPEG и сглаживающие фильтры на входе модели, убирающие высокочастотный шум
- [ ] Отдельный детектор adversarial-примеров, обученный на примерах атак FGSM и PGD

**Почему.** Randomized smoothing даёт сертифицированный радиус, пусть и небольшой. Adversarial training — самая надёжная эмпирическая защита, но формальных гарантий не даёт; предобработку входа и детекторы обычно обходят адаптивными атаками.

## Какие утверждения верны? (выберите все верные)
- [x] PGD делает несколько шагов размера α и после каждого проецирует результат в ε-окрестность исходного входа
- [ ] Adversarial training повышает устойчивость и при этом не снижает точность на чистых данных
- [x] Adversarial training — это минимакс-задача: внутри ищется сильнейшее возмущение, снаружи минимизируется потеря на нём
- [ ] Устойчивость к FGSM гарантирует устойчивость к PGD

**Почему.** Это определения PGD и adversarial training по Мадри. Но устойчивость достигается ценой точности на чистых данных и многократно большего времени обучения, а PGD как многошаговая атака сильнее FGSM — защита от одной может не выдержать другой.
