# Функции активации — мини-тест

## Что произойдёт, если во всех слоях двухслойной полносвязной сети убрать функции активации?
- [ ] Сеть станет глубже и сможет строить более изогнутые границы
- [ ] Сеть перестанет обучаться, так как градиенты не определены
- [ ] Сеть будет обучаться, но только на задачах классификации
- [x] Сеть станет эквивалентна одной линейной модели

**Почему.** Без нелинейности два слоя дают y = W₂(W₁x + b₁) + b₂ = (W₂W₁)x + const, то есть снова линейное преобразование. Градиенты при этом считаются без проблем, а выразительность не растёт сколько бы слоёв ни было.

## Производная сигмоиды не превышает 0.25. Какую долю исходного градиента в лучшем случае пропускают через себя три последовательных сигмоидных слоя (учитываем только производные активаций)?
- [ ] 3/4 ≈ 0.75
- [ ] 1/8 ≈ 0.125
- [x] 1/64 ≈ 0.016
- [ ] 1/12 ≈ 0.083

**Почему.** Градиент умножается на производную активации на каждом слое: 0.25³ = 1/64 ≈ 0.0156. Для 20 слоёв получится порядка 10⁻¹², поэтому первые слои глубокой сети с сигмоидами почти не учатся. Складывать производные (3·0.25 = 0.75) или делить на число слоёв нельзя — они перемножаются.

## В чём ошибка в этом коде для классификации на 5 классов?
```python
model = nn.Sequential(
    nn.Linear(20, 64),
    nn.ReLU(),
    nn.Linear(64, 5),
    nn.Softmax(dim=-1),
)
loss_fn = nn.CrossEntropyLoss()
```
- [ ] ReLU в скрытом слое неизбежно даёт «мёртвые» нейроны, поэтому для классификации нужна другая активация
- [ ] Для пяти классов на выходе нужна сигмоида, поскольку softmax применим только к двум классам
- [x] `CrossEntropyLoss` уже включает softmax, получается двойной softmax
- [ ] Параметр `dim=-1` у softmax выбирает ось батча, а для оси классов нужно задать `dim=0`

**Почему.** `nn.CrossEntropyLoss` ожидает на входе сырые логиты и сама делает log-softmax. Лишний softmax в модели ухудшает и замедляет обучение. ReLU в скрытом слое — нормальный выбор, а `dim=-1` как раз выбирает ось классов.

## Какую активацию поставить на выходе сети, которая для статьи предсказывает набор тегов, причём у одной статьи может быть сразу несколько тегов?
- [ ] Softmax по всем тегам с выбором самого вероятного тега
- [ ] Линейный выход без активации, а тег выбирать по наибольшему значению
- [x] Независимую сигмоиду на каждый тег
- [ ] ReLU на каждый выходной нейрон, чтобы вероятности были неотрицательными

**Почему.** При multi-label каждая метка — независимая бинарная задача, поэтому нужна сигмоида на каждый выход. Softmax заставляет вероятности суммироваться в 1, то есть выбирает практически одну метку; ReLU не ограничивает выход вероятностным диапазоном.

## Какие утверждения верны? (выберите все верные)
- [x] Если вход нейрона ReLU всегда отрицателен, его выход и градиент равны нулю, и нейрон перестаёт обучаться
- [ ] Производная tanh не превышает 0.25
- [ ] GELU задаётся формулой x·σ(x)
- [x] Leaky ReLU сохраняет ненулевой градиент при x < 0, поэтому помогает против «мёртвых» нейронов

**Почему.** Это суть «dying ReLU» и причина появления Leaky ReLU. Производная tanh в нуле равна 1 (оценка 0.25 относится к сигмоиде), а x·σ(x) — это SiLU/Swish; GELU определяется как x·Φ(x) с функцией распределения нормального закона Φ.
