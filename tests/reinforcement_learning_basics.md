# Основы обучения с подкреплением (RL) — мини-тест

## Чем обучение с подкреплением принципиально отличается от обучения с учителем?
- [ ] В RL нет функции потерь и градиентного спуска, поэтому нейросети и градиентные методы в нём не применяются
- [ ] В RL данные независимы и одинаково распределены, они берутся из заранее собранной фиксированной выборки
- [ ] В RL правильные ответы заданы заранее для каждого шага, но их заметно меньше, чем в обычной размеченной выборке
- [x] В RL нет эталонного действия на каждом шаге: есть лишь отложенная награда, а данные зависят от действий агента

**Почему.** Агент пробует действия и получает награды, часто с задержкой, поэтому возникает проблема распределения заслуг во времени. Кроме того, он видит лишь последствия выбранных им действий. Градиентные методы в RL применяются (policy gradient, DQN).

## Агент получил награды 1, 2 и 3 на трёх последовательных шагах. Чему равен дисконтированный возврат G = r₁ + γ·r₂ + γ²·r₃ при γ = 0.5?
- [x] 2.75
- [ ] 3.500
- [ ] 6.000
- [ ] 1.250

**Почему.** G = 1 + 0.5·2 + 0.25·3 = 1 + 1 + 0.75 = 2.75. Значение 3.5 получится, если дисконтировать все награды лишь на γ, а не на γ², γ³… Шесть — недисконтированная сумма, а один — учёт только первой награды (γ = 0).

## Как изменится поведение агента, если уменьшить γ с 0.99 до 0.5?
- [ ] Станет дальновиднее: будет учитывать награды на сотни шагов вперёд
- [ ] Станет чаще выбирать случайные действия, так как γ — вероятность исследования
- [x] Станет близоруким: главную роль будут играть ближайшие награды
- [ ] Не изменится: γ влияет только на скорость обучения

**Почему.** Горизонт, который учитывает агент, примерно равен 1/(1 − γ): около 100 шагов при γ = 0.99 и всего около 2 шагов при γ = 0.5. Вероятность случайного действия задаёт ε, а скорость обучения — α.

## Почему, зная Q(s, a), можно выбрать действие без модели среды, а зная только V(s) — нельзя?
- [ ] Значения V(s) хранятся только для терминальных состояний, поэтому в остальных выбрать нечего
- [x] Q оценивает каждое действие напрямую, а по V нужно знать, в какое состояние оно приведёт
- [ ] V(s) не зависит от политики π и от действий, поэтому не подходит для выбора действий
- [ ] Q всегда больше V, поэтому значения Q проще и надёжнее сравнивать между собой

**Почему.** Для политики достаточно взять argmax по a от Q(s, a). Чтобы сделать то же по V, нужно знать вероятности переходов P(s' | s, a), то есть модель среды. V(s), наоборот, определяется для политики π и существует для всех состояний.

## Что верно про исследование и использование (exploration и exploitation)? (выберите все верные)
- [x] При ε-жадной стратегии с вероятностью ε выбирается случайное действие, иначе — лучшее из известных
- [ ] ε обычно начинают с малого значения и увеличивают, чтобы к концу обучения агент больше исследовал
- [x] Агент без исследования может застрять на первом найденном приемлемом варианте
- [ ] При ε = 1 агент всегда выбирает действие с максимальным Q

**Почему.** Только использование не даёт узнать о лучших вариантах, поэтому нужно исследование. Обычно ε начинают с 1 и постепенно уменьшают до 0.01–0.1. При ε = 1 действие выбирается случайно всегда, а не по максимуму Q.
