# Экспоненциальное сглаживание — мини-тест

## Простое экспоненциальное сглаживание с α = 0.3. Какие веса получают три последних наблюдения (от самого свежего к более старым)?
- [ ] 0.30; 0.15; 0.075
- [x] 0.3; 0.21; 0.147
- [ ] 0.3; 0.09; 0.027
- [ ] 0.3; 0.3; 0.3

**Почему.** Вес k-го с конца наблюдения равен α·(1 − α)ᵏ⁻¹: 0.3, затем 0.3·0.7 = 0.21, затем 0.3·0.49 = 0.147. Веса убывают экспоненциально, но не в 2 раза и не как степени α; одинаковые веса соответствовали бы обычному среднему.

## Ряд y = 10, 14, 20, начальный уровень ℓ = 10 (первое наблюдение), α = 0.5. Чему равен прогноз SES на два шага вперёд?
- [ ] 20
- [ ] 18
- [ ] 14.7
- [x] 16

**Почему.** Обновляем уровень: после 14 получаем 0.5·14 + 0.5·10 = 12, после 20 получаем 0.5·20 + 0.5·12 = 16. Прогноз SES не зависит от горизонта: ŷ(t+h) = ℓ(t) = 16. Значение 20 — наивный прогноз, а 14.7 — среднее за всё время.

## В методе Хольта после последнего наблюдения получены уровень ℓ = 100 и тренд b = 5. Чему равен прогноз на 3 шага вперёд?
- [x] 115
- [ ] 105
- [ ] 120
- [ ] 107.5

**Почему.** Прогноз Хольта — наклонная прямая: ŷ(t+h) = ℓ(t) + h·b(t) = 100 + 3·5 = 115. Значение 105 — это прогноз только на один шаг, а 107.5 получится, если усреднить тренд по горизонту, и оба не годятся: у Хольта прогноз растёт линейно.

## Месячные продажи имеют сезонность, причём размах сезонных пиков растёт вместе с общим уровнем продаж; нулевых значений нет. Какую сезонность лучше выбрать в Хольте–Уинтерсе?
- [ ] Аддитивную, потому что размах колебаний при росте уровня должен оставаться постоянным
- [ ] Не включать сезонность: растущий размах колебаний — это обычный шум
- [x] Мультипликативную, или аддитивную после логарифмирования самого ряда продаж
- [ ] Метод Хольта без сезонной компоненты, так как тренд уже объяснит пики

**Почему.** Когда «волны» растут вместе с рядом, сезонный эффект пропорционален уровню (в декабре на 20% больше), то есть сезонность мультипликативная. Аддитивная модель недооценивала бы пики, а метод Хольта вообще не умеет описывать повторяющиеся сезонные колебания.

## Какие утверждения верны? (выберите все верные)
- [x] Прогноз простого сглаживания — горизонтальная линия, так как модель хранит только уровень
- [ ] При α, близком к 0, прогноз быстро реагирует на каждое новое наблюдение
- [x] Затухающий тренд (φ < 1) делает длинный прогноз осторожнее: он выходит на плато
- [ ] Мультипликативная сезонность хорошо работает на рядах с большим числом нулей

**Почему.** SES не знает о тренде и сезонности, а затухание φ < 1 не даёт линейному тренду бесконечно продолжаться. При α около 0 прогноз почти константа и медленно замечает изменения — быстро реагирует α около 1. Мультипликативная сезонность не работает с нулевыми и отрицательными значениями.
