# Vision Transformers (ViT) — мини-тест

## Изображение 384×384 пикселей подаётся в ViT с патчами 16×16. Сколько токенов получит энкодер Transformer с учётом токена `[CLS]`?
- [ ] 197
- [ ] 576
- [ ] 1537
- [x] 577

**Почему.** Патчей (384 / 16)² = 24² = 576, плюс один токен `[CLS]` — всего 577. Для 224×224 было бы 14² + 1 = 197, а число токенов растёт квадратично с размером картинки.

## Почему исходному ViT нужно больше обучающих данных, чем свёрточной сети?
- [ ] Потому что у ViT больше слоёв, чем у любой CNN, и они хуже масштабируются на большие наборы данных
- [x] Потому что нет встроенных локальности и инвариантности к сдвигу, и их приходится выучивать из данных
- [ ] Потому что ViT не умеет использовать предобучение и всегда учится только с нуля на одной задаче
- [ ] Потому что патчи 16×16 теряют цветовую информацию и мелкие детали в каждом из каналов

**Почему.** CNN изначально предполагает локальность и одинаковую обработку разных мест картинки. В ViT каждый патч с первого слоя может смотреть на любой другой, поэтому на небольших наборах вроде ImageNet-1k исходный ViT уступал ResNet, а на сотнях миллионов изображений обгонял.

## Какую проблему решает локальное внимание в окнах (со сдвигом между слоями) в Swin Transformer?
- [ ] Отсутствие позиционной информации в патчах на входе энкодера
- [ ] Невозможность использовать токен `[CLS]` для классификации
- [ ] Необходимость размечать данные для предобучения на больших наборах
- [x] Квадратичную стоимость внимания при высоком разрешении

**Почему.** Внимание считается внутри небольших окон, и стоимость растёт линейно с размером изображения; сдвиг окон от слоя к слою позволяет информации перетекать между ними. Постепенное объединение патчей даёт иерархию масштабов, удобную для детекции и сегментации.

## Что делает метод самообучения MAE (Masked Autoencoders)?
- [x] Закрывает значительную долю патчей (около 75%) и учит модель их восстанавливать
- [ ] Заставляет модель копировать предсказания сильной CNN-учителя через специальный токен
- [ ] Обучает модель различать картинки и их текстовые описания
- [ ] Согласует представления разных аугментаций одного изображения

**Почему.** MAE — аналог маскированного языкового моделирования из BERT для картинок и не требует разметки. Дистилляция через специальный токен относится к DeiT, согласование аугментаций — к DINO, а связь картинок с текстом — к CLIP.

## Как в ViT получают предсказание класса?
- [ ] Берут эмбеддинг первого патча в левом верхнем углу и подают в линейный слой
- [ ] Усредняют позиционные эмбеддинги всех патчей и подают в линейный слой
- [x] Выход токена `[CLS]` идёт в линейный слой
- [ ] Подают в классификатор метку класса вместе с картинкой на вход энкодера

**Почему.** Как и в BERT, в начало последовательности добавляют обучаемый вектор `[CLS]`; после всех слоёв энкодера он аккумулирует информацию о картинке, и его выход идёт в линейную голову. Позиционные эмбеддинги нужны, чтобы модель знала расположение патчей, а не для классификации.
