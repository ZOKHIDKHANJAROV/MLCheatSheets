# NumPy для ML — мини-тест

## Матрица `X` имеет форму `(500, 8)`: 500 объектов и 8 признаков. Какую форму имеет `X.std(axis=0)` и что означает каждое число?
- [ ] `(500,)` — стандартное отклонение каждого объекта по признакам
- [x] `(8,)` — стандартное отклонение каждого признака по объектам
- [ ] `(500, 8)` — отклонение каждого элемента от среднего по своему столбцу
- [ ] `()` — одно число: стандартное отклонение всей матрицы целиком

**Почему.** Ось, указанная в `axis`, схлопывается: при `axis=0` значения «идут вниз по строкам», и на каждый столбец-признак получается одно число. Статистика по объектам получилась бы при `axis=1`, а одно число — при вызове без `axis`.

## Какую форму получит `err` в этом коде?
```python
import numpy as np

y = np.zeros((5, 1))
y_pred = np.ones(5)
err = y_pred - y
print(err.shape)
```
- [ ] `(5,)`
- [ ] `(5, 1)`
- [ ] Будет ошибка из-за разных форм
- [x] `(5, 5)`

**Почему.** Формы сравниваются справа налево: `(5,)` дополняется до `(1, 5)`, и вместе с `(5, 1)` получается матрица `(5, 5)` всех попарных разностей. Исключения нет — просто тихо неверные числа, поэтому вектор `(n,)` и столбец `(n, 1)` нужно различать (`ravel()` или `reshape(-1, 1)`).

## Что выведет этот код?
```python
import numpy as np

a = np.array([1, 2, 3, 4, 5])
b = a[1:3]
c = a[[3, 4]]
b[0] = 100
c[0] = -1
print(a)
```
- [ ] [1, 2, 3, 4, 5]
- [ ] [1, 2, 3, -1, 5]
- [x] [1, 100, 3, 4, 5]
- [ ] [1, 100, 3, -1, 5]

**Почему.** Срез `a[1:3]` — это «окно» на те же данные, поэтому запись в `b` меняет `a`. Индексация списком `a[[3, 4]]` (как и булева маска) создаёт копию, поэтому запись в `c` на `a` не влияет.

## Чему равен элемент `[0, 1]` результата `A @ B`?
```python
import numpy as np

A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
```
- [x] 22
- [ ] 12
- [ ] 19
- [ ] 26 (сумма элементов B)

**Почему.** Оператор `@` — матричное умножение: элемент `[0, 1]` равен скалярному произведению строки 0 матрицы A и столбца 1 матрицы B: 1·6 + 2·8 = 22. Значение 12 — это `[0, 1]` у поэлементного `A * B`, 19 — элемент `[0, 0]` матричного произведения, а 26 — просто сумма элементов B.

## Что выведет этот код?
```python
import numpy as np

x = np.array([1, 2, 3])
x[0] = 0.7
print(x)
```
- [ ] [0.7 2.0 3.0]
- [ ] [1 2 3]
- [ ] Ошибка: нельзя записать дробное число в целочисленный массив
- [x] [0 2 3]

**Почему.** Массив `np.array([1, 2, 3])` имеет целочисленный `dtype` (`int64`), поэтому запись дробного числа молча отбрасывает дробную часть: 0.7 превращается в 0. Для данных заранее используют вещественный тип, например `float`.
