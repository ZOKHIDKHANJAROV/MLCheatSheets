# Искусственный нейрон (перцептрон) — мини-тест

## Перцептрон с весами w = (0.5; −1), смещением b = 0 и скоростью η = 0.1 видит объект x = (1; 1) с истинным классом y = 1. Какими станут веса после одного шага правила обучения w ← w + η·(y − ŷ)·x?
- [ ] w = (0.5; −1) — веса не изменятся
- [ ] w = (0.4; −1.1)
- [x] w = (0.6; −0.9)
- [ ] w = (0.6; −1)

**Почему.** z = 0.5·1 − 1·1 + 0 = −0.5 ≤ 0, поэтому ŷ = 0 и y − ŷ = 1. Веса сдвигаются в сторону x: (0.5 + 0.1; −1 + 0.1) = (0.6; −0.9), а b становится 0.1. Вариант (0.4; −1.1) соответствовал бы сдвигу от x, то есть ошибке противоположного знака.

## Почему один нейрон со ступенчатой активацией не может выучить XOR?
- [ ] Ступенчатая функция не принимает на вход значения 0 и 1 одновременно из-за разрыва в нуле
- [ ] Для XOR слишком мало обучающих объектов — всего четыре точки, для сходимости нужны сотни
- [ ] Правило обучения не умеет менять веса на объектах класса 0, оно обновляется только по классу 1
- [x] Классы XOR нельзя разделить одной прямой: единицы и нули лежат на разных диагоналях

**Почему.** Нейрон с `w·x + b = 0` проводит одну гиперплоскость, а у XOR класс 1 у (0,1) и (1,0), класс 0 — у (0,0) и (1,1). Такие точки одной прямой не разделить, сколько ни учи. Выход — несколько слоёв нейронов (многослойный перцептрон).

## Что изменится, если у нейрона убрать смещение b?
- [ ] Нейрон перестанет быть линейным классификатором и станет квадратичным
- [x] Прямая w·x = 0 обязана проходить через начало координат
- [ ] Разделяющая прямая станет кривой второго порядка
- [ ] Нейрон сможет разделять и линейно неразделимые классы, например XOR

**Почему.** Смещение сдвигает границу `w·x + b = 0` относительно начала координат. Без него остаётся прямая (гиперплоскость) через ноль, то есть нейрон остаётся линейным, но становится заметно слабее.

## Что гарантирует теорема сходимости перцептрона?
- [ ] Алгоритм всегда останавливается, а на шумных данных находит прямую с минимумом ошибок
- [ ] Если данные линейно разделимы, алгоритм сходится за число шагов, не зависящее от данных
- [x] Для линейно разделимых классов алгоритм за конечное число шагов найдёт прямую
- [ ] Сходимость гарантирована для любых данных, если выбрать достаточно малую скорость η

**Почему.** Гарантия касается только линейно разделимых классов, и число шагов конечно, но зависит от данных. Если разделить классы прямой нельзя, веса продолжают «качаться», и правило само не остановится.

## Какие утверждения верны? (выберите все верные)
- [x] Нейрон с сигмоидой и функцией потерь log-loss — это логистическая регрессия
- [ ] Классический перцептрон со ступенькой возвращает вероятность принадлежности к классу
- [x] Ступенчатая активация недифференцируема, поэтому в многослойных сетях её заменили гладкими
- [ ] На неразделимых данных классическое правило сходится к лучшей по числу ошибок прямой

**Почему.** Сигмоида с log-loss — это именно логистическая регрессия, а через ступеньку нельзя пропустить градиент. Ступенчатый перцептрон отвечает лишь 0 или 1 без оценки уверенности, а на неразделимых данных результат зависит от того, на какой эпохе остановились.
