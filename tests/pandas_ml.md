# Pandas для ML — мини-тест

## Что выведет этот код?
```python
import pandas as pd

df = pd.DataFrame({"x": range(10, 20)})   # индекс 0..9
print(len(df.loc[:5]), len(df.iloc[:5]))
```
- [ ] 5 5
- [x] 6 5
- [ ] 5 6
- [ ] Ошибка KeyError: срез по меткам нельзя применять к числовому индексу

**Почему.** `loc` выбирает по меткам, и срез по меткам включает правый конец, поэтому `df.loc[:5]` вернёт строки с метками 0…5, то есть 6 строк. `iloc` выбирает по позициям, как обычный срез Python, и `df.iloc[:5]` вернёт 5 строк.

## Сколько строк будет в результате этого `merge`?
```python
import pandas as pd

left = pd.DataFrame({"user_id": [1, 2, 3]})
right = pd.DataFrame({"user_id": [1, 1, 2], "x": [10, 20, 30]})
res = pd.merge(left, right, on="user_id", how="left")
print(len(res))
```
- [ ] 3
- [ ] 2 + 1 + 2 = 5
- [x] 4
- [ ] 6

**Почему.** Ключ 1 встречается в правой таблице дважды, поэтому строка с `user_id` = 1 размножается: 2 строки для ключа 1, по одной для ключей 2 и 3 (для ключа 3 значения `x` будут `NaN`), итого 4. После `merge` стоит сверять `shape`, а параметр `validate="many_to_one"` поймает такую ситуацию сразу.

## Пропуски в `age` заполняют медианой. Как сделать это без утечки данных?
- [x] Посчитать медиану по train и этой же медианой заполнить train и test
- [ ] Посчитать медиану по всему датасету до разбиения: так оценка точнее
- [ ] Для test посчитать собственную медиану по тестовой части, для train — по обучающей
- [ ] В test заполнить пропуски нулями, а в train — медианой по обучающей части

**Почему.** Статистики для заполнения — параметры предобработки, их оценивают на обучающих данных и затем применяют ко всем выборкам. Медиана по всему датасету «подсматривает» тест, а своя медиана для test недоступна в продакшене, где объекты приходят по одному. Удобнее всего делать это внутри `Pipeline`.

## Чем `df.groupby("city")["salary"].transform("mean")` отличается от `df.groupby("city")["salary"].mean()`?
- [ ] `transform` считает медиану по городу, а `mean` — среднее по всей таблице
- [ ] `transform` возвращает одну строку на город, а `mean` — по одной строке на каждый объект
- [ ] `transform` работает только со строковыми столбцами, а `mean` — только с числовыми
- [x] `transform` даёт среднее города для каждой строки, а `mean` — одно значение на город

**Почему.** `groupby(...).mean()` схлопывает группы — получается одна строка на город. `transform` возвращает результат того же размера, что исходная таблица, поэтому его можно сразу записать как новый признак, например «средняя зарплата по городу».

## Что может пойти не так, если применить `pd.get_dummies` к train и test по отдельности?
- [ ] `get_dummies` удалит из test все категориальные столбцы, не найденные в train
- [x] Наборы столбцов могут не совпасть, если категории в train и test разные
- [ ] Столбцы получатся одинаковыми, но с разным масштабом значений в train и test
- [ ] Пропуски в test будут автоматически заполнены медианой по обучающей части

**Почему.** `get_dummies` создаёт столбцы только для категорий, которые видит в переданных ему данных, поэтому в train и test их может оказаться разное число. В продакшене используют `OneHotEncoder` из scikit-learn, который запоминает категории при `fit`.
