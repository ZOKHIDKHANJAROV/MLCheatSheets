# Случайный лес — мини-тест

## Зачем при каждом разбиении узла лес ищет лучший порог лишь среди случайного подмножества признаков?
- [ ] Чтобы ускорить обучение каждого дерева: на качество леса в целом это не влияет
- [x] Чтобы деревья не выбирали в корне один и тот же сильный признак и стали менее похожими
- [ ] Чтобы отсеять шумовые признаки и оставить в каждом дереве только действительно полезные
- [ ] Чтобы уменьшить смещение каждого отдельного дерева за счёт более точных порогов

**Почему.** Без случайных подмножеств признаков все деревья начинали бы с одного и того же самого сильного признака и были бы сильно коррелированы, а усреднение коррелированных деревьев почти не снижает ошибку. Ускорение — побочный эффект, а не цель; отбор признаков этот приём не выполняет.

## Что именно уменьшает усреднение деревьев в случайном лесу по сравнению с одним глубоким деревом?
- [ ] Смещение, потому что каждое дерево в лесу строится глубже
- [ ] И смещение, и дисперсию примерно в равной степени
- [x] Дисперсию: слабо коррелированные ошибки деревьев взаимно гасятся
- [ ] Число используемых признаков: лес автоматически отбрасывает лишние

**Почему.** Глубокие деревья имеют низкое смещение и высокую дисперсию. Усреднение снижает дисперсию, почти не увеличивая смещение, и тем сильнее, чем слабее деревья коррелированы.

## Обучающая выборка содержит 1000 объектов. Для дерева строится бутстрэп-выборка из 1000 объектов (выбор с возвращением). Сколько объектов в среднем не попадёт в неё и станет out-of-bag?
- [x] Примерно 368
- [ ] Примерно 632
- [ ] Ровно 500 объектов
- [ ] Примерно 100

**Почему.** Вероятность того, что объект не выбран ни разу, равна (1 − 1/n)ⁿ ≈ 1/e ≈ 0.368, то есть около 368 из 1000. Число 632 — это, наоборот, доля объектов, попавших в выборку (1 − 1/e).

## Лес из глубоких деревьев на шумных данных заметно хуже работает на валидации, чем на обучении. Что стоит попробовать?
- [ ] Уменьшить `n_estimators`, потому что с ростом числа деревьев переобучение усиливается
- [ ] Включить `oob_score=True`, чтобы модель меньше подгонялась под шум
- [ ] Применить `StandardScaler`, чтобы выровнять масштабы признаков
- [x] Увеличить `min_samples_leaf` или ограничить `max_depth`

**Почему.** Переобучение леса возникает из-за слишком глубоких деревьев на шуме, и его снижают `min_samples_leaf` и `max_depth`. Число деревьев переобучения не вызывает: оно лишь делает усреднение точнее. `oob_score` только оценивает качество, а деревья к масштабу признаков нечувствительны.

## Какие утверждения о случайном лесе верны? (выберите все верные)
- [ ] Масштабирование признаков необходимо, как для k-NN
- [x] `feature_importances_` по уменьшению impurity завышает важность признаков с большим числом уникальных значений
- [x] В регрессии лес не предсказывает значения за пределами диапазона обучающих ответов
- [ ] Вероятности классов, которые выдаёт лес, обычно очень близки к 0 и 1

**Почему.** Важность по impurity смещена в пользу непрерывных и высококардинальных признаков, поэтому полезна permutation importance. Лес усредняет значения в листьях, поэтому не экстраполирует тренд. Деревья не требуют масштабирования, а вероятности леса, наоборот, обычно «сжаты» к середине.
